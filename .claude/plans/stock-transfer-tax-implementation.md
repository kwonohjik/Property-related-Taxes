## 1. 도메인 개요 — 부동산 양도세와 무엇이 다른가

| 항목 | 부동산 양도세 (현재 구현) | 주식 양도소득세 (신규) |
|---|---|---|
| 과세대상 결정 | 부동산 전부 과세 | **대주주만** 과세 (상장/코스닥/코넥스) + 비상장은 원칙 전부 |
| 평가방식 | 실거래가 + 환산취득가 (PHD/Vworld) | 실거래가 + **기준시가 환산** (1개월 종가평균 / 비상장 보충적 평가) |
| 세율 구조 | §55 누진세율 8단계 + 중과 | 단일세율(10·20·30%) **또는** 누진(3억 경계 20%/25%) |
| LTHD(장기보유공제) | 보유·거주 분리, 80% 한도 | **없음** (주식은 LTHD 미적용) |
| 기본공제 | 250만원 (그룹·연간 1회) | 250만원 (주식 그룹 별도 — §103) |
| 거주요건/1주택 비과세 | 핵심 | 없음 |
| 신고 단위 | 양도 건별 | **반기별 예정신고 + 연간 확정신고** (§105·§110) |
| 지방소득세 | 양도세 × 10% | 동일 |

**핵심 메시지**: 주식 양도세는 부동산 양도세 엔진을 **확장**하기보다 별도 도메인(`lib/tax-engine/stock-transfer/`)으로 **분리**하는 것이 안전합니다. 부동산 양도세 4-파일 분할 패턴(`transfer-tax.ts` + helpers + rate-calc + finalize)을 차용하되, 평가·LTHD·중과·**§114의2 환산취득가 가산세** 모듈은 공유하지 않습니다.

**과세 범위 제한 (본 엔진 1차 스코프)**:
- ✅ **거주자**의 국내 상장·코스닥·코넥스·비상장 주식·기타자산 양도

- ❌ 국외전출세 (§118의9~118의15 — 거주자 국외이주 의제양도, 별도 도메인)

## 4. 양도가액·취득가액 산정

### 4.1 양도가액

| 케이스 | 산식 |
|---|---|
| 실거래가 (원칙) | 양도 주식 수 × 주당 양도가액 |
| 부동산·채무면제·현금 교환 (사례 49) | ① 부동산 인도시 정상가액 + ② 채무감소액 + ③ 현금 합계 |

### 4.2 취득가액

**선후 적용 순서**:

1. **실거래가** (원칙, §97①1·소령§162⑤ 선입선출법)
2. **매매사례가액** (비상장만 가능, 상장·코스닥은 불가)
3. **감정가액** (실무 적용 사례 거의 없음)
4. **환산취득가** (기준시가 비율 환산)

### 4.3 환산취득가 — 기준시가 산정 (핵심 분기)

#### (A) 상장·코스닥 주식 (양도 후 거래정지·관리종목 아닌 경우)

```
기준시가 = 평가기준일 이전 1개월간 한국거래소 매일 최종시세가액 평균
       (거래실적 유무 무관, 일요일·공휴일 제외)
```

`사례 48` 화면: 양도일 2023-02-26(일) → 평가기준일 2023-02-24 → 1개월 이전 23영업일 종가평균 **8,659원**.

#### (B) 비상장주식 (소득세법 §99①3·시행령 §165⑤) — 보충적 평가

```
1주당 기준시가 평가가액 = (1주당 순손익가액 ÷ 10%) × 3/5
                       + 1주당 순자산가액 × 2/5
```

> 📎 **"÷ 10%" 위임 관계**: 이 10%는 시행령 §165④2가 위임한 "기획재정부령으로 정하는 율"로, **시행규칙 §82**에서 10%로 규정. 향후 율 변경 가능성 대비해 `legal-codes/stock.ts`에 시행령→시행규칙 위임 관계 주석으로 명시 + `STOCK_LOSS_GAIN_DISCOUNT_RATE = 0.10` 상수화.

**부동산과다보유법인** (부동산 등 ≥ **자산총액 50%** — §165⑤ 가중치 반전용 기준): 가중치 반전
```
1주당 기준시가 = (순손익가치) × 2/5 + 순자산가액 × 3/5
```

> ⚠️ **개념 분리**: §94①4 나목의 "기타자산 부동산과다보유법인"은 **80% + 골프장·스키장**, §165⑤ 가중치 반전용 "부동산과다보유"는 **50%**. 같은 단어지만 임계가 다른 **별개 개념** — 엔진 변수명 분리(`isHeavyRealEstateForRate` vs `isHeavyRealEstateForValuation`).

**★ 순자산가액 80% 하한 — 시행령 §165④1 본칙 단서 직접 적용** (검토자 ② + 6차 정정):

> ⚠️ 본 계획서 5차까지 "상증령 §54④ 준용" 표기 잘못. KoreanLaw MCP §165④1 본문 재확인:
> 「다만, **그 가중평균한 가액이 1주당 순자산가치에 100분의 80을 곱한 금액보다 적은 경우에는 1주당 순자산가치에 100분의 80을 곱한 금액을 평가액으로 한다.**」
> → §165④1 단서에 직접 명시되어 있으며 상증령 준용 구조 아님. **부동산 환산취득가의 §176의2와는 완전 별개 조문 — LawArticleModal 링크 분리 필수**.

```
1주당 평가가액이 1주당 순자산가치의 80% 미만이면 → 1주당 순자산가치 × 80% 적용
```
**사례 49 검증**: 1주당 평가가액 = max(① 30,000×3/5 + 200,000×2/5, ② 200,000×80%) = max(98,000, **160,000**) = **160,000원** → 양도기준시가 1,280,000,000원.

**순자산가액 단독 평가** (시행령 §165④3 — 가중평균 안함, **4가지 사유 — KoreanLaw MCP 정확 인용**):

> ⚠️ 본 계획서 4차까지 "결손금 3년" 사유를 적시했으나 **시행령 원문에는 결손금 사유가 없음**. 정정된 4가지:

1. **가목** — 양도세 확정신고기한(§110) 내 **청산절차 진행 중** OR **사업자 사망**으로 사업계속 곤란한 법인
2. **나목** — **사업개시 전** / **사업개시 후 1년 미만** / **휴·폐업** 중인 법인
3. **다목** — 법인 자산총액 중 **주식등 가액 합계가 80% 이상**인 법인 (지주회사형) ★ 4차까지 누락
4. **라목** — 정관상 **잔여 존속기한 3년 이내**인 법인 ★ 4차까지 누락

→ 모두 시행령 §165④1나목(순자산가치만)으로 평가. 가중평균 미적용.

#### (C) 비상장 평가의 소득세법-상증법 차이

| 차이 내용 | 소득세법 (양도세용) | 상증법 (상속·증여) |
|---|---|---|
| 1주당 순손익액 산정 | **직전 1개 연도** 순손익액 | 직전 3개 연도 가중평균 |
| 자산 평가차액 | **토지의 평가차액만** 반영 | 토지 등 부동산 상증법 평가 |
| 영업권 평가액 반영 | **반영 안함** | 주당 순자산가액에 반영 |
| 할증평가 | **최대주주 할증 안함** (소득세법 집행기준 99-165-5) | 최대주주 20% 할증 (중소·중견 매출 5천억↓ 제외) |

→ 양도세는 1년만 사용·토지만 반영·영업권 미반영·할증 미적용 (**상속세 엔진과 분리** 필요).

#### (D) 비상장 평가의 시기별 연혁

| 시기 | 소득세법 | 상증법 |
|---|---|---|
| ~1998 | (순손익+순자산)÷2 | (순손익+순자산)÷2 |
| 1999~2000 | (순손익+순자산)÷2 | max(순손익, 순자산) (2000~) |
| 2001~2003 | max(순손익, 순자산) | max(순손익, 순자산) |
| 2004~2007.2 | max(순손익, 순자산) | (순손익×3 + 순자산×2)÷5 |
| **2007.2.28~ 현재** | **(순손익×3 + 순자산×2)÷5** | (순손익×3 + 순자산×2)÷5 |

→ 평가기준일 시기별 분기 필요 (오래된 취득 시점 환산용).

#### (E) **취득 후 상장 (사례 48)** — 시행령 §165⑤ 단서

양도일에는 상장이지만 취득당시 비상장이었던 경우:

```
취득기준시가 = 상장일로부터 1개월간 최종시세가액 평균
            × ( 취득일 비상장주식 평가액 / 상장일 비상장주식 평가액 )
```

**3시점 평가** 필요:
- ① 양도일 직전 사업연도 (양도일 평가용 — 시장가 있으면 1개월 종가평균이지만 비상장 평가도 병행)
- ② 상장일 직전 사업연도 (상장일 비상장 평가액)
- ③ 취득일 직전 사업연도 (취득일 비상장 평가액)

사례 48 결과:
- 양도가 = 5,000주 × 8,950원 = 44,750,000 **(확정 anchor)**
- 상장 후 1개월 종가평균 = **8,001원 (PDF 입력값 — 평가 검증 대상)**
- 산출세액 **2,372,760** / 지방세 **237,276** **(확정 anchor)**
- 양도소득금액 14,363,800 / 과세표준 11,863,800 **(확정 anchor)**

> ⚠️ **참고 anchor (확정 보류 — PR-1 Pre-Do에서 확정)**:
> - **주당 취득가 6,019원 / 취득가 30,095,000** — PDF 588~589p 입력값을 §165⑤ 본칙(순손익×3/5 + 순자산×2/5)에 단순 대입 시:
>   - 상장일 직전 평가 = 61,570×0.6 + 5,352×0.4 = **39,083.8**
>   - 취득일 직전 평가 = 44,520×0.6 + 4,348×0.4 = **28,451.2**
>   - 환산비율 = 28,451.2 / 39,083.8 = **0.7279**
>   - 8,001 × 0.7279 = **5,824원 ≠ PDF 6,019원** (차이 195원, 3.3%)
>   - 가능 원인: ① **소득칙 §81④ 월할 가산식** 적용 (취득일이 사업연도 중간일 때 직전 사업연도 평가액에 월할 보정) ② 순자산 80% 하한이 평가식에 발동
> - **필요경비 291,200원** — 30,095,000 × 1% = 300,950 ≠ 291,200 (차이 9,750원, 우연 아님)
>   - §163⑥ 산식은 "**취득당시 기준시가** × 1%"이지 "환산취득가 × 1%"가 아님
>   - 가능성: ① PDF의 실제 base는 30,095,000이 아닌 **29,120,000**(주당 5,824 × 5,000 일치) → 6,019원 비확정 가설과 연결 ② 별도 산식 적용
>
> **PR-1 Pre-Do 단계 필수 확인 (KoreanLaw MCP)**:
> 1. 소득세법 시행령 §165⑤ 단서 + **시행규칙 §81④ 전문** (월할 가산식)
> 2. 시행령 §163⑥ (개산공제 base 정의)
> 3. 집행기준 99-165-7
>
> 위 3개 조문 확정 전에는 6,019원·291,200원을 PR-1 anchor에서 제외하고, 산출세액 2,372,760·지방세 237,276만 확정 anchor로 사용. 산식 확정 후 디자인 문서 §6 케이스 매트릭스에 반영 (`feedback_pre_anchor_verification`).

**예외**: 취득일과 상장일 비상장 평가액이 동일한 경우 (소득칙 §81④):
```
상장일 비상장주식평가액 = 취득일 비상장주식평가액
                       + (취득일 - 직전사업연도) × (취득일~상장일 월수 / 사업연도 월수)
```
→ 월할 가산.

#### (F) **장부분실 — 취득당시 기준시가 확인 불가** (소득세법 §99①4)

```
취득당시 기준시가 = 액면가액
```

`사례 49` 적용: 1985.9.13. 상속 취득 + 액면가 12,500원 → 4만주 × 12,500 = **5억원**.

### 4.4 필요경비

**원칙**: 실제 발생 자본적 지출(§97①2·시행령 §163③) + 양도비용(§97①3·시행령 §163⑤). **증권거래세는 시행령 §163⑤1호 가목에 명시** ("「증권거래세법」에 따라 납부한 증권거래세"). 양도세과세표준 신고서 작성비용·계약서 작성비용·공증비용·인지대·소개비·명도비용도 §163⑤1호 나목~라목에 포함. 단, 개산공제 적용 시에는 별도 가산 불가(중복배제).

**개산공제** (실가 확인 불가 시):
```
필요경비 = 취득기준시가 × 1%
```

(소득세법 §97②1·시행령 §163⑥)

→ 환산취득가 사용 시 필수. **개산공제는 취득가 합산이 아닌 별도 차감 — `feedback_estimated_deduction_separation` 정책 준수**.


- **확정 보류 (PR-1 Pre-Do 단계에서 산식 확정 후 추가)**:
  - 주당 취득가 6,019원 / 취득가 30,095,000 / 필요경비 291,200 → **소득칙 §81④ 월할 가산식 + §163⑥ base 정의** 확인 후 anchor 승격

### PR-2 — 비상장 보충적 평가 (사례 49)
**목표**: 비상장 §165⑤ 가중평균 + 부동산과다보유 가중치 반전 + 장부분실 액면가 + 교환 양도가액.

- `stock-valuation.ts` (1주당 순손익가치·순자산가액 입력 → 가중평균)
- 부동산과다보유 50% 토글 → 가중치 반전 분기
- 순자산 단독 평가 3가지 사유 (청산·휴폐업·결손)
- 장부분실 액면가 분기
- 교환 양도가액 합계 (부동산 정상가액 + 채무면제 + 현금)
- **anchor**:
  - 사례 49 PDF: 양도가 6,000,000,000 / 취득기준시가 500,000,000 / 양도기준시가 1,280,000,000 / 환산취득가 **2,343,750,000** / 필요경비 **5,000,000**
  - 부동산과다보유 가중치 반전 회귀 1건
  - 시기별 평가 연혁 분기 회귀 5건

### PR-3 — 가산세·세액공제·다자산 신고
- ~~환산취득가 5% 가산세 (§114의2)~~ — **주식 미적용**. §114의2는 "토지·건물·부동산에 관한 권리"만 대상이며 주식·기타자산은 제외. 부동산 엔진 `penaltyConvertedAcquisition` 모듈을 주식 도메인에 **이식하지 않음** (`feedback_legal_codes` — 조문 정확성)
- ~~외국납부세액공제 (§57)~~ — **PR-3에서 삭제**. 본 엔진 스코프는 §1에 명시한 대로 **거주자의 국내주식** 한정이며, 외국납부는 정의상 해외주식 양도 도메인에서만 발생. 해외주식 별도 도메인 신설 시 이전
- 신고불성실 가산세 (무신고 20% / 과소신고 10% / 부정 40%)
- 납부불성실 가산세 (1일 22/100,000)
- 전자신고 세액공제 (개인 2만원 — §52의2)
- 다자산 합산신고 (다종목 양도) — `aggregate` prop 패턴
- 신고서 양식 출력 (PDF 화면 모사)
