# korean-law-citation-verify — 법령 인용 위임 체인 끝까지 추적

법령 조문 인용 시 KoreanLaw MCP로 **위임 체인 끝까지** 추적하여 최종 본칙·시행령·시행규칙을 검증하는 정책. "이 조문에 있을 것" 같은 추정 인용 금지.

## 적용 시점

- 신규 엔진 산식·legal-codes 상수에 조문 인용 추가 시
- Plan/Design 문서에 법령 근거 인용 시
- JSDoc·주석에 조문 인용 시
- 사용자 안내 메시지·결과 화면 라벨에 조문 인용 시
- 기존 인용을 정정·갱신할 때

## 적용 금지

- 일반 텍스트 (조문 인용 없음)
- 외부 자료(책·블로그)의 단순 발췌 (재인용)
- 학술적 토론 (법령 적용 아님)

## 핵심 원칙

### 1. 위임 체인 끝까지 추적

```
사용자 요청 안내:
"비상장주식 순손익가치 환원율 10%는 어디 조문에 있나요?"

❌ 추정 인용 (위반):
"소득세법 시행규칙 §82에 있습니다" → 검증 안 함
(실제 소칙 §82 = "소형 신축주택 및 준공 후 미분양주택의 요건")

✅ 위임 체인 추적:
1. KoreanLaw MCP: search_law("소득세법 시행령") → get_law_text(mst, jo="제165조")
2. 소령 §165④1 가목 본문: "재정경제부령이 정하는 이자율" (위임)
3. 소칙 §81② 본문: "「상속세 및 증여세법 시행규칙」 제17조에 따른 이자율" (준용)
4. 상증칙 §17 본문: "연간 100분의 10" (최종 본칙)

→ 정확한 인용:
"환원율 10% — 소령 §165④1 가목 → 소칙 §81② → 상증칙 §17"
```

### 2. 추정 인용 정정 사례

본 프로젝트 발견·정정된 사례들:

| 발견 시점 | 잘못된 인용 | 정정된 인용 | 위치 |
|---|---|---|---|
| 2026-05-18 | "환원율 소칙 §82" | "소령 §165④1 가목 → 소칙 §81② → 상증칙 §17" | stock-transfer Phase A |
| 2026-05-19 | 1개월 분모 §163⑨ | §99①3 · 시행령 §165③ 준용 | kiwoom D-1 |
| 2026-05-19 | 환산취득가 본칙 §163⑨ | 시령 §176의2②1호 | kiwoom D-2 |

### 3. KoreanLaw MCP 사용 강제

```
법령 인용 작성 전 반드시:

1. mcp__claude_ai_KoreanLaw__search_law(query)
   → 법령 검색

2. mcp__claude_ai_KoreanLaw__get_law_text(mst, jo)
   → 본문 확인 (mst·lawId는 search_law에서 획득, jo="제N조")

3. mcp__claude_ai_KoreanLaw__legal_research(query, task="law_system") (선택)
   → 법률·시행령·시행규칙 3단 + 위임 통합 리서치
```

## 표준 워크플로

### Step 1: 인용 후보 식별

```
"신축주택 5년 내 양도소득금액 차감 (조특법 §99의3)"
```

### Step 2: KoreanLaw MCP로 본문 확인

```
mcp__claude_ai_KoreanLaw__search_law("조세특례제한법")
→ get_law_text(mst, jo="제99조의3")
→ 본문 확인: "...취득한 날부터 양도일까지 발생한 양도소득금액을 양도소득세 과세대상소득금액에서 빼며..."
```

### Step 3: 위임 여부 확인

본문에 다음 표현이 있으면 위임 추적 필요:
- "대통령령으로 정한다"
- "기획재정부령으로 정한다"
- "별도로 정한다"
- "다음 각 호 어느 하나..."

```
§99의3 ① "...대통령령으로 정하는 지역 외의 지역에 있는 ... 신축주택..."
→ 시행령 §99의3 본문 추적 필요
```

### Step 4: 최종 본칙 확인 후 인용

```ts
// lib/tax-engine/legal-codes/transfer.ts
export const TRANSFER_REDUCTION_ARTICLE = {

  // NEW_99_3: "조특법 §99의3",

  // ✅ 위임 체인 명시
  NEW_99_3: "조특법 §99의3 + 시행령 §99의3",
} as const;
```

## 인용 표기 컨벤션

### 본칙·항·호·목

| `§47` | 제47조 |
| `§47②` | 제47조 제2항 |
| `§47①1호` | 제47조 제1항 제1호 |
| `§47①1호 가목` | 제47조 제1항 제1호 가목 |

| `§47 단서` | 제47조 단서 |

## "추정 인용" 안티 패턴

다음 표현이 보이면 검증 필요:
- "...에 있을 것"
- "...에 정해져 있음" (출처 미상)
- 조문 번호만 단독 (예: "§163⑨") — 본문 확인 안 함
- "...로 알고 있음"
- "법령상..."

→ 즉시 KoreanLaw MCP 호출하여 검증.

## 본 프로젝트 사례

**소칙 §82 → 소령 §165④1 가목·소칙 §81②·상증칙 §17 정정** (project_stock_transfer_post_listing_pdf_replica Phase A):
- v3 계획서·디자인 문서·엔진 주석에 "환원율 = 시행규칙 §82"라 표기됨
- KoreanLaw MCP 검색 → 소칙 §82 본문은 "소형 신축주택 및 준공 후 미분양주택의 요건" (환원율 없음)
- 위임 체인 추적 → 소령 §165④1 가목 → 소칙 §81② → 상증칙 §17 "연간 100분의 10"에서 발견
- legal-codes·JSDoc·Plan/Design 모두 정정

**§163⑨ → §99①3 + 시행령 §165③ 준용** (kiwoom D-1):
- 1개월 평균 분모 인용을 §163⑨로 추정
- §163⑨ 본문 확인: 상속·증여받은 자산의 취득가액(상증법 §60~66 평가가액) — 1개월 평균 분모 산식과 무관
- 실제 적용 조문: §99①3 본문 + 시행령 §165③ 준용
- 정정 후 anchor 통과

**§163⑨ → 시령 §176의2②1호** (kiwoom D-2):
- 환산취득가 산식 본칙을 §163⑨로 추정
- §163⑨은 평가가액 조항 — 환산 산식 없음
- 실제: 시령 §176의2②1호
- 정정 후 산식 anchor 통과
