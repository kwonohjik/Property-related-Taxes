## 1. 개요·범위·전제

### 1.1 두 도메인 분리 권고

| 구분 | 국외전출세 (Exit Tax) | 해외주식 양도소득세 (Foreign Stock) |
|---|---|---|
| 근거 | 소득세법 §118의9~§118의16 | 소득세법 §94①3다목 + §118의2~§118의8 |
| 납세의무자 | 거주자 → 비거주자 전출 대주주 | 5년 이상 국내 주소·거소 보유 거주자 (국외자산 양도) |
| 과세 시점 | 출국일 (간주양도) | 실제 양도일 |
| 세율 | §118의11 → §104①11가목2) 준용. **확정: 3억 이하 20% / 초과 25%(누진공제 15,000,000)** (stock-rate-tables.ts `STOCK_MAJOR_PROGRESSIVE_BRACKETS`) <!-- 세율 환각 정정 2026-05-19 R3 --> | §118의5 → §55① 누진. **확정: 6~45% 8구간 (누진공제 0~65,940,000)** (stock-rate-tables.ts `BASIC_PROGRESSIVE_BRACKETS`) <!-- 세율 환각 정정 2026-05-19 R3 --> |
| 기본공제 | §118의10④ — 연 250만원 (§103·§118의7과 별도 그룹) | §118의7 — 연 250만원 (§103·§118의10④과 별도 그룹) |
| 외국납부세액 | §118의13 (공제한도: 산출세액−조정공제액). 배제 사유: ①외국이 산출세액 공제 허용 ②외국이 취득가액을 출국일 시가로 조정 <!-- 검토 정정 2026-05-19 --> | §118의6 공제 또는 필요경비 산입 선택 |
| 복잡도 | 높음 (납부유예 5/10년, 경정청구 2년, 보유현황 신고) | 중간 (환율 환산, 시가 보충 평가) |

**권고안: PR-4A(해외주식)와 PR-4B(국외전출세)로 분리 구현.** 이유:
1. 국외전출세는 "간주양도" 개념·납부유예·경정청구 흐름이 일반 양도와 근본적으로 다름 — 별도 UI 마법사 또는 전용 탭 필요
2. 해외주식은 §118의5 → §55 누진 세율 + 환율 환산만 추가하면 기존 엔진 흐름(양도가 → 필요경비 → 양도차익 → 기본공제 → 세율)을 재사용 가능
3. PR-4A 완료 후 PR-4B에서 국외전출세 고유 로직(시가 계산·납부유예·조정공제)을 독립 모듈로 구현

### 1.2 스코프 내

- **PR-4A (해외주식)**: §94①3다목 거주자의 해외주식 양도 — 실거래가·환율 환산·§118의5 누진세율·§118의6 외국납부세액공제·§118의7 기본공제
- **PR-4B (국외전출세)**: §118의9 요건(5년+대주주) 충족 거주자 출국 시 간주양도 — 출국일 시가·§118의11 세율·납부유예(5/10년)·조정공제·외국납부세액공제·보유현황 신고 가산세
