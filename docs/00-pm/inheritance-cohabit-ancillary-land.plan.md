# 상속세 §23의2 동거주택 부수토지 별도입력 — 검토 결과: ❌ 불필요 (CANCELLED)

> 작성·검토: 2026-06-02 (13단계 자가 검토 + KoreanLaw §61 검증 + 사용자 확인)
> 결론: **구현하지 않음** — 전제 무효. v3 현행이 이미 정확.

## ⛔ 검토 결론 (핵심)

기능 착수 전 **전제를 KoreanLaw로 검증한 결과, 이 기능은 불필요하며 구현 시 오히려 오류(이중계상)를 유발**한다.

**근거 (상증법 §61①4호, mst 276123 검증 + 사용자 확인 2026-06-02)**:
- §61①4호 주택 평가 = 「부동산 가격공시에 관한 법률」 **개별주택가격 및 공동주택가격**.
- 개별주택가격(단독주택)·공동주택가격(아파트)은 **주택(토지+건물 일체)의 가격** — **부수토지 가액을 이미 포함**한다.
- §23의2① "상속주택가액(주택부수토지 가액을 **포함**하되 …)"의 "포함"은 *별도 합산하라*가 아니라 *주택가액이 부수토지를 포함함을 확인*하는 의미.

**따라서**:
- v3의 `deriveCohabitHouseStdPrice`가 **단일 주택 EstateItem의 standardPrice**(=개별/공동주택가격, 부수토지 포함)를 쓰는 것은 **이미 법령상 정확**.
- 부수토지를 **별도 토지 EstateItem으로 입력+합산**하면 주택가격에 이미 포함된 토지를 **이중계상**(공제 과대) → 잘못된 구현.
