# 재개발 완공APT × §155⑳ 장기임대주택 보유자 거주주택 특례 — 수정 계획서

- 출처: `redev-apt-one-house-warning-parity.plan.md` §6 별건(V-4에서 발견).
- 검증 깊이: **L3** — 세액이 바뀐다(과다과세 정정). 해석이 갈리는 지점은 Q-n으로 사용자 결정을 받는다.

## 0. 요약

- 재개발로 완공된 신축주택(`redevelopment_apt` · subject `apt`)을 **거주주택**으로 양도하고 장기임대주택을 함께 보유한 세대는 §155⑳ 특례를 받을 수 있다는 것이 국세청 해석이다(§2). 거주기간은 멸실 전 주택과 신축 주택의 실제 거주를 통산한다.
- 계산기는 이 경우를 **입력할 수 없고**(⑤·⑧·④ 술어가 완공APT를 뺀다), API로 넣어도 **엔진이 읽지 않는다**(재개발 분기가 §155⑳ 단계보다 먼저 반환한다).
- ⇒ 같은 사실관계에서 일반 주택은 비과세인데 완공APT는 전액 과세된다(§1 실측 124,366,000 vs 0).
- 반대 방향 관찰: 조합원입주권(`right_to_move_in`) 양도에는 카드가 열려 있으나, 해석상 §155⑳은 입주권 양도에 적용되지 않고(서면-2017-법령해석재산-1581) 엔진도 읽지 않아 결론은 맞다. 다만 결과에 반영되지 않는 입력 칸이다(§1.2 · Q-4).

## 1. 실측

### 1.1 같은 사실관계 — 일반 주택 vs 완공APT

시료: 원조합원 완공APT. 종전주택 2008-01-01 취득, 인가 2016-06-01, 청산금 1억 납부. 거주 2019-06-01~2024-06-01, 2024-06-01 10억 양도. 명부에 장기임대 1채(2007-01-01 취득 · `isLongTermRental`)가 있고 세대 주택 수 2. 일반 주택 짝은 같은 날짜·같은 양도차익으로 둔다(하네스 `__tests__/calc/_helpers/redev-one-house-route.ts`). §155⑳ 입력은 시나리오 A · 임대 1호(2015-01-01 등록 · 장기일반 · 요건 확인) · 직전 특례 이력 「없음」.

| 경로 | §155⑳ 없음 | §155⑳ 넣음 |
|---|---|---|
| 일반 주택(계산기 화면) | 과세 124,366,000 | **비과세 0** · `rentalHousingExceptionDetail.applied = true` (RH-A1) |
| 완공APT(계산기 화면) | 과세 124,366,000 | **입력 불가** — ④ 본문에 `rentalHousingException` 없음 |
| 완공APT(API 직접) | 과세 124,366,000 | **과세 124,366,000** — 상세 없음 · 경고 없음(엔진이 무시) |

### 1.2 조합원입주권 양도

같은 명부 + 입주권 양도(`right_to_move_in` · subject `right`). 화면 카드가 열리고 ⑧이 「임대주택 정보를 1호 이상 입력하세요」로 입력을 요구한다. API로 §155⑳을 넣어도 결과는 같다(과세 155,166,000 · 상세 없음). 재개발·입주권 엔진 파일은 `rentalHousingException`을 읽지 않는다(grep 0건).

- ✅ **현행 법문**(V-1) — 「소득세법 시행령」 §155⑳(MST 290841 · 2026-10-01 시행 · DRF `lawService` 실독 2026-10-24):
  - 본문 — 장기임대주택(또는 장기어린이집)「과 그 밖의 1주택을 국내에 소유하고 있는 1세대가 각각 제1호와 제2호 또는 제1호와 제3호의 요건을 충족하고 해당 1주택(이하 이 조에서 "거주주택"이라 한다)을 양도하는 경우에는 국내에 1개의 주택을 소유하고 있는 것으로 보아 제154조제1항을 적용한다」.
  - 1호 — 「거주주택: **보유기간 중 거주기간**(직전거주주택보유주택의 경우에는 … 등록을 한 날 … 이후의 거주기간을 말한다)이 2년 이상일 것」.

## 4. 설계안

- **D-1 입력 게이트** — `isRentalHousingExceptionApplicable`에 `redevelopment_apt`를 더한다(⑤·⑧·④가 같은 술어 — 한 곳 변경). 자산 전환 리셋(`housing-flag-reset.ts:47`)도 같은 술어를 쓰므로 함께 따라온다.
  - ⚠️ subject `right`로 둔 `redevelopment_apt`는 없다(입주권은 `right_to_move_in`) — 확인 필요(V-5).
- **D-2 엔진 — 판정 전제로 주입(권장)** — 완공APT 판정(`judgeRedevAptOneHouseExemption`)에서 일반 경로와 같은 두 leaf를 번역 입력에 적용한다.
  1. STEP 0.96과 같은 `restoreRentalUnitsToHouseCount` — §155⑳ A 요건(`judgeRentalHousingEligibility`)이 서면 임대주택을 주택 수에서 뺀 전제로 판정하고, 서지 않으면 되돌린다.
  2. 세대 구성 회수 `revokeExemptionOnRentalCompositionExceeded`(W1)와 그 고지.
  - 판정이 비과세·부분과세(12억 초과)를 내면 `calculateRedevelopmentTax`의 기존 경로(§95③ 안분 · 표2)가 그대로 처리한다. 신규 세액 산식 없음.
  - 비교안 **D-2'**(STEP 2.5를 §166용으로 따로 구현)은 산식이 중복되고 B(§161 안분)와 §166 결합 근거가 없어 권장하지 않는다.
- **D-3 거주기간** — 거주요건(「거주기간 2년 이상」)은 판정이 이미 쓰는 번역 입력의 거주월수(`resolveAptResidenceMonths` — §154⑧1호 통산 · OH-48)를 그대로 쓴다. 원조합원은 종전주택 + 신축 거주를 통산한다(827과 같은 방향). 승계조합원은 신축 거주만 해당한다(V-2).
- **D-4 시나리오 B(직전거주주택보유주택 · §161 기간 안분)** — Q-2.
- **D-5 결과·고지** — 일반 경로와 같은 `rentalHousingExceptionDetail`(결과 카드)·고지를 싣는다. 대상 범위는 V-6.
