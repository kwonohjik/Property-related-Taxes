# 조특법 §99의4 농어촌주택·고향주택 과세특례 — 구현 계획서

> 효과: 농어촌주택등을 **1세대 소유주택이 아닌 것으로 보아** 소득세법 §89①3호(1세대1주택 비과세) 적용 — 세액감면이 아닌 **주택수 제외**(effectCategory `house_count_exclusion`).
> 대상 ID: `new_99_4_rural`(농어촌) · `new_99_4_hometown`(고향) — metadata 기등록, Phase 1 stub 상태.
> 법령 검증: **KoreanLaw 2026-06-11 원문 전문 확보** (법 mst 286597 · 령 mst 286143 — §1 표가 단일 진실).

## §3. 효과 분석 — "주택수 제외"의 적용 범위 (엔진 통합의 핵심)

§89①3호 적용 의제이므로 **비과세 판정 전체 체인**에 일관 적용:

| 적용 지점 | 현행 코드 (실측) | §99의4 적용 시 |
|---|---|---|
| 비과세 판정 | `checkExemption` — `transfer-tax-helpers.ts:222` `householdHousingCount !== 1` 차단 | 유효 주택수 = count − 1 (농어촌주택 제외) |
| 일시적 2주택 (E-3) | `helpers:196` `count === 2 && temporaryTwoHouse` | 3주택(일반+신규+농어촌)도 농어촌 제외 후 2주택으로 결합 가능 — 케이스 #7 |
| 12억 고가주택 부분과세 | `checkExemption` E-2 (`helpers:255`) | §89①3호 체인이므로 동일 적용 |
| LTHD 표2 (보유+거주 80%) | `helpers:497`·`helpers:536` `isOneHousehold && count === 1` | ✅ **R-A 해소**: 소령 §159의4 원문 — "1주택(§155 계열 **및 그 밖의 규정에 따라 1세대 1주택으로 보는 주택을 포함**)" → §99의4 의제 포섭, **표2에도 유효 주택수 주입**. 거주 2년 요건은 표2 자체 요건으로 그대로 적용 |
| 다주택 중과 주택수 | `transfer-tax.ts:515-519` (소령 §167의3 별개 체계) | **범위 외** — §99의4는 비과세 한정. 중과 판정에는 영향 없음 명시(결과 안내) |

> **R-A 해소 (2026-06-11, 검토 STEP 1)**: 소령 §159의4 원문 확보(mst 286211) — 표2 1세대1주택 정의가 "그 밖의 규정에 따라 1세대 1주택으로 보는 주택 포함" 포괄 문구를 명시 → §99의4 의제 주택 포섭으로 **표2 적용 채택**. 비과세·고가주택 부분과세·표2 세 지점 모두 유효 주택수(count−1) 일관 주입. (포괄 문구의 조특법 포섭은 실무 통설과 일치 — 사용자(세무 전문가) 최종 확인 권장)

## §5. 설계 방향

### 5.1 입력 필드 (자산-수준 reduction variant — 농어촌/고향 공통 + 분기)

```
공통: ruralHouseAcquisitionDate (농어촌주택등 취득일 — 시한·3년 보유·취득순서 판정)
      ruralHouseStdPrice (취득 당시 주택+부속토지 기준시가 합계, 원 — 3억/4억 한도)
      isRegisteredHanok (등록 한옥 — 한도 4억 전환, 령⑭)
      isAdjacentArea (③ 연접 배제 — 사용자 확인 토글, 주소 자동판정 범위 외)
      meetsLocationRequirement (소재지 요건 충족 — 사용자 확인 토글 + hint에 배제지역 열거)
hometown 전용: meetsHometownRequirement (등록기준지/거주 10년 — 토글, 령⑥ hint)
```
- **취득순서(① "취득 전 보유") 판정**: 일반주택 취득일 = **자산-수준 `acquisitionDate` 재사용** (신규 입력 없음). `ruralHouseAcquisitionDate > acquisitionDate` 필수 — 위반 시 불적용 사유.
- 양도일 − `ruralHouseAcquisitionDate` < 3년 → **④ 선적용 허용 + ⑥ 추징 경고 echo** (차단 아님).
- 소재지·연접은 v1에서 **사용자 확인 토글** (별표 12·읍면동 연접 자동판정은 범위 외 — hint에 법령 기준 열거). 자동 안분 fallback 금지 정책 준수: 토글 미확인 시 불적용 사유 echo.

### 5.2 엔진 통합 (2-레이어 — evaluator + checkExemption 주입)

1. **evaluator** `transfer-reductions/new-99-4.ts`: 요건 검증(시한 D-1 정정 포함·가액·소재지 토글·연접·취득순서) → `{ isEligible, houseCountExclusion: 1, ineligibleReasons, 추징경고 }`. rural/hometown은 단일 evaluator + id 분기 (§97 main/proviso 패턴).
2. **유효 주택수 주입 (R-A 해소 반영 — 설계 실측으로 정밀화)**: `effectiveInput`이 비과세(transfer-tax.ts:291)·LTHD(529)·**중과 하위호환(515)**에 공유됨 → 일괄 복제 주입 시 중과 오염. 따라서 **호출부 2곳(checkExemption·calcLongTermHoldingDeduction)에만** `{ ...effectiveInput, householdHousingCount: count - 1 }` 개별 전달. 중과(515·STEP 0.5)는 원본 유지 — ⚠️ R-D(중과 판정의 농어촌주택 제외 여부는 소령 §167의3 별개 체계, 미확인 → v1 원본 + 결과 경고).
3. **결과 echo**: `result.new994Detail` (isEligible·제외 주택수·추징 경고·미적용 사유) + 결과 카드.
4. 중과 주택수(`transfer-tax.ts:515`)는 **원본 count 유지** + 카드에 "다주택 중과 판정에는 영향 없음" 안내.

### 5.3 UI (new_housing 그룹 — §99의3 옆 라디오 2종)

- 폼 1파일 공용(`New994InputForm`) + `variant: "rural" | "hometown"` prop — 농어촌/고향 차이는 hometown 전용 토글 1개와 hint 문구.
- **v1 한계 명시**: §99의3(양도하는 신축주택 특례)과 §99의4(타주택 보유 특례)는 대상이 달라 이론상 동시 적용 가능하나, new_housing 그룹 라디오 단일 선택이 동시 선택을 차단 — v1 한계로 결과 안내 없이 유지(동시 케이스 희소), 후속 검토 항목으로 기록.
- 결과 카드: "농어촌주택 1채를 소유주택에서 제외 → 1세대 1주택 비과세 판정" 산식 한국어 풀어쓰기 + ④ 선적용 시 amber 추징 경고.
- 사이드바: 영향 없음 (세액 변동은 비과세 결과로 자연 반영).
