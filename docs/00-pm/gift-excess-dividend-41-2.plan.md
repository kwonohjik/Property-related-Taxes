## 1. 법령 체계 (검증 완료)

### 1.1 법 §41의2 (상증법, 시행 2026-01-02)
- **①** 최대주주등이 배당 포기/불균등 배당 → 특수관계인이 초과배당 수령 → `증여재산가액 = 초과배당금액 − 초과배당금액에 대한 소득세 상당액`. 증여일 = 법인이 배당·분배금액을 **지급한 날**.
- **②** 정산: 실제 소득세 납부 시(납부세액 0 포함) `2호 증여세액(정산) − 1호 증여세액(당초)` 납부. 1호 > 2호이면 차액 **환급**.
- **③** 정산증여재산가액 신고기한: 발생연도 다음연도 **5.1~5.31** (성실신고확인대상 6.30).
- **④** 산정방법 시행령 위임.

### 1.2 시행령 §31의2
- **②** `초과배당금액 = ①가액 × ②비율`
  - ①가액 = (특수관계인이 받은 배당 − 본인 지분 비례 배당)
  - ②비율 = 총과소배당금액 중 **최대주주등의 과소배당금액** 비율
- **③** 소득세 상당액:
  - **1호** (신고기한이 발생 다음연도 6.1, 성실신고 7.1 **이후**) → ④2호 금액(실제소득세). **그리고 ⑥에 따라 정산(법②③) 미적용** → 처음부터 실제소득세 단일 계산.
  - **2호** (그 밖) → 규칙§10의3① **율표** 곱한 금액.
- **④** 정산증여재산가액 = 초과배당금액 − 규칙 실제소득세액.
- **⑥** ③1호 해당 시 법②③ 미적용.

### 1.3 시행규칙 §10의3 (소득세 확정 여부로 분기)
- **① 소득세 미확정(율표)** — 아래 §2 율표 2세트.
- **② 실제소득세액(확정)**:
  | 구분 | 소득세액 |
  |---|---|
  | 비과세 (소득령§26의3⑥ 자본준비금 감액배당 등) | 0 |
  | 분리과세 (소득법§14⑤) | 해당 세액 |
  | 종합과세 (소득법§14②) | **Max(ⓐ−ⓑ, 초과배당금액×14%)** |
  - ⓐ = 수증자 종합소득과세표준 × 종합소득세율
  - ⓑ = (종합소득과세표준 − 초과배당금액) × 종합소득세율
  - 여기서 초과배당금액은 **배당가산액(Gross-up) 제외분만** (법규재산-2377, 2024.08.07)

## 4. 정산 2-pass (현행 2021~ 전용) — 최대 설계 리스크

```
㉮ 당초 증여세액 = calcGiftTax(증여재산가액 = 초과배당금액 − 율표소득세상당액)
⑭ 정산 증여세액 = calcGiftTax(정산증여재산가액 = 초과배당금액 − 실제소득세액)
정산 납부(환급) = ⑭ − ㉮   (음수면 환급)
```

- **㉮·⑭ 모두 `calcGiftTax` 본체를 거쳐야** 한다(증여재산공제·세율·세대생략 할증·신고세액공제 반영). 단순 deemedGiftValue 차이가 아님.
- 🔴 **핵심 리스크**: `lib/tax-engine/gift-tax.ts`에 **deemed 연결이 없음**(grep 0건). deemed-gift 계산기는 독립적으로 `deemedGiftValue`만 산출. 정산 2-pass는 deemed 결과를 `calcGiftTax` 입력(증여재산가액)으로 연결하는 **신규 통합 지점**을 요구.
  → **Design 1순위 조사**: `DeemedGiftCalculator` → `gift-deemed-api` → route → `calcGiftTax` 연결 경로 실측. 정산을 deemed 엔진 내부에서 처리할지(calcGiftTax import) vs route/클라이언트 레벨에서 2회 호출할지 결정.
- 신고기한 분기(영§31의2③1호·⑥): 신고기한이 6.1(성실 7.1) 이후 → **정산 미적용 + 처음부터 실제소득세**. 입력에 `신고기한구분`(일반/성실신고) + `실제소득세 확정여부` 필요.
