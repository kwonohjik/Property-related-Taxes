## 3. 결함: 비과세 × 양도차손 [직접]

### 3.1 일반 주택 단건 — 취득가액이 양도가액으로 표시된다 (브라우저 확인)

시료: 1세대1주택 비과세(보유 8년·거주 96개월) 주택, 양도가액 500,000,000, **취득가액(상속개시일 평가액 / 매매 실가) 700,000,000** → 양도차손 200,000,000. ⑧ 통과(이슈 0건).

| 항목 | 신고서 | 명세서 |
|---|---|---|
| 양도가액 | 500,000,000 | 500,000,000 |
| **취득가액** | **500,000,000** (입력 700,000,000) | «취득가액 500,000,000 (실제 거래가액)» |
| 필요경비 | « - » | «양도비 0» |
| 전체 양도차익 | 0 | «양도가액 − 취득가액 − 필요경비 = 0» |

매매 실가(`fixedAcquisitionPrice` 700,000,000)도 같은 결과다. 엔진은 `isExempt: true · transferGain: 0 · exemptGrossGain: 0`이고, 표시부가 취득가액을 «양도가액 − gross 양도차익 − 필요경비»로 역산하므로(`FilingFormTableHelpers.ts:538-539`) gross가 0으로 눌리면 취득가액 = 양도가액이 된다 — 항등식은 성립해 자기검산이 못 잡는다.

### 3.2 집계·겸용 컴패니언 — 취득가액은 맞고 전체 양도차익이 0이라 항등식이 어긋난다

- **일반 주택(함께 양도 · 토지 + 비과세 손실 주택):** 신고서 주택 열 양도가액 466,666,667 / 취득가액 700,000,000 / 전체 양도차익 **0** → 열 항등식 −233,333,333.
- **겸용 + 배율초과 + 1세대1주택 비과세(K8):** 주택 토지 카드(양도가액 119,667,590 / 취득가액 197,368,421)·주택 건물 카드(15,955,679 / 26,315,790)의 gross가 −77,700,831·−10,360,111(손실)인데 0으로 눌려 항등식이 각각 −77,700,831·−10,360,111, **합계 열 −88,060,942** 어긋난다. 눌리지 않은 상가 카드는 gross +98,785,426·+19,757,085 그대로다. 진짜 Σ gross = 60,000,000(단건과 같음), 눌린 Σ = 148,060,942.
- **단건 겸용 4열은 정상**이다 — 겸용 엔진 breakdown이 파트 gross를 음수로 보존한다(K8 단건 4열 항등식 0, 주택 gross −196,842,106).
