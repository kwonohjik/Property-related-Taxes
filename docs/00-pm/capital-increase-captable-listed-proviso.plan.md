**"cap-table에 단서가 미구현"이 문제가 아니다.** PR#992로 sub-case 경로만 고쳐진 결과, **같은 사실관계에서 두 경로가 서로 다른 세액을 낸다.**

|---|---:|---|

> 🔴 **v1.2 판정: C 채택**(§4-5) — 상장이면 다주주 모드에 안내를 띄우고 단일 모드로 유도한다.

> 🆕 그 과정에서 **단서와 무관한 기존 불일치**도 나왔다 — 부분 실권+재배정 주주에 대해 cap-table은 「증여자」, 법정 산식은 「수증자 +50,000,000」으로 **부호가 반대**다(§4-5 파생 발견).

그리고 naive 적용이 왜 안 되는지도 실측으로 확정됐다 — **Phase D 계획서 v1.1 §3-B의 서술을 정정한다**:

> ~~"저가/고가 방향이 주주마다 갈린다"~~ → **정확한 사유는 「zero-sum(balanced) 불변식 붕괴」**다(§2).

## 1. 실측 (throwaway probe, 재현 입력 포함)

```ts
// 주주 2인 · 저가발행 · 실권주 전량 재배정
const SH = [
  { id: "A", preShares: 60_000, entitledShares:  60_000, subscribedShares:      0, relatedTo: ["B"] },
  { id: "B", preShares: 40_000, entitledShares:  40_000, subscribedShares: 100_000,
    reallocatedShares: 60_000, relatedTo: ["A"] },
];
// preIssuePrice 20,000 · newSharePrice 10,000 · direction "low"
// ⇒ preTotal 100,000 · issuedActual 100,000 · 이론 ㉯ = 15,000
```

| 측정 | 값 |
|---|---|
| `calcCapitalIncreaseAllocation` `perShareAfter` | **15,000** |
| 〃 `byShareholder` delta | A **−300,000,000** / B **+300,000,000** |
| 〃 `reconciliation` | `{ totalGain: 300,000,000, totalLoss: 300,000,000, balanced: true }` |
| 〃 `perBeneficiary[B].total` | **300,000,000** |
| `calcCapitalIncreaseGift` 단서 **無** (동일 사실, `forfeitedShares: 60,000`) | **300,000,000** ⇒ **대수적 동치 확인** |
| 〃 단서 **有** (`isListed: true, listedMarketAvg: 13,000`) | **180,000,000** |
| cap-table ㉯를 13,000으로 **naive 치환** 시 delta | A **−420,000,000** / B **+20,000,000** |

> 📌 **동치가 성립하던 것은 단서 이전까지다.** 단서 없을 때 두 경로가 300,000,000으로 일치했다는 사실이, 단서 적용 후 180,000,000 ↔ 300,000,000으로 갈린 것이 **회귀임을 증명**한다.

## 2. naive 적용이 불가능한 이유 — zero-sum 붕괴 (실측 근거)

cap-table의 `perShareAfter`(㉯)는 **가중평균**이므로 항등식이 성립한다:

```
Σ postValuation = (preTotal + issuedActual) × ㉯ = Σ preValuation + Σ paidIn
⇒ Σ delta = 0  ⇒  totalGain == totalLoss  (reconciliation.balanced)
```

이 항등식 위에 모델의 두 축이 얹혀 있다:
1. **누가 증여자/수증자인지**를 `delta` 부호로 판정 (`:49·70`)
2. **증여자별 배분**을 `손해비례 = −d.delta / totalLoss`로 계산 (`:81`)

단서의 ㉯는 **시장가(외생값)** 라 가중평균이 아니다 ⇒ 항등식이 깨진다. 실측: `Σ delta = −420,000,000 + 20,000,000 = −400,000,000 ≠ 0` (= 200,000주 × (15,000 − 13,000)).

⇒ `balanced: false`가 되고, 배분 분모(`totalLoss` 420,000,000)와 배분 대상(`b.delta` 20,000,000)이 **서로 다른 기준**이 된다. 결과값 20,000,000은 법정 산식값 180,000,000과도 어긋난다. **단순 치환은 어떤 해석으로도 정당화되지 않는다.**

**모델 자체의 정합성 문제이지 법 해석 문제가 아니다** — 이 부분은 근거 조사 없이 확정할 수 있다.

| 안 | 내용 | 위 사례 B 값 | 필요한 근거 |
|---|---|---:|---|
| **A. 호별 산식 재도입** | 수증자별 이익을 §29②1~5로 직접 계산, 증여자 배분만 손해비례 유지 | **180,000,000** | ⓐ 배분 대상 교체의 근거(§4-5 C-2) ⓑ **유형별 산식·수증자 판정 재설계**(§4-2-R ③-R) — **둘 다 미확보** |

| **C. 상장 시 cap-table 차단** | 상장법인이면 다주주 모드를 막고 단일(sub-case) 모드로 안내 | (계산 안 함) | **근거 불요** — 조용한 오답 대신 명시적 차단 |
| **D. 현행 유지** | 단서 미적용 | 300,000,000 | ❌ 경로 불일치 지속 — 이미 회귀 상태 |

> ⚠️ **A′가 A와 일치하는 것은 우연이다(실측).** 수증자 delta는 `(㉯−인수가)×인수신주 + 기존주식수×(㉯−증자전평가)` 두 항으로 분해되고 **두 항이 ㉯에 다르게 반응**한다. 위 사례 B: 이론 `5,000×100,000 + 40,000×(−5,000) = 300,000,000`, 단서 `3,000×100,000 + 40,000×(−7,000) = 20,000,000`. 단일 비율 스케일(3/5 → 180,000,000)은 이 구조를 재현하지 못하며 **오직 특정 파라미터에서만 호별 산식과 같아진다**. ⇒ **A′는 후보에서 제외 권고**.

**⇒ 실질 후보는 A(근거 필요)와 C(근거 불요)뿐이다.** → **v1.2 판정: C**(§4-5).

⇒ **A안의 이익 산정은 유형 추론 없이 가능**하다:
```
수증자 i의 이익 = |단서㉯ − 인수가| × (저가: i의 reallocatedShares / 고가: i의 forfeitedBy())
```
v1.0 §3이 걱정한 「다목 도출을 위한 유형 추론 재도입」은 **필요 없다**.

#### 🔴 ③-R. **v1.2 반증 — 위 결론은 깔끔한 케이스에만 성립한다**

v1.1의 probe는 **전량 실권 / 전량 인수**만 다뤘다. 경계 케이스를 추가 실측한 결과 §5 공식이 **두 곳에서 깨진다**:

| # | 케이스 | cap-table | 법정 산식 | 판정 |
|---|---|---:|---:|---|
| **C-10** | 저가 · A가 **40,000 실권 + 재배정 10,000 동시 수령** (B: 실권 없음·재배정 30,000) | A **−150,000,000**(증여자로 분류) · 수증자 = **B뿐** | A = `(15,000−10,000) × 다목 10,000` = **+50,000,000**(수증자) | 🔴 **부호까지 반대** |
| **C-9** | 고가 · **순수 제3자배정**(기존주주 A·B에 배정 자체 없음, C가 전량 인수) | A **450,000,000** | `forfeitedBy(A) = max(0, 0 − 0) = 0` ⇒ **0** | 🔴 §5 공식이 **이익을 소멸**시킴 |

- **C-10**: cap-table의 equity-delta는 「실권 손해」와 「재배정 이익」을 **상계**한다. 법문 §39①1호가목은 「실권주를 **배정받은 자가** 배정받음으로써 얻은 이익」만 정하고 **상계 규정이 없다** ⇒ 문언상 A는 **증여자이자 동시에 수증자**로 읽힌다(단, 상계 여부에 대한 예규·심판례는 **미발견 — 확인 필요**).
  ⭐ **이 불일치는 단서와 무관하게 현행에 이미 존재한다.** 파일 주석의 「호별 산식과 **대수적으로 동치**」는 **깔끔한 케이스 한정**이며, mixed 케이스에서는 성립하지 않는다.
- **C-9**: 고가 이익 산식을 `forfeitedBy()`로 쓴 §5 스케치가 **틀렸다**. 순수 제3자배정은 실권이 0이라 이익이 사라진다 — §29②5의 「미달배정 신주수」는 `entitled − ownSub`가 아니라 **균등배정 가정분**을 기준으로 해야 한다.

⇒ **③의 「유형 추론 불요」 결론을 철회한다.** 최소한 (ⓐ 실권·재배정 혼합 ⓑ 제3자배정·초과배정)에서 **유형별 분기가 필요**하며, ⓐ는 **수증자 판정 자체**가 갈린다.

#### ① 「증여자별 배분」의 법적 지위 — ⭐ **A안의 신규 쟁점이 아니다**

- 「상증법」**§47①** 본문 실측: 「증여세 과세가액은 … **증여재산가액을 합친 금액**에서 …」 — **증여자별 구분을 명문으로 요구하지 않는다**. 구분 필요성은 §47②(동일인 10년 합산)·§53(관계별 공제)에서 **파생**된다.
- 「상증법」**§39①1호가목** 본문 실측: 「그 실권주를 **배정받은 자가** 실권주를 배정받음으로써 얻은 이익」 — **증여자 특정도, 다수 실권자 간 배분 산식도 없다**. (나목·2호는 「포기자의 **특수관계인**」으로 쌍을 지정)
- ⇒ 손해비례 배분은 **법에 없는 프로젝트 구성물**이다. 그런데 이는 **단서 도입 이전부터 이미 그랬다**.
- ⭐ **A안은 배분 기준을 바꾸지 않는다** — 총이익만 법정 산식으로 교체하고 배분 비율(이론 ㉯ delta)은 **현행 그대로** 둔다. ⇒ **단서로 인해 새로 생기는 법적 판단이 0건**이다.

#### ② 상장법인 실권주 재배정 실사례 — ❌ **직접 근거 미발견** (총 8회 검색)

### 🆕 4-5. **v1.2 재검토 — A 권고 철회, C 채택**

#### C-1 🔴 §4-4는 **내가 세운 게이트를 내 해석으로 우회**했다

§4-3은 「근거 미발견 → C」라는 **기계적** 게이트다. ②가 미발견인데 §4-4는 「게이트의 취지상 A 가능」으로 재해석했다 — 이는 `feedback_unverified_authority_blocks_tax_change`가 경계하는 바로 그 패턴이다. 게이트를 세운 사람이 그 게이트를 해석으로 낮추면 게이트가 아니다.

#### C-2 🔴 「신규 법적 판단 0건」은 **사실이 아니다**

§4-4 표는 「배분 축 = 현행 무변경」이라 했으나 부정확하다:

| | 현행 | A안 |
|---|---|---|
| 배분 **비율** | delta 손해비례 | 동일 ✓ |
| 배분 **대상(금액)** | `b.delta` **그 자체** | **법정 총이익**(delta와 다른 값) |

현행에는 「총이익을 delta 비율로 나눈다」는 개념이 **없다** — delta가 곧 이익이었다. A안은 총이익 ≠ Σdelta 상황에서 **새 배분 규칙**을 도입하며, 다수 증여자일 때 증여자별 귀속액이 바뀌어 §47② 동일인 합산·§53 공제를 통해 **세액이 달라진다**. ⇒ **신규 판단 1건, 근거 미발견.**

#### C-3 🔴 ③-R로 **A의 산식 자체가 미완성**임이 드러남

C-9(순수 제3자배정)에서 §5 공식이 이익을 0으로 만들고, C-10(부분 실권+재배정)에서는 **수증자/증여자 판정이 법정과 반대**다. A를 제대로 하려면 유형별 분기 + 수증자 판정 재설계가 필요하며, 이는 **단서 적용을 훨씬 넘어서는 작업**이다.

#### ⇒ 판정: **C 채택** (§6)

- ②가 미발견인 채로 A를 강행하지 않는다 — §4-3 게이트 문언대로.
- A는 ①(배분 근거)뿐 아니라 ③-R(산식·수증자 판정)까지 해결해야 하므로 **범위가 재산정**돼야 한다. 근거가 확보되면 **새 계획서**로 다시 세운다.

#### 🆕 파생 발견 — **단서와 무관한 기존 불일치**(별건 등록)
