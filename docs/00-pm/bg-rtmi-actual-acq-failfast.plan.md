# 조합원입주권 부담부증여 실지취득가액 미입력 ⑫ fail-fast

> 상위: [bg-successor-rtmi-bundle-gate.plan.md](bg-successor-rtmi-bundle-gate.plan.md) §3 · [bg-successor-rtmi-axis-b.plan.md](bg-successor-rtmi-axis-b.plan.md) §4(미수정으로 남긴 틈). 사용자 지시: 「열거 이전 취득가액 0 틈 진행해」(2026-11-01).

## 1. 증상 (실측)
조합원입주권은 부담부증여에서 **취득가액이 실지취득가액 × 채무비율**(K-4 고정)인 경로(열거 이전 · 보충 승)가 있는데, 실지취득가액(승계취득가액 + 추가분담금 / 원조합원은 종전 부동산 실지취득가액)을 모두 비우면 ⑧은 막지만 ⑫는 **취득가액 0으로 200**이었다 — 양도차익 과대, 막히지 않는 오답.

| 경로(열거 이전 · 승계 입주권, 실지 칸 비움) | 종전 ⑫ | 양도차익 |
|---|---|---|
| 단건 시가 모드 | 400 (Zod `actualAcquisitionTotal` 요구) | — |
| 단건 기준시가 모드 | **200** | 3,000,000,000 (= 양도가액) |
| 함께 양도 묶음(시가) | **200** | 5,485,000,000 (주택 2,485,000,000 + 입주권 3,000,000,000) |
| 축 B 카드 2 비움(시가) | **200** | 2,760,000,000 |
- 원인: ⑫ refine(`transfer-tax-schema-required-refines.ts`)의 실지취득가액 요구는 단건 시가 모드 주 자산에만 있고, 엔진 K-4(`burdened-gift-acquisition.ts` `const total = info.actualAcquisitionTotal ?? 0`)가 0을 그대로 썼다.
- 화면으로는 도달하지 못한다 — ⑧(승계: 승계취득가액 · 원조합원: 종전 부동산 실지취득가액)이 이미 막는다. 직접 호출(API)만 해당. ⑧ ⊇ ⑫ 정합이 한쪽만 맞던 곳이다.

## 2. 변경 (엔진 1곳)
`burdened-gift-acquisition.ts` K-4 분기: **조합원입주권**(`isRightToMoveInValuation`)이고 토지·건물 분리 입력이 없으며 `actualAcquisitionTotal ≤ 0`이면 `INVALID_INPUT`(400)으로 중단한다. 자동 대체값 없음(미입력은 검증 오류).
- 엔진에 둔 이유: 단건·묶음·축 B·기준시가·시가·보충 승이 모두 이 한 곳을 지난다 — ⑫ refine을 경로마다 늘리면 컴패니언 arm 등 복제가 생긴다(「⑫ 요구 위치 복제」 회피).
- 입주권 한정: 비입주권 K-4는 총액 0을 다른 경로가 쓴다(가드를 전 종류로 넓힌 뮤테이션에서 기존 2건 적색).
- 쓰이지 않는 경우는 막지 않는다 — 열거 이후 승계 담보·임대 승(기준시가 강제)은 `acqStdPriceForced` 분기가 먼저라 실지 칸을 비워도 200.
- ⑤⑥⑦⑧ 변경 없음(⑧이 이미 요구). 14지점 중 ⑭ 엔진 입력 쪽만.
