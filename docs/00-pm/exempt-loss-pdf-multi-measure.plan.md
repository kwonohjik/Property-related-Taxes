## 1. 측정 설계 [직접]

- P1 함께 양도: 토지(취득 100,000,000·양도 200,000,000) + 상속 주택(취득가 700,000,000·양도 500,000,000, 1세대1주택 비과세), 일괄 총액 700,000,000 → `/api/calc/transfer` → `aggregateToFilingResult` → `TransferSection`.
- P2 비과세 손실 단건 → `TransferSection`.
- P3 다건: `calculateTransferTaxAggregate`로 토지(300,000,000/100,000,000) + 비과세 손실 주택(500,000,000/700,000,000) → `TransferMultiSection`.
- P4 같은 다건 결과의 주택 breakdown → `breakdownToFilingResult` → `buildRows`·`buildStatementItems`.
