## 2. 핵심 산식 — 호별 고시 전 취득의 환산취득가

상업용건물·오피스텔은 2005-01-01부터 국세청이 **호별 ㎡당 기준시가**를 고시. 2000년 취득 시점은 호별 고시가 없으므로 **토지·건물 ㎡당 기준시가 비율**로 최초고시액을 역환산.

```
최초고시 호별총액  = 최초고시(2005) ㎡당 호별고시가 × 연면적
취득시 환산기준시가 = INT( 최초고시 호별총액 × (취득시 토지·건물 ㎡당기준시가합) / (최초고시시 토지·건물 ㎡당기준시가합) )
양도시 호별총액    = 양도시(2022) ㎡당 호별고시가 × 연면적

환산취득가(합계)  = INT( 양도가액 × 취득시 환산기준시가 / 양도시 호별총액 )
환산취득가(토지)  = INT( 환산취득가합계 × (취득시 토지/(토지+건물)) )
환산취득가(건물)  = 환산취득가합계 - 환산취득가(토지)
```

여기서 **㎡당 기준시가합** = 개별공시지가 × 대지면적 + 건물 ㎡당 기준시가 × 연면적.

### 토지·건물 분리 흐름
- 양도가액 540,000,000 → 양도시 호별총액(C33) 비율로 토지/건물 분배
- 각 항목별 양도차익·장특공·산출세액 계산 후 **합산**
- 장특공률 = MIN(15, 보유연수) × 2% (소법 §95② 표1 일반자산. 1세대1주택 표2 80%는 적용 안 함)
- 보유연수 산정: 취득일 ~ 양도일, **1년 미만 절사** (소법 §95④)
- 기타필요경비 = 환산취득가 × **3%** (토지·건물 모두 동일률, 소법 §97②2호 + 시행령 §163⑥ — 자산별 개산공제율: 토지·건물 3%, 지상권·전세권 7%, 부동산취득권리 1%. 본 자산은 토지·건물이므로 3% 사용)

| 케이스 | 자산종류 | 취득시점 | 모드 | 비고 |
|---|---|---|---|---|
| C-01 ★ | commercial_building (상업용·오피스텔) | 호별고시 전 (~2004) | 환산 | **사례 29 anchor** |
| C-02 | commercial_building | 호별고시 후 (2005~) | 환산 | 양도시·취득시 모두 호별고시가 사용. 토지·건물 분리 환산은 단순 비율 |

## 5. UI 설계 골격

### Step 1 (자산 정보)
신규 자산종류 옵션 "**상업용건물·오피스텔**" 추가. 선택 시:
- **취득원인 카드**: 일반취득(매매) + (필요 시 상속/증여 — 후속 PDCA)
- **모드 토글** (`ToggleCard`): "환산취득가 사용" ON/OFF
  - OFF → 기존 실가 입력 (취득가액 직접)
  - ON → 호별고시 시점 분기 라디오 (`RadioCardGroup`):
    - "호별 고시 전 취득 (~2004.12)" → 3종 데이터 모두 입력 (C-01)
    - "호별 고시 후 취득 (2005.1~)" → 호별고시가만 (C-02)
- **면적 카드**: 전용·공유·대지 (`DecimalInput`)
- **호별 고시가 카드**: 양도시·최초고시(2005) ㎡당 가액 (CurrencyInput)
- **건물 ㎡당 기준시가 카드** (C-01 only): 취득·최초고시·양도 3시점
- **개별공시지가 카드**: `LandPriceLookupField` 3시점

### 결과 화면
- 환산취득가 산정 근거 표 (엑셀 B33~E41 재현):
  - 양도시 / 취득시 / 최초고시시 × 토지 / 건물 / 합계
- 토지·건물 분리 양도차익·장특공·산출세액 → 합산
- 산식 한국어 풀어쓰기 (변수약어 금지)

### 주의 사항
- placeholder 숫자 예시 금지 → FieldCard `hint` prop
- 모드 토글은 영향 필드 직전 배치
- 0원 항목 사이드바 합계 제외

## 8. 위험·미해결

1. **건물 ㎡당 기준시가 데이터** — 사용자 수동 입력 전제. 추후 자동 조회 PDCA는 별도 분리.

5. **2005년 최초고시 자산이 아닌 경우** (수도권·5대광역시 외, 3000㎡ 미만 등) — UI 안내 텍스트로 처리, 엔진은 사용자 입력 신뢰.
