## 1. 배경 — 데이터와 두 이력

### 1.1 이력은 하나다 (확정)

- 단일 원천: `REGULATED_REGIONS` (`lib/tax-engine/data/regulated-areas-data.ts:106~`). **109개 지역 = 2자리 1건(`"11"` 서울 전역) + 5자리 108건**, 코드 중복 0 (probe `data-summary`).
- `isRegulatedByBjdCode`(`regulated-areas.ts:164`)는 이 배열을 그대로 쓴다.
- 엔진의 `RegulatedAreaHistory`는 같은 배열을 `toRegulatedAreaHistoryFrom`(`regulated-areas.ts:256-265`)으로 **투영**한 것이다 — `code/name/designations`만 남기고 `excludedSubCodes`·`includedSubCodes`는 **버린다**. 주입은 `transfer-tax-helpers.ts:149`.
- Supabase `regulated_areas` 테이블(`supabase/migrations/20260413000002_create_regulated_areas.sql`)과 DB 키 `transfer:special:regulated_areas`는 **읽는 곳이 없다**(`rate-table.schema.ts:210-215, 273-274` 주석 · `from("regulated_areas")` grep 0건).

⇒ 두 이력은 **같은 원천의 정밀본과 축약본**이다. 축약본(`RegulatedAreaHistory`)은 5자리 코드와 동·지구 규칙이 빠진 형태라 10자리 입력을 받을 수 없다.

### 1.2 5자리로 표현할 수 없는 지정 (확정)

- 하위 규칙이 있는 지역: `excludedSubCodes` **25개** · `includedSubCodes` **13개**(probe). 예: 용인 처인구 포곡읍 등 제외(`regulated-areas-data.ts` 처인구 엔트리), 수원 영통구 광교택지 4개 동만 2018-08-28~2020-02-20 지정.
- 하위 규칙 경계 중 어떤 `designatedDate`와도 겹치지 않는 날: **2018-12-31**(팔달·수지·기흥 구 전역 확대 — 광교택지 한정 규칙의 `appliesTo` 2018-12-30 다음 날), 2019-11-08(부분 해제 시작), 2022-11-14(probe `p2`). 2018-12-31은 **지정 사건**인데 명부에 날짜로 존재하지 않는다.
- 실측(`isRegulatedByBjdCode`): `4111510100`(팔달) 2018-12-30 미지정 → 12-31 지정 · `4111710500`(영통, 광교 4개 동 밖) 2020-02-20 미지정 → 02-21 지정. 5자리 `41117`은 전 기간 「지정(medium)」.

## 4. 법령 독해

### 4.1 조문 (확정 — KoreanLaw MCP MST 286211 현행 · MST 204914 2018.10.23. 시행본)

네 호의 문언이 같다: 「조정대상지역의 공고가 있은 날 이전에 해당 지역의 주택을 **양도하기 위하여** 매매계약을 체결하고 계약금을 **지급받은** 사실이 증빙서류에 의하여 확인되는 주택」 — §167의3①11호 · §167의4③5호 · §167의10①11호 · §167의11①10호. 2018.10.23. 신설 이후 현행까지 문언 변경 없음(2018.10.23. 시행본과 현행 대조).

- **양도 측 계약이다.** 이 주택을 **팔기 위한** 계약 + 계약금 **수령**. 이 주택의 취득 계약이 아니다(⇒ D-3).
- 계약금 일부만 공고일 전에 받은 경우도 해당 — 조심2022구6631(2022.12.13., 취소) · 조심2022서6067 같은 뜻.
- 수용: 공고일 전 수용재결만으로는 해당하지 않음(과세기준자문 2021.3.12. — 「조정대상지역의 공고가 있은 날 후에 대금을 청산한 날, 수용의 개시일 또는 소유권이전등기접수일 중 빠른 날이 도래하는 주택은 … 제11호에 해당하지 않는」). 이 계산기 입력과 무관(범위 밖).

### 4.2 「공고가 있은 날」

1. **주택법상 공고일**이다 — 기재부 재산세제과-73(2022.1.11.)이 11호(§167의10①11호)에 대해 세 안(2017.8.3. / 2017.9.6. 예정지 공고 / 2017.11.10. 주택법 법률 제14866호 시행) 중 **제3안(2017.11.10.)**을 택했다(서면-2019-법규재산-4276 회신 본문). §155①2호도 같은 결론(사전-2022-법규재산-0326).
2. 공고일과 효력일이 다를 수 있다 — 사전-2019-법령해석재산-0067: 「해당 지역이 조정대상지역으로 지정되는 공고의 **관보게시일**과 계약체결일 … 에 따라 판단」. 2018 이후 확인된 차수는 공고(발령)일 = 효력일이었다(§1.3 표).
3. **당일 포함** — 서면-2021-부동산-0624(§154①5호 거주요건, 같은 문구 「공고가 있은 날 이전에」): 공고일(2020.12.18.)에 계약·계약금 지급 → 「공고 이전에」 해당. 11호에 대한 직접 해석은 미확보(문언 동일에 따른 적용 — 확인 필요 Q-2).

### 4.3 해제 후 재지정·동 단위 편입 — 어느 공고인가

- 문언은 「조정대상지역의 공고」 — 차수를 특정하지 않는다.
- 유사 해석: 종부세 합산배제 제외규정(서면-2025-부동산-3811, 2025.10.31.) — 「조정대상지역 지정 공고가 여러 차례 있는 경우 **해제되어 실효된 공고가 아니라** 매 과세연도마다 과세기준일 현재 **유효한 공고**를 기준으로」. 11호에 대한 직접 해석은 미확보.
- 11호의 기능은 양도 당시 중과 대상(조정대상지역 소재)이 된 원인이 계약 뒤에 생긴 경우를 보호하는 것이다. 양도일에 효력이 있는 공고(그 주택 소재 동을 조정대상지역으로 만든 공고)를 기준으로 보는 것이 위 해석과 같은 구조다. 현행 「최초 지정일」 기준은 재지정 지역에서 계약 시점에 비조정이었던 계약까지 배제하지 않는다(probe E).
- ⇒ 권고 독법: **양도일이 속한 연속 지정 구간의 시작을 만든 공고**. 사용자 결정 Q-1.
