# 겸용주택(주택+상가) × 부담부증여 실구현 — 통합 계획서

> 상태: **Design 완료 · G-1~G-13 전부 권고안으로 확정(2026-10-16 사용자 「권고대로 진행해」) · Do 진행 중** · 선행: #2211(이 조합을 ⑧·⑫에서 차단)
> 설계서: 엔진 `docs/02-design/features/transfer-burdened-gift-mixed-use.engine.design.md`(R3) · UI `docs/02-design/features/transfer-burdened-gift-mixed-use.ui.design.md`(R2)
> 두 설계서의 결정 번호(Q-n)는 서로 다른 뜻이라, 이 문서에서 **G-n으로 다시 매겼다**. 남은 불일치는 없다(엔진 §10 · UI §16). 단 엔진 R4가 추가한 MB-16·MB-17의 UI 행·문구는 G-13 결정 후 Do에서 확정한다.

## 1. 왜 지금 막혀 있나 (실측)

- 겸용 경로(`calcMixedUseTransferTax`)에는 단건의 STEP 0.48(§159) 같은 단계가 없다. ④가 부담부증여면 채무 합계를 `transferPrice` 임시값으로 보내는데(`lib/calc/transfer-tax-api.ts:232-234`), 겸용 엔진은 그 값을 물건 전체 양도가액으로 쓰고 취득가액은 채무비율을 곱하지 않은 채로 뺀다 → 양도차손 → 결정세액 0(엔진 설계서 §1.2 재현).
- `BurdenedGiftInfo`는 토지·건물 2부분 모델이라 주택건물·주택부수토지·상가건물·상가부수토지 4부분을 담지 못한다.

## 2. 법령·해석 근거 (KoreanLaw MCP 본문 확인 — 소득세법 시행령 MST 290841)

| 근거 | 내용 | 설계 반영 |
|---|---|---|
| 시행령 §159① | 취득가액·양도가액 = 각 가액 × 채무액 ÷ 증여가액. 양도가액을 기준시가로 산정하면 취득가액도 기준시가 | 4부분 각각에 부분별 채무비율 |
| 시행령 §166⑥ → 부가세령 §64①1호 | 토지·건물 가액 구분이 불분명하면 기준시가 비율로 안분. **다만 감정평가가액이 있으면 그 가액 비율로 안분** | 증여가액을 주택·상가로 나누는 법정 안분(G-5·G-13) |
| 시행령 §160① 괄호 | 고가주택이면 「주택 외의 부분은 주택으로 보지 않는다」 — 2022.1.1. 이후 양도분(부칙 제30395호 제1조3호·제42조) | 고가 겸용은 주택분만 주택 |
| **국세청 부동산거래관리과-119 (2010.01.22.)** | 「증여가액 중 그 채무액에 상당하는 부분이 주택 또는 상가에 대한 부분으로 **구분이 분명한 경우에는 그 채무액이 속하는 주택 또는 상가의 양도로 보아** 양도차익을 산정」(사실관계: 주택<상가, 상가 임차보증금 1억). taxlaw.nts.go.kr 원문 Playwright 열람 | **채무 귀속 축 신설**(엔진 D-7) — 채무를 4부분에 같은 비율로 나누면 이 해석과 충돌한다 |

## 3. 설계 요지

- **엔진**: 새 서브엔진을 만들지 않고, 겸용 엔진에 부담부증여 단계를 하나 얹는다. 채무 상당 양도가액을 겸용 엔진에 넣으면 양도가액 4부분 안분·장특·비과세·중과·세율은 기존 경로가 그대로 계산한다. 새로 필요한 것은 취득가액·개산공제·실비에 부분별 채무비율을 곱하는 일과 12억 판정 기준이다.
- **채무 귀속**: 인수 채무를 「주택 귀속 / 상가 귀속 / 구분 불분명」으로 필수 입력받는다. 불분명분은 주택·상가 증여가액 비율로 안분하고, 부분마다 「채무 ≤ 증여가액」을 검증한다. 전부 불분명으로 입력하면 균일 비율과 1원까지 같다(M-10′ = M-1).
- **한쪽에만 귀속**되면 다른 쪽은 양도가 없다. 결과에는 「비과세」가 아니라 「양도 없음(증여세 대상)」으로 표시한다.
- **차단 판정은 한 함수**(`collectMixedBurdenedGiftIssues`, MB-1~MB-15)를 엔진·⑫·⑧이 공유한다. UI는 그 위에 더 좁은 v1 제한만 얹는다(UI 허용 ⊂ 엔진 허용).
- **화면**: 4부분 기준시가는 지금 위치(겸용 패널)를 유지하고, 부담부증여 블록에는 읽기 전용 요약과 「채무 귀속」 카드를 둔다. 엔진이 읽지 않는 중복 칸(양도시·취득시 총액, 증여세용 건물 기준시가)은 숨긴다. 결과는 `MixedUseResultCard` 하나로 모인다.

## 5. 확인 필요 (법령·해석 근거 미확보)

- V-D 실비(자본적지출·양도비)에 채무비율을 곱하는 것은 §159① 법문(취득가액·양도가액)에 없고 단건의 기존 규약이다 · V-E 부담부증여 양도시기 = 증여일의 법령 근거 · V-F 의제취득일(1985.1.1.) 전 취득 × 환산(K-5) 경로
- V-17 구분 불분명 채무 안분(G-2) · V-18 부분 단위 초과부담부를 오류로 보는 것(법문·해석례에 부분 단위 규정 없음) · V-19 해석례 범위(주택<상가·임차보증금·2010년 사안만 답함, 담보대출 귀속 기준 미답) · V-20 귀속 증빙(임대차계약서 임차 대상, 근저당 설정 대상)
- V-4 부가세령 §64①1호 단서(감정평가가액 우선)는 기존 겸용 엔진도 미구현이다. 부담부증여 시가 모드는 증여가액이 감정가액인 경우가 많아 **이 조합에서 위험이 커진다**(G-13) · V-6 §114조의2 신축 가산세가 겸용 엔진에 없음(→ 신축 취득 차단 MB-15) · V-9 12억+1원에서 상가분만 과세되는 경계는 기존 거동 · V-13 배율초과·중과·미등기 × 겸용 부담부증여 수치 미실측

## 6. 수치 상태
