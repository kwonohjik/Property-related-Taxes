### 7.1 V-2 실측

- **컴패니언(함께 양도)** — 주택 주 자산 + 비주택 건물 컴패니언(신축 donor): 특례 없음 base 250,000,000 / 공매·수용 **500,000,000**(= 배분 양도가 5억 × 2억/2억), 양도차익 −6,000,000(A와 일치). 단건 엔진 경로(`calculateTransferTax` → `calcCarryoverScenarios` → `withDonorBuiltPenalty`)를 그대로 타므로 DP-6 수정이 같이 적용된다 [직접].
- **다건 `/api/calc/transfer/multi`** — 신축·증축 × 특례 없음·공매 4칸 모두 **단건과 base·가산세·양도차익 일치**(신축 150,000,000→300,000,000, 증축 22,500,000→45,000,000) [직접].
- **일반건물 이월과세 라우트(F27 건물 카드)** — 수용을 켜면(최상위 `transferCause`·`compensationPerSqm`) **토지** 환산취득가가 250,000,000 → 500,000,000으로 바뀌지만 **건물** 환산취득가·가산세 base는 250,000,000 그대로다. `general-building-converted-acquisition.ts`가 «건물 환산취득가 — 분모 무변경(§164⑨ 미적용)»으로 설계했기 때문이다(D16-GB) [직접: 코드 + 실측]. 그래서 같은 카드 안에서 base와 A 건물 취득가가 갈리지 않는다. 건물 분모에 §164⑨를 적용해야 하는가는 별개의 법령 문제이고 이번 범위가 아니다 [확인 필요].
- **분리 취득 이월과세 파트(P6)·부담부증여(BG)** — `transfer-tax-split-carryover.ts`에는 §164⑨·공매·수용 참조가 없고(grep 0건), BG 가산세 base는 §159 step이 만든다. 이 둘이 특례 분모를 아예 받지 않는다는 것은 **정적 확인**이고 실측하지 않았다 [확인 필요].

### 7.3 V-3 별건 — 특례 분모의 지분 척도 [확인 필요]
