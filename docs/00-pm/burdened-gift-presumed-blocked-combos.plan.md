# 부담부증여 매매사례가액·감정가액 — 1차 차단 조합 해소 (이월과세 · 지분 분할 취득 · 상속 · 조합원입주권)

> 선행: #2196(K-6/K-7 화면·엔진) · #2199(§114조의2) · #2200(증여세 마법사). 사용자 결정(2026-10-14)을 아래에 박제한다.

## 1. 네 조합의 법적 지위 (KoreanLaw MCP 본문 확인 2026-10-14)

| 조합 | 판정 | 근거 | 처리 |
|---|---|---|---|
| **상속** | **법령상 해당 없음** | 소령 §163⑨ — 상속·증여받은 자산의 §97①1호가목 실지거래가액은 상속개시일(증여일) 현재 상증법 평가액으로 본다 → 가목이 늘 존재해 나목(매매사례·감정·환산)에 닿지 않는다 | **차단 유지 + 안내 보강**(결정). 대신 쓸 방식을 문구에 적는다: 「실지취득가액」에 상속개시일 평가액 |
| **조합원입주권** | **법령상 해당 없음** | 소령 §166③ — 기존건물·부수토지의 취득가액을 확인할 수 없으면 취득일·인가일 현재 기준시가 비율 **환산식을 직접 규정**한다. §166④2호의 매매사례·감정(§176의2③1·2호)은 **「평가액」** 산정이지 취득가액이 아니다 | **차단 유지 + 안내 보강**(결정) |
| **이월과세**(§97의2) | **지원 가능** | 소법 §97의2①1호 — 취득가액은 당초 증여자가 **취득할 당시의 §97①1호 금액**이며 나목이 포함된다. 비교 대상인 양도인 본인 쪽은 증여받은 자산이라 소령 §163⑨(증여일 상증법 평가액)가 적용된다 | **구현**(결정: 당초 증여자 값만 새 방식, 양도인 값은 증여일 평가액) |
| **지분 분할 취득**(축 B) | **지원 가능** | 취득일 전후 3개월 값이 지분마다 다르다(소령 §176의2③) | **구현**(결정: 지분별 각자의 값을 받아 합산) — 별도 PR |

## 2. 이월과세 설계

엔진은 이미 두 시나리오를 돌린다(`transfer-tax-carryover.ts`): **A**=당초 증여자 기준(`applyCarryoverDonorBasis`가 `burdenedGiftInfo` 사본 치환), **B**=양도인 기준(`buildInputB`는 `rawInput`을 그대로 쓴다).

- 입력 의미: `info.acquisitionMethod ∈ {salesCase, appraisal}`는 **당초 증여자 쪽** 방식이다. 당초 증여자 값은 `carryoverDonorBasis.presumed{Land,Building,Total}`(신설), 양도인의 증여일 상증법 평가액은 기존 K-4 칸 `actual*`에 싣는다.
- A: `applyCarryoverDonorBasis`가 `presumed*`를 당초 증여자 값으로 **직접 치환**(양도인 값으로 fallback 금지)하고, 개산공제 base인 취득시 기준시가도 당초 증여자 값(기존 `landStd/buildingStdPriceAtAcquisition`)으로 치환된다.
- B: 새 `toTransferorBasisInfo`가 `acquisitionMethod: "actual"`·`presumed*` 제거로 바꾼다(§163⑨ — 양도인 쪽은 가목). 그래서 양도인 `actual*`가 필수다.
- 게이트 `assertCarryoverDonorBasis`: 종전 K-6/K-7 차단을 풀고 ① 당초 증여자 presumed 금액 ② 당초 증여자 취득시 기준시가 토지·건물 ③ 양도인 actual 금액을 요구한다(미입력 fallback 금지 — 침묵 A=B 무력화 방지).
- **계속 차단**: 신축·증축 5년 이내 × 감정가액 × 이월과세 — §114조의2의 5년 기산(당초 증여자 취득일 vs 신축일)과 base(A/B 어느 쪽 건물 감정가액)가 미정이라 가산세가 조용히 틀릴 수 있다. 엔진·⑤·⑧ 같은 술어.
- 화면: 이월과세 박스에 당초 증여자 매매사례가액·감정가액 칸(`bgCoDonorPresumedAcquisition{Land,Building,Total}`, 입력 형태는 `bgPresumedInputKind`), 양도인 칸은 실지취득가액 블록을 새 방식에서도 보여 「증여받은 때의 상증법 평가액」으로 라벨한다.

## 3. 상속·입주권 안내 보강

`bgPresumedBlock` 문구에 대체 경로를 적고(상속은 기존대로, 입주권은 「환산」 대신 정확한 설명), 입주권은 현재 라디오가 아예 렌더되지 않으므로 ⑤에 짧은 안내 한 줄을 추가한다.

## 4. 검증 기준

- 이월과세 × 감정가액/매매사례: 엔진 anchor(A·B 두 시나리오 값·채택·미입력 가드·신축 감정 차단) · Zod 라우트 · ④ · ⑧ · ⑤ · E2E
- 기존 이월과세 × K-4/K-5 회귀 0

## 5. 미검증

- 이월과세 × 부담부증여에서 당초 증여자 취득가액을 감정·매매사례로 구하는 것을 정면으로 다룬 해석례는 확인하지 못했다(문언 §97의2①1호 + §97①1호나목 + 재산세과-1059 해석에 의존).
