### 1-1. A — 페이지 컨테이너가 내용 폭으로 늘어난다

- `app/layout.tsx:68` `<body className="min-h-full flex flex-col">`의 **직계 항목**인 페이지 컨테이너가 `mx-auto max-w-…`만 있고 `w-full`이 없다.
- flex 항목에 좌우 auto 여백이 있으면 늘이기(stretch)가 꺼지고 **내용에 맞춘 폭**이 된다. 그래서 말줄임(`truncate`)·줄바꿈 금지(`nowrap`) 글자가 줄지 않고 컨테이너를 넓힌다.
  - 건물 기준시가(`app/tools/building-standard-price/page.tsx:24`): 「건물 용도」 Select 값 309px, 계산서 섹션 제목(`truncate`), 계산서 표 — 컨테이너 443·405·525px.
  - 계산 이력(`app/history/page.tsx:10`): 이력 제목(`truncate`) 333px — 컨테이너 443px.
- 실험: 컨테이너에 `max-width:100%`를 주니 문서 폭이 375로 돌아왔다(계산서 표가 펼쳐진 화면만 표 자체 때문에 496 — B 묶음).
- **같은 구조인 경로를 전수 확인**(주요 경로 14개를 새로 열어 봄): `/history` · `/tools/building-standard-price` · **`/profile`**(`app/profile/page.tsx`) 3곳뿐이다. 다른 계산기 페이지는 한 겹 더 감싸여 있어 해당하지 않는다.
- 처음 열었을 때는 넘치지 않는다. 긴 값이 들어간 상태에서만 난다.

## 3. 구현 시 주의(코드 확인)

- **인쇄**: `ReportEvalTable`(국세청 계산서)·의제증여 표는 인쇄 대상이다. `overflow-x-auto` 상자는 인쇄에서 표를 자를 수 있으므로 `print:overflow-visible`을 함께 넣는다. 인쇄 E2E(`selective-print.spec.ts` 등)로 확인한다.
- **R의 범위**: 같은 모양의 `ExitTaxResultCard.tsx:54`(국외전출세)도 함께 고친다(같은 `Row` 구조, 375 넘침은 미측정 — 확인 필요).
- **E의 범위**: 공용 `ExpandToggleButton`이 아니라 **머리 줄**(`DeductionBesshiFormsSection.tsx:88`)에 `flex-wrap`을 준다. 모사에서 함께 줄어든 다른 머리 줄은 Do 1단계에서 위치를 특정해 같은 처리를 할지 정한다.
- **H**: 세무사 모드 + 의뢰인 배너가 있을 때만 375에서 제목이 말줄임된다. 일반 화면에서는 지금도 넘치지 않는다(경로 14개 새로 열어 확인).
