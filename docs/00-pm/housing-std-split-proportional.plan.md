## 0. 요약

개별주택가격·공동주택가격(「소득세법」 §99①1호 라목 — 부수토지 포함 결합 공시)을 토지분·건물분으로 나눌 때

- **국세청·조세심판원·집행기준 = (B) 비례 안분**: 토지분 = 주택가격 × 가목 ÷ (가목 + 나목), 건물분 = 주택가격 × 나목 ÷ (가목 + 나목). 가목 = 개별공시지가 × 부수토지 면적, 나목 = 국세청 건물 기준시가 산정방법을 **건축물대장 연면적**으로 준용한 값.
- **현행 계산기 = (A) 뺄셈 역산**(일부 경로): 건물분 = 주택가격 − 가목. 근거는 코드 주석(「결합 공시라 건물분 단독 공시가 없으므로 역산이 정본」 — `transfer-tax-split-acq-price.ts:26-27`, `transfer-tax-split-acq-mode.ts:261-262`)뿐이고, **(A)를 지지하는 문헌은 찾지 못했다.** 주택가격 < 가목이면 (A)는 건물분 음수(실제 사안 재산세과-463: 개별주택가격 419백만 < 공시지가 합계 644백만).

⇒ **(A)는 법령·실무와 어긋난다.** 다만 세액이 움직이는 것은 토지·건물 배분이 세액에 닿는 경로뿐이다(§3).

## 3. 영향 (가상 fixture, 가목+나목 = 1.25 × 주택가격, 산출세액 기준 — 엔진 수정 없이 비례값을 입력해 재현, 1원 일치 검증 포함)

- 총 양도차익은 불변 — 토지·건물 배분만 바뀐다. 세액이 움직이는 조건: 파트별 장기보유공제율 상이 · 소유자 분리 · 환산 척도 불일치 · 비과세 + 배율 초과분.
- 부호 혼재 — 납세자 유·불리로 단정하지 않는다.
- 두 방식은 **주택가격 = 가목 + 나목**일 때만 같다. 실제 괴리 근거는 저장소의 Excel 정본 fixture 1건(+48.8%·+58.2%) — 「흔하다」는 단정 불가(표본 확인 필요).
