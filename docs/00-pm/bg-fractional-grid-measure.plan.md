## 1. 방법

#2750 의 `cell()`(⑧ 게이트 수 · ⑫ 상태 · 합산 증여가액 · 양도차익 · 총세액 · 카드 채무)을 격자로 돌렸다. 셀마다 불변식:

| | 불변식 | 근거 |
|---|---|---|
| (a) | ⑧ 통과 → ⑫ 200 | ⑫ 가 ⑧ 이 허용한 입력을 막지 않는다 |
| (b) | 자산별 승자가 서로 다르면 ⑫ 400 | 혼합이면 합산 증여가액 < ΣA (#2746) |
| (c) | ⑫ 200 이면 합산 증여가액 = ΣAᵢ(±2원) · 카드 채무 합 = 폼 채무 합(±0) | Σmax = max(Σ성분)은 승자가 같을 때만. 채무 재배분의 「마지막 자산 잔액 흡수」(`apportionCompanionBurdenedGiftDebt`) |
| (d) | 균일 비보충 승이면 양도차익 = 자산별 단건 지분 실행의 합 | 담보·임대가 이기면 Aᵢ = Bᵢ 라 가산된다 (#2750) |
| (e) | 균일 보충 승이면 「지분율 100% · 시가·면적·금액 ×r」 환산 오라클과 증여가액 ±0 | 보충 승 영역에서만 유효한 오라클 (#2750 §7) |

승자는 ⑧ 과 같은 `companionBurdenedGiftValuations`(`transfer-tax-api-burdened-gift.ts`)로 구해 ⑫ 결과와 대조했다.
시료 주의: 채무 4억(`sup`)은 지분 1/3·25% 에서 지분 시가(3.33억·2.5억)보다 커 **담보 승**이 된다 — 보충 승 균일 쌍은 채무 2억·1억(`supL`·`ssupL`)으로 따로 만들었다. (처음 91셀 격자에서 `sup+sup@r1/r3` 이 혼합으로 나와 알게 됨.)
