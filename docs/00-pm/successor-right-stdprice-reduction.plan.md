## 0. 한 줄 요약

승계조합원 입주권은 일반 「취득시·양도시 기준시가」 칸이 **화면에 없다**(`CompanionAcqPurchaseBlock.tsx:370`). 환산 모드에서는 그 대신 §165① 네 칸(납입액 + 프리미엄)이 보이고 ④가 그 합계를 보낸다.

- **D1 (세액이 바뀜)** — **함께 양도한** 승계 입주권이 **실가 모드**면 ④가 화면에 없는 일반 양도시 칸의 옛 값을 보내고, 감면 카드의 양도시 기준시가가 비면 §98의3·§99의3 등이 **그 값으로 5년 안분**을 한다. 결정세액 296,490,000(옛 값 없음) → 237,690,000(옛 값 7억) / 257,290,000(9억).
- **D2 (⑧이 다른 칸을 봄)** — 승계 입주권 **환산 모드**에서 엔진은 §165① 양도시 합계를 폴백으로 쓰는데, ⑧ §99의3은 화면에 없는 일반 칸을 본다. 일반 칸이 비면 쓸 값이 있는데도 막고, 옛 값이 있으면 통과시킨다(그리고 계산은 §165① 값으로 한다).

수정안: #2346의 leaf(`redevHiddenGeneralStdPrice`)가 «화면에 없는 일반 칸»을 판정할 때 **승계 입주권도 포함**하게 넓히고, ⑧은 승계 입주권 환산 모드에서 ④가 보내는 값(§165① 합계, 같은 leaf `successorRightStdPriceAtTransfer`)을 인정한다. 엔진은 바꾸지 않는다.

## 2. 법령 (확인 필요 — 이번 수정은 세액 해석을 바꾸지 않는다)

- 「소득세법」 제99조제1항제2호가목 — 「부동산을 취득할 수 있는 권리: 양도자산의 종류, 규모, 거래상황 등을 고려하여 대통령령으로 정하는 방법에 따라 평가한 가액」. 다만 그 항의 머리는 「**제100조 및 제114조제7항에 따른** 기준시가는」이다.
- 「소득세법 시행령」 제165조제1항 — 「취득일 또는 양도일까지 납입한 금액과 취득일 또는 양도일 현재의 프리미엄에 상당하는 금액을 합한 금액」.
- 「조세특례제한법 시행령」 제99조의3제2항제2호 — 감면대상 양도소득금액 = 양도소득금액 × (신축주택 취득일부터 5년이 되는 날의 기준시가 − 신축주택 취득 당시 기준시가) ÷ (양도 당시 기준시가 − 신축주택 취득 당시 기준시가). 「기준시가」를 따로 정의하지 않는다.

입주권을 양도할 때 조특령의 5년 안분 「양도 당시 기준시가」에 영 §165① 평가액을 쓰는지 정한 명문·해석례는 찾지 못했다. **Q-2 a**: 엔진 현행 동작(§165① 값 폴백)을 유지하고 ⑧만 그 값에 맞춘다 — 세액이 바뀌는 쪽(b)은 근거 확인 전에는 착수하지 않는다.

## 3. 원인

#2346은 «화면에 없는 일반 칸»을 `redevHidesGeneralAcqSection`(원조합원 §166 자산)으로만 정의했다. 그런데 ⑤ 게이트는 그 술어에 `isSuccessorRightTransfer`를 **OR로 더 붙여** 승계 입주권도 숨긴다. ⑤와 ④·⑧의 «숨김» 정의가 갈라졌다.

- ④ 컴패니언은 «숨김이 아니면 일반 칸을 보낸다»이므로 승계 입주권 실가 모드에서 숨은 칸을 보낸다(D1).
- ⑧은 «숨김이 아니면 일반 칸을 인정한다»이므로 승계 입주권에서 숨은 칸을 인정하고, 정작 ④가 보내는 §165① 합계는 보지 않는다(D2).

## 4. 수정안

### 4.1 leaf — «일반 기준시가 영역이 화면에 없는가»를 하나로

`lib/calc/redev-acquisition-price-source.ts`:

```ts
/** 일반 「취득가액 산정 방식·기준시가」 영역이 화면에 없는가 — ⑤ 게이트와 ④⑧ 숨김 판정의 단일 소스. */
export function hidesGeneralAcqSection(asset): boolean {
  return redevHidesGeneralAcqSection(asset) || isSuccessorRightTransfer(asset);
}
```
