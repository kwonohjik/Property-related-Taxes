## §1 문제

상속인이 아닌 사람이 유증·사인증여로 받은 자산(`nonHeirBequest`)은 취득원인을 「상속」으로 고른다 — 취득가액·취득시기는
상속과 같다(사전-2015-법령해석재산-0095: 사인증여 취득시기 = 상속개시일). 갈리는 것은 **상속 특례**다. #2297·#2301·#2305가
소득세법 쪽 특례를 정리했고, 조특법 감면 두 갈래가 남았다.

| 갈래 | 조문 | 현행 코드 | 수유자 처리 |
|---|---|---|---|
| ① 자경농지 피상속인 경작기간 합산 | 조특령 §66⑪·⑫ | `self-farming-reduction.ts:231` `canAggregateDecedent` — 취득원인·수유자 여부를 보지 않는다 | **상속인과 같이 합산** |
| ② 수용 감면 취득일 소급 | 조특법 §77⑨ · §77의3③ | `public-expropriation-reduction.ts:531` `inheritedAcquisitionDate` — `cause === "inheritance"`만 본다 | **상속인과 같이 소급** |

## §2 법령 · 해석 (원문 확인)

### 조특령 §66⑪·⑫ (현행 · 2018.2.13. 개정본 동일 문언)
- ⑪ 「경작한 기간을 계산할 때 **상속인이** 상속받은 농지를 1년 이상 계속하여 경작하는 경우 … 다음 각 호의 기간은
  **상속인이** 이를 경작한 기간으로 본다. 1. 피상속인이 취득하여 경작한 기간 … 2. … 피상속인의 배우자가 취득하여 경작한 기간」
- ⑫ 「제11항에도 불구하고 **상속인이** 상속받은 농지를 1년 이상 계속하여 경작하지 아니하더라도 … 상속받은 날부터 3년이
  되는 날까지 양도하거나 … 수용되는 경우로서 … 지정되는 경우 … 제11항제1호 및 제2호의 경작기간을 **상속인이** 경작한 기간으로 본다」

### 조특법 §77⑨ · §77의3③ (현행 원문)
- §77⑨ 「제1항 및 제2항을 적용하는 경우 **상속받거나** 「소득세법」 제97조의2제1항이 적용되는 증여받은 토지등은
  피상속인 또는 증여자가 해당 토지등을 취득한 날을 해당 토지등의 취득일로 본다」
- §77의3③ 「제1항 및 제2항을 적용하는 경우 **상속받은** 토지등은 피상속인이 해당 토지등을 취득한 날을 해당 토지등의 취득일로 본다」

## §3 결정 (2026-10-20 사용자 확정: **Q-1 (b) · Q-2 (a) · Q-3 (a)**)

### Q-1 §77⑨·§77의3③ — 수유자에게 피상속인 취득일 소급을 적용하는가 → **(b) 소급 미적용 + 고지**
- **(a) 현행 유지(소급 적용) + 결과 고지 「수유자에 대한 정면 해석 미확보 — 확인 필요」** — 권장.
  근거: 수유자에게 불리한 배제를 뒷받침하는 §77 해석이 없다. 위 두 결정은 §69(자경)·§168의8에 대한 판단이고, 조심2021구1132의
  「조특법에는 상속의 개념에 유증을 포함하지 않는다」는 일반론을 §77에 옮기는 것은 확장이다. 이 저장소의 선례도 해석이 없는
  갈래(§71의2 등)는 고치지 않았다.
- (b) 소급 미적용(②를 ①과 같은 축으로) + 고지 — 조심2021구1132의 일반론을 원용. 실측 시료에서 감면 25,959,000 → 0.
- (c) 손대지 않음(고지도 없음).

### Q-2 §69 화면 — 수유자일 때 피상속인 경작기간 입력부 → **(a)**
- **(a) 입력부를 숨기고 안내문을 띄운다** — 「상속인이 아닌 수유자는 피상속인 경작기간을 합산하지 않습니다(조특령 §66⑪·⑫ ·
  조심2021구1132 · 조심2023중10792)」. 숨긴 칸의 값은 ④가 싣지 않는다(3중 패턴). 권장.
- (b) 입력부는 보이되 비활성 + 같은 안내.

### Q-3 §69 엔진 고지 문구 — 감면 결과 산식(breakdown)에 합산 제외 사유를 싣는가 → **(a)**
- **(a) 싣는다** — 피상속인 경작기간이 입력돼 있는데(API 직접 호출 등) 수유자라 뺐으면 「피상속인 N년은 상속인이 아닌 수유자라 합산 제외
  (조특령 §66⑪·⑫ · 조심2021구1132)」. 종전 「§66⑪·⑫ 요건 미확인 → 합산 제외」 문구(`self-farming-reduction.ts:253-256`)와 같은 자리. 권장.
- (b) 싣지 않는다(④가 값을 안 보내므로 화면 경로에서는 보이지 않는다).
