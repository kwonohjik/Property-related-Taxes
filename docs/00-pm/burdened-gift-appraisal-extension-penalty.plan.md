# 부담부증여 K-7 감정가액 × 증축 5년 이내 — §114조의2 가산세 base 입력 칸 신설 (+ 이월과세 × 신축 감정 판정)

> 선행: #2196(K-6/K-7) · #2199(신축 × 감정가액 가산세 연결, 증축은 차단) · #2200(증여세 마법사) · #2202(이월과세) · #2204(축 B).
> 이 문서는 #2199가 남긴 두 건 — ① 증축 × 감정가액(증축부분 감정가액 입력 칸 없음), ② 이월과세 × 신축 감정가액(5년 기산점·base 미정) — 을 다룬다.

## 1. 법령 (KoreanLaw MCP 본문 확인, 2026-10-15 · 소득세법 MST 280405 시행 2026-01-01)

「소득세법」 제114조의2 ① 거주자가 건물을 신축 또는 증축(증축의 경우 바닥면적 합계가 85제곱미터를 초과하는 경우에 한정한다)하고 그 건물의 취득일 또는 증축일부터 5년 이내에 해당 건물을 양도하는 경우로서 제97조제1항제1호나목에 따른 감정가액 또는 환산취득가액을 그 취득가액으로 하는 경우에는 해당 건물의 **감정가액(증축의 경우 증축한 부분에 한정한다)** 또는 환산취득가액(증축의 경우 증축한 부분에 한정한다)의 100분의 5에 해당하는 금액을 제92조제3항제2호에 따른 양도소득 결정세액에 더한다. ② 제1항은 산출세액이 없는 경우에도 적용한다.

| 요건 | 엔진 구현 (`calculateBuildingPenalty`) |
|---|---|
| 증축은 바닥면적 합계 85㎡ 초과 | `extensionFloorArea > 85` |
| 취득일·증축일부터 5년 이내 | `addYears(constructionDate, 5)` |
| 감정가액은 양도일 ≥ 2020-01-01(환산은 2018-01-01) | `buildingPenaltyMethodApplies` |
| base = 증축한 부분에 한정한 감정가액 | **입력 칸이 없어 차단 중이었다 → 이 작업** |

## 3. 이월과세 × 신축·증축 × 감정가액 — **구현하지 않는다** (조사 결과)

「5년 기산점·가산세 기준 미정」이라는 종전 표기를 조사했다. 결론은 **정해지지 않은 것이 아니라 §114조의2의 요건에 해당하는지부터 불분명**하다는 것이다.

- 조문의 주체는 「**거주자가 건물을 신축 또는 증축하고** 그 건물의 취득일 또는 증축일부터 5년 이내에 해당 건물을 **양도**하는 경우」다. 이월과세(§97의2①)에서 양도하는 사람은 **증여받은 사람**이고 건물을 신축한 사람은 당초 증여자다. 양도인은 신축·증축한 자가 아니다.
- 화면에서도 신축·증축 입력은 `selfBuiltActive`(매매 취득, `acquisitionCause === "purchase"`)에서만 열린다. 이월과세 자산의 취득원인은 `carryover_gift`라 입력 경로가 없다 → API 직접 호출에서만 도달.
- 이 조합을 정면으로 다룬 자료를 확인하지 못했다. 조세심판원 재결 조심 2019서3934(부담부증여 × 신축 × 환산, 신축한 **증여자 본인**이 양도)와 조심 2020중0535(신축자 본인 양도)는 **신축자가 양도인인 경우**라 이월과세와 다른 질문이다. 국세청 예규(`nts`)·법령해석례(`interpretation`)에서 「114조의2」·「이월과세 신축」·「증여받은 신축건물」·「증축한 부분 감정가액」 검색 결과 없음.

⇒ 가산세를 붙이는 것도(문언상 양도인이 신축자가 아님) 빼는 것도(5년 기산이 당초 증여자 신축일인지 불명) 근거가 없다. **엔진의 기존 차단(`assertCarryoverDonorBasis`)을 유지**한다. 「확인 필요」: 이월과세 양도에 §114조의2 적용 여부(해석례 미확보). 재제안 전에 해석례부터 확보할 것.
