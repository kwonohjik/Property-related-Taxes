# 특수관계인 범위 조회 버튼 — 구현 계획서

> 작성일: 2026-06-19 · 대상: 증여세 "저가양수·고가양도 상세 입력" 모달(§35)
> 성격: **순수 정보성(읽기 전용) UI** — 엔진·Zod·계산식·DB 무변경

## 1. 목표

증여세 의제 유형 "저가양수·고가양도(§35)" 상세 입력 모달에서, 사용자가 **"특수관계인 간 거래 (§35①)"** 토글을 켜기 전에 **특수관계인의 범위**(상증령 §2의2)를 즉시 확인할 수 있도록 **"특수관계인 범위 조회" 버튼**을 추가한다. 버튼 클릭 시 요약된 범위가 모달(Dialog)로 표시된다.

### 왜 필요한가
- §35①(특수관계인) ↔ §35②(비특수관계인)에 따라 **공제 기준이 달라진다**(특수관계인 = MIN(시가 30%, 3억) / 비특수관계인 = 3억 고정 — `lib/tax-engine/bargain-transfer.ts:1-14`). 토글 선택이 결과를 좌우하므로, 판단 근거인 "특수관계인 범위"를 그 자리에서 제공해야 한다.

## 3. 설계 결정

### 결정 A — 트리거 형태: 명시적 텍스트 버튼 (권장)
사용자 요구가 "조회 **버튼**"이므로 작은 `ⓘ` 아이콘이 아니라 **"특수관계인 범위 조회"** 텍스트 버튼으로 만든다.

두 가지 방법 중 택1:
- **A-1 (권장)**: `TaxHelp`에 optional `triggerLabel?: string` prop 추가 → 값이 있으면 텍스트 버튼, 없으면 기존 `ⓘ` 아이콘. 기존 사용처 무영향(하위호환), 재사용 인프라 확장.
- **A-2**: 전용 컴포넌트 `RelatedPartyScopeButton.tsx` 신설. 콘텐츠 양이 많고 ①~⑧ 계층 구조라 색상 카드로 시각화하고 싶으면 이 쪽. `TaxHelp`의 단순 마크다운 렌더(`## / - / **bold**`)보다 가독성↑.

> 권장: **A-1으로 버튼 트리거만 확장 + 콘텐츠는 상수로 분리**. 콘텐츠 가독성이 부족하다고 판단되면 A-2로 승격(전용 모달 + 관계 3분류 색상 카드). Do 단계 1차 anchor 확인 후 결정.

### 결정 B — 콘텐츠 위치: 상수 분리
요약 텍스트를 `shared.tsx`에 인라인하지 않고 `components/calc/deemed-gift/related-party-scope.ts`(신규)에 **상수**로 분리한다. 추후 다른 의제 유형(§34·§37·§41의4 등 특수관계인 등장 규정)에서 재사용 가능.

### 결정 C — 배치
`BargainFields`(`shared.tsx:529`) 컨테이너 상단, §35① `ToggleCard` **바로 위**에 버튼을 둔다(토글 판단 직전 노출 — UI 순서 = 판단 순서 원칙). 카드 우측 정렬 작은 버튼.

### 결정 D — 범위(Scope)
이번 작업은 **저가양수·고가양도(bargain) 모달 한정**. 컴포넌트·상수는 재사용 가능하게 만들되, 다른 의제 유형으로의 확산은 별도 후속.

## 4. 표시할 요약 콘텐츠 (deliverable 초안)

> ⚠️ **Do 단계 게이트**: 아래 조문·내용은 첨부 교재 기준 초안. 확정 전 KoreanLaw MCP로 상증령 §2의2 / 국세기본법 시행령 §1의2① / 법인세법 시행령 §40① 본문을 위임 체인 끝까지 검증한다(정책 `korean-law-citation-verify`·`feedback_korean_law_82_vs_81_2_drift`). 추정 인용 금지.

**특수관계인의 범위 (상증령 §2의2①)**
본인과 아래 관계 중 하나에 해당하는 자. *본인도 특수관계인의 특수관계인으로 본다.*

**① 친족관계** (국세기본법 시행령 §1의2① 1~4호 + 직계비속의 배우자의 2촌 이내 혈족과 그 배우자)
- 4촌 이내의 혈족
- 3촌 이내의 인척
- 배우자 (사실혼 포함)
- 친생자로서 친양자 입양된 자 및 그 배우자·직계비속
- 본인이 민법상 인지한 혼인 외 출생자의 생부·생모 (생계유지 또는 생계공동 한정)
- 직계비속의 배우자의 2촌 이내 혈족과 그 배우자 *(2014.2.21. 이후 상속·증여분부터: 부계혈족 → 혈족 개정)*

**② 경제적 연관관계** (상증령 §2의2① 2호)
- 사용인 (임원·상업사용인·고용계약관계자, "출자에 의해 지배하는 법인"의 사용인 포함)
- 사용인 외의 자로서 본인 재산으로 생계를 유지하는 자

**③ 경영지배관계** (상증령 §2의2① 3호)
- (본인이 개인) 본인·친족 등이 임원 임면권·사업방침 결정 등으로 사실상 영향력을 행사하는 기업집단 소속기업 + 퇴직임원(공시대상기업집단 5년 / 그 외 3년)
- (본인이 법인) 본인이 속한 기업집단 소속기업 및 그 임원에 영향력을 행사하는 자

**④~⑧ 출자·설립 지배관계**
- 공동 재산출연 설립 또는 이사 과반수인 비영리법인 (④⑤⑧)
- ①~⑤이 30% 이상 출자한 법인 (⑥)
- ①~⑥이 50% 이상 출자한 법인 (⑦)

**참고 — 임원의 범위 (법인세법 시행령 §40①)**: 회장·사장·부사장·이사장·대표이사·전무·상무 등 이사회 구성원 전원과 청산인 / 합명·합자·유한회사 업무집행사원 또는 이사 / 유한책임회사 업무집행자 / 감사 / 그 밖에 준하는 직무 종사자.

하단 **관련 조문 링크**: `상증령 §2의2`, `국세기본법 시행령 §1의2`, `법인세법 시행령 §40` (LawArticleModal 자동 연결).

- 양도세(소득세법상 특수관계인) — 정의가 달라 본 컴포넌트와 혼용 금지.
