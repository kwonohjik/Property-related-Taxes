# 조합원입주권 부담부증여 × 시가 모드 × 담보 승 — 엔진 fail-fast 대칭 (I-0)

`bg-nonsupp-winner-support.plan.md` §4.2.1. 착수 순서는 사용자 결정(S-1 → S-2 → I-0 → I-1 → 질의 병행 → I-2·M-1), Q-I1(I-0 채택).

## 1. 무엇이 어긋나 있었나

같은 사실 — 입주권의 증여재산 평가에서 담보평가(상증법 §66)가 이겨 증여가액 C가 담보평가액인 경우 — 을 평가 모드에 따라 엔진이 다르게 처리했다.

| 모드 | 종전 엔진 | 취득가액 |
|---|---|---|
| 기준시가 모드 · 담보·임대 승 | **400**(`burdened-gift-apportionment.ts` fail-fast) | — (괄호가 기준시가를 정하는데 입주권 기준시가 입력 경로가 없음) |
| 시가 모드 · 담보 승 | **200** | 실지취득가액(K-4) — 양도차익 2,500,000,000(원조합원 시료: 30억 − 실지 3억 − 청산금 2억) |

원인: `resolveBgAcquisitionBasis`의 `collateralForcedStdInMarketMode = 시가 모드 ∧ 담보 승 ∧ ¬입주권`이 시가 모드 입주권을 괄호 발동에서 뺐다. 그러나 소령 §159①1호 A 괄호는 **2023.2.28.부터 양도가액을 상증법 §66으로 산정한 경우도 열거**한다(지원 계획서 §2 L-1, MCP 확인) — 입주권 평가는 §61③이지만 시가 모드에서 담보평가가 이겨 C가 §66 평가액이 되면 양도가액의 산정 근거는 §66이다. 법문이 명확하므로 해석례를 기다릴 이유가 없고, 값을 정할 입력(입주권 기준시가, 소령 §165①)이 없어 두 모드를 같게 **중단**하는 것이 맞다.

⑧은 #2788부터 두 모드 모두 막는다 — 이 비대칭은 API 직접 호출에서만 드러났다.

## 2. 변경

`buildBurdenedGiftBreakdown`(`burdened-gift-apportionment.ts`)에 기존 fail-fast 바로 아래 한 블록을 더했다: 입주권 ∧ 시가 모드 ∧ 담보 승 ∧ `giftDate(= 양도일) ≥ BG_PAREN_MORTGAGE_66_FROM(2023-02-28)`이면 `INVALID_INPUT`. 문구는 기준시가 모드와 같은 사유(입주권 기준시가 입력 경로 없음)에 시가 평가 맥락을 붙였다.

- **연혁 게이트:** 2023.2.28. 이전 양도는 열거에 §66이 없어 실지 그대로다(RT-2 — 종전 값 불변). `giftDate`가 없으면(증여세 계산을 생략하는 호출) 판정하지 않는다 — 종전 동작. 운영 경로는 항상 `giftDate`를 넘긴다(`transfer-tax-burdened-gift-step.ts`).
- **임대 승은 해당 없음:** 시가 모드에는 임대 승이 없다(`burdened-gift-valuation.ts` `rentalEligible`).
- 판정표 주석(`resolveBgAcquisitionBasis`)에 한 줄 추가. ⑤⑥⑦⑧⑫⑬⑭ 변경 없음 — ⑧은 이미 막고, ⑫(Zod)는 입주권을 담보 승 강제에서 제외한 채 엔진 400이 받는다.

## 3. 엔진의 연혁 관행과의 관계

비입주권의 시가 모드 담보 승은 **양도일과 무관하게** 괄호대로 계산하고 2023.2.28. 이전이면 «확인 필요»를 고지한다(`bgParenthesisEraNotice` — 사용자 결정 2026-10-22). 입주권의 새 fail-fast는 그와 달리 이전 양도를 실지로 계산한다. 이유: 입주권은 괄호를 발동시킬 입력이 없어 「현행 문언대로 계산 + 고지」가 불가능하고, 이전 양도의 실지 계산은 당시 열거(§66 없음)와 일치하기 때문이다.

## 5. 하지 않은 것 · 확인 필요

- **⑧의 이전 양도 과차단(종전부터):** ⑧(`rtmiNonSupplementaryWinnerIssue`, #2788)은 시가 모드 담보 승 입주권을 양도일과 무관하게 막는다. 2023.2.28. 이전 양도는 엔진이 실지로 계산하는데 ⑧은 «괄호에 따라 … 계산하지 않습니다»라고 막으므로 그 시기엔 사유가 맞지 않는다(⑧ ⊇ ⑫는 유지). **측정:** 같은 시료로 양도일 2022-06-01 · 2023-02-27 · 2023-02-28 모두 ⑧이 «담보평가액이 시가보다 커서 …» 1건으로 막았다. 이 과차단의 의도·수정 여부는 정하지 않았다 — I-1에서 입주권 ⑧을 정리할 때 함께 정한다.
- 원조합원 입주권의 취득시 기준시가 정의는 질의 H-2 대기(I-2). 이 PR은 그 값을 정하지 않고 중단만 한다.
- 승계 입주권은 I-1에서 입력 칸·발동·개산공제 1%를 연결한다 — 이 fail-fast는 I-1이 입력 경로를 만들면 「취득시 입주권 기준시가 > 0 요구」로 교체된다.
- 축 B 입주권(⑧ 건너뜀)의 ⑫ 400 가능성은 측정하지 않았다(V-I1).
