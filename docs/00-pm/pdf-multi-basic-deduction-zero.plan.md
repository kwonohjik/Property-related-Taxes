# 다건 PDF 합산 양식 — 기본공제 0 표기 (`- 0` → `0`)

## §0 결론
- 결함: 다건 PDF 「합산 신고서 양식」의 «기본공제 (§103)» 행이 값이 0이어도 `- 0`으로 찍힌다 (`ResultPdfTransferSections.tsx` 다건 구간).
- 원인: 단건 행(같은 파일, `> 0 ? "- 값" : "0"`)에는 가드가 있었으나 다건 행에는 없었다.
- 수정: 다건 행에 같은 가드 — `(num(r.basicDeduction) ?? 0) > 0 ? "- 값" : "0"`. 표시 전용, 세액·과세표준 불변.
- 범위 밖(언급만): `ResultPdfDocument.tsx:238` 주택분 종부세 기본공제 행도 `- {값}` 이나 다른 세목이며 0이 되는 경로를 측정하지 않았다 — 확인 필요, 이번 PR 미변경.
