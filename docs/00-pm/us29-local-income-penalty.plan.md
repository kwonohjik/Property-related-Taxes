## 2. 설계 (확정 기본값 + 구현 중 확인한 사항)

1. **지방소득세 신고·납부일 = 국세 신고·납부일과 같은 날**로 본다(별도 입력 없음). 결과에 가정 고지.
2. **지방 법정신고·납부기한** = 입력한 국세 기한 + 2개월(민법 §160 월 단위, 해당 일이 없으면 말일) → 지방세기본법 §24①(토·일·공휴일이면 다음 날). 날짜 연산은 기존 `civil-period.ts` `deadlineEnd`(공휴일 표 `data/public-holidays-kr.ts`)를 재사용한다 — §24①과 민법 §161은 토·일·공휴일 → 익일로 같은 효과다. 입력한 국세 기한을 그대로 쓰므로 국기법 §5 연장 전(05-31)·후(06-01) 어느 쪽을 입력했는지에 따라 일수가 다르다(리뷰 304일 vs 301일, 1,995원) → 「확인 필요」 고지.
3. **기준세액** = 국세 기준(무신고/과소신고 납부세액 `penaltyBase`, 미납세액 `unpaidTax`) × 10%(원 미만 절사). 지방 기납부 = 국세 기납부 × 10% 가정.
4. **무신고 §53**(20%, 부정 40% — 지방은 역외 60% 없음) / **과소·초과환급 §54**(10%, 부정분 40% 가목·나목 분해는 국세 `fraudSplit`을 지방 base로 환산) / **납부지연 §55**: 일수 = 지방 법정납부기한 **다음 날부터 자진납부일까지(양끝 포함)**, 이자율 10만분의 22 · 75% 한도. (국기법 §47의4는 납부일 전날까지 — 다름.)
5. **이자율 연혁**: 기간 중 2022-06-07 이후는 22, 그 전은 기한 다음 날이 2019-01-01 이후면 25, 2018년이면 30(10만분의). **2018-01-01 이전 기한은 이자율 근거를 확인하지 못해 산정하지 않고 `unsupportedPeriod` + 고지**(침묵 0 금지).
6. **§57② 감면**: 무신고 = 2호 계단(지방 예정신고기한 기준 1/3/6개월)과 4호가목(지방 확정신고기한까지 신고 시 50%) 중 **큰 쪽**(겹침 우열 문언 없음 → 확인 필요). 수정신고 = 1호 계단(지방 법정신고기한 기준). 경정할 것을 미리 알고 한 경우(`priorAssessmentNotified`)·기한 후 날짜 입력 없음 → 감면 없음. 수정신고 4호나목은 입력에 예정/확정 구분이 없어 미적용(확인 필요).
7. **수정신고일이 지방 법정신고기한 이내**면 지방소득세는 아직 기한 내라 §54 과소신고가 아니다(가산세 0). 국세 기한만 지난 구간(국세 05-31 ~ 지방 08-02) 신고분이 여기에 해당한다.
8. **끝수**: 지방세기본법 §59가 국고금 관리법 §47(10원 미만 불계산)을 준용한다는 근거를 **찾았다**. 다만 §47③은 「준용할 수 있다」이고 본세 `localIncomeTax`가 원 단위이므로 같은 축(원 미만 절사)을 유지하고 「10원 미만 적용 여부 — 확인 필요」로 고지한다.
9. **§103의8**(소득세법 §115 기장불성실 × 10%와 §53·§54 큰 쪽): 엔진에 소득세법 §115 산정이 없다(`grep` 0건) → 영향 없음, 범위 밖 고지.
10. 정당한 사유 면제(수정신고 `underReductionMode: "exempt"`, 국기법 §48①2호)를 고르면 지방 §54도 부과하지 않는다(지방세기본법 §57① 정당한 사유 — 확인 필요).

## 3. 결과 필드

- `filing?` {kind non_filing|under_filing, base, fraudBase?, normalBase?, rate, grossPenalty, reductionRate, reductionAmount, reductionBasis, penalty, basis}

## 5. 14 동기화 지점

입력 필드 추가가 **없다**(국세 가산세 입력 `filingPenaltyDetails`·`delayedPaymentDetails`·`amendment`를 그대로 재사용) → ①~⑤·⑧~⑭ 해당 없음(⑫ Zod·⑬ body·⑭ route 매핑 불변). 해당하는 것은 **결과(⑦)** 와 **사이드바(⑥)** 뿐이며 사이드바는 총부담을 입력 단계에서 계산하지 않아 해당 없음. ⑦ 결과 표시 지점: 단건 hero · 상세 명세서 행 · 수정신고 카드 · 다건 합계 · 겸용 합계 · 일괄 어댑터 · PDF · Step6 고지. 신고서 별지 표(`FilingFormTable*`)는 국세 서식이라 지방소득세 가산세 칸을 만들지 않았다.

## 6. 가정·확인 필요

1. 지방소득세를 국세와 같은 날 신고·납부했다고 본다(의제 규정 없음, 납부서 납부 시에만 의제).
2. 지방 기한 = 입력 국세 기한 + 2개월 + §24①. 국기법 §5 연장 반영 여부에 따른 일수 차이.
3. §57② 2호와 4호가목이 겹칠 때 큰 쪽 채택.
4. 수정신고에 §57②4호나목 미적용(예정/확정 구분 입력 없음).
5. 10원 미만 끝수(지방세기본법 §59 · 국고금 관리법 §47) 미적용.
6. 2018-01-01 이전 기한의 납부지연 이자율 미확인 → 산정 안 함.
7. 공휴일 표 밖의 해(2036년~)는 토·일만 반영.
8. 지방 기납부·미납 = 국세의 10% 가정(§114조의2 가산 지방분은 base에 반영 안 됨).
9. §103의8 미산정(소득세법 §115 엔진 없음).
