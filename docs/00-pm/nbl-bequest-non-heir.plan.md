# 비사업용 토지 상속 특례에서 유증·사인증여를 상속으로 보는지 — 수정 계획서 v0.1

- 작성일: 2026-10-20 · 기준 커밋: master `7bbc6fe2e` · 워크트리 `-nblbq` (브랜치 `fix/nbl-bequest-as-inheritance`)
- 출처: #2277(`nbl-forest-pasture-inherit-3y-cause.plan.md` §5) · #2282(`nbl-unconditional-inherit-cause.plan.md` §6)가 범위 밖으로 남긴 항목. 두 PR은 상속 특례를 취득원인 `inheritance`와 취득일(상속개시일)로 자동 판정하게 바꿨다.

## 1. 법령·해석

### 1-1. 조문 (현행 — KoreanLaw 조회 2026-10-20)

비사업용 토지의 상속 특례는 모두 «상속받은»·«상속에 의하여 취득한»이라고만 쓴다. 유증·사인증여는 따로 언급하지 않는다.

| 특례 | 조문 문언 |
|---|---|
| ③1호 | 「소득세법 시행령」 §168조의14③1호 「2006년 12월 31일 이전에 **상속받은** 농지ㆍ임야 및 목장용지」 |
| ③1의2호 | 같은 항 1의2호 「… 해당 직계존속 또는 해당 배우자로부터 **상속ㆍ증여받은** 토지」 |
| ③3호 나목 | 같은 항 3호 나목 「취득일(**상속받은** 토지는 피상속인이 해당 토지를 취득한 날 …)」 |
| ③4호 나목 | 같은 항 4호 나목 「**상속에 의하여 취득한** 농지로서 그 상속개시일부터 5년 이내에 양도하는 토지」 |
| 임야 3년 | §168조의9③7호 「**상속받은** 임야로서 상속개시일부터 3년이 경과하지 아니한 임야」 |
| 목장 3년 | §168조의10②1호 「**상속받은** 목장용지로서 상속개시일부터 3년이 경과하지 아니한 것」 |
| 농지 3년 | §168조의8③2호 「「농지법」 제6조제2항제4호에 따라 **상속에 의하여 취득한** 농지로서 그 상속개시일부터 3년이 경과하지 아니한 토지」 |

**농지 3년만은 법률이 범위를 직접 정한다.** 「농지법」(MST 284301) §6②4호 「상속[**상속인에게 한 유증(遺贈)을 포함한다**. 이하 같다]으로 농지를 취득하여 소유하는 경우」.

### 1-2. 국세청 해석 (taxlaw.nts 원문 확인)

| 해석 | 요지 |
|---|---|
| 재산세과-3654 (2008.11.6.) | ③1호의 「상속받은 농지의 범위에는 유증으로 취득한 농지도 포함」 |
| 서면인터넷방문상담5팀-927 (2007.3.22.) | 「**상속인에 해당되지 않는 자가 유증으로 취득한 농지**는 … "2006년 12월 31일 이전에 상속받은 농지 …"에 해당되지 않아」 사업용 토지가 아님 |
| 부동산거래관리과-0994 (2011.11.25.) | 「민법 제1000조 내지 제1005조 규정에 따른 상속인에 해당되지 않는 자가 … 유증으로 취득한 임야는 … ③3호 규정이 적용되지 않는 것」(종조부 → 유증 사례 — 피상속인 취득일 소급 불가) |

**인접 영역** — 비사업용 토지에 대한 직접 해석은 아니다.
- 1세대1주택 상속주택 특례(§155②)
  - 「상속주택의 범위에는 유증 또는 증여자의 사망으로 인하여 효력을 발생하는 증여주택(**사인증여**)을 포함」(서면4팀-1926, 2004.11.29. · 서일46014-10233, 2002.2.26.)
  - 단, 「**법정상속인이 아닌 자**가 … 유증으로 취득한 주택은 … 상속받은 주택에 해당하지 아니함」(부동산거래관리과-307, 2011.4.11.)
- 취득시기: 「상속인에 해당하지 않는 자가 … **사인증여**로 취득한 자산의 취득시기는 상속이 개시된 날」(사전-2015-법령해석재산-0095, 2015.4.22.)

### 1-3. 정리

- **상속인**이 유증·사인증여로 받은 토지는 «상속받은» 토지다.
  - ③1호는 재산세과-3654가 직접 근거다.
  - 농지 3년은 「농지법」 §6②4호 괄호가 직접 근거다.
- **상속인이 아닌 사람(수유자)**이 유증으로 받은 토지는 «상속받은» 토지가 아니다.
  - ③1호는 서면5팀-927, ③3호 나목은 부동산거래관리과-0994가 직접 근거다.
- 나머지 특례(③1의2호·③4호 나목·임야 3년·목장 3년)와 **사인증여**는 비사업용 토지에 대한 직접 해석을 찾지 못했다.
  - 같은 낱말(«상속받은»·«상속에 의하여 취득한»)의 해석이고, 인접 영역(§155②)도 같은 선을 긋는다(상속인 → 포함, 비상속인 → 제외).
- 상속인이 아니어도 취득시기는 상속개시일이다(사전-2015-0095). 수유자도 상속세 납세의무자이므로 취득가액은 지금처럼 상속개시일 평가액이다(§163⑨).
  - 따라서 «취득원인 = 상속»을 고르는 것 자체는 맞다. 갈리는 것은 **상속 특례의 적용 여부**뿐이다.

## 2. 현행 구조

- 양도세 취득원인은 `purchase | inheritance | gift | carryover_gift | newConstruction | burdened_gift`다(`transfer-tax-schema-base-shape.ts:75`). 유증·사인증여는 따로 없고, 화면에도 «유증»이라는 안내가 없다(grep 0건).
- 상속 특례는 `acquisitionCause === "inheritance"` 하나로 정한다.
  - `resolveInheritanceStartDate`(`form-mapper-helpers.ts:195`) → ③1호·③4호 나목·임야 3년·목장 3년

  - ③1의2호 게이트 `INHERITED_OR_GIFTED_CAUSES`(`:105`)
- 상속인인지 아닌지를 묻는 칸이 없다.
- **농지 3년(§168조의8③2호)은 엔진에 없다** — `checkFarmlandDeeming`(`farmland.ts:43-72`)의 사유는 주말농장·전용허가·개발지구·한계농지·매립·공익사업·질병고령 임대 7종뿐이다(이농 3년 §168조의8③3호도 없다).

## 4. 수정안

### 4-1. 수유자 여부를 받는 방식 (Q-1)

- **(a) 취득원인 «상속» 아래 토글 하나 — 권장.**
  - 제목: 「상속인이 아닌 사람이 유증·사인증여로 받음」. 끈 상태가 기본이다.
  - 설명에 «민법상 상속인(선순위 · 대습상속인 포함)이 유언이나 사인증여로 받은 것은 상속이므로 켜지 않는다»를 적는다.
  - 취득원인·취득일·취득가액(상속개시일 평가액)은 지금처럼 상속으로 둔다(§1-3).
  - 대부분의 상속 자산에는 질문이 늘지 않는다. 드문 경우만 선언한다.
- (b) 취득원인에 「유증·사인증여(상속인 아님)」 값을 새로 둔다.
  - 취득가액·취득시기·상속 평가 블록 등 `acquisitionCause === "inheritance"`를 보는 모든 지점을 함께 바꿔야 한다. 영향 범위가 넓고, 빠뜨린 곳은 조용히 «매매»처럼 계산된다.
- (c) 안내만 한다(«상속인이 아닌 수유자는 상속 특례 대상이 아님 — 확인 필요»). 세액은 바뀌지 않는다.

### 4-2. 수유자일 때 비사업용 토지 특례 (Q-2)

직접 해석이 있는 ③1호·③3호 나목은 «적용하지 않음»으로 고정한다. 나머지 넷(③1의2호·③4호 나목·임야 3년·목장 3년)을 어떻게 할지 정해야 한다.

- **(a) 적용하지 않고 «확인 필요»를 알린다 — 권장.**
  - 같은 낱말(«상속받은»)을 서면5팀-927·부동산거래관리과-0994가 «상속인»으로 읽었다. 인접 §155②(부동산거래관리과-307)도 같은 선이다.
  - 수유자라는 사실은 사용자가 밝혔으므로 모르는 사실이 아니다. 남는 것은 해석의 공백이라 고지로 밝힌다.
- (b) 적용하고 «확인 필요»를 알린다. 직접 해석이 없으니 종전처럼 혜택을 둔다.

### 4-3. 사인증여 (Q-3)

- **(a) 유증과 같이 본다 — 권장.**
  - 상속인의 사인증여 = 상속, 비상속인의 사인증여 = 수유자 토글.
  - 근거: 「상속세 및 증여세법」(MST 276123) §2 1호가 「상속」에 가목 유증 · 나목 사인증여를 포함한다. 5호는 둘 다 받은 사람을 「수유자」로 묶는다. 상속주택 해석(서면4팀-1926)도 사인증여를 넣는다. 취득시기도 상속개시일이다(사전-2015-0095).
  - 비사업용 토지에 대한 직접 해석은 없어 «확인 필요»를 함께 알린다.
- (b) 사인증여는 계약(증여)이므로 «증여»로 고르게 안내한다. 그러면 취득가액·취득시기가 증여 규칙으로 바뀌어 위 해석과 어긋난다.

### 4-4. 범위 (Q-4)

- **(a) 이번 PR은 비사업용 토지 상속 특례만 고친다 — 권장.**
  - 1세대1주택 상속주택 특례(§155② — 부동산거래관리과-307)와 그 밖의 상속 특례는 영향 지점을 따로 세서 후속 계획서로 한다.
  - 토글 설명에 «현재 비사업용 토지 판정에만 반영»이라고 밝힌다.
- (b) 1주택 상속 특례까지 한 번에 고친다.

### 4-5. 인접 결함 — 농지 상속 3년·이농 3년 (Q-5)

- **(a) 별건 계획서로 뺀다 — 권장.**
  - §168조의8③2호·3호를 `checkFarmlandDeeming`에 넣는 일이다. 기간기준(§168의6)과 함께 판정해야 하고, 사용자 결정이 필요하다(예: 이농일 입력).
  - 그때 «상속인에게 한 유증 포함»(「농지법」 §6②4호)이 이 계획서의 토글과 맞물린다.
- (b) 이번 PR에 함께 넣는다.

## 6. 범위 밖 (확인 필요)

- **상속인 판정** — 민법 §1000~§1005(순위·대습상속)는 사용자가 판단해 선언한다. 상속을 포기한 사람이 유증을 받은 경우는 정리하지 않았다. 「상속세 및 증여세법」 §2 4호는 상속 포기자를 「상속인」에 넣지만, 위 소득세 해석례는 「민법 제1000조 내지 제1005조」의 상속인을 기준으로 삼았다.
- **특별연고자 분여 · 유언대용신탁 · 수익자연속신탁** — 「상속세 및 증여세법」 §2 1호 다목~마목. 소득세 상속 특례 해석은 찾지 않았다.
- **1세대1주택·다른 세목의 상속 특례** — Q-4 (a)이면 후속.
- **포괄유증과 특정유증** — 해석례가 구분하지 않는다(민법 §1078: 포괄적 수유자는 상속인과 동일한 권리의무). 포괄적 수유자를 상속인처럼 볼지는 확인 필요다.
