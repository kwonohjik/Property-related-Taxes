## 1. 법령·해석

### 1-1. 조문 (현행 — KoreanLaw 조회 2026-10-20)

비사업용 토지의 상속 특례는 모두 «상속받은»·«상속에 의하여 취득한»이라고만 쓴다. 유증·사인증여는 따로 언급하지 않는다.

| 특례 | 조문 문언 |
|---|---|
| ③1호 | 「소득세법 시행령」 §168조의14③1호 「2006년 12월 31일 이전에 **상속받은** 농지ㆍ임야 및 목장용지」 |
| ③1의2호 | 같은 항 1의2호 「… 해당 직계존속 또는 해당 배우자로부터 **상속ㆍ증여받은** 토지」 |
| ③3호 나목 | 같은 항 3호 나목 「취득일(**상속받은** 토지는 피상속인이 해당 토지를 취득한 날 …)」 |
| ③4호 나목 | 같은 항 4호 나목 「**상속에 의하여 취득한** 농지로서 그 상속개시일부터 5년 이내에 양도하는 토지」 |
| 임야 3년 | §168조의9③7호 「**상속받은** 임야로서 상속개시일부터 3년이 경과하지 아니한 임야」 |
| 목장 3년 | §168조의10②1호 「**상속받은** 목장용지로서 상속개시일부터 3년이 경과하지 아니한 것」 |
| 농지 3년 | §168조의8③2호 「「농지법」 제6조제2항제4호에 따라 **상속에 의하여 취득한** 농지로서 그 상속개시일부터 3년이 경과하지 아니한 토지」 |

**농지 3년만은 법률이 범위를 직접 정한다.** 「농지법」(MST 284301) §6②4호 「상속[**상속인에게 한 유증(遺贈)을 포함한다**. 이하 같다]으로 농지를 취득하여 소유하는 경우」.

1주택 쪽은 §155②(「상속받은 주택」)·§155③(「공동상속주택」)·§156의2⑦1호·§156의3⑤1호(「상속받은 주택」)가 같은 낱말을 쓴다.

### 1-4. 정리

- **상속인**이 유증·사인증여로 받은 자산은 «상속받은» 자산이다(재산세과-3654 · 「농지법」 §6②4호 괄호 · 서면4팀-1926 · 서면4팀-2691).
- **상속인이 아닌 사람(수유자)**이 유증·사인증여로 받은 자산은 «상속받은» 자산이 아니다. 직접 해석이 있는 특례:
  - ③1호(서면5팀-927) · ③1의2호(사전-2024-0820) · ③3호 나목(부동산거래관리과-0994) · ③4호(기준-2019-0324) · 농지 3년(기준-2019-0324) · §155②(부동산거래관리과-307) · §104②1호(서면4팀-3304 — 사인증여)
- **직접 해석이 없는 것**: 임야 3년 · 목장 3년 · §155③ · §156의2⑦1호 · §156의3⑤1호. 같은 낱말이고 위 해석이 모두 같은 선(상속인 → 포함, 비상속인 → 제외)을 긋는다.
- **예외 — 동일세대원 간 통산**: 부동산거래관리과-1345는 수유자라도 피상속인과 동일세대면 1주택 보유·거주기간을 통산한다. 이것은 «상속받은 주택» 특례가 아니라 동일세대원 간 이전의 통산 원칙(동일세대원 증여 — 재산세과-684 등)을 적용한 것이다.
- 상속인이 아니어도 취득시기는 상속개시일이다(사전-2015-0095). 수유자도 상속세 납세의무자이므로 취득가액은 지금처럼 상속개시일 평가액이다(§163⑨).
  - 따라서 «취득원인 = 상속»을 고르는 것 자체는 맞다. 갈리는 것은 **상속 특례의 적용 여부**뿐이다.

## 4. 수정안 (결정 확정)

### 4-1. 수유자 여부를 받는 방식 (Q-1 → (a))

- 취득원인 «상속» 아래에 토글 하나: 「상속인이 아닌 사람이 유증·사인증여로 받음」. 끈 상태가 기본이다.
- 설명에 «민법상 상속인(선순위 · 대습상속인 포함)이 유언이나 사인증여로 받은 것은 상속이므로 켜지 않는다»를 적는다.
- 취득원인·취득일·취득가액(상속개시일 평가액)은 지금처럼 상속으로 둔다(§1-4).
- 필드명은 자산·주택 행 모두 `nonHeirBequest`(boolean)다.
- 두 곳에 둔다.
  - **양도 자산** — 상속 취득 블록(`CompanionAcqInheritanceBlock.tsx`). 이 자산에서 토글이 바꾸는 판정은 비사업용 토지뿐이므로 `assetKind === "land"`일 때만 보인다(§4-4 — 양도 주택 자신의 1주택 통산은 바뀌지 않는다).
  - **보유 주택 목록 행** — 「상속받은 주택」 토글 아래(`HouseEntryEditor.tsx`).

### 4-2. 수유자일 때 특례 (Q-2 → (a) 적용하지 않음 + 직접 해석 없는 것은 «확인 필요»)

v0.2에서 ③1의2호·③4호에 직접 해석이 생겼다(§1-3). 직접 해석이 없는 것은 임야 3년·목장 3년·§155③·§156의2⑦1호·§156의3⑤1호다.

### 4-3. 사인증여 (Q-3 → (a) 유증과 같이)

- 상속인의 사인증여 = 상속, 비상속인의 사인증여 = 수유자 토글.
- 근거: 「상속세 및 증여세법」(MST 276123) §2 1호가 「상속」에 가목 유증 · 나목 사인증여를 포함한다. 5호는 둘 다 받은 사람을 「수유자」로 묶는다. 상속주택 해석(서면4팀-1926)도 사인증여를 넣는다. 취득시기도 상속개시일이다(사전-2015-0095). 비상속인 사인증여는 §104②1호의 「상속받은 자산」이 아니다(서면4팀-3304).

## 6. 범위 밖 (확인 필요)

- **다주택 중과의 상속주택**(§167의3①7호 · §167의4 · §167의10 등)과 **조특법 §71의2 인구감소지역** — 같은 `isInherited`를 읽지만 이번 범위(1주택)가 아니다. 수유자 행도 지금처럼 상속주택으로 본다.
- **§104②1호 세율 보유기간 통산**(피상속인 취득일 기산) — 수유자의 사인증여는 적용하지 않는다는 직접 해석(서면4팀-3304)이 있다. 이번 범위가 아니어서 지금처럼 상속이면 통산한다. 후속 후보.
- **상속받은 조합원입주권·분양권**(`presaleRights[].isInherited` — §156의2⑥·⑦ · §156의3④·⑤) — 권리 행에는 토글을 두지 않는다. 후속 후보.
- **상속인 판정** — 민법 §1000~§1005(순위·대습상속)는 사용자가 판단해 선언한다. 상속을 포기한 사람이 유증을 받은 경우는 정리하지 않았다. 「상속세 및 증여세법」 §2 4호는 상속 포기자를 「상속인」에 넣지만, 위 소득세 해석례는 「민법 제1000조 내지 제1005조」의 상속인을 기준으로 삼았다.
- **특별연고자 분여 · 유언대용신탁 · 수익자연속신탁** — 「상속세 및 증여세법」 §2 1호 다목~마목. 소득세 상속 특례 해석은 찾지 않았다.
- **포괄유증과 특정유증** — 해석례가 구분하지 않는다(민법 §1078: 포괄적 수유자는 상속인과 동일한 권리의무). 포괄적 수유자를 상속인처럼 볼지는 확인 필요다.
- **§154⑫ 공동상속주택 거주기간 고지**(양도 주택 자신) — 고지만 내는 갈래다. 양도 자산 토글을 주택에 두지 않으므로 바뀌지 않는다.
