## 1. 핵심 산식 (PDF p.296 제3장)

### 1.1 공통 기본식

```
건물 기준시가 = ㎡당 금액 × 건물 연면적(㎡)
㎡당 금액   = 건물신축가격기준액 × 구조지수 × 용도지수 × 위치지수 × 경과연수별 잔가율
```

- **㎡당 금액은 1,000원 단위, 1,000원 미만 절사** (`truncateToThousand` 재사용). — p.296 본문 실측 확정(R4 해소).
- 공동주택 연면적 = 전유면적 + 공용면적.
- 지수는 **100 기준 정수**로 고시(예: 구조지수 110 = 1.10). 엔진 내부에서 `/100` 환산.

**잔가율 적용 규칙 (p.301 §7 — 실측)**:
- ② **신축연도** = 사용검사일(준공검사일) 속한 연도. 그 이전에 가사용 승인일·사실상 사용일이 있으면 **그 빠른 날**이 속한 연도.
- ③ **개축건물**(연면적 증감 없음): 당초 신축연도 기준.
- ④ **증축건물**: 증축 연면적 부분은 증축연도를 신축연도로 보고 잔가율 적용 → 사용자가 부분별로 분리 계산(UI 안내).
- ⑤ **복합 구조·용도 건물**: 구조·용도별로 각각의 그룹으로 계산. **분류 곤란 특수구조 → 잔가율 III그룹** 적용.

**기계식주차전용빌딩 특수산식 (용도지수표 구분 IV — ⚠️ 연도 가변, PDF 실측)**:
- 2025·2026년 #61: `기준시가 = 6,000,000원 × 경과연수별잔가율(내용연수 30년) × 주차대수`
- 2001·2002년 #39: `기준시가 = 5,000,000원 × 경과연수별잔가율(내용연수 20년) × 주차대수`
- → **단가·내용연수 모두 연도별로 다름**. 연도 → {단가, 내용연수} 테이블(`mech-parking-formula.ts`) 필수, 중간 연도는 Phase A 전사로 확정. 잔가율 그룹은 그룹번호 하드코딩이 아닌 **내용연수로 결정**.

### 1.2 양도소득세 모드 (취득시 + 양도시 각각 산정)

| 시점 | 산식 |
|---|---|
| **양도시 기준시가** | 양도연도 ㎡당 금액 × 연면적 (위 기본식, 양도연도 지수표) |
| **취득시 (2001.1.1. 이후)** | 취득연도 ㎡당 금액 × 연면적 (취득연도 지수표) |
| **취득시 (2000.12.31. 이전)** | `2001.1.1. 현재 ㎡당 금액 × 연면적 × 취득당시 건물기준시가 산정기준율` (소령 §164⑤) |

- 산정기준율 = `취득당시 건물기준시가 산정 기준율표.pdf` (그룹 I/II/III × 신축연도 × 취득연도 매트릭스).
- **산정기준율 적용 규칙 (p.301 §8 — 실측)**:
  - ① 취득연도: 취득일 속한 연도. 단 **1984.12.31. 이전 취득 → 1985년**으로.
  - ③ ⚠️ **신축연도는 1984.12.31. 이전이라도 1985년으로 적용하면 안 된다**(본문 명문). 신축연도 행은 그룹별 최저행(1945/1955/1965년이전)까지 그대로 사용.
  - ⑤ 취득연도 기준 역산하여 **그룹별 내용연수가 종료되는 연도 이전에 신축**한 건물은 **내용연수 종료 연도를 신축연도로** 한다.
  - ④ 완공 전 취득 가능 → **취득연도 < 신축연도 입력 허용**(validation에서 차단 금지).
- **2001.1.1. 현재 ㎡당 금액**의 위치지수는 2001.1.1. 현재 개별공시지가 기준(§1.5 ①).
- **개별건물 특성 조정률은 양도세에 미적용**(조정율 PDF 적용요령 (1)).
- **동일 연도 취득·양도(단기양도, 소령 §164⑧ / PDF p.302 제9절)**: 양도연도=취득연도면 산식상 양도차익이 0이 되므로 양도기준시가를 환산한다.
  - 제1산식: `양도기준시가 = 취득기준시가 + (취득기준시가 − 취득전기 기준시가) × 보유월수 / 기준시가조정월수` (비율 100/100 한도, 초일 산입, 1월 미만 일수=1월).
  - **제2산식(p.302 — 실측 신규)**: 예정신고기한(양도일부터 2월이 되는 날이 속하는 월의 말일)까지 **새로운 기준시가 고시 시** 거주자는 `양도기준시가 = 취득기준시가 + (새로운 기준시가 − 취득기준시가) × 보유월수 / 기준시가조정월수` 선택 가능 → 산식 선택 토글(중립 표기, 유불리 표현 금지).
  - 기준시가조정월수 = 전기 기준시가 결정일 ~ 취득당시 기준시가 결정일 전일까지의 월수. 연 1회(1.1.) 정기고시 체계상 **기본 12** + 직접 입력 override. → §3 `calcSameYearTransferStdPrice()` 별도 처리.

### 1.3 상속·증여세 모드 (1회 산정)

```
㎡당 금액 = 신축가격기준액 × 구조지수 × 용도지수 × 위치지수 × 경과연수별잔가율 × 개별건물특성조정율
```

- **위치지수 적용 개별공시지가 기준일**: §1.5 표(양도·상증 공통).
- **리모델링(대수선)**: 리모델링년도를 신축연도로 보아 상속·증여연도 잔가율 적용.
- **취득당시 기준시가 산정 불필요** → 산정기준율 미적용.
- **개별건물 특성 조정율**: §1.4 자동 도출.

### 1.4 개별건물 특성 조정율 (상증 전용, `상증법 조정율.pdf`)

7개 구분의 곱(미해당 구분 = 100):
```
조정율 = (I 지붕재료) × (II 최고층수/연면적/IB) × (III 주택유형) × (IV 상가·부속) × (V 개축) × (VI 무벽) × (VII 구조진단/철거) / 100^(해당구분수-1)
```

| 구분 | 선택 규칙 | 항목·지수 |
|---|---|---|
| I 지붕재료 | **구조지수<100일 때만** 적용, 1개 | 1=100, 2=80, 3=60 |
| II 최고층수/연면적/지능형빌딩 | **가장 높은 지수 1개**. 최고층수: 지하·옥탑 제외. 주거용은 아파트만 최고층수. 연면적은 주거용 미적용 | 4~13(층수·연면적), 14·15(IB) |
| III 단독/공동주택 | 가장 높은 지수 1개 | 16=120,17=140 / 18=120,19=140 |
| IV 상가·주차장·부속 | **가장 낮은 지수 1개**. 단 20~23 해당+24~25면 60 | 20~25 |
| V 개축 | 일부 개축만. 전부 개축은 개축년도=신축년도(조정률 미적용) | 26=110(1회), 27=120(2회↑) |
| VI 무벽건물 | 납세자 입증 시. 무벽면적비율 | 28=80,29=70,30=60 |
| VII 구조진단/철거/멸실 | 가장 낮은 지수 1개(입증 시) | 31~37 (37=정상사용면적비율) |

> 적용요령: 구분 간 **중복 시 각 조정률을 곱하여 중복 적용**. 통나무조는 지붕재료 미적용.

### 1.5 위치지수 적용 개별공시지가 기준일 (양도·상증 공통, PDF p.300)

| 취득·양도·상증 시기 | 적용 개별공시지가 |
|---|---|
| ① 2000.12.31. 이전 | **2001.1.1. 현재** 결정·공시 개별공시지가 |
| ② 2001.1.1.~2002.12.31. | **해당연도 1.1. 현재** 결정·공시 개별공시지가 |
| ③ 2003.1.1. 이후 | **양도·취득·상속·증여일 현재** 결정·공시 개별공시지가 |

> 새 공시지가 고시 전 취득·양도는 직전 공시지가 적용(소령 §164③). 개별공시지가 없는 토지는 인근 유사토지 기준(소법 §99① 1호가목 단서·소령 §164①).

### 2.1 잔가율 그룹 매핑 (잔가율표 헤더 기준, 2026)

**산정기준율표 그룹 구성** (취득당시 기준율표 헤더, 잔가율표와 별개):

| 그룹 | 내용연수 | 구조 |
|---|---|---|
| I | 40년 | 통나무조, 철골(철골철근)콘크리트조, 철근콘크리트조, 석조, 프리캐스트 콘크리트조, 목구조 |
| II | 30년 | 연와조, 보강콘크리트조, 시멘트벽돌조, 철골조, 스틸하우스조, 황토조, 목조 |
| III | 20년 | 시멘트블럭조, 경량철골조, 철파이프조, 석회 및 흙벽돌조, 돌담 및 토담조, 기계식 주차전용빌딩 |

### 2.2 구조·용도 선택 — B안(지수표 분류 직접 선택)

- 국세청 화면의 마스터 코드표(01~09)는 **예시**일 뿐 → 채택 안 함. **지수표 분류 항목을 그대로 선택지로** 사용.
- **구조 선택**: 사용자가 고른 **연도의 구조지수표**를 기반으로 하되, ⚠️ **드롭다운 옵션은 행이 아닌 개별 구조명 단위**(실측: 1행에 다수 구조 묶음 — #4행의 철근콘크리트조=잔가율 I·목조=잔가율 II로 **같은 행 안에서 잔가율 그룹이 갈림**. 행 단위 선택으로는 잔가율·산정기준율 그룹 결정 불가). 같은 행의 구조들은 같은 지수 공유.
  - ⚠️ 연도별로 행 구성이 다름(2021~2026=11행 / 2003~07=8항목). → **선택 연도(양도연도/취득연도·상증연도)에 해당하는 구조지수표 옵션 셋**을 동적으로 노출. 양도세 취득시·양도시는 각 시점 연도 기준.
- **용도 선택**: 해당 연도 용도지수표 항목(번호 1~30+, "아파트 / 단독주택 / 관광호텔 / …")을 그대로 옵션으로.
- 별도 마스터 코드표·코드↔분류 매핑 resolver **불필요**.
- 단, **구조 항목 → 잔가율/산정기준율 그룹** 매핑은 여전히 필요(§2.1·§2 `structure-group-map.ts`) — 구조지수표 항목명을 키로 그룹(I~IV / I~III) 연결.

## 7. 토지등급가액표에 대한 정리 (사용자 초기 언급 대응)

- 사용자 초기 요청: "토지등급가액표는 양도세 분야 기존 구현 활용".
- **사실**: 건물 기준시가 산식에 토지등급가액표는 **들어가지 않는다**. 토지 위치 반영은 "위치지수"(부속토지 ㎡당 개별공시지가 구간)가 담당.
- 활용 접점:
  1. 위치지수 입력의 개별공시지가 조회/계산 → 양도세에서 쓰는 **`LandPriceLookupField` 재사용**(이것이 실질적 "양도세 분야 로직 활용").
  2. `land-grade-values.ts`(1990 이전 토지등급)는 추후 "토지+건물 합산 기준시가" 확장 시 토지분에 재사용 가능 — 현 범위(건물만) 밖.

## 8. 미결 / 리스크

- ~~R1 구조·용도 마스터 코드 매핑~~ → **B안 채택으로 해소**. 지수표 분류 직접 선택. 단 연도별 옵션 셋이 다르므로 `listStructureOptions(year)`로 동적 노출, 선택 연도 변경 시 기존 선택 무효화 가드 필요. 구조 옵션은 **개별 구조명 단위 분해**(§2.2).
