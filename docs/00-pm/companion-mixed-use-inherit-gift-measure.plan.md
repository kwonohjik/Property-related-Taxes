## 1. 측정 설계 [직접]

- 시료 공통: #3334의 기존 anchor와 같은 픽스처(겸용 주택 100㎡·상가 60㎡·대지 200㎡ + 토지 매매 컴패니언, 계약 총액 12억, 양도 2023-09-18). 컴패니언 배치(`[토지, 겸용]`)와 primary 겸용(`[겸용, 토지]`, P1) 둘 다 쟀다. 단서 구간 PHD는 `transfer.route.mixed-use-sec163-9-compare` 픽스처의 PHD 입력을 썼다(`makeMockRatesWithHouseEngine`).
- 대조군: 같은 겸용을 **단건**으로 계산(양도가액 = 파트 카드 양도가액 합) → 4부분 `[취득가액, 필요경비]`을 파트 카드와 비교했다.
- 증여는 증여 전용 칸(`mixedHousing/CommercialGiftValueOverride`·`…GiftExpense`)을 썼다 — ④가 취득원인에 종속해 고른다.
