# C — §104⑤ 크로스 엔진: 부동산 ↔ 기타자산 합산 (8호·9호 동일 자산 의제 포함)

**상태**: 🔴 **미착수** — 법령 근거는 완비(§2). **범위가 선행 계획서보다 넓다**(§1).
**선행**: [[stock-other-asset-104-5-and-104-1-9.plan.md]] 결함 C — A(PR#1026)·B(PR#1028) 완료
**성격**: 결함 수정이 아니라 **기능 신설**(현재 제품에 교차 신고 경로 자체가 없다)

---

## 1. ⚠️ 범위 재정의 — 「8호·9호 의제」보다 넓다

선행 계획서는 C를 「§104⑤ 후단 **8호·9호 동일 자산 의제** 미구현」으로 적었다.
조사해 보니 **그것은 더 큰 공백의 한 조각**이었다.

> §104⑤ 본문: 「해당 과세기간에 제94조제1항제1호ㆍ제2호 **및 제4호**에서 규정한 자산을
> **둘 이상 양도**하는 경우 …」

**§104⑤은 부동산(§94①1·2호)과 기타자산(§94①4호)을 원래 한 덩어리로 본다.** 그런데 우리는
부동산 엔진과 주식 엔진이 분리돼 있어:

| 조합 | §104⑤ 적용 |
|---|---|
| 부동산 2건 | ✅ `transfer-tax-aggregate` |
| 기타자산 2건 | ✅ `stock-transfer-aggregate` (PR#1026·#1028) |
| **부동산 1건 + 기타자산 1건** | ❌ **전혀 적용되지 않는다** |

⇒ C의 정확한 범위는 **「§104⑤이 부동산 ↔ 기타자산을 아우르지 못한다」**이고,
**8호·9호 동일 자산 의제는 그 안의 특수 규칙**(2호 계산 시 두 호를 한 버킷으로)이다.

## 2. 법령 (본문 전부 확보 — 보류 사유 없음)

| 조문 | 내용 |
|---|---|
| §104⑤ 본문 | 「§94①1호ㆍ2호 **및 제4호** … **둘 이상 양도** … 각 호의 금액 중 **큰 것**」 |
| §104⑤1호 | 「해당 과세기간의 양도소득과세표준 **합계액**에 §55①의 세율」 ⇒ **부동산 + 기타자산 전부 합산** |
| §104⑤2호 | 「§104①~④·⑦에 따라 계산한 **자산별** 산출세액 합계액」 + 예규(재산-536) 「자산별 = **각 호별로 합산한 자산**」 |
| §104⑤ 본문 **후단** | 「제2호의 금액을 계산할 때 **제1항제8호 및 제9호의 자산은 동일한 자산으로 보고**」 ⇒ 부동산 비사토(8호)와 비사토 과다소유법인 주식(9호)이 **한 버킷** |
| 실무 교재 ③ | 「…실질은 비사업용 토지가 양도되는 것과 같다고 보기 때문에 … **누진세율 효과가 반영된 산출세액으로 비교되어야 합리적**이므로 2018.4.1. 이후 양도분부터 … **동일한 자산으로 보아 양도소득금액을 합산하여 세율을 적용**한다」 |

📌 교재는 「**양도소득금액**을 합산」이라 쓰지만, 법문 §104⑤2호는 「자산별 **산출세액**」이고
산출세액은 과세표준 × 세율이다. 부동산 정본도 **과세표준 합산**으로 구현했다
(`clauseBucketKey` → `mergedBase = Σ taxBase`). ⇒ **과세표준 합산**이 맞다(교재 표현이 느슨).

## 3. 실측 — 과소 **25,680,000**

부동산 비사업용 토지 1건(§104①8호) + 기타자산 9호 주식 1건, 2024년 양도:

| | 과세표준 | 세액 |
|---|---:|---:|
| 부동산 비사토 (기본공제 250만 소진) | 243,500,000 | 96,940,000 |
| 기타자산 9호 | 300,000,000 | 124,060,000 |
| **현행 단순합** | | **221,000,000** |
| 「동일한 자산으로 보아」 합산 (543,500,000 × 52% − 35,940,000) | 543,500,000 | **246,680,000** |
| **차이** | | **25,680,000 과소** |

⚠️ **현재 제품에서 이 값을 한 화면에 낼 수 있는 경로는 없다.** 사용자가 두 계산기를 각각 돌려
더하면 221,000,000이 나온다 — 실무상 **틀린 금액**이다.

|---|---|---|

## 7. 리스크

| # | 리스크 | 대응 |
|---|---|---|
| R-1 | **8호와 9호의 floor 횟수가 다르다** — 부동산은 `floor(base×r) − d` **+** `floor(base×0.1)`(2회), 주식 9호는 `floor(base×(r+0.1)) − d`(1회) | 합산 후에는 **한쪽 규약으로 1회** 계산하므로 조정 레이어에서 자연 해소. 다만 **기존 anchor가 ±1원 흔들릴 수 있어** C-2-3 이관 시 전건 확인 필수 |
| R-2 | **§103② 기본공제 중복** — 부동산과 기타자산은 **같은 1호 그룹**인데 두 엔진이 각각 250만을 쓸 수 있다 | 현재는 사용자 수동 입력(제약 4)으로 회피 중. 조정 레이어가 이것도 봐야 정확하다 — C-2 범위에 포함 |
| R-3 | **감면 차감 후 비교**(§104⑤ 본문 괄호) | 단일 엔진에서는 감면세액이 산출세액에 비례해 MAX 승자가 불변이었다. **크로스에서는 한쪽에만 감면이 있을 수 있어** 비례가 깨진다 — C-2 착수 시 재검토 |
| R-4 | 가산세·지방소득세 재계산 | 부동산·주식 정본 모두 「자산별 단건 값의 합」 방침 — 조정 레이어도 승계 |
| R-5 | C-1 경고가 **오탐**하면 사용자를 불필요하게 불안하게 한다 | 노출 조건을 좁게(비사토·기타자산 실제 존재 시만) + 문구에 「해당 시」 조건 명시 |

## 8. 범위 밖

- **차손 통산(§102②)** — 주식 엔진 미구현(PR#1026에서 확인한 별건). 크로스 통산은 더 뒤.
- **부동산 ↔ 주식(§94①3호) 합산** — §104⑤ 본문이 **3호를 열거하지 않으므로 대상이 아니다**.
- 「법인세법 §55의2②」 비사업용 토지 판정 엔진 구현 — 법인의 자산 구성 사실(B 계획서 §7과 동일).
