## 2. 조문·자료 실독 [직접, KoreanLaw MCP, 조회기준일 2026-11-09]

- 조세특례제한법 §127⑦(MST 284389): «거주자가 토지등을 양도하여 둘 이상의 양도소득세의 감면규정을 동시에 적용받는 경우에는 그 거주자가 선택하는 하나의 감면규정만을 적용한다. 다만, 토지등의 일부에 대하여 특정의 감면규정을 적용받는 경우에는 남은 부분에 대하여 다른 감면규정을 적용받을 수 있다.» 위임 문언 없음.
- 조세특례제한법 시행령 §123(MST 288915): 법 §127①2호·3호의 «대통령령으로 정하는 바»만 정한다. §127⑦ 위임 규정은 시행령에 없다.
- 조심 2024서2915(2024.12.12., 기각): 처분청이 §97의4와 §99의3을 §127⑦로 중복 적용 불가라며 경정청구를 거부했고, 재결요지는 «§97의4 추가 공제율 10% 과세특례도 소득공제와 유사한 것으로서 조세감면에 해당한다고 해석함이 타당». **전문은 읽지 못했다**(조회 결과가 14,849자 중략) → V-4.
- 국세청 법령해석 «조특법 제127조 제7항»·«조특법 제127조» 검색은 0건, 조세심판원 «조특법 제127조 제7항 일부»도 0건이었다. 검색 실패이지 부존재 증명이 아니다 → V-5.

## 3. 측정 [직접]

### 3.1 방법
throwaway probe(저장소에 남기지 않음)로 폼 → ④ 변환 → route(⑫⑭) → 엔진을 호출. 시료: 취득 2003-03-01 · 양도 2024-08-01 · 양도가액 900,000,000 · 취득가액 200,000,000 · 비과세 회피(`isOneHousehold:false`, `householdHousingCount:"2"`).
- §99의3: 1호(주택건설사업자) · 구간 밖 · 5년 후 기준시가 100M/150M/400M.

### 3.2 결과

## 4. 결정 대기

- **Q-1 (NH-41, Q-25)** 단서를 어떻게 지원하나.
  - **a (권장)**: ⑫ Zod에서 같은 카드의 교차를 ⑧과 같은 술어로 400 차단한다. 단서는 «카드 분할»로 이미 되므로 유지(§3.2 D)하고, 같은 카드 안 «일부 분할» 입력 칸은 만들지 않는다. 변경은 UI 없음 · ⑫ refine 1개 + 호출 2곳 + ⑧ 문구 단일 소스화.
  - b: 같은 카드 안에서 감면별 적용 면적·가액을 입력받아 단서를 계산한다. 조문에 구분 기준이 없어 입력·안분 기준을 정해야 하고, 14지점 + 결과·PDF·사이드바가 걸린다(리뷰 추정 «30여 파일» — 이 PR에서 측정하지 않았다).
  - c: 엔진 진입에서도 막는다. 다건 집계가 겸용 컴패니언을 land·building 카드로 쪼개 같은 감면 배열을 싣는 구조(NH-54에서 엔진 게이트를 기각한 이유)라 위양성 여부를 먼저 재야 한다 → 미측정.
- **Q-2 (신규)** §97의3·§97의4와 차감형·세액감면형의 병용을 이번에 함께 막나.
  - a: 이번 PR에서 `classifyTrack127_7`에 §97의3·§97의4를 추가한다. ⑤·⑧이 지금 허용하는 조합이 막히는 **UI 동작 변경**이다.
  - **b (권장)**: 별건으로 분리한다. 근거가 재결 1건(요지만 읽음)이고 §97의3까지 같게 볼지 확인되지 않았다. 별도 계획서에서 병용 세액을 측정한 뒤 결정한다.
