## 1. 스코프 결정사항 (✅ 사용자 확정 2026-06-27)

### 결정 1 — 적용 세목 범위 → **상속·증여 전용으로 정정** 🔴 (2026-06-27 검토 정정)
> **정정 사유 (KoreanLaw 재검증, 소득세법 시행령 mst=286211 §165④ 본문 실측)**: 기존 "공통 엔진(소득세법 시행령 §165④ → 상증법 §63 → 상증령 §56② 준용)"은 **허위 준용 체인**이다. §165④는 자기완결(자족) 규정으로, 1호 가목 순손익가치 = **「양도일/취득일이 속하는 사업연도의 직전 사업연도의 1주당 순손익액 ÷ 3년만기회사채 유통수익률 이자율」(단일 직전연도)**이며, 상증법 §63·상증령 §54·§56을 **전혀 준용하지 않는다**(§165의 준용은 ②→§51①, ③→§52의2③, ⑦→§58의2②, ⑧2호→§59②, ⑫→§61뿐 — §54~56 부재). §56②가 갈음하는 '최근 3년 순손익액 가중평균액' 자체가 양도세 §165④에 존재하지 않아 **구조적으로 갈음 대상이 없다**. 기존 코드(`stock-valuation-unlisted.ts:4·12`, `unlisted-messages.ts:17-24`)도 §165④를 자족 규정으로 명시(영업권 가산조차 명문 없음).
>
> **정정 결정**: 추정이익 산출(§56②)은 **상속·증여 전용**. `estimated-profit-section-56-2.ts`를 단일 소스로 확장하되 적용 세목은 상속·증여로 한정. **양도세 순손익가치는 §165④1호 가목(직전연도 순손익액 ÷ 이자율) 그대로 유지** — 추정이익 갈음 주입 금지(명문 근거 없는 적용 = 납세자 유불리 영향). 양도세 포함을 유지하려면 §165④에 추정이익 갈음을 허용하는 **별도 명문 근거를 먼저 제시**해야 하나 현행법상 없음. **dual-truth 금지.**

### 결정 2 — 산출방법 구현 깊이 → **1차 구현 범위 = D + E. A는 no-op(무변경 확정). B·C는 deferred** 🟠 (2026-06-27 검토·재정정)
> **정정 사유**: §0-3에서 스스로 진단했듯 B(연도별 주당추정이익 산식)·C(1차·2차 3:2 가중평균)는 **구법(2012.12.5 이전)** 산식이며 2012.12.6 이후 사례에는 **적용 금지**(§5). 미수요 구법 산식을 정식 엔진 모드로 풀 구현하는 것은 추측성 범위 확장(Simplicity First 위반)이고, 실제 pre-2012.12.5 평가기준일 사례 수요가 문서에 제시되지 않았다(근거 = 교재 이미지뿐). 또한 **A(자본환원율)는 실질이 비어 있다** — max-capRate 치환은 §17 위반으로 거부(=무변경), '차입금×1.5'는 1차 출처 미확정으로 deferred → A에 1차 착수할 코드 작업이 없다.
>
> **정정 결정**: **1차 구현 범위 = D(시점 안내) + E(평가기관 메타)**. 영역 **A는 "capRate=§54① 순손익가치환원율은 상증규 §17 연 10% 고정 유지(=무변경 결론)"만 확정 — 1차 작업 = no-op(코드 변경 없음)**. '차입금 가중평균이자율 × 1.5' 자본환원율은 1차 출처 확정까지 deferred(Phase A·§6과 일치). **B·C는 실제 2012.12.5 이전 평가기준일 사례 1건 확보 후 착수하는 별도 후속(deferred) 작업으로 분리**.
> ⚠️ **A 제약 — 전역 capRate 변경 금지** (아래 결정 별항·Phase A 참조): orchestrator의 §54①/§56① 순손익가치환원율은 **상증규 §17의 연 100분의 10 고정값**(max·하한 아님)이므로 교체 불가.

## 3. 작업 분해 (정정 후: 결정 1=상속·증여 전용 / 결정 2=A·D·E 1차·B·C deferred / 결정 3=보조계산기 단일경로)

### Phase A — 자본환원율 (영역 A) 🔴 정정 — **전역 capRate 변경 금지, 보류 후보**
> **정정 사유 (KoreanLaw 실측)**: orchestrator `capRate`(line 69)는 §54①/§56①의 **순손익가치환원율**이며 상증규 §17이 **연 100분의 10 고정**(max·하한 아님)으로 확정한다. 이 capRate는 line 158의 **모든 비상장 평가**(가중평균 ÷ capRate), line 100(유상증자 조정), line 469(결과 echo)에 전역 적용된다. 또한 §17의3④는 추정이익 평균가액 = 수익가치 × §54① 환원율(10%)로 정의하므로, 엔진이 같은 10%로 나눠야(§56①) ×10%가 상쇄되어 수익가치가 복원된다. **capRate를 10%가 아닌 값(max 산식)으로 바꾸면** (가) §56② 추정이익 갈음 산식의 상쇄가 깨지고, (나) 정상 §56① 순손익가치 경로·유상증자조정·결과 echo까지 전부 오염되며, (다) 모든 일반 평가가 §17 위반(환원율↑→순손익가치↓)이 된다.
>
> **정정된 작업 범위**:
> 1. **orchestrator line 69 capRate를 max 산식으로 교체 금지** — §54①/§56① 순손익가치환원율은 상증규 §17 고정 10% 유지(`resolveCapitalizationRate(...)→max(...)` 도입 금지).
> 2. '차입금 가중평균이자율 × 1.5' 자본환원율은 **1차 출처(구 증권공시세칙 수익가치 산정 등) 확정 전 도입 금지**(§5에서 미확정 표기). 도입하더라도 평가기관의 수익가치(자본시장법 시행령 §176의5②) 산정 **내부 할인율**로서 `agencyEstimates`에 이미 내재되는 값이지, 엔진의 §56② 제수(capRate)가 아니다 → §54① 환원율 슬롯과 **물리적으로 분리**.
> 3. 결론: **Phase A는 1차 출처 확정 전까지 보류**. 확정되면 §54① 경로와 분리된 수익가치 sub-계산 레이어로만 한정 구현.

### Phase B — 평가기관 메타 + 시점 안내 (영역 D·E)
1. `EstimatedProfitInput`에 `agencies?: { type, name }[]` 또는 `agencyTypes` optional 추가 (검증 강화, 산식 무관).
2. 평가기준일 2012.12.6 전/후 분기 → 산출방법 안내 라벨(현행 모형 vs 구법 산식). 차단 아닌 안내.
3. UI `EstimatedProfitToggle`에 시점 배지 + 기관 유형 표시.

### Phase C — 연도별 주당추정이익 산식 + 3:2 가중평균 (영역 B·C) 🟠 **deferred (결정 2 정정 — 실 사례 1건 확보 후 착수)**
1. 순수함수 `calcPerShareEstimatedProfit({ pretaxContinuingIncome, preferredDividendAdj, corporateTax, yearEndShares })` (영역 B).
2. `calcWeightedEstimatedProfit(year1, year2)` — 3:2 가중, 2차<1차면 단순평균 (영역 C).
3. UI: 보조 계산 패널 → 결과를 `agencyEstimates`에 주입. **엔진 단일 소스 유지** (UI 자체 매트릭스 재구현 금지).
   - 🔴 **≥2 정합 (정정)**: 보조 계산기는 단일 값 산출이지만, **평가기관별로 ≥2회 산출 → `agencyEstimates`에 ≥2개 항목으로 주입**해야 한다(schema refine `unlisted-stock-valuation-v2.schema.ts:319` '둘 이상' + 엔진 `estimated-profit-section-56-2.ts:83` `agencyCount>=2` 게이트). 단일 행 주입 시 length 1 < 2 → 검증 위반.
   - 🔴 **위젯 사양 enumerate (정정)**: 금액 필드(`pretaxContinuingIncome`·`preferredDividendAdj`·`corporateTax`)=`CurrencyInput`, **`yearEndShares`(발행주식수, 주 단위·원화 아님)=정수 입력**으로 명시. 연도별 주당추정이익·3:2 가중 vs 2차<1차 단순평균 분기를 보여줄 **결과 카드 행 추가**.
   - 🔴 **결과 카드 ⑤ hint (정정)**: 현행 `PerShareValuationResultCard.tsx:103-109` hint는 '기관 N개 평균 ÷ 환원율'로 하드코딩 → B·C 보조계산기 주입값에는 '기관 평균' 표현이 사실과 다름. **주입 출처 플래그 기준으로 '기관 평균'과 '구법 B·C 산출'을 분기 표시**. 신규 엔진 result 필드(연도별 주당추정이익·weighted 결과)에 대응하는 ⑦ 결과 산식 행도 enumerate.
4. anchor: 3:2 가중 / 단순평균 분기 경계.

### Phase D — 양도세 연결 🔴 **삭제 (결정 1 정정 — 양도세 스코프 제외)**
> **정정 사유 (KoreanLaw 실측, 소득세법 시행령 §165④)**: §165④는 자족 단년 규정으로 상증령 §54~56을 준용하지 않으며, §56②가 갈음할 '3년 가중평균액' 자체가 양도세 산식에 존재하지 않는다 → **추정이익 갈음은 양도세에 존재하지 않는 제도**. 따라서 본 Phase의 핵심 작업인 "순손익가치 필드(`transferYearNetIncomePerShare`)를 추정이익 산출값으로 갈음"은 **명문 근거 없는 적용(납세자 유불리 영향)**이므로 삭제한다.
>
> **결정**: 양도세 비상장 순손익가치는 **§165④1호 가목(직전연도 순손익액 ÷ 이자율) 그대로 유지**, 추정이익 모드 주입 금지. 양도세 포함이 정말 필요하면 §165④에 추정이익 갈음을 허용하는 **실제 근거 조문을 먼저 확정**(현재 발견 안 됨)하고 별도 계획으로 재기안. 산출 보조계산기(B/C) 코드 자체는 재사용 가능하되, 그 결과를 양도세 §165④ 슬롯에 주입하는 것은 금지.

## 5. 리스크·주의

- **자본환원율 ① 출처 미확정**: "차입금 가중평균이자율 × 1.5"의 1차 법령 출처가 자료에 명시 안 됨. Do 전 확정 못 하면 Phase A 보류.
- **환원율 이중적용**: 현재 코드는 `÷ capRate` 적용. 자료 C'(주당추정이익 ÷ 자본환원율)과 정합 — 추정이익 평균가액(환원 전)을 받는다는 전제. agencyEstimates의 의미를 "환원 전 주당추정이익"으로 문서·라벨 고정 (혼동 차단).
- **구법/현행 혼동**: B·C는 구법. 현행 사례에 강제 적용 금지 — 안내·보조로 한정 (납세자 불리/오적용 방지).
- **단일 소스**: 상속·증여 내에서 `applyEstimatedProfit` 단일 소스 유지. 산식 재구현(dual-truth) 금지. 🔴 **양도세 연결은 제외**(결정 1·Phase D 정정 — §165④ 추정이익 갈음 명문 근거 부재).
