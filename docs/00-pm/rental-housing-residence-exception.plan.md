# 장기임대주택 보유자의 거주주택 양도 — 구현 계획서

> **소득세법 시행령 §155⑳·㉒·㉓ + §161 + §156(고가주택)** 기반 1세대1주택 비과세 특례 구현
> 작성일: 2026-05-05 / 작성자: kwonohjik
> 적용 시점: **2025.2.28 이후 양도분(현행)** — 횟수 제한 없음

## 1. 배경

### 1.1 사례 (예제 2023 PDF, 사례 25)
- 갑씨 — 거주주택(상지아파트, 2009.8.12 취득, 2023.3.3 양도가 8억) + 장기임대주택 1채(8년 임대) 보유
- 직전거주주택 양도일 2016.8.25 → 그 이전 양도소득금액은 과세, 이후는 비과세 (§161①)
- 결과: 양도차익 311,000,000 / 장기보유공제 80,860,000 / 양도소득금액 172,605,000 / 산출세액 44,699,900

### 1.2 2025년 현행 규정 (PDF#2)
- **2025.2.28 이후**: 거주주택 비과세 횟수 제한 없음 (이전: 생애 1회 부칙)
- 임대주택 등록신청일별 의무임대기간 변동: 5년/8년/10년, 2025.6.4 이후 단기 6년 신설
- 임대료 5% 상한, 자진말소·자동말소(5년 내 양도) 등 하위 분기 다수
- §155⑳ 2개 시나리오 + (3) 2주택자 자가→임대 전환 시나리오

## 3. 시나리오 매트릭스 (Design 단계 확정 대상)

| ID | 시나리오 | 양도 대상 | 과세대상 양도소득금액 | 장기보유특별공제표 |
|---|---|---|---|---|
| RH-A1 | 임대주택 N채 + 거주주택 → **거주주택** 양도 (12억 이하) | 자가 거주주택 | 0 (전액 비과세) | — |
| RH-A2 | 동상 (12억 초과 = 고가주택) | 자가 거주주택 | 양도소득금액 × (양도가-12억)/양도가 | §95② **표2** (1세대1주택) |
| RH-B1 | 자가→직전거주주택 양도 후 임대주택을 거주주택으로 전환 → **PHRP 양도** (12억 이하) | 임대→거주 전환 주택 | **§161①** — 직전 양도일 **이전** 보유분만 과세 | §161④ → §95② **표1** (일반) |
| RH-B2 | 동상 (12억 초과 = 고가) | PHRP | **§161② 1호**(이전분 전액) + **§161② 2호**(이후분 × (양도가-12억)/양도가) 합산 | 1호 → **표1** / 2호 → **표2** (§161④) |
| RH-C | (참고: 2주택자 1채 임대등록 후 거주 양도) | — | A1과 동일 (A1에 흡수) | — |

**§161③ 캡**: §161① 또는 §161② 합산 결과가 §95① 양도소득금액을 초과하면 그 초과분은 없는 것으로 본다 → 엔진에서 `Math.min(allocated, baseGain)` 강제.

**Design 단계에서 케이스 인벤토리 표 행 ≥ 4 enumerate 강제 (CLAUDE.md 정책 ★★★)**

### 5.1 §161① 산식 (B1 — 12억 이하)
```
과세대상 양도소득금액
  = §95① 양도소득금액
    × (직전거주주택 양도 당시 PHRP 기준시가 − PHRP 취득 당시 기준시가)
      ÷ (PHRP 양도 당시 기준시가 − PHRP 취득 당시 기준시가)
```
→ 이 금액만 과세, 나머지는 비과세
→ §161④: 장기보유특별공제는 **§95② 표1** 적용 (양도소득금액 산정 시점에 이미 차감됨)

### 5.2 §161② 산식 (B2 — 고가주택, 양도가 > 12억)

> 산식 자체는 §161②, 장기보유공제 표 매핑은 §161④ 별도 규정. 아래는 양 조항을 결합한 구현 형태.

**변수 정의**:
- `gain95(표X)` = §95① 양도소득금액 = 양도차익 − §95② 표X 장기보유공제
- `P_acq` = PHRP 취득 당시 기준시가
- `P_prior` = 직전거주주택 양도 당시 PHRP 기준시가
- `P_transfer` = PHRP 양도 당시 기준시가
- `S` = 양도가액

**1호 — 직전거주주택 양도일 이전 보유분** (전액 과세):
```
①호 양도소득금액 = gain95(표1) × (P_prior − P_acq) / (P_transfer − P_acq)
                                                                  (§161②1호)
                  장기보유공제 표1 적용                          (§161④)
```

**2호 — 직전거주주택 양도일 이후 보유분** (12억 초과분만 과세):
```
②호 양도소득금액 = gain95(표2) × (P_transfer − P_prior) / (P_transfer − P_acq)
                              × (S − 12억) / S            (§161②2호)
                  장기보유공제 표2 적용                          (§161④)
```

**합산**:
```
B2 과세대상 양도소득금액 = 1호 + 2호                           (§161②)
                          단, §161③ 캡 적용                    (§5.4 참조)
```

### 5.3 §161① 산식의 §161④ 적용 (재정리)
```
B1 과세대상 양도소득금액 = gain95(표1) × (P_prior − P_acq) / (P_transfer − P_acq)
                                                                  (§161①)
                          장기보유공제 표1 적용                  (§161④)
```

### 5.4 §161③ 캡 비교 대상 (해석 쟁점 — Design 단계 확정)

조문: "제1항 및 제2항에 따라 계산한 직전거주주택보유주택등의 양도소득금액이 **법 제95조제1항에 따른 양도소득금액**을 초과하는 경우에는 그 초과하는 금액은 없는 것으로 한다."

여기서 "§95① 양도소득금액"이 표1·표2 중 어느 표 기준의 §95①인지가 §161②(B2) 케이스에서 모호합니다 (B1은 표1만 쓰므로 무관):

| 해석안 | 캡 비교 대상 | 적용 시점 |
|---|---|---|
| (a) 호별 분리 비교 | 1호 ≤ gain95(표1), 2호 ≤ gain95(표2) | 각 호 산정 직후 |
| (b) 합산 후 표1 기준 비교 | (1호+2호) ≤ gain95(표1) | 합산 후 |
| (c) 합산 후 표2 기준 비교 | (1호+2호) ≤ gain95(표2) | 합산 후 |

**Design 단계 액션**: 국세청 예규(서면법규재산 등) 검색하여 다수설 확정. 미확정 시 (a) 보수적 해석으로 1차 구현 후 anchor 테스트로 검증.

### 5.3 §161④ 표 분리 적용 구조
- 본 엔진은 §95① 양도소득금액을 **두 번** 계산해야 함 (표1 기준 / 표2 기준)
- `ltc-table-split.ts`에서 동일 양도차익에 대해 표1·표2 각각의 장기보유공제를 산출하여 두 양도소득금액을 도출
- B1·B2-1호는 표1 결과 사용, B2-2호는 표2 결과 사용
