## 1. 두 관찰이 나온 경위 [직접]

- 시료: 함께 양도(컴패니언) 토지 + 조합원입주권(종전 취득 100,000,000 · 청산금 납부 90,000,000 · 권리가액 300,000,000), 합계 750,000,000을 기준시가로 안분(입주권 107,142,857 / 토지 642,857,143).
- 입주권 쪽에 `redevPreApprovalExpenses` 3,000,000과 `redevPostApprovalExpenses` 5,000,000을 넣고 계산했더니 필요경비가 **3,000,000만** 잡혔고, 같은 입주권 단건도 같은 값(−85,857,143)이었다.
- 합계 칸 결정세액(72,155,714)과 자산별 칸(71,002,857 · 0)의 합이 달랐다.

## 2. 실측 — 원조합원의 지출이 어디로 가는가 [직접]

단건 조합원입주권(원조합원 · 청산금 납부), 양도 520,000,000 · 종전 취득 100,000,000 · 권리가액 300,000,000 · 청산금 90,000,000 · 2023-03-02 양도. 신고서 «합계 · 인가 전 분 · 인가 후 분»의 필요경비 행. API 응답 200.

| 시료 | 입력 | 합계 | 인가 전 분 | 인가 후 분 | 결정세액 |
|---|---|---|---|---|---|
| E0 기준 | 없음 | 0 | 0 | 0 | 81,710,000 |
| E1 자본적지출 | 5,000,000 | **5,000,000** | 0 | **5,000,000** | 79,810,000 |
| E2 양도비 | 2,000,000 | **2,000,000** | 1,153,846 | 846,154 | 81,081,538 |
| E3 인가 전 경비 | 3,000,000 | **3,000,000** | 3,000,000 | 0 | 80,912,000 |

- 전체 양도차익도 맞게 줄었다: 330,000,000 → 325,000,000 / 328,000,000 / 327,000,000 (항등식 성립).
- 양도비 안분 비율은 양도가액 열(300,000,000 : 220,000,000)과 같다 — 1,153,846 : 846,154 [직접].
- ⇒ 원조합원이 «인가 후에 쓴 돈»을 넣을 곳은 **자본적지출 칸**이다. 별도 «인가 후 필요경비» 칸이 없어도 계산에는 반영된다.
- **측정하지 않은 것:** 승계조합원에서 `redevPostApprovalExpenses`가 인가 후 분에 실리는 값(이전 계획서 `remaining-4-measurements.plan.md` K-5·Q-52가 다룸 — 이번 세션 미실측) · 완공 APT 원조합원 · 청산금 수령 방향.
