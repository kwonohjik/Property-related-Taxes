## 1. 구현 (이 PR)
- `PenaltyDetailBlock.tsx`: `filingViolation === "non_report"`면 «가산세 기준금액 (무신고납부세액)» / «국세기본법 §47조의2① — 산출세액 전액이 아니라 «그 신고로 납부하여야 할 세액»(가산세·이자상당가산액 제외)이 기준이며, 여기서 뺀 금액에 세율을 곱합니다». 과소신고는 종전 그대로. 이자상당가산액 칸 근거 «(국세기본법 §47조의2①·§47조의3①)». 파일 머리 주석도 같이 정정.
- anchor `__tests__/components/stock-penalty-base-header.anchor.test.tsx`(5): 무신고 제목·설명·이자상당 근거, 과소 대조군, 미선언 시 블록 없음. 구현 **전** 5건 중 3건 실패(BH-1-1~3) → 구현 후 전부 통과. BH-1-3은 처음엔 기납부 안내문에 같은 병기가 있어 구현 전에도 통과했다 → 이자상당가산액 힌트의 문장 전체로 단언을 정밀화했다.
- 뮤테이션 7종 전부 사망(분기 조건 거짓/참·제목·설명 조문·제외 문구·이자 근거·과소 설명), 복원 `cmp` 일치.
