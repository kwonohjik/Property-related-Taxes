## 1. 질문

#2725 가 파트 슬롯을 `compareSec164(①, 적용, ②)` 로 바꿨다 (`transfer-tax-api-gb-sec163-9.ts:100`). 의제취득일(1985.1.1.) 전 상속·증여 파트는 ①② 를 슬롯과 **따로** `landPreDeemedClauseA {reported, sec164}` 로 싣고(`gb-pre-deemed.ts:56-63`) 엔진이 ③ 환산과 비교해 경로를 고른다(`general-building-pre-deemed.ts` `resolveGbPreDeemedRoute`).
1. 그 ①② echo · ③ 비교가 `compareSec164` 변경과 어긋나는가? (#2725 V-2)
2. 파트 카드의 `sec1639Basis` echo (`adopted: reported | sec164`) 가 규칙과 맞는가? (#2725 V-4)
3. 1980 파트의 슬롯이 비면 echo 가 어떻게 되는가? (#2729 V-4)

## 2. 측정

환경: vitest + `makeMockRates`. 취득시 기준시가 토지 205,000,000 · 건물 150,000,000. 상속·증여 × 증여·상속일 4(1980·1988·1995·2005) × 분리 OFF·ON(증여는 ON 만 — OFF 는 ⑧ 이 막는다) × 토지·건물 신고가액 5조합(§164 의 0.5배·1배·2배, 서로 엇갈린 둘) × 위치 3(컴패니언·주 자산·단건) = **180셀**, 양도가액 1.6B·1.0B 두 번.

**시료를 갈랐다.** 양도가액 1.6B 는 ③ 환산이 ①② 를 이기는 셀 36을, 1.0B 는 ③ 채택 0 · **② §164 채택 90파트**(1.6B 는 54파트)를 만든다. 비교 채널이 모두 갈리는 셀이 있어야 어긋남이 보인다.

오라클(이미 동작하는 채널, ±0):
- ⓐ 멱등 — 파트 가액을 max(①,②,③) 로 미리 넣은 같은 자산의 세액이 같다 (③ 채택 셀 제외).
- ⓑ 증여 — 같은 날짜의 **매매(실가) 채널** 세액이 같다 (③ 채택 파트는 추계 모드로).

## 4. 새로 확인된 한 건 (V-1) — 세액 영향 실측 (Q-1 a)

**BG 상속 × 취득방식 「converted」 × 상속개시일 1985.1.1. 이후** — ⑧ 은 막는다(`transfer-tax-validate-bg.ts:380-384` — 상속개시일 현재 상증법 평가액이 실지거래가액이라 환산 불가, 소득세법 §97①1호 단서). ⑫ 에는 같은 조건이 없다.

위치별: 컴패니언·주 자산은 이미 닫혀 있다 — 일반 양도 자산과 BG 는 함께 양도로 묶을 수 없어 ⑧·⑫ 모두 400 (96셀: 일자 3 × 분리 2 × 평가액 4 × 위치 2 × 방식 2). **단건만** 열려 있다.

단건 24셀(일자 1988·1995·2005 × 분리 OFF·ON × 평가액 4): converted 는 **전부 ⑧ 차단 · ⑫ 200** 이고 세액이 평가액·일자와 무관하게 **76,712,292** 로 같다(평가액이 쓰이지 않고 환산으로 계산된다). 올바른 경로(`bgAcquisitionMethod: actual` + `bgActualAcquisitionLand/Building` 에 평가액 — ⑧ 통과 · 200, K-4 실지취득가액 칸이 §163⑨ 평가액이다)와 비교하면:

| 평가액(토지/건물) | 올바른 경로 | converted(⑫ 200) | 차 (converted − 올바른) |
|---|---|---|---|
| 100,000,000 / 75,000,000 | 88,835,000 | 76,712,292 | −12,122,708 |
| 205,000,000 / 150,000,000 | 64,895,000 | 76,712,292 | +11,817,292 |
| 400,000,000 / 300,000,000 | 14,752,481 | 76,712,292 | +61,959,811 |
| 800,000,000 / 600,000,000 | 0 | 76,712,292 | +76,712,292 |

- **부호가 평가액에 따라 갈린다** — 평가액이 환산취득가액보다 크면 과대, 작으면 과소. 어느 쪽이든 오답이다.
- 화면 도달: 불가능하다 (⑧ 차단). API 직접 호출·⑧ 우회 입력에서만 생긴다 (V-5 와 같은 계열).
- 법문은 명확하다 — 상속받은 자산의 취득가액은 평가액(영 §163⑨)이고 환산취득가액은 쓸 수 없다(법 §97①1호 단서). 해석례가 필요한 사안이 아니다.
- 의도된 비대칭이라는 근거 문서는 찾지 못했다 (`bg-gb-residuals.plan.md` §2.2 는 ① 비움만 다룬다). 이 건은 평가액이 **있는데도** 쓰이지 않는다는 점에서 ① 비움과 다르다.
- 앵커 EC-2 가 **현재 동작을 기록**한다 (고쳐지면 반전).
