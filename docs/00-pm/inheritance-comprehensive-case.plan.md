### Phase A — 추정상속재산 §15 모듈 (G1)
- `lib/tax-engine/presumed-inheritance.ts` 신규 (~200줄)
- `PresumedInheritanceItem` 타입 (category, amountWithin1Y, amountWithin2Y, verifiedUseAmount, heirAllocations?)
- `evaluatePresumedInheritance(items: PresumedInheritanceItem[]): { items: PresumedInheritanceItemResult[]; total: number }` ← Design §4-0과 명명 일치
- 임계 판정: 부동산/예금 = 1년 이내 2억 OR 2년 이내 5억 / 기타재산 동일 / 금융기관채무 동일
- 차감 산식: Min(처분금액 × 20%, 200,000,000)
- anchor: PDF 표 그대로 (A토지 108M / B아파트 100M / 예금 100M / 영업권 0 (1년이내 2억 미만, 소명대상 아님) / 차입금 142M = 350M)

### Phase B — 영리법인 면제 §3의2② (G4)
- `PriorGift.beneficiaryType: "heir" | "legatee" | "corporate"` enum (기존 `isHeir: boolean` 보완 — 기존 필드는 backward compat용으로 유지하되 신규 코드에서는 enum 사용)
- 영리법인 사전증여 회차는 §13 ② 합산 대상이지만 §3의2②에 의해 상속세 면제
- 면제세액 = Min(증여세 산출세액, 한도) — 한도 = 상속세 산출세액 × (영리법인 가산 과세표준 / 상속세 과세표준)
  - PDF: 한도 = 1,627,500,000 × 700,000,000 / 4,175,000,000 = 272,874,251
  - 면제세액 = Min(150,000,000, 272,874,251) = 150,000,000
- 신규 결과 필드: `corporateExemption: { amount, limit, breakdown[] }`

### Phase C — 상속인별 배부 §3·§28 (G3·G6·G7)
- `lib/tax-engine/inheritance-allocation.ts` 신규 (~300줄)
- `EstateItem.heirAllocations?: { heirId: string; amount: number }[]` (총액의 합 = valuated value)
- 상속인별 과세가액 = 본래상속재산(직접배분) + 사전증여(직접) + 추정상속재산(귀속자별)
- 상속인별 과세표준 상당액:
  - **직접배부** (D_i) = max(0, 상속인별 사전증여 과세표준 − 증여공제) — PDF: 배우자 160M, 장남 1,450M, 차남 0, 손녀 0
  - **간접배부** (I_i) = (상속인별 과세가액 − 직접배부 − 증여재산가액) × (간접배부 대상 과세표준 / 증여재산 제외 과세가액)
    - PDF 분모 = 5,815,000,000 (= 8,775M − 760M − 1,500M − 700M)
    - PDF 간접대상 과세표준 = 1,865,000,000 (= 4,175M − 160M − 1,450M − 700M)
  - 상속인별 과세표준 상당액 = D_i + I_i
- **배부대상 산출세액** (PDF 책 1866 ⑨) = 상속세 산출세액 − 영리법인 면제세액 = **1,627,500,000 − 150,000,000 = 1,477,500,000** (할증세액 30,232,198은 분리 가산 — 손녀에게만 추가)
- 상속인별 산출세액상당액 = 배부대상 산출세액 × 상속인별 과세표준상당액 ÷ (상속세 과세표준 − 영리법인 사전증여 과세표준)
  - 분모 = 4,175,000,000 − 700,000,000 = 3,475,000,000
  - 배우자: 1,477,500,000 × 1,101,319,862 / 3,475,000,000 = 468,259,021
  - 장남: 1,477,500,000 × 1,658,469,476 / 3,475,000,000 = 705,147,813
  - 차남: 1,477,500,000 × 554,849,527 / 3,475,000,000 = 235,910,842
  - 손녀(수유자) 산출세액상당액 = 1,477,500,000 × 160,361,135 / 3,475,000,000 = 68,182,324
  - **손녀 최종 = 산출세액상당액 + 세대생략 할증세액 = 68,182,324 + 30,232,198 = 98,414,522** (할증은 수유자 직접 가산)
- 상속인별 사전증여세액공제 (§28 ① 안분)
  - 한도_i = 상속인별 산출세액상당액 × 상속인별 사전증여 과세표준 / 상속인별 과세표준상당액
  - 공제_i = Min(상속인별 증여세 산출세액, 한도_i)
- 상속인별 신고세액공제 (§69) = (상속인별 차가감세액) × 3%
- 상속인별 자진납부세액 = 차가감 − 신고세액공제

### Phase D — 배우자공제·§24 한도 정확 산식 (G8·G10)

**G8 — §19 배우자 법정상속분 정확 산식** (PDF 책 1862 표 그대로):
```
배우자 법정상속분 = (상속재산 가액) × 배우자 법정지분 − 배우자 사전증여 과세표준

상속재산 가액 = 총상속재산
              + 상속인에게 증여한 사전증여재산 가액 (상속인 외의 자는 제외)
              − 상속인 외 자에게 유증한 금액
              − 상속포기 후순위 상속분
              − (공과금·채무 − 장례비)   ※ 장례비는 차감하지 않음
              − 비과세·과세가액불산입재산

PDF 계산:
  = 7,030M + 2,260M − 500M − 0 − 1,200M − 0 = 7,590M
  × (1.5/3.5) = 3,252,857,142
  − 배우자 사전증여 과세표준 160M
  = 3,092,857,142
```

**G10 — §24 종합한도 분자 (PDF 책 1864 표 그대로)**:
```
공제 한도 = 상속세 과세가액
          − 상속인 외 자에게 유증한 금액
          − 상속포기 후순위 상속분
          − [상속재산에 가산한 사전증여재산 가액 (전체 — 영리법인·비상속 수유자 포함)
              − (증여재산공제 + 신고기한내 재해손실공제)]

PDF 계산:
  = 8,775M − 500M − 0 − [(760M + 1,500M + 700M) − (600M + 50M)]
  = 8,775M − 500M − 2,310M = 5,965,000,000
  공제 합계 4,600M < 5,965M → 한도 미발동, 4,600M 그대로 적용
```

**※ PDF 자체 오기 주의**: 책 1864 표는 `5,945,000,000`으로 인쇄되어 있으나, 같은 페이지 ⑥ 산식은 `5,965,000,000`. 산식 기준 **5,965M 채택** (5,945M은 PDF 표 오기).

## 5. 산식 검증 (PDF 본문에서 직접 발췌)

### 5-1. 추정상속재산 §15 (책 1857)

```
추정상속재산 = ⑦ + ⑧ + ⑨ = 350,000,000원
  ⑦ 부동산 및 부동산권리: 108,000,000원
    미소명액 = 885M − 600M = 285M
    추정상속 = 285M − 177M (Min(885M×20%, 2억)) = 108M
  ⑧ 예금 인출액: 100,000,000원
    미소명액 = 1,500M − 1,200M = 300M
    추정상속 = 300M − 200M (Min(1500M×20%, 2억)) = 100M
  ⑨ 기타재산: 영업권 1년 이내 처분금액 180M < 200M → 소명대상 아님
  ⑩ 금융기관채무: 142,000,000원
    미소명액 = 1,000M − 658M = 342M
    추정상속 = 342M − 200M (Min(1000M×20%, 2억)) = 142M
```

### 5-2. 영리법인 면제세액 (책 1866)

```
증여세액공제 = Min(가, 나)
  가. 영리법인 증여세 산출세액 = 150,000,000원
  나. 한도 = 1,627,500,000 × (700,000,000 / 4,175,000,000) = 272,874,251원
∴ 면제세액 = 150,000,000원

배부대상 산출세액 = 1,627,500,000 − 150,000,000 = 1,477,500,000원
```

### 5-3. 세대생략할증 (책 1864)

```
세대생략할증 = 1,627,500,000 × 500,000,000 / (8,775,000,000 − 700,000,000) × 30%
            = 1,627,500,000 × 500,000,000 / 8,075,000,000 × 30%
            = 30,232,198원

※ 분모 "총상속재산가액"은 상증법 §13 가산 증여재산 중 상속인·수유자가 받은 것 포함,
   상속인 외 자(영리법인)가 받은 증여재산은 차감 (서서이-1447, 2008.6.17.)
```

### 5-3-1. 채무·공과금·장례비 협의분할 (책 1858 표) — heir-level 분배 필수

```
| 구분       | 채권자                   | 금액      | 배우자  | 장남    | 차남    |
|-----------|-------------------------|----------|--------|--------|--------|
| 금융채무  | 강남구 역삼동 K은행      | 400M    |        | 400M  |        |
|           | 강남구 역삼동 S저축은행  | 745M    | 500M  |        | 245M  |
| 공과금    | 종합소득세 등 (2022 귀속)| 55M     |        |        | 55M   |
| 장례비    | S장례식장 (식대 한도 10M)| 10M     | 10M   |        |        |
|           | **공원묘지 (한도 5M)    | 5M      | 5M    |        |        |
| 합계      |                          | 1,215M  | 515M  | 400M  | 300M  |
```
∴ 상속인별 과세가액 계산에서 채무·공과금·장례비도 협의분할 분배 필요.

### 5-4. 상속인별 과세표준상당액 (책 1864)

```
상속인별 과세표준 상당액
= 상속인별 사전증여 과세표준 (직접)
+ (상속인별 과세가액상당액 − 가산 증여 과세표준) × {간접배부 대상 과세표준 / (과세가액 − 가산 증여재산가액)}

배우자:
  직접 = 760M − 600M = 160M
  간접대상 과세표준 = 4,175M − 160M − 1,450M − 700M = 1,865M
  증여재산 제외 과세가액 = 8,775M − 760M − 1,500M − 700M = 5,815M
  간접 = 1,865M × (3,695M − 760M) / 5,815M = 941,319,862
  ∴ 1,101,319,862

장남:
  직접 = 1,450M (= 1,500M − 50M 증여공제)
  간접 = 1,865M × (2,150M − 1,500M) / 5,815M = 208,469,476
  ∴ 1,658,469,476

차남:
  직접 = 0
  간접 = 1,865M × 1,730M / 5,815M = 554,849,527

손녀:
  직접 = 0
  간접 = 1,865M × 500M / 5,815M = 160,361,135
```

### 5-5. 사전증여세액공제 안분 (책 1867)

```
배우자: Min(22M, 한도)
  한도 = 468,259,021 × 160M / 1,101,319,862 = 68,028,777
  공제 = Min(22M, 68M) = 22,000,000

장남: Min(420M, 한도)

  공제 = Min(420M, 616M) = 420,000,000
```

## 6. 위험 / 모호 / 후속

### 6-1. 위험 (High)
1. **상속인별 자산 분배 UI** — 자산 1개를 여러 상속인이 비율 분할(공장부지 2500/4000㎡ vs 1500/4000㎡). 자산 카드 안에 분배 입력 위젯 필요. UI 복잡도 ↑
2. **§13 vs §3의2② 영리법인** — 영리법인은 §13 ②에 따라 5년 이내 사전증여 합산 대상이지만 §3의2②에 의해 상속세는 면제. 가산은 하되 면제 차감. 두 단계 분리 명확화 필요.
3. **§28 ① 안분 한도 분모** — 현재 `taxBase` 사용. PDF는 상속인별 산출세액상당액 기준 — 다른 분모. **상속인-단위 §28 vs 총액-단위 §28** 일관성 확보.

### 6-2. 모호 (Medium)
1. 추정상속재산 귀속자 — PDF는 "부동산처분 ㉠ 150M / ㉡ 100M / ㉢ 100M" 식으로 배우자·장남·차남에 안분. 안분 규칙이 사례 본문에 명시되지 않음 (협의분할로 결정). UI 입력 시 분배 입력 필수.
2. 손녀 정의 — 장남의 자녀이지만 "상속인이 아닌 수유자". §27 ②에 따라 30% 할증.
3. 가업상속공제 — PDF는 차남이 단독 가업승계 (장남 미관여). 가업상속 분배는 차남 전체.
4. **Heir 타입 확장 결정** — 손녀(수유자)·영리법인이 `Heir` 배열에 들어가는 방식 결정 필요. 옵션:
   - (A) `Heir.relation`에 `"legatee" | "corporate"` 추가 + `Heir.isHeir: boolean` 플래그
   - (B) 별도 `legatees: Legatee[]` 배열 분리
   - **추천 (A)** — 단일 배열로 배부 로직 일관성 (heirAllocations[].heirId 참조 단순화)
5. **PDF 자체 오기**: 책 1864 한도액 5,945M vs 5,965M — 산식 기준 5,965M 채택. 다음 세션 KoreanLaw MCP 재확인.

### 6-3. 후속 (PDF 100% 재현 이후)
- 가업상속공제 요건 자동 판정 UI (피상속인 영위기간·가업상속인 근무·대표이사 취임)
