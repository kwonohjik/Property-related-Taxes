## 1. 배경 / 제거 사유

양도세 결과 화면의 "상세 내역" 요약 표(양도차익→지방소득세 8행, 이미지3)는
이제 더 풍부한 **신고서 양식(FilingFormTable)** + **계산결과 상세명세서
(DetailedCalculationStatementCard, 1~7단계·전체 엔진 계산 과정)** = 이미지4·5로
완전히 대체되어 중복이다. 사용자 요청: 이미지3만 제거, 이미지4·5는 불변.

## 2. 제거 대상 (정확한 경계)

`TransferTaxResultView.tsx` **321~458행** 단일 블록:

```tsx
{/* 상세 내역 */}
{!result.isExempt && (
  <div className="rounded-lg border border-border overflow-hidden">
    <table ...> ...양도차익 / 장기보유특별공제 / 양도소득금액 / 기본공제 /
                  과세표준 / 산출세액 / 결정세액 / 지방소득세 ... </table>
  </div>
)}
```

이 블록은 `PrintSection id="calculation"`(215행) **내부**에 있으나, 같은 섹션의
다른 콘텐츠(총납부세액 배너 218~257·필지별 내역 259~293·중과세 정보 460~)는
모두 **유지**한다. 섹션 자체는 제거하지 않는다.

## 6. ⚠️ 재검토 정정 (2026-06-29) — PDF·다건 뷰에는 이미지3이 없음

기반하므로, 그대로 실행하면 **이미지4를 삭제하게 되어 제약을 위반**한다.
