## 1. 법문 [직접: KoreanLaw MCP]

- 소득세법 §111③ (현행 시행 2026-01-01본) — 위 §0 #1 인용.
- 소득세법 §107① — «예정신고 산출세액 = (A − B − C) × D (A 양도차익 · B 장기보유 특별공제 · C 양도소득 기본공제 · D 제104조제1항에 따른 세율)». §107② — 2회 이후 예정신고는 합산 산식에서 이미 신고한 예정신고 산출세액(E)을 뺀다(V-9에서 확인한 내용).
- 조특법 §104의8① — «납세자가 직접 … 전자신고의 방법으로 **대통령령으로 정하는** 소득세, 양도소득세 또는 법인세과세표준 신고를 하는 경우에는 해당 납부세액에서 대통령령으로 정하는 금액을 공제».
- 조특법 시행령 §104의5 — ① (현행) «소득세법 제70조에 따른 종합소득 과세표준 확정신고, 같은 법 제105조에 따른 양도소득 과세표준 예정신고 및 법인세법 제60조에 따른 과세표준신고» · ②2호 «소득세법 제105조에 따른 양도소득 과세표준 예정신고를 한 경우: 2만원». 2015-07-01 시행본 ①은 소득세법 §70 확정신고와 법인세법 §60만 열거(양도소득세 없음). 2022-01-01 시행본 ①은 현행과 같고 개정 이력 표기가 «2021.2.17.».
- 시행령 공포 제31444호(2021-02-17) 부칙 제2조② — «이 영 중 양도소득세 및 증권거래세에 관한 개정규정은 이 영 시행 이후 양도하는 분부터 적용한다» [직접]. ①의 «2021.2.17.» 개정이 이 공포본인지는 개정 이력 표기와 같은 날 공포된 제31463호 부칙(제100조의14만 개정)으로 읽은 것이다 [해석].

## 2. 엔진 실측 [직접: throwaway probe, 삭제함 · 복사본 스크래치패드 `v19-probe/`]

픽스처: 코스피 대주주 · 취득 2022-01-01 · 양도 2024-06-01 · 소득 5,500,000 산출세액(첫 종목), 둘째 종목 합산 시 산출세액 합계 9,500,000.

**(가) 신고 유형 × 전자신고** (단건, `calculateStockTransferTax`):

| 신고 유형 | e | 산출세액 | 전자신고 공제 | finalTax |
|---|---|---|---|---|
| 예정 | false | 5,500,000 | 0 | 5,500,000 |
| 예정 | true | 5,500,000 | 20,000 | 5,480,000 |
| **확정** | false | 5,500,000 | 0 | 5,500,000 |
| **확정** | true | 5,500,000 | **20,000** | 5,480,000 |
| 예정, **양도 2020-06-01** | true | 5,500,000 | **20,000** | 5,480,000 |

**(나) 합산 확정(2종목)**: e=false → 공제 0 · 결정세액 9,500,000. e=true → 공제 **20,000** · 9,480,000.

**(다) 예정신고 `finalTax`(= 이력 자동 채움값) − 산출세액**:

| 전자신고 | 신고 위반 | 산출세액 | finalTax | 차 |
|---|---|---|---|---|
| ✗ | 없음 | 5,500,000 | 5,500,000 | 0 |
| ✓ | 없음 | 5,500,000 | 5,480,000 | −20,000 |
| ✗ | 무신고 | 5,500,000 | 6,600,000 | **+1,100,000** |
| ✓ | 무신고 | 5,500,000 | 6,576,000 | +1,076,000 |

**(라) 합산 확정 정산 손계산**(예정 첫 종목 무신고 가공 사례): 법문 공제 5,500,000 → 정산 추가납부 9,500,000 − 5,500,000 = **4,000,000**. 자동값 6,600,000 공제 → 9,500,000 − 6,600,000 = **2,900,000**(−1,100,000).

## 3. 원인·범위 [직접: 코드 읽기]

- 자동 채움: `paidTaxOf`(`stock-aggregate-entry.ts:108-111`)가 `resultData.finalTax`·`localIncomeTax`를 읽는다. `finalTax`는 `finalizeStockTax`에서 `floorTen(결정세액 + 신고불성실가산세 + 납부지연가산세)`이고 결정세액은 `산출세액 − 외국납부세액공제 − 전자신고 세액공제`다(`stock-transfer-finalize.ts:213-241`). 산출세액은 결과의 `calculatedTax` 필드로 같은 객체에 있다(probe에서 읽힘).
- 지방소득세: `localIncomeTax = floorLocalTax(floor(calculatedTax × 0.10))`이라 **산출세액 기준**이다 — 국세 쪽만 `finalTax`를 읽어 두 값의 기준이 서로 다르다.
- 전자신고 공제: `calcElectronicFilingCredit(isElectronicFiling, calculatedTax)`(`stock-transfer-helpers.ts:168-175`)는 신고 유형·양도일 인자가 없다. 합산은 `inputs.some(isElectronicFiling) && totalCalculatedTax > 0 ? 20_000 : 0`(`stock-transfer-aggregate.ts:629-630`)이고 `each_item` 경로도 같다(`stock-transfer-aggregate-each-item.ts:73`). UI 토글 문구는 «납세자가 직접 전자신고하면 20,000원을 세액공제합니다 … 신고 1건에 1회 적용됩니다»(`Step3.tsx:583-584`)로 예정신고 한정을 말하지 않는다.
- 과거 검토(`docs/reviews/penalty-code-review-2026-09.md` G-26·G-45)는 법 §104의8①의 «양도소득세» 문구까지만 확인했다 — 시행령 §104의5를 읽은 기록이 저장소에 없다 [직접: grep `104의8`].
- 이 PR에서 코드·테스트·시드는 바꾸지 않았다.

## 5. 미검증 · 확인 필요

1. 시행령 §104의5① 양도소득세 열거가 제31444호(2021-02-17) 개정에서 들어갔다는 연결 — 개정 이력 표기와 부칙으로 읽은 것이다. 2015-07-01~2021-02-16 사이 중간 시행본(2016~2020)을 하나씩 대조하지 않았다.
2. 법 §104의8①에 «양도소득세»가 들어간 시점(법률 개정 이력 표기 «2020.12.29.») — 시행일·적용례 부칙은 조회하지 않았다.
3. 법 §111③이 함께 말하는 «제114조에 따라 결정·경정한 세액 또는 제82조·제118조에 따른 수시부과세액» — 앱의 `preliminaryPaidTax` 입력은 이 둘을 구분하지 않고 하나의 칸이다. 이 계획서는 다루지 않았다.
4. §0 #4 사례는 가산세가 붙은 예정신고를 가공한 것이다. 실제 이력에서 예정신고에 가산세가 붙은 채 저장되는 빈도는 모른다.
5. 예정신고 가산세와 확정신고 가산세의 중복 배제(국세기본법 §47조의2⑤) 모델링은 V-17로 열려 있다 — Q-1 a는 그 문제를 해결하지 않고 «공제 기준»만 맞춘다.
6. 부동산 양도세 다건(`multi-prior-filed`)이 같은 `finalTax` 계열을 읽는지는 이번에 보지 않았다.
