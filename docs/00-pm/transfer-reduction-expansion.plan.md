# 양도소득세 감면 조문 확장 계획

> **작성일**: 2026-05-06
> **상태**: Plan (Phase 0 직전)
> **선행 산출물**: 본 계획서 → 조문별 PDCA Design Doc → Engine/UI 구현

---

## 1. 배경

현재 양도세 감면 UI는 **5개 평면 항목**(자경농지 §69 / 장기임대주택 §97의3 / 신축주택 §99 / 미분양주택 §99의3 / 공익사업 수용 §77)으로 구성되어 있으나, 실제 조세특례제한법은 **카테고리별 다수 조문**으로 세분화되어 있다.

현재 화면의 분류 오류도 발견됨:
- "미분양주택 감면 §99의3" → 조특법 §99의3은 **신축주택 과세특례** (2001-2003 한시)이며 미분양 조문이 아님
- 실제 미분양 시리즈는 §98·§98의2~§98의8·§99의2

본 계획은 **3개 카테고리 23개 조문** (장기임대 6 + 신축 4 + 미분양 10 + 자경/공익 별도)을 우선 골격(스켈레톤)으로 일괄 추가하고, **§99의3을 1번 우선순위**로 완전 구현(C안)한다.

> **2026-05-06 갱신** (2회):
> - 1차: §98의9(2024년 신설) 추가 → 22개
> - 2차: 사용자 제공 §97~§99의4 전체 원문 검토 후 §98의4(비거주자 일반주택 감면 10%) 추가 → **23개**. 시드 데이터 `99-2~99-6` 실제 조문 확정 (§98의3·§98의5·§98의7·§99의2·§98의8).
