# §155④ 합가 × §155⑳ 장기임대 — 상대 쪽이 임대를 보유할 때 양도자 쪽 주택 (V-9)

금액은 전부 mock 세율이다. 「기대값」은 구현 전 값으로, 임대 행을 뺀 입력(명부 1행 · 주택 수 2)으로 돌린 대리 실측(proxy)이다 — 구현 후 anchor로 다시 고정한다.

## 0. 요약

부친이 거주주택 + 장기임대 1채, 자녀가 1채인 세대가 동거봉양 합가 후 **자녀 주택**을 양도하면 §155⑳1호 거주 2년이 걸리지 않는다(0061). 지금 계산기는 3채라 ④가 불성립하고 ⑳은 거주 2년을 요구해, 비조정·거주 0이 과세되거나 입력 단계에서 막힌다.

권장 설계: E-3.5 합가 의제 경로에서 **임대 행만 주택 수에서 뺀다**. ⑳은 2호(임대 호별 요건) 판정만 빌린다.
