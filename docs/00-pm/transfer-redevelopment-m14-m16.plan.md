## 1. 재개발 양도세 프레임워크 총정리 (2축 + 조특법 연계)

재개발·재건축 양도세는 **성격이 다른 두 축(+ 조특법 감면 연계 축 C)**으로 구성된다. M-14/M-16이 어느 축인지가
설계·파일영향·anchor 전략을 가른다.

```
 ┌─ 축 A: 입주권·신축주택 「자체」 양도 (§166 양도차익 산정) ────────────┐
 │   자산: 조합원입주권(right) / 신축주택(apt)                          │
 │   엔진: lib/tax-engine/redevelopment.ts (+ 7 서브모듈)               │
 │   상태: ★ 이미 광범위 구현 (사례 36~42·44~48)                              │
 └────────────────────────────────────────────────────────────────────┘
 ┌─ 축 B: 주택+입주권 보유자의 「주택/대체주택」 양도 비과세 특례 ────────┐
 │   사건: 종전주택 양도 / 대체주택 양도 (일반 주택 양도 + 특례 게이트)  │
 │   엔진: lib/tax-engine/transfer-tax-exemption.ts (1세대1주택 판정)   │
 │   상태: ⚠ §155 계열(주택+주택)만 §156의2(주택+입주권)는 미구현       │
 └────────────────────────────────────────────────────────────────────┘
```

> 위 다이어그램은 **자산-양도 2축(A·B)** 만 표시. **축 C(조특법 감면)는 축 A 신축주택 양도차익에
> 감면을 얹는 오버레이**라 층위가 달라 별도 박스 대신 §1-9로 기술.

### 1-1. 자산 분류 & 과세대상 — §94①2호가목

- 조합원입주권 = **"부동산을 취득할 수 있는 권리"** (§94①2호 가목: "건물이 완성되는 때에 그 건물과
  이에 딸린 토지를 취득할 수 있는 권리를 포함"). 토지·건물(1호)이 아닌 **권리(2호)**.
- 취득 계기: 도시정비법 §74 **관리처분계획인가** 또는 소규모주택정비법 §29 **사업시행계획인가**
  (인가일 전 기존주택 철거 시 철거일)로 취득한 **입주자로 선정된 지위**. (§89①4호 괄호)

### 1-2. 양도차익 산정 — 시행령 §166 전항 해부 (verified 전문)

재개발 양도차익은 **①입주권 양도**와 **②신축주택 양도**를 분리하고, 각각 **청산금 납부/수령**으로
갈린다. "관리처분계획등인가전양도차익"과 "관리처분계획등인가후양도차익"을 축으로 조립.

**§166① — 조합원입주권 양도** (`subject="right"`)
- **1호 (청산금 납부)**: 인가후차익 `[양도가액 − (평가액 + 납부청산금) − §97①2·3호 필경]`
  **＋** 인가전차익 `[(평가액 − 취득가액) − §97①2·3호 또는 §163⑥ 필경]`
- **2호 (청산금 수령)** = 가목 **＋** 나목의 합
  - 가목 `[양도가액 − (평가액 − 수령청산금) − §97①2·3호 필경]`
  - 나목 `[(평가액 − 취득가액 − 필경)] × [(평가액 − 수령청산금) ÷ 평가액]`

**§166② — 신축주택 및 그 부수토지 양도** (`subject="apt"`)
- **1호 (청산금 납부)** = "청산금납부분양도차익" **＋** "기존건물분양도차익"
  - 청산금납부분 = `인가후차익 × 납부청산금 ÷ (평가액 + 납부청산금)`
  - 기존건물분 = `인가후차익 × 평가액 ÷ (평가액 + 납부청산금)` **＋** 인가전차익
- **2호 (청산금 수령)** = **§166①2호 준용** (가목＋나목)

**§166③** — 기존건물·부수토지 **취득가액을 확인할 수 없는 경우** 환산 산식 적용 (재개발 전용 환산 1차 근거).
**§166④** — "평가액" 정의 = **① 관리처분계획등에 따라 정하여진 가격(변경 시 변경가격)**,
② 없으면 §176의2③1·2·4호 순차 적용(이때 "양도/취득일 전후" → "인가일 전후"). → 엔진의 **권리가액**.
**§166⑤** — LTHD 보유기간 기산 (1-3 참조).
**§166⑥** — 토지·건물 가액 구분 불분명 시 부가세령 §64①/상증법 §62① 안분 (§166⑥ = 다필지 분리 근거).
**§166⑦** — **기준시가에 의한 양도차익** = 3구간 합계 (취득~인가전일 / 인가일~준공전일 / 준공~양도).
  ⇒ 실지거래가 불명이 아닌 **기준시가 과세** 경로. 현행 엔진 미구현(1-9 갭 N-7).
**§166⑧** — §100③ 단서 "다른 법령 가액구분/철거 후 토지만 사용" 사유.

### 1-3. 장기보유특별공제 — §95②·§95④ (원조합원·인가전 한정)

§95② 본문(verified)이 재개발 LTHD의 **직접 근거**(엔진 주석의 "별표2 [비고] 1호"는 이 본문 단서로 정정 인용):

- 대상 = **§94①1호 자산(보유 3년+)** ＋ **§94①2호가목 조합원입주권** —
  단, **"조합원으로부터 취득한 것은 제외"** ⇒ **원조합원만 LTHD, 승계조합원 배제**.
- 입주권 양도 시 = **"관리처분계획 인가 및 §29 사업시행계획인가 전 토지분 또는 건물분의 양도차익으로 한정"**
  ⇒ **인가후 분 LTHD 미적용**의 법적 근거.
- 표1(보유 6~30%) vs 표2(1세대1주택: 보유 최대40% ＋ 거주 최대40%). §95④ 보유기간 = 취득일~양도일.
- §166⑤ 기산 세분:
  - **1호** = 인가전차익 · §166①2호나목: **취득일 ~ 인가일**
  - **2호가목** = 청산금납부분차익: **인가일 ~ 신축주택 양도일**
  - **2호나목** = 기존건물분차익: **취득일 ~ 신축주택 양도일**

### 1-4. 세율 — §104 (입주권 단기세율) ★ 이미 구현

- **§104①1호** = §55① 기본세율(6~45%) — 입주권·신축주택 2년이상. (분양권만 60% 단일)
- **§104①2호** = 보유 1~2년: **60%** (주택·조합원입주권·분양권)
- **§104①3호** = 보유 1년미만: **70%** (주택·조합원입주권·분양권)
- 구현 확인: `transfer-tax-rate-calc.ts:352-366` — `right_to_move_in`·`redevelopment_apt`가
  `isHousingLikeProp` ⇒ 70%/60% 정확 적용. (승계조합원은 준공일 기산 §162①4호)

### 1-5. 비과세 — §89①4호(입주권 자체) + §89②(주택 양도 배제)

- **§89①4호 가목** = **1세대 1조합원입주권**(다른 주택·분양권 없음) → 입주권 양도 비과세.
  12억 초과 시 과세. **★ 구현됨** (`applyOneRightExemption`, `RedevelopmentRightExemptionSection.tsx`).
- **§89①4호 나목** = 1입주권 **＋ 1주택**(분양권 없음)으로서, **그 주택 취득일부터 3년 이내** 입주권 양도.
  (3년 초과 부득이 사유 포함) → **⚠ 미구현 (갭 N-1)**.
- **§89②** = 주택 **＋** 조합원입주권/분양권 보유 상태에서 **그 주택**을 양도하면 §89①3호(1세대1주택)
  **적용 배제**. **단, 대통령령(=§156의2) 사유는 예외** → 축 B의 근거.

### 1-6. 주택+입주권 1세대1주택 특례 — 시행령 §156의2 (verified 전문) ★ 축 B, 대부분 미구현

§89② 단서의 위임. **일반 주택/대체주택 양도에 1세대1주택 비과세(§154①)를 의제**:

| 항 | 특례 | 요건 요약 | 구현 |
|---|---|---|---|
| ③ | **일시적 1주택+1입주권** | 종전주택 취득 1년후 입주권 취득 + **입주권 취득 3년내** 종전주택 양도 | ✗ N-2 |
| ④ | **완성주택 실입주 전제 종전주택 양도** | 신축 완성 후 3년내 세대전원 이사·1년거주 + 완성 전 또는 후 3년내 종전 양도 | ✗ N-3 |
| ⑤ | **대체주택 특례** | 사업시행인가일 이후 거주목적 대체주택 취득·1년거주 + 신축 완성 3년내 이사·1년거주 + 완성 전/후 3년내 대체주택 양도. **보유·거주기간 제한 없음** | ✗ N-4 ★재개발 최빈출 |

| ⑧ | **동거봉양 합가** | 10년내 최초양도주택 비과세 (1주택+1입주권 등 조합) | ✗ N-6 |
| ⑨ | **혼인 합가** | 10년내 최초양도주택 비과세 | ✗ N-6 |

### 1-7. 고가주택 12억 초과 안분 — §95③·시행령 §160 ★ 구현됨

- 과세 양도차익 = `§95① 양도차익 × (양도가액 − 12억) ÷ 양도가액`, LTHD도 동율 안분.
- 입주권도 §89①4호 단서(12억 초과 과세) → 동일 안분. 구현: `highValueAllocation`·`oneRightHighValueApplied`.

### 1-8. 환산취득가·개산공제 — §166③·§164③⑤⑥⑦·§163⑥ ★ 대부분 구현됨

- **§166③** 환산 (산식 본문은 이미지로 법제처 API 미표출 → 엔진 `redevelopment-valuation.ts` 구현·§176의2③ 준용 기준): `floor(권리가액 × 취득당시 종전자산 기준시가 / 관리처분 직전 기준시가)`.
- **§164③** — 새 기준시가 고시 전 취득/양도는 **직전 고시분** 적용. (memory `feedback_standard_price_year_164_3_prior`)
- **§164⑤**(건물)·**⑥**(공동주택·오피스텔·상업용)·**⑦**(개별/공동주택가격 공시 전 취득) — 최초공시 전 취득 환산.
- **§163⑥ 개산공제** (verified): 대상은 입주권이 아니라 **환산 대상 종전 기존건물·부수토지**.
  - 1호 토지 = 개별공시지가 × **3%**
  - 2호 건물(주택 라목/오피스텔·상업용 다목) = 기준시가 × **3%**
  - 3호 §94①2호 **나목·다목**(지상권·전세권) = 기준시가 × 7% *(입주권=가목이므로 비해당)*
  - 4호 그 외 = 기준시가 × 1%
  - ⇒ 재개발 개산공제 **3%가 정확** (종전 토지 1호/주택 2호 기준). 입주권 7% 아님.
    *(종전 건물이 주택·오피스텔·상업용이 아닌 「가목외 건물」(§163⑥2호나목)이면 율 별도 — 재개발 종전자산은 통상 토지/주택 → 3% 전제.)*

### 1-9. 조특법 감면 연계 (축 C) — 재개발·재건축 신축주택 [실측 부분 구현]

축 A(§166)로 산정한 **신축주택 양도차익에 조특법 감면을 오버레이**하는 연계 축 (`transfer-reductions/` 실측):

### 3-3. M-14/M-16 후보 배정 (사례 지문 도착 시 확정 — 아래는 근거 있는 잠정 가설)

비과세 특례는 교재 최빈출 주제이고 현재 **전무**하다.

| 순위 | M-14/M-16 후보 | 근거 |
|---|---|---|
| **1순위** | **N-4 대체주택 특례 (§156의2⑤)** | 재개발 비과세의 대표 논점, 미구현, 교재 단골 |
| **1순위** | **N-2 일시적 1주택+1입주권 (§156의2③)** | 대체주택과 쌍, 미구현 |
