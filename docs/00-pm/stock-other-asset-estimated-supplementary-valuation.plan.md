## 2. 법령 (원문 확인 2026-10-04 — 소득세법 시행령 MST 290841 §165)

| 조문 | 원문(발췌) | 의미 |
|---|---|---|
| **영 §165⑧1호** | 「법 제94조제1항제4호나목부터 라목까지의 규정에 따른 **주식등**: 법 제99조제1항제3호 및 제4호에 따라 평가한 가액. 이 경우 법 제94조제1항제4호**라목**에 따른 주식등이 법 제99조제1항제4호의 주식등에 해당하는 경우에는 이 조 제4항제1호**나목**의 계산식에 따라 평가한 가액으로 한다」 | 기타자산 중 **주식등**(다목 과점주주·라목 부동산과다보유법인)의 기준시가는 §99①3(상장)·§99①4(비상장) 평가를 **그대로 준용**한다 |
| 법 §99①4 후단 | 「장부 분실 등으로 취득 당시의 기준시가를 확인할 수 없는 경우에는 액면가액을 취득 당시의 기준시가로 한다」 | §99①4로 평가하는 기타자산 주식등에도 적용된다 → 장부분실 토글이 기타자산에서 의미를 가진다 |
| 영 §165④1호 | 순손익가치 : 순자산가치 = 3 : 2, **§94①4호 다목 법인은 2 : 3**, 순자산가치 80% 하한 | 보충평가 산식 — 엔진 `calcUnlistedValuation`이 이미 구현 |

⇒ 기타자산 주식등을 비상장 보충평가로 푸는 것은 **법이 정한 방법**이고, 화면·⑧·⑫가 이미 그 전제로 입력을 받는다. 엔진만 어긋나 있다.

> ⚠️ **같은 조문의 후문이 새 쟁점이다**(§8 S-1c): 라목 주식등이 §99①4에 해당하면 가중평균이 아니라 **순자산가치 단독**이다. 현행 비상장 + 라목 경로가 이를 지키는지는 이 계획에서 확인하지 않았다 — 기타자산을 같은 경로에 편입하면 **그 경로의 현행 동작을 그대로 상속**한다.

## 3. 설계

### 3.1 단일 소스 술어

`stock-acquisition-basis.ts:213`, ④ `:422`·`:442`, 장부분실 leaf(`gift-acquisition-163-9.ts:61`), ⑤ Step2 시장 조건이 모두 «비상장 보충평가를 타는 시장인가»를 각자 `=== "unlisted"`로 적고 있다 — 이번 결함의 형태 그대로 다시 갈리지 않도록 **엔진 leaf 하나**로 모은다.

```ts
// 신설 (위치: stock-transfer 엔진 leaf — `trading-halt-market-scope.ts` 옆)
/** 비상장 보충평가(§99①4 → 영 §165④)로 기준시가를 구하는 시장인가 — 영 §165⑧1호가 기타자산 주식등도 같게 본다 */
export function usesUnlistedSupplementaryValuation(marketType: string | undefined): boolean {
  return marketType === "unlisted" || marketType === "other_asset";
}
```
