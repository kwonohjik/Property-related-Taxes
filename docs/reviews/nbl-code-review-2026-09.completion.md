## 4. 🔴 리뷰 자체가 틀렸던 것

리뷰 산출물을 그대로 채택했다면 **새 결함을 만들었을** 지점들이다.

### 4-1. 배경 전제 오류 — 「비사업용 토지는 장기보유특별공제 배제」

리뷰 착수 시 배경 규칙으로 제시했으나 **현행법과 어긋난다**. §95②의 제외 열거는 **미등기양도자산(§104③)과 §104⑦ 각 호(다주택 중과)뿐**이고, 비사업용 토지는 §104①8호라 열거에 없다 — **표1 공제가 그대로 적용**된다.

2차 검증 에이전트가 잡아냈고 메인 루프가 조문 본문으로 재확인했다. 파급:

- 1차 발견들의 세액영향에 계상된 「장특 배제분」은 **과대 계상**이었다(+10%p 부분만 유효).
- 반대로 **과거 양도분에는 배제가 실재했고 그것이 미구현**이었다 → H-2(44,000,000원).

### 4-2. 처방의 판별식이 틀림 — PR-4 일반구 판정

리뷰 처방은 일반구를 `code[3:5] !== "00"`으로 가르라고 했다. 실측하니 **256건 중 238건**이 걸려 서울 종로구(11110)·의정부시(41150)까지 오탐한다. 대안 「끝자리 ≠ 0」도 12건 오탐.

정본은 **명칭**이었다 — `fullName`이 3토큰(도 + 시 + 구)인 것이 정확히 **39건 · 13개 시**, 반례 0. 그대로 구현했다면 자치구까지 접혀 **반대 방향의 과대적용**이 됐다. 원 리뷰 문서에 정정 블록을 남겼다.

### 4-3. 착수 조건이 미해소인 채였던 것 — COV-1

처방에 「⚠️ 0.8 적용 여부는 개정 전 §168의6 본문을 확인한 뒤 결정 — **확인 전 numeric 변경 금지**」가 걸려 있었고, 리뷰는 그 조회에 실패한 상태였다. 시행일별 MST로 직접 받아냈다:

| 시행본 | §168의6 각 호 다목 |
|---|---|
| 2014.03.11. (MST 151843) | 「소유기간의 **100분의 20**」 |
| 제26067호 [시행 2015.02.03] (MST 168102) | 「**100분의 40**」 |

⇒ 레거시 0.8이 **법적으로 옳다**는 것이 확인돼 배관을 고칠 수 있었다. 같은 조회에서 **경계 상수가 하루 어긋난 것**(`2015-02-02` strict `<` → 구법이 적용될 하루를 신법으로)도 함께 드러났다.

### V5-d 상세

리뷰는 「임야만 §168의9①2호가 단서로 과세측 재포섭 구조」라고 지적했다. 확인 결과:

- **계산은 공유가 맞다** — 2014 시행본에서 §168의8⑥ 「2년」 / §168의9①2호 단서도 「편입된 날부터 **2년**이 경과한」이었고, 제26067호에서 셋 다 3년으로 **함께** 개정됐다. 문언 방향은 반대지만(「지나지 아니한」 제외 / 「경과한」 제외) 귀결이 「N년 이내 → 사업용」으로 같다.
- **갈리는 곳은 미상 기본값 하나**다. 농지·목장은 날짜가 **납세자 유리 예외**라 미입증 시 예외 미적용이 자연스럽지만, 임야는 「N년 경과」가 **과세를 되살리는 적극적 사실**이다.

⇒ `checkForestIncorporationGrace` 래퍼로 분리해 현행 기본값이 **의도된 선택**임을 못 박고, 공용 함수 주석에 임야가 이 경로를 쓴다는 사실과 연혁 실측 근거를 적었다. 실무 노출은 좁다 — ⑧ 검증이 도시지역 임야에 편입일을 **필수로 차단**하므로 미상 조합은 API 직접 호출·구 이력 복원에서만 생긴다.

## 8. 교훈

1. **리뷰 산출물은 그 자체가 검증 대상이다.** 배경 전제 1건·처방 판별식 1건이 틀렸고, 그대로 채택했으면 새 결함이 됐다. 특히 **처방에 적힌 판별식은 실측으로 재현**해야 한다.

2. **「착수 금지」 조건은 넘어선 뒤에도 살아 있다.** COV-1은 리뷰가 조회에 실패해 조건이 미해소인 채였다. 그 조회를 다시 시도해 해소한 뒤에야 손댈 수 있었다.

3. **배치 누락은 ID 대조로만 잡힌다.** U1-02는 🔴 등급인데 계획서에 없었다. 사람 눈으로는 78건 중 1건이 빠진 것을 알 수 없다.

4. **한쪽만 고치면 조용히 통과한다.** rowOrder를 단건만 고쳤을 때 합계 단언이 공허하게 통과했고, 타입도 테스트도 잡지 못했다. **양쪽에 같은 구조가 있으면 parity 테스트**를 둔다.

## 10. E2-09 후속 — 결격 과세기간을 실제로 차감한다 (#1429)

## 11. 별표6 3호바 **표**까지 엔진이 산출한다 (#1433)

#1427은 10% 상한만 강제하고 **표는 사용자가 직접 계산**하게 했다(입력 hint에 「표의 기준면적에

### 표는 이미 저장소에 있었다

`lib/tax-engine/non-business-land/data/area-standards.ts`의 `employeeSportsArea(kind, n)`가
**「소득세법 시행규칙」 [별표 5]** 를 구현하고 있었고(§168의11①1호 기타토지 체육시설용지),
그 수치가 **「지방세법 시행규칙」 [별표 6] 3호바와 완전히 동일**했다(양쪽 본문 실측).

⇒ 사본을 만들지 않고 표를 세목 중립 위치(`lib/tax-engine/data/employee-sports-standard-area.ts`)로
옮겨 **양쪽이 같은 수치를 쓴다**. 기존 호출부는 재수출로 그대로 둔다.

🔴 **비고는 이미 다르다** — 표만 공유하고 비고 적용은 각 소비 모듈이 자기 법령대로 한다:

| | 「소득세법 시행규칙」 별표5 | 「지방세법 시행규칙」 별표6 3호바 |
|---|---|---|
| 50인 이하 코트만 | 「50인 이하인 **자**」 (개인·법인 불문) | 「50명 이하인 **법인**」 |
| 실내 배율 단서 | §101①2호 부속토지면 **배율 미적용** | 단서 없음 |

### 인정면적 산식

```
운동장   = min(운동장 용지면적, 표[운동장](종업원수))
코트     = min(코트 용지면적,   표[코트](종업원수))
실내기준 = min(실내 건축물 바닥면적, 표[실내](종업원수))   ← 비고 2-다
실내     = 실내기준 × §101② 용도지역별 적용배율            ← 비고 2-라

인정면적 = (종업원 ≤ 50 且 법인) ? 코트 : 운동장 + 코트 + 실내   ← 비고 2-나
최종     = min(인정면적, 공장입지기준면적 × 10%)               ← 바목 괄호
```

⚠️ **행별로 min을 잡는다.** 합계끼리 비교하면 한 행의 초과분이 다른 행의 여유분을 먹는다 —
운동장 2,000㎡(표 1,000)·코트 0㎡(표 970)이면 행별 1,000 vs 합계끼리 1,970으로 **970㎡ 과대**.

⚠️ 비고 1(운동경기 가능 시설·영구 시설물·탁구대 2면 이상)은 **사실 판단**이라 엔진이 검증하지
않는다. 면적 입력이 곧 요건 충족 선언이며 UI가 그 사실을 밝힌다.

### 미입력은 차단한다

- 시설 면적을 넣고 **종업원수가 없으면** 표를 적용할 수 없어 인정면적이 **통째로 0**이 된다
  (기준면적 과소 → 비사업용·종합합산 과대 = **납세자 불리**) ⇒ ⑧에서 차단.
- 종업원 50명 이하인데 **사업주체 미선택**이면 비고 2-나 적용 여부가 갈린다. 개인에게 적용하면
  법 근거 없이 불리해지므로 ⑧에서 명시 선택을 요구한다.
- 실내 바닥면적을 넣었는데 **§101② 배율을 알 수 없으면**(세분 전 주거지역 등) 실내분을 산입하지
