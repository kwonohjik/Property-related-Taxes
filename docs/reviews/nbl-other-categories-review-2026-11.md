## 1. critical — 9건

### 1.1 V1-A — 건축물 없는 기타토지의 비과세·면제·분리과세·별도합산 선언을 종합합산으로 덮어쓴다 (부분 확정 · 기존 결정 재검토)

- **위치**: `other-land.ts:42-50`(isBareLand의 `!hasBuilding → true`) · `:89-90`(effectiveTaxType 강제) · `:196-198`(공장 입력 시 exempt 무시) · `:511`(2% 바닥면적 carve-out이 exempt·special_sum 선언에도 적용) · `OtherLandDetailSection.tsx:222`(토글 설명 「건물 없으면 나대지 간주(종합합산)」) · `calc-wizard-asset-factory.ts:374`(건축물 토글 기본값 OFF).
- **법령**: 법 §104의3①4호 가목(「「지방세법」 또는 관계 법률에 따라 재산세가 비과세되거나 면제되는 토지」)과 나목(「…별도합산과세대상 또는 분리과세대상이 되는 토지」)은 건축물을 요건으로 하지 않는다. 「지방세법」 §106①2호나목(공지상태 토지)·다목(철거·멸실 토지 → 「지방세법 시행령」 §103의2), 같은 항 3호(분리과세 → 「지방세법 시행령」 §102), 「지방세법」 §109③(비과세). 2% 규칙(「지방세법 시행령」 §101①2호나목)은 **건축물 부속토지 범위** 안의 제외 규정이다. 국세청 서면4팀-1116(2006.4.25.)·서면4팀-1272(2008.5.26.): 재산세 비과세 도로는 비사업용 토지가 아니다. 서면4팀-3604(2007.12.21.): 잡종지 차고지가 별도합산이면 「별도합산 또는 분리과세대상인 기간동안」 제외한다.
- **실측**: 화면 경로(⑧ 통과 null)에서 exempt·separate·special_sum 세 선언 모두 비사업용. 산출 261,240,000 vs 대조 204,090,000 → **+57,150,000**(총부담 +62,865,000). 하위 결함: 2% 미달 + exempt·special_sum → 비율 0.95, 사유에 「별도합산 유지」 오표기. 공장 + exempt → 비율 0.6(좁은 경로).
- **기존 결정**: PR#291(2026-06-19)이 「override 로직 변경 금지 — 나대지를 근거 없이 별도합산으로 선언하는 역버그 방지」로 명시 결정했다(`docs/00-pm/nbl-gaps/nbl-residual-gaps-2026-06-19.plan.md:181·196`). 그 결정의 법적 근거는 「지방세법 시행령」 §101①2호나목뿐이었다. 가목, 「지방세법」 §106①2호나·다목·3호, §109, 국세청 해석은 검토되지 않았다 → **Q-1**.
- **처방**: 재산세 분류 아래 «근거» 하위 선택을 둔다(§7.1). 「건축물 없음 + 비종합합산 선언 + 근거 미선택 → 종합합산 + 확인 필요」는 **엔진**에 둔다. 그래야 직접 API·다건에서도 역버그 방지가 유지된다. 2% 규칙은 건축물 부속토지 근거에만 적용한다. 공장 경로는 exempt를 먼저 검사한다. 한시 지위(「지방세법 시행령」 §103의2 1년·빈집 3년)와 §101③ 각 호의 면적 한도는 입력이 없으므로 확인 필요로 고지한다. 새 조문 상수는 manifest에 등록한다.
- **바꿔야 할 테스트**: `__tests__/lib/calc/nbl-detailed-cases.test.ts:202-215`(「나대지 + 별도합산 → override 정당」)을 «근거 미선택» 케이스로 재정의한다. BM-10은 이 강제를 고정하지 않는다(발견의 주장 정정).

### 1.2 V1-B — 다목 호를 고르면 나목이 이미 인정한 사업용 면적을 버린다 (확정)

- **위치**: `other-land.ts:255-419` — 다목(⑥ :283-320 · ⑤ :327-377 · ① :380-403)이 부분 결과를 즉시 반환한다. 나목 부분 적용(배율 :427-453 · 공장 :455-504 · 2% 바닥면적 :511-550)은 다목에 해당하지 않을 때만 도달한다. 코드 자신의 주석(:110-114·:158-160·:421-423, 「가·나·다목 중 어느 하나면 사업용」)과 반대 방향이다.
- **법령**: 법 §104의3①4호 「다음 각 목을 제외한 토지」 — 가·나·다목은 위계 없는 병렬 제외 사유다. 나목(「지방세법 시행령」 §101①2호 「…용도지역별 적용배율을 곱하여 산정한 면적 범위의 토지」)과 다목(영 §168의11①2호가목 「설치기준면적 이내」·7호 「100분의 120 이내」)은 모두 **면적 범위**로 제외한다. 따라서 제외 면적은 적어도 max(나목, 다목)이다. 같은 필지를 면적별로 나눠 판정한 사례: 사전-2019-법령해석재산-0289. 다목이 나목을 대체한다는 해석례는 찾지 못했다.
- **실측**(메인 루프 직접 재현 포함): 녹지 7배 · 1,000㎡ · 별도합산 · 2% 통과.
  - 바닥 143㎡(허용 1,001㎡) → 사업용 · 산출 198,210,000
  - 바닥 142㎡(허용 994㎡) → 비율 0.006 · 산출 198,210,000(§104⑤가 흡수)
  - 바닥 142㎡ + 부설주차장(설치기준 200㎡) 선택 → 비율 0.8 · 산출 220,570,000 → **+22,360,000**
  - 발견자 시료(하치장) +31,368,000, 검증자 시료 +18,755,000
- **처방**: 목별 사업용 면적을 각각 산출하고 max로 합성한다(§7.1 누산기). 다목이 나목보다 좁으면 나목 결과를 쓰고 「두 범위가 다른 위치면 더 넓을 수 있음 — 확인 필요」를 남긴다. 단순 합산은 이중 계상 위험이 있어 기각한다.

### 1.3 V2-C1 — 유예기간(영 §168의14①)과 양도일 의제(영 §168의14②)를 받아 놓고 판정에 쓰지 않는다 (확정)

- **위치**: 기타토지가 비사업용으로 끝나는 분기(종합합산 기본 `other-land.ts:552-562` · 배율 초과 :427-453 · 2% 바닥면적 :511-550 · 호별·연접 초과 · 공장 초과 · ⑥ 잔여)는 기간 판정을 하지 않는다. 사업용 분기는 `fullPeriod`를 넘겨 기간기준이 공허하게 충족된다(`:456-459` 주석이 스스로 밝힌다). `housing-land.ts`는 기간 판정 자체가 없다. 그런데 화면 `GracePeriodSection.tsx:101`은 「사업용 사용 기간에 가산됩니다」라고 안내하고, ⑧은 사유별 날짜를 필수로 검증한다.
- **법령**: 영 §168의14① 「…해당 각 호에서 규정한 기간동안 법 제104조의3제1항 각 호의 어느 하나에 해당하지 않는 토지로 보아…」 — 지목 제한이 없다. 규칙 §83의5①5호(건축물 없는 토지를 취득해 착공: 취득일부터 2년 + 건설 진행 기간) · 9호(멸실·철거)는 사실상 나대지를 위한 사유다.
- **실측**: 나대지 + 「법령상 사용 금지」 유예 전 기간 → 비사업용 그대로(메인 재현 297,640,000). 같은 유예의 농지는 사업용(233,490,000). 검증자 시료: 산출 **+55,750,000**(총부담 +61,325,000) · 배율 초과 0.6 시료 +7,780,000 · 주택부수토지 0.5 시료 +1,510,000.
- **처방**: 비사업용 잔여분을 확정하기 직전에 `meetsPeriodCriteria([], acquisitionDate, pjDate, "other_land", rules, gracePeriods)`(빈 사업기간 + 유예)로 판정한다. 기존 fullPeriod 호출에 유예만 얹으면 합집합 증가분이 0이라 효과가 없다.
- **순서 제약**: **V3-PR05(9호 연혁)를 같은 PR이나 그 앞에** 둔다. 그렇지 않으면 2025.3.21. 전 양도 나대지에 9호 5년이 적용돼 2~5년 구간이 과다 산입된다(과소 과세 경로가 새로 열림).
- **주택부수토지**: 2026-07-31 사용자 방침(«주택 배율 초과분은 기간요건 판정 없이 일률»)과 겹친다 → **Q-3a**. 결정 전에는 「주택부수토지 판정에는 반영되지 않음 — 확인 필요」 고지만 단다.

## 5. 완전성 비평이 추가로 찾은 것

> 아래 5.1~5.3은 완전성 비평 에이전트가 probe로 재현했지만 **독립 반증 검증은 거치지 않았다.** 착수 전 Pre-Do anchor로 다시 재현할 것.

### 5.1 이월과세가 배제된 토지(시나리오 B)에도 증여자 취득일 소급이 남는다 — high

- **법령**: 영 §168의14③3호 괄호 「…법 제97조의2제1항을 **적용받는 경우**에는 증여자가 해당 자산을 취득한 날」. 이월과세는 법 §97의2②1호(수용 2년 이전 증여 — 사용자 선언), ②3호(세액 비교 — 자동), ③(기간 경과)으로 흔히 배제된다. 배제되면 수증일이 기준이다.
- **위치**: `nbl-unconditional-exemption-status.ts:178-180`(carryover_gift면 항상 증여자 취득일) → `non-business-land-request.ts:139` → `form-mapper-helpers.ts:148-153`(이월과세 적용 여부와 무관). `transfer-tax-carryover-inputs.ts:57-63`의 buildInputB는 주석이 「§97의2 적용 없는 일반 취득」인데도 `nonBusinessLandDetails`를 그대로 둔다.
- **실측**(route · 폴백 세율 · ⑧ 통과): 기간 경과 배제 → totalTax 250,371,000 vs 대조 319,396,000 → **−69,025,000**. 수용 2년 이전 증여 배제 → **−72,105,000**. 세액 비교로 B가 채택된 경우 A/B 비교 자체가 왜곡될 수 있다.
- **기존 결정**: L22(2026-11-08) 「이월과세 토지의 NBL 소유기간 기산일 = 증여자 취득일」. 근거 해석례(서면4팀-2622 등)는 이월과세가 «적용된» 자산에 관한 것이다. 이번 리뷰 period 축의 정상 확인 2건(C36·C37 「③3호나목 소급이 원문 괄호와 일치」)이 이 경로를 놓친 false-clean이었다 → **Q-11**.
- **순서**: V3-PR01·V3-BX03 처방이 「이월과세 = 증여자 취득일」을 조건 없이 복제하지 않도록, 이 처방(R23)을 같은 PR이나 그 앞에 둔다.

### 5.2 증여세 부담부증여의 양도소득세 — 비사업용 토지 처리 (medium)

- 증여세 마법사의 부담부증여 양도분은 토지 «전량» 체크박스만 있고, 부분 비사업용·건물 부수토지 초과분을 반영하지 않는다.
- 실측(초과 40% 시료): 체크 ON +30,525,000(과대). 초과 70% 시료: 체크 OFF −2,013,000(과소). route·Zod는 raw를 받을 수 있어 ④⑤만 없다.
- 처방: 최소 «확인 필요» 고지, 근본은 `NblSectionContainer`·`buildNonBusinessLandRaw` 재사용 또는 양도세 마법사 핸드오프 → **Q-13**.

### 5.3 토지 일부(분필) 양도 — 판정 면적 단위 (해석 미확인)

- 1,000㎡ 중 400㎡를 양도하면 비율을 총 취득면적 기준으로 계산해 양도분에 적용하고, 경고는 0건이다.
- 법령상 정답(양도 필지 자체로 판정 vs 전체 비율 안분)의 해석례를 확인하지 못했다. 결론 전까지 확인 필요 고지, 또는 ⑧에서 양도 필지의 정착·바닥면적을 요구한다.

### 5.4 정상 확인 (결함 재현 안 됨)

- 다건(연간 합산) route ↔ 단건 parity: 나대지 · 배율 초과 0.4 · 하치장 0.4 · 주택부수 0.7 · 별장 1.0 다섯 셀 모두 원 단위 동일, 2건 합산에서도 건별 판정 유지.
- 축 B(지분) 경로: 기타토지 · 주택부수 · 별장의 지분별 비율이 단건과 같다.

### 5.5 2026-09 리뷰 종결 계측 결함

- 종결 역grep 정규식 `^### [A-Z0-9-]*`가 소문자 접미 ID(V1-a … V10-f 29건)를 「V1-」로 잘라 다른 ID 마커에 걸리게 했다. 같은 원인으로 U1-03·U2-03·U2-04가 「처리됨」으로 잘못 집계됐다(V9-J·DM-13).
- 소문자를 받는 정규식으로 다시 재면 마커 0건이 8개다: 해소 4(V1-b·V2-a·V5-f·V7-c) · 코드 무관 3(V7-a·V9-b·V10-d) · **미해소 의심 1(V9-d)** — 정밀판정 raw가 없을 때 `isNonBusinessLand` 전송을 막거나 route 400을 주라는 처방의 흔적이 없다(`transfer-tax-api.ts:540`). V6-PU01·신규 발견 #16과 같은 계열이다.

## 7. 개선 방향

### 7.1 기타토지 판정기 → 「목별 제외 면적 누산기」

- **원인**: 법문은 가·나·다목을 병렬 제외 사유로 두는데, `judgeOtherLand`는 «차례로 시험하다 첫 결론에서 반환»하는 조기 반환 16곳의 결정 목록이다. V1-B(다목 부분 결과가 나목을 가림), V2-C1(비사업용 분기엔 기간 판정 지점이 없음), V10-P(echo 불일치)가 같은 뿌리다.
- **설계**: 각 목의 사업용 면적을 후보로 push하고, 끝(`finalizeOtherLand`) 한 곳에서 max로 합성한 뒤 유예를 판정한다. 전량 PASS 6곳은 지금처럼 즉시 반환해 기존 step 부재 단언(ORDER-1·3, BM-4·5)을 지킨다. 세액 계약(`isNonBusinessLand`·`nonBusinessAreaRatio` 두 값)은 그대로라 PR#248 산식·다건·신고서는 변하지 않는다. probe 기준 V1-B 시료 6건이 정정되고 기존 anchor 20건의 비율은 바뀌지 않는다.
- **재산세 분류 + 근거 모델(Q-1)**: 근거별 후보 — 가목(§109·관계 법률)과 분리과세(§102)는 전량, 공지상태 별도합산(§101③)은 전량 + 호별 한도 확인 필요, 철거·멸실(§103의2)은 종전 바닥면적 × 배율 + 한시 지위 확인 필요. 2% 강등과 배율 게이트는 건축물 부속토지 근거에만.
- **다목 호 메타데이터 단일 표**: 호 · 요건 · 면적 산식 · 근거 조문 · 필요 입력 · 자동 검증 가능 여부를 표 하나(`satisfies` 커버리지 가드)에 두고 UI 선택지·⑧·⑫ enum·엔진 switch·결과 근거를 여기서 만든다. 지금은 7곳(union·UI 옵션·UI 근거·면적 switch·근거 switch·⑧·⑫)에 흩어져 있어 누락 호·자유 문자열·레거시 경로가 드러나지 않는다.
- **단계**: P0 독립 정합(V7-E·V6-D·V9-DM06·V7-DM02·V9-DM11) → P1 체육 술어 → P2 누산기 → P3 유예(V2-C1, V3-PR05 선행) → P4 근거 모델(Q-1) → P5 호 메타 표(Q-5·Q-6) → P6 시간축(Q-4 결정 후).
- **기각**: 나목·다목 면적 단순 합산(이중 계상), 위치 입력 기반 합집합(입력 부담), 모든 목을 항상 평가(법적 이득 없이 step 단언만 깨짐), 기존 fullPeriod 호출에 유예만 얹기(효과 0).

### 7.2 건물 부속토지 초과분 → 「비사업용 파트」 단일 모델

- **원인**: 같은 사실(한 필지 중 배율 초과 면적)이 9개 입구(NBL Step 0.6 · building_site · GB 3경로 · CB STEP 0.62 · 다건 aggregate · 겸용 주택/상가분 · G-2 · §155⑳ · 컴패니언 카드)에서 따로 처리된다. 그래서 위기취득(V4-HS01), 장특 연혁(V5-G1·G2), 공익수용 의제(V3-BX03), 소재지 기본값(V4-HS02·HS06), 부동소수(V9-I)가 경로마다 다르다.
- **설계**: 입구는 공용 부품만 공유한다 — leaf 4개(면적 산수 · 장특 연혁 · 가산 배제 · 수용 의제) + 판정기 2개(주택 영 §168의12 / 비주택 「지방세법 시행령」 §101① — 두 조문을 한 함수 뒤에 두지 않는 A-BS-1 원칙 유지) + 고지 세트 1개.
- **P0 등가 대조 anchor 격자**: 같은 사실을 입구별로 넣어 같은 세액이 나오는지 고정한다. 결함 셀은 «기대 vs 현재» 표로 고정하고, 수정 PR마다 하나씩 GREEN으로 넘긴다. 프로덕션 코드 변경 0.
- **단계**: P0 격자 → P1 GB 카드 조립 단일 leaf(V10-BX08) → P2 면적 산수 leaf(V9-I) → P3 파트 규칙 leaf + 신고서 코드(V4-HS01·V5-G2·V9-RI05) → P4 토지 자산 부분 비사업용 파트 장특(V5-G1·V5-H) → P5 소재지 결정성 leaf(V4-HS02 먼저, HS06 뒤) → P6 수용 의제 leaf + 고지 세트(V3-BX03·Q-3b) → P7 CB 3파트(V5-BX01) → P8 겸용 상가분(Q-8).
- **기각**: NBL 엔진 하나로 GB·CB 초과분 판정(CB 계획서 §3.5의 기각 사유가 유효 — 영 §168의6이 끼어들고 building_site엔 다목이 없다), building_site 지목 개방(자체 헤더가 다목 이식 전 노출 금지), CB 스칼라 보정만(2016 전 장특·신고서·차손 통산 표현 불가), 소재지 미입력 «판정 생략»(조용한 비과세).

### 7.3 단일 소스 — 연혁 leaf · 입력 소비 지도 · echo 파생 표시 · 면적 정확 비교 · 인용 의미 게이트

- **연혁 leaf 표준**: 연혁 결함 3건(V3-PR01·V3-PR05·V8-VL01)은 「현행 숫자 리터럴 + 선택적 날짜 인자」라는 같은 생성기에서 나왔고, 2026-09 리뷰가 현행 시행본만 대조해 놓친 부류다. 기준일 축(양도일·고시일·취득일)별 값과 근거·부칙 echo를 돌려주는 leaf를 `lib/tax-engine/data/`에 두고, 레지스트리 스캔 테스트로 리터럴 재발을 막는다. 「미제공 시 현행」 하위호환 계약(`urban-area.ts:104-110` 등)은 필수 인자로 바꾼다 — V9-J(화면이 양도일 없이 현행값을 받음)의 원인이다.
- **지목별 공통 입력 소비 지도**: 어느 지목이 도시편입일·유예·의제·수도권을 실제로 소비하는지 엔진 술어로 export하고 ⑤ 렌더·⑧·④·결과 카드가 공유한다(`consumesPeriodJudgmentDate` 확장). V10-PU10·V8-VL08·V2-C1 고지가 한 곳에서 해결된다.
- **결과 카드 = 엔진 echo 파생**: `periodEvaluation`·`areaProportioning.legalBasis` echo를 신설하고 고정 문구를 없앤다. V5-H(장특 0인데 「표1 적용」), V10-P(비사업용인데 「사업용 비율 100%」), V10-K, V9-J가 구조적으로 사라진다.
- **면적 정확 비교 헬퍼**: 한도·초과 비교는 반올림 없는 정수 정확 비교로 한다(공장 경로의 「근거 없는 반올림 금지」와 정합, 1.2·1.5배 같은 비정수 배율에서도 일관). 배율은 정본 진입점만 쓰도록 원시 맵 인덱싱 금지 스캔을 둔다(V7-E 재발 방지).
- **법령 인용 의미 게이트**: manifest는 조 단위 키라 상수의 «의미» 오기(V10-BX10)를 못 잡는다. 조 제목 스냅샷·topic 표로 보완한다. 소비처 0건 오기 상수 6종의 삭제는 Surgical 원칙의 예외라 사용자 승인이 필요하다.
- **리뷰 종결 계측**: 리뷰 접두 ID(`NBL2611-`), 소문자 허용 정규식, 경로 한정(docs 포함 여부 명시), «처방 후단까지» 테스트로 계측.

### 7.4 입력 UX — 결론 대신 사실·출처·«모름»을 묻는다

- **재산세 분류**: 재산세 과세내역(고지서)·위택스 확인 안내 + 근거 하위 선택 + 「모름」 선택지(→ 불리 + 확인 필요). 미선택 차단(2026-09 A1-01)은 유지한다. 외부 자동 조회는 본인 인증·공개 조회 수단 미확인·개인정보 부담으로 기각.
- **다목**: 「용도 질문 → 호 자동 매핑」 2단계 흐름과 요건 체크리스트(자동 검증 가능 / 사용자 확인 구분).
- **숨김·검증·전송을 한 술어로**: 숨긴 칸의 값은 store에서 지우지 않는다(이력 복원값 보존). 대신 매퍼 게이트가 전송하지 않는다. useEffect 미러링 금지 규칙과 맞는다.
- **기간 행 공통 검증 helper**: 역순·같은 날·빈 행을 별장·농지 자경·거주 이력·유예 행에 공통 적용(V8-VL02).
- **면적 정의 정본 문구 상수**: 정착면적 = 건축면적(「건축법 시행령」 §119), 「지방세법 시행령」 §101① 바닥면적, 부속토지 면적을 공용 상수로(V4-Q).
- **결과 상단 «확인 필요» 목록**: 판정이 기댄 가정과 자기 선언 요건을 모아 보여 주고 인쇄에도 포함한다. 「모름 = 혜택 불성립 + 확인 필요」 원칙을 화면에서 지키는 장치다.
