  - **정정 ②(구조)** — 「두 가중항이 모두 ≤1」이 아니다. 다목은 첫째·셋째 항이 약분되어 **`특수관계인 실권주수 × 증자후 신주인수자의 지분비율`** 2인자다. ⇒ 사용자가 라벨(「실권주수」)에 특수관계인분만 넣더라도 **지분비율이 여전히 누락**되므로 어떤 입력 해석에서도 과다과세 결론이 유지된다.

- **수정 방향**: `increaseLow`의 `no_realloc` 분기를 §29②2호 다목 전용 인자로 분리한다 — 「특수관계인의 실권주수」와 **「증자후 신주인수자의 지분비율」**(현행 입력 타입에 없는 새 축)을 받아 `safeMultiplyThenDivide`로 가중하고, **그 가중값을 `:72`의 3억 판정에도 쓴다**. 기존 `relatedAcquiredShares`/`ratioDenomShares`는 §29②4·5호 전용 「신주수 분수」라 의미가 달라 그대로 재사용하면 안 된다. 14지점 중 ⑤(`needsRatio` 조건 확대)·⑧(지분비율 필수화)·⑫를 함께 고치고, **`[CI-LOW-NR]`·`[CI-LOW-NR-FAIL]` anchor 기대값을 가중 후 값으로 정정**해야 한다(현재 안전망이 틀린 값을 지키고 있다).

- **수정 방향**: 수증자별 이익을 「재배정·제3자·초과배정 몫(§29②1·3·5호)」과 「실권처리 몫(§29②2·4호)」으로 나눠 게이트를 **각각** 적용한다. 분리 기준은 이미 입력에 있다 — 수증자의 `reallocatedShares`(가·다·라목분)와 나머지(나목분). 재산세과-60의 「각각 산정하여 합산」과 정합하며, 전량 재배정·전량 실권처리 케이스에서는 현행과 동일값이 되어 기존 anchor(C1~C6)를 깨지 않는다.
