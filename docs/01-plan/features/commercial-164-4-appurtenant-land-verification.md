# 검증 — §164④(1990.8.30. 이전 취득 토지)가 상가 부수토지에 적용되는가

> 대상: 소득세법 시행령 §164⑥ 경로(상가·오피스텔 호별고시 전 취득)에서 **취득일이 1990-08-30 이전**일 때
> 기준시가합의 **토지 성분**을 어떻게 산정하는가.
> 발단: [`commercial-164-6-proviso-164-5-application.plan.md`](commercial-164-6-proviso-164-5-application.plan.md) §9-B (별건 이관).

## 0. 결론

**적용된다.** §164⑥ 산식의 토지 성분은 「법 §99①1호 **가목**의 가액」이고, 그 가액이 개별공시지가
고시 전이면 이를 정하는 규정이 §164④다. **준용 조항이 없는 것은 배제가 아니라 불필요**하기 때문이다.

- 확신도: **확정** — **§164⑥ 산식 원문이 분자·분모를 "법 제99조제1항제1호 가목의 가액과 나목의 가액의 합계액"으로 명시**한다(§2-0, 2026-07-28 원문 확보). 종전의 시행규칙 §80③3호 유추가 직접 근거로 격상됐다. (판례·심판례·유권해석은 여전히 미발견 — §4)
- 프로젝트 영향: **갭 실재** — 상가 경로에 1990 환산 입력 경로가 없다(§5).

## 2-0. ★ 산식 원문 (2026-07-28 확보 — 종전 §7-B 미해소 항목)

**§164⑥ 산식**
```
                                취득당시의 법 제99조제1항제1호 가목의 가액과 나목의 가액의 합계액
국세청장이 당해 자산에      ×  ────────────────────────────────────────────────────────────
대하여 최초로 고시한            당해 자산에 대하여 국세청장이 최초로 고시한 기준시가 고시당시의
기준시가                        법 제99조제1항제1호 가목의 가액과 나목의 가액의 합계액
                                (취득당시의 가액과 최초로 고시한 기준시가 고시당시의 가액이
                                 동일한 경우에는 제8항의 규정을 준용한다)
```
<개정 2000.12.29, 2005.2.19, 2005.8.5, 2020.2.11>

**§164④ 산식**
```
1990년 1월 1일을      취득당시의 시가표준액
기준으로 한        ×  ────────────────────────────────────────────────────
개별공시지가          1990년 8월 30일 현재의 시가표준액과 그 직전에 결정된
                      시가표준액의 합계액을 2로 나누어 계산한 가액
```
<개정 1999.12.31, 2005.2.19, 2016.8.31>

**확정된 것 3가지**

1. **§164⑥의 "기준시가합" = 「가목의 가액 + 나목의 가액」** — 산식 원문에 명문화. 토지 성분이
   가목(개별공시지가)임이 **유추가 아니라 문언**으로 확정된다 → 본 문서 §0 결론의 직접 근거.
2. **§164④ 산식 = 프로젝트 구현과 일치** — `pre-1990-land-valuation.ts`의
   `분모평균 = (90.8.30. 현재 + 직전) / 2`, `㎡당 = 1990.1.1. 개별공시지가 × (취득시 / 분모)`가
   원문 그대로다(시행규칙 §80⑥의 분모 상한·§80⑦의 "직전" 정의 포함). ✅ 배선 근거 확인 완료.
3. 🔴 **신규 갭 — 괄호 단서 "제8항 준용" 미구현** → §8.

## 2. 보강 근거 — 시행규칙 §80③3호·④의 동일 패턴

`get_law_text(mst=286379, jo=제80조)`. §164⑧(보유기간 중 새 기준시가 미고시) 적용 시
**다목·라목 자산의 "전기의 기준시가"** 를 정하는 규정이다:

> **§80③3호** 법 제99조제1항제1호**다목의 오피스텔 및 상업용 건물**과 같은 호 라목의 주택
>
> ```
> 전기의      취득당시의     전기의 법 §99①1호 가목의 가액과 동호 나목의 가액의 합계액
> 기준시가  =  기준시가   ×  ──────────────────────────────────────────────
>                            취득당시의 법 §99①1호 가목의 가액과 동호 나목의 가액의 합계액
> ```
>
> **§80④** 제3항제3호를 적용함에 있어서 당해 자산의 취득당시 또는 전기의 법 §99①1호
> **나목의 가액이 없는 경우**에는 제3항제2호를 준용하여 계산한 가액으로 한다.

**두 가지가 확정된다.**

1. **다목 자산 환산에서 "기준시가합"의 법적 정체 = 「가목의 가액 + 나목의 가액」.**
   즉 토지 성분은 **가목(개별공시지가)** 이다 — 다목 일괄고시가가 아니다.
   (§164⑥ 산식도 같은 구조의 「취득시 합 / 최초고시시 합」이다.)
2. **§164⑥ 단서와 §80④가 똑같이 "나목만" 준용 규정을 둔다.** 이는 §164⑥에 국한된 우연이 아니라
   **다목 자산 환산 전반의 입법 방식**이다.

## 3. 왜 나목만 준용 규정이 있고 가목은 없는가 — 배제가 아니다

§164⑥ 단서의 발동 요건은 **"최초로 고시한 기준시가 고시당시 **또는** 취득당시"** 의 나목 가액 부재다.

| | §164⑤(나목 건물) | §164④(가목 토지) |
|---|---|---|
| 조문이 스스로 정하는 시점 | "고시되기 전에 취득한 건물의 **취득당시**" | "…고시되기 전에 취득한 토지의 **취득당시**" |
| §164⑥이 필요로 하는 시점 | 취득당시 **+ 최초고시당시(2005)** | 취득당시 **만** |
| 조문 자체로 커버되는가 | ✕ — 최초고시당시는 §164⑤ 문언 밖 | ✅ — 2005년 개별공시지가는 실재 |
| → 준용 조항 | **필요** | **불필요** |

상가·오피스텔 최초고시(2005-01-01) 시점에는 **개별공시지가가 이미 존재**하므로(1990-08-30 시행),
가목 쪽은 "최초고시당시 가액 부재" 문제가 애초에 생기지 않는다. 취득당시 하나만 문제되고
그것은 §164④가 이미 정한다. **따라서 준용 조항의 부재는 배제가 아니라 불요의 표현이다.**

**반대 해석의 귀결 (배제설)**: 1990-08-30 이전 취득 상가는 취득당시 토지 기준시가를 정할 방법이
없어 §164⑥ 산식 자체가 성립하지 않는다 → 환산취득가 산정 불능 또는 토지분 0 → 취득가액 과소 →
**세액 과다**. 명문 근거 없이 납세자에게 불리한 결과이며, 프로젝트 정책
(memory `feedback_no_unfavorable_application_without_legal_basis` — 명문 부재 = 유리)에 반한다.

## 8. 🔴 신규 갭 — §164⑥ 산식 괄호 단서(§164⑧ 준용) 미구현

> (취득당시의 가액과 최초로 고시한 기준시가 고시당시의 가액이 **동일한 경우**에는 **제8항의 규정을 준용**한다)

**현행**: `commercial-building-valuation.ts` `calcEstimatedStdPriceAtAcq()`는 두 합계액이 같아도
그대로 비율 계산한다(비율 = 1 → P_A = 최초고시 기준시가). §164⑧ 준용 분기가 **없다**(grep 0건).

**발동 조건**: 취득당시 (가목+나목) == 최초고시당시(2005-01-01) (가목+나목).
취득이 **2004년**이고 그 사이 개별공시지가·건물 기준시가가 모두 그대로면 실제로 발생한다.

**§164⑧ 자체는 이미 구현돼 있다** — `building-standard-price.ts:374` `sameYearFormula`,
