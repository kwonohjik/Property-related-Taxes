- 호수는 **그 호의 다른 목 요건을 모두 갖춘 주택**의 수다(문언 「다음 각 목의 요건을 모두 갖춘 주택이 2호 이상」). 목록의 한 채가 가격 초과로 불성립이면 그 채는 호수에 들어가지 않는다 — 입력 안내에 적고, (c)안만 자동 점검 가능(§5).
