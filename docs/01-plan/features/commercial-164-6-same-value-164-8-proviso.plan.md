# §164⑥ 산식 괄호 단서 — 취득당시 = 최초고시당시 합계액인 경우 §164⑧ 준용

> 발단: [`commercial-164-4-appurtenant-land-verification.md`](commercial-164-4-appurtenant-land-verification.md) §8.
> 산식 원문 확보(2026-07-28)로 드러난 미구현 단서.

## 0-1. ★ 산정 산식 확보 (2026-07-28, 사용자 제공) — A·B·C 해소

```
취득 당시의 기준시가 = 국세청장이 당해 자산에 최초로 고시한 기준시가 × A / [ A + (A − B) × C / D ]

  A : 취득시 토지 및 건물의 기준시가
  B : 전기의 토지 및 건물의 기준시가
  C : 취득일로부터 최초고시일까지 보유기간 월수
  D : 토지 및 건물 기준시가 조정월수
```

**§7 미확정 3건이 해소된다.**

| # | 미확정 | 해소 |
|---|---|---|
| A | 준용이 **분모**를 조정하는가 | ✅ 분모가 `A + (A−B)×C/D`로 대체된다 |
| B | 조정 **방향** | ✅ A>B면 분모 > A → 비율 < 1 → **P_A 하향**(§3 도출과 일치) |
| C | 시행규칙 §80①1호 가목/나목 | ✅ **가목** — `취득당시 + (취득당시 − 전기) × 보유월수/조정월수` 구조 동일 |

**입력 소요 재산정** (§5의 3종 → **2종**)

| 값 | 조달 |
|---|---|
| A = 취득시 기준시가합 | ✅ 기보유 — `combinedStdAtAcq` |
| **B = 전기의 기준시가합** | ❌ **신규 입력** (원, 총액) |
| C = 취득일 ~ 최초고시일 월수 | ✅ 파생 — `acquisitionDate` + 최초고시일(2005-01-01) |
| **D = 기준시가 조정월수** | ❌ **신규 입력** (기본 12) |

**미해소로 남는 판단 2건** (시행규칙 §80①1호가목·1호 본문 단서의 준용 여부 — 산식 이미지에는 없다)

1. **`C/D`에 100% 한도** — §80①1호가목 원문은 `[보유월수/조정월수(100분의 100을 한도로 한다)]`다.
   취득이 최초고시보다 훨씬 이르면 `C/D`가 10을 넘어 분모가 폭주하므로 **한도 적용이 타당**해 보이나,
   제공 산식에는 표기가 없다.
2. **분모 하한(≥ A)** — §80①1호 본문 단서는 "산식에 의하여 계산한 양도당시의 기준시가가 취득당시의
   기준시가보다 적은 경우에는 취득당시의 기준시가를 양도당시의 기준시가로 한다"고 한다. 준용하면
   `분모 = max(…, A)` → 비율 ≤ 1. **A < B(기준시가 하락) 구간에서 납세자 불리** 방향이라
   근거 확인이 필요하다.

→ 두 판단은 **구현 착수 시 사용자 확인**을 받는다.

> **§164⑧** 보유기간중 새로운 기준시가가 고시되지 아니함으로써 … 양도당시의 기준시가와
> 취득당시의 기준시가가 동일한 경우에는 당해 토지 또는 건물의 **보유기간과 양도일 전후 또는
> 취득일 전후의 기준시가의 상승률을 참작**하여 재정경제부령이 정하는 방법에 의하여 계산한 가액을
> **양도당시의 기준시가**로 한다.

**괄호의 위치**: 분모(최초고시당시 합계액) 뒤에 붙어 있다 → 준용이 대체하는 것은 **분모**다.

## 2. 현행 구현 — 분기 없음 (실측)

`lib/tax-engine/commercial-building-valuation.ts`

```ts
export function calcEstimatedStdPriceAtAcq(
  unitTotalAtFirstDisclosure, stdPriceSumAtAcq, stdPriceSumAtFirst,
): number {
  if (stdPriceSumAtFirst === 0) return 0;
  return safeMultiplyThenDivide(unitTotalAtFirstDisclosure, stdPriceSumAtAcq, stdPriceSumAtFirst);
}
```

두 합계액이 같으면 **비율 = 1 → P_A = 최초고시 기준시가**를 그대로 반환한다.
`§164⑧`·`제8항`·`SAME_YEAR` grep **0건** — 준용 분기가 없다.

## 3. 준용의 의미 — 조문 구조상 도출 (확정 아님)

| §164⑧ 본칙 | §164⑥ 괄호 준용 |
|---|---|
| 쌍 = (취득당시, **양도당시**) | 쌍 = (취득당시, **최초고시당시**) |
| 조정 대상 = **나중 시점**(양도당시) | 조정 대상 = **나중 시점**(최초고시당시) = **분모** |
| 두 값이 같으면 상승률 참작해 나중 값을 **올린다** | 분모를 올린다 |

**귀결**: 분모 ↑ → 비율 ↓ → **P_A ↓** → 취득가액 ↓ → **세액 ↑**(납세자 불리).
법령에 명문 근거가 있으므로 `feedback_no_unfavorable_application_without_legal_basis`에 저촉되지 않는다
— 다만 **불리한 방향이므로 근거 없이 임의 적용해서는 안 된다**. 이것이 탐지까지만 하는 이유다.

## 5. 산정에 필요한 미보유 입력

시행규칙 §80①1호가목(§164⑧의 구체 산식):

```
나중 시점 기준시가 = 취득당시 기준시가 + (취득당시 기준시가 − 전기의 기준시가)
                      × [보유기간 월수 / 기준시가 조정월수 (100% 한도)]
```

| 필요 값 | 정의 | 폼 보유 |
|---|---|---|
| **전기의 기준시가** | 취득당시 기준시가 결정일 **전일**의 기준시가(§80②2호). 다목 자산은 §80③3호가 다시 「전기 가목+나목 / 취득당시 가목+나목」 비율로 정의 → **전기 개별공시지가·전기 건물 기준시가**가 필요 | ❌ |
| **기준시가 조정월수** | 전기 기준시가 결정일 ~ 취득당시 기준시가 결정일 전일(§80②1호) | ❌ |
| **보유기간 월수** | 취득 ~ (여기서는) 최초고시 | ⚠️ 파생 가능 |

→ 입력 3종 신설 없이는 산정 불가. §164⑤ 때와 같은 구조("엔진이 자동 산정할 수 없다")다.
