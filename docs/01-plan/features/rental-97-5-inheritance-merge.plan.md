## 2. 법령·해석 근거 (원문 확인분)

### 2.1 조특령 §97의5③ (현행 MST 288915, 2026-09-18 시행) [법령]
「장기일반민간임대주택등의 임대기간의 계산에 관하여는 **제97조제5항제1호 및 제3호를 준용**한다. 이 경우 「소득세법」 제168조에 따른 사업자등록과 「민간임대주택에 관한 특별법」 제5조에 따른 임대사업자등록을 하고 장기일반민간임대주택등으로 등록하여 임대하는 날부터 임대를 개시한 것으로 본다.」

### 2.2 조특령 §97⑤3호 (같은 MST) [법령]
「상속인이 상속으로 인하여 피상속인의 임대주택을 취득하여 임대하는 경우에는 **피상속인의 주택임대기간을 상속인의 주택임대기간에 합산**할 것」

### 2.3 조특령 §97의5① (같은 MST) [법령]
「…장기일반민간임대주택등으로 **10년 이상 계속하여 등록하고, 그 등록한 기간 동안 계속하여 10년 이상 임대**한 경우로 한다. 이 경우 다음 각 호의 경우에는 해당 기간 동안 계속하여 임대한 것으로 본다.」 1호 공실 6개월 이내 · 2호 수용 · 3호 정비사업(관리처분 인가일 전 6개월 ~ 준공일 후 6개월).
- 준용 문언(③)은 「**임대기간**의 계산」만 말한다. ①의 「**등록**」 기간에 피상속인 등록이 들어가는지는 문언이 정하지 않는다 → Q-A.

### 2.4 해석례 [해석례]
- §97의5에 §97⑤3호를 적용한 해석: **없음**(국세청 「피상속인 임대기간 합산」 2건·「상속받은 임대주택 임대기간」 5건·「상속 준공공임대」 0건 — 2026-11-13).
- 같은 준용 구조의 유추: 서면인터넷방문상담4팀-3265(2007.11.12.) — 구 §97의2(신축임대주택, 령 §97의2②가 §97②~⑥ 준용)에 피상속인 임대기간을 합산.
- 「상속받은 장기임대주택 임대기간」 해석 4건(재삼46014-415 · 재산세과-1495 · 서면-2015-부동산-1813 · 서면인터넷방문상담5팀-1689)은 **본문 미확인** — Do 착수 전 V-1에서 읽는다.

## 3. 설계

### 3.1 엔진
- **입력**: 새 키 `inheritance975?: { inheritanceDate: Date; decedentRegistrationDate: Date; decedentRentalStartDate: Date }` (모양은 `inheritance974`와 공유하는 타입 별칭).
  - 키를 따로 두는 이유: `inheritance974`에는 §97의4 전용 의미(소령 §167의3 일몰 기준일을 피상속인 등록일로 — `rental-97-4.ts:144-148`)가 붙어 있다. 같은 키를 쓰면 의미가 번진다.
- **무효 날짜**: §97의4와 같은 조건 → `INVALID_INHERITANCE_DATES`(피상속인 임대개시일·등록등일 ≥ 상속개시일, 상속개시일 > 양도일).
- **10년 계속 임대**(`rental-97-5.ts:196-250`): `evaluateContinuousRental975`의 `start`를 피상속인 의제 개시일 `max(피상속인 임대개시일, 피상속인 등록등일)`로 앞당기고, 상속개시일 ~ 상속인 의제 개시일 사이 간격을 **공실 구간으로 추가**한다(→ 6개월 이내면 계속, 넘으면 단절 — Q-D). 상속인 의제 개시일은 상속개시일 전으로 거슬러 가지 않는다(§97의4 `rental-97-4.ts:337`과 같은 `max`).
  - §97의4는 일수 합산이지만 §97의5는 「**계속**하여」라 달력 구간 방식이 맞다.
  - 공실 목록은 하나 — 피상속인 구간에도 같은 목록을 적용한다(새 입력 없음).
- **임대료 5% 증액 제한**(`:142-162`): 위반 기산을 피상속인 의제 개시일로 앞당긴다(Q-E).
- **기준시가 한도**(령 §97의3③4호 준용, `checkRental973Clause24`): 코드 변경 없음 — `officialPriceAtStart` 입력의 의미(어느 「임대개시일 당시」인가)만 정한다(Q-C). 칸 hint를 바꾼다.
- **3개월 등록·취득 시한·안분**: 변경 없음(§1 표).
- **결과 echo**: `Rental97Result`에 `rentalPeriod975?: { decedent?: { start; end }; heir: { start; end } }` 신설 — 결과 카드가 합산 구간을 보인다.
- **라우터**: `rental-97-router.ts` `case "rental_97_5"`에 `inheritance975: r.inheritance975` **명시 매핑**(빠지면 조용히 사라진다).
