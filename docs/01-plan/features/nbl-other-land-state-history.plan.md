## 0. 한눈에

- **문제**: 기타토지(농지·임야·목장 외) 판정이 «양도일 현재 상태를 소유기간 전체에 적용»한다. 법 §104의3①은 «소유하는 기간 중 대통령령으로 정하는 기간 동안» 비사업용인지를 따지고 영 §168의6은 «기간의 계산은 일수로 한다»(현행 MST 290841 — 본문 머리), 국세청 해석례(서면4팀-3431 · 3604 · 1272(2008.5.26.) · 사전-2019-법령해석재산-0289)도 «별도합산·분리과세·비과세 대상인 기간동안은 비사업용에서 제외»라는 기간별 판정 취지다(V-2: 현행 문언에서도 같음).
- **현행 실측**(`makeMockRates` · 잡종지 1,000㎡ · 양도 10억 · 취득 3억 · 2014-01-01→2024-01-01): 전량 사업용 198,210,000 / 전량 비사업용 253,960,000 — 차이 55,750,000.
  - 철거 2021-01-01 후 나대지로 양도: 현행 비사업용 → 이력 반영 시 사업용(과대 해소).
  - 신축 준공 2023-06-01 직후 양도: 현행 사업용 → 이력 반영 시 비사업용(과소 해소).
- **모델**: 사용자는 **사건**(건축물 신축·멸실 + 날짜, 멸실 행엔 철거 직전 재산세 구분)을 입력하고, 엔진 공용 leaf `deriveOtherLandStateIntervals`가 **일 단위 상태 구간**으로 바꾼다. 후처리 leaf `applyStateHistory`가 그 구간으로 `meetsPeriodCriteria`(영 §168의6)를 한 번 돌린다. 마지막 구간(양도일 현재 상태)은 기존 기타토지 입력을 그대로 쓴다 → 이력 미입력이면 판정·세액·고지 **바이트 동일**(Anchor 2 골든 스냅샷으로 확증).
- **v1 범위**: 기타토지 + 정밀판정 ON + 무조건 사업용 의제 불성립 + 전량 사업용/전량 비사업용 경로. 사건은 건축물 신축·멸실만.

## 2. 판정 흐름

```
judgeNonBusinessLand
 ├─ 무조건 사업용 의제(§168의14③) 성립 → 즉시 사업용 (이력 무관 · 기존 순서)
 └─ judgeOtherLand
      ├─ core: 양도일 현재 상태 판정(= 마지막 구간) — 기존 fullPeriod 호출 7곳 무변경(정의 other-land.ts:162)
      │    └─ DM-01 등 core 자체 사업기간(당해 사업개시일 · 3호 조성 완료 등): Q-15에 따른다
      └─ 신규 후처리 leaf applyStateHistory
           · 이력 없음/unchanged/unknown/부분 면적/양도일 의제 동시 → 변경 없음 + 고지
           · 전량 사업용·전량 비사업용 →
               ① deriveOtherLandStateIntervals(사건, 소유 시작, 의제양도일, 꼬리) → 일 단위 상태 구간  (⑤·⑦·⑭ 공용)
               ② 사업용 구간 = (이전 구간 중 건축물 있음 ∧ 재산세 구분 ∈ {비과세·면제, 분리과세, 별도합산})
                              ∪ (core가 사업용이면 꼬리 구간 — Q-15 (가)면 꼬리 ∩ core 자체 사업기간)
               ③ meetsPeriodCriteria(사업용 구간, 취득일, 의제양도일, "other_land", rules, 유예) 한 번
```

- 유예는 기존처럼 합집합(이중 계상 없음 — `period-criteria.ts`).
- echo: 실제 판정값(`effectiveBusinessDays`·`gracePeriodDays`·`ratio`·`criteria`) · `periodEvaluation.basis = "state_history"` · 구간표 `intervals[{start, end, days, hasBuilding, propertyTaxType, business}]`.
- 사건일 = 새 상태의 첫날(규칙 §83의5①9호 «날부터» · 서면법규과-16 «신축일부터» — V-13 해소).
