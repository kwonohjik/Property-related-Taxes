## 0. 한눈에

- **문제**: 기타토지(농지·임야·목장 외) 판정이 «양도일 현재 상태를 소유기간 전체에 적용»한다. 법 §104의3①은 «소유하는 기간 중 대통령령으로 정하는 기간 동안» 비사업용인지를 날마다 따지고(영 §168의6 «일수로 계산»), 국세청 해석례 4건(서면4팀-3431·3604·1272, 사전-2019-법령해석재산-0289)도 «별도합산·분리과세·비과세 대상인 기간동안은 비사업용에서 제외»라는 기간별 판정 취지다.
- **현행 실측**(엔진 계획서 §1.3·§6, `makeMockRates` · 잡종지 1,000㎡ · 양도 10억 · 취득 3억 · 2014-01-01→2024-01-01): 전량 사업용 198,210,000 / 전량 비사업용 253,960,000 — 차이 55,750,000(리뷰 ±55,750,000 재현).
  - 철거 2021-01-01 후 나대지로 양도: 현행 비사업용 253,960,000 → 이력 반영 시 사업용(과대 해소).
  - 신축 준공 2023-06-01 직후 양도: 현행 사업용 198,210,000 → 이력 반영 시 비사업용(과소 해소).
- **추천 모델**: 사용자는 **사건**(건축물 신축·멸실 + 날짜)을 입력하고, 엔진 공용 leaf `deriveOtherLandStateIntervals`가 **구간 배열**로 바꿔 판정한다. 마지막 구간(양도일 현재 상태)은 기존 기타토지 입력을 그대로 쓴다 → 이력 미입력이면 판정·세액·고지 **바이트 동일**.
- **v1 범위**: 기타토지 + 정밀판정 ON + 무조건 사업용 의제 불성립 + 전량 사업용/전량 비사업용 경로. 사건은 건축물 신축·멸실만.

## 2. 판정 흐름 (엔진 계획서 §4 요약)

```
judgeNonBusinessLand
 ├─ 무조건 사업용 의제(§168의14③) 성립 → 즉시 사업용 (이력 무관 · 기존 순서)
 └─ judgeOtherLand
      ├─ core: 양도일 현재 상태 판정(= 마지막 구간) — 기존 fullPeriod 8곳 무변경
      │    └─ DM-01(당해 사업개시일): 이력 mode=changed이면 건너뜀(Q-9)
      └─ 신규 후처리 leaf applyStateHistory
           · 이력 없음/unchanged/unknown/부분 면적/양도일 의제 동시 → 변경 없음 + 고지
           · 전량 사업용·전량 비사업용 → 사업용 구간 = (이전 구간 중 건축물 있음 ∧ 재산세 구분 ∈ {비과세·면제, 분리과세, 별도합산}) ∪ (core가 사업용이면 마지막 구간)
             → meetsPeriodCriteria(사업용 구간, 취득일, 의제양도일, "other_land", rules, 유예) 한 번
```

- 유예는 기존처럼 합집합으로 들어간다(이중 계상 없음 — `period-criteria.ts`).
- 기간 수치 echo는 실제 판정값(`effectiveBusinessDays`·`gracePeriodDays`·`ratio`·`criteria`) · `periodEvaluation.basis = "state_history"` · 구간표 `intervals[{start,end,days,hasBuilding,propertyTaxType,business}]`.
