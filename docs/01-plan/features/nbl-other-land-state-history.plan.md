- **현행 실측**(엔진 계획서 §1.3·§6, `makeMockRates` · 잡종지 1,000㎡ · 양도 10억 · 취득 3억 · 2014-01-01→2024-01-01): 전량 사업용 198,210,000 / 전량 비사업용 253,960,000 — 차이 55,750,000(리뷰 ±55,750,000 재현).
  - 철거 2021-01-01 후 나대지로 양도: 현행 비사업용 253,960,000 → 이력 반영 시 사업용(과대 해소).
  - 신축 준공 2023-06-01 직후 양도: 현행 사업용 198,210,000 → 이력 반영 시 비사업용(과소 해소).
- **추천 모델**: 사용자는 **사건**(건축물 신축·멸실 + 날짜)을 입력하고, 엔진 공용 leaf가 ① 사건 → 일 단위 상태 구간(`deriveOtherLandStateIntervals`)으로 바꾼 뒤 ② **과세기준일(6.1.) 현재 상태로 접어 과세연도 버킷**(`foldStateToTaxBaseYears` — V-1 결정)으로 판정한다. 마지막 구간(양도일 현재 상태)은 기존 기타토지 입력을 그대로 쓴다 → 이력 미입력이면 판정·세액·고지 **바이트 동일**.

- **v1 범위**: 기타토지 + 정밀판정 ON + 무조건 사업용 의제 불성립 + 전량 사업용/전량 비사업용 경로. 사건은 건축물 신축·멸실만.

## 2. 판정 흐름 (엔진 계획서 §4 요약)

```
judgeNonBusinessLand
 ├─ 무조건 사업용 의제(§168의14③) 성립 → 즉시 사업용 (이력 무관 · 기존 순서)

      ├─ core: 양도일 현재 상태 판정(= 마지막 구간) — 기존 fullPeriod 8곳 무변경

           · 이력 없음/unchanged/unknown/부분 면적/양도일 의제 동시 → 변경 없음 + 고지
           · 전량 사업용·전량 비사업용 →
               ① deriveOtherLandStateIntervals(사건) → 일 단위 상태 구간          (⑧·⑤ 공용)

                  각 소유일 d → 과세연도 Y(d)의 6.1. 현재 상태 S(Y) (사건 재생 + 꼬리 연장)
                  사업용 버킷 = S(Y)가 (건축물 있음 ∧ 재산세 구분 ∈ {비과세·면제, 분리과세, 별도합산}) ∪ (꼬리 상태이고 core가 사업용)
               ③ 사업용 버킷을 [Y-01-01, Y+1-01-01) ∩ 소유기간 구간으로 펼침
               ④ meetsPeriodCriteria(펼친 구간, 취득일, 의제양도일, "other_land", rules, 유예) 한 번
```

- 유예는 기존처럼 합집합으로 들어간다(이중 계상 없음 — `period-criteria.ts`; V-1 재실측 M7에서 유효 일수 1,308 동일 확인).

### 2-1. V-1 모델 한 줄 정의 — ⚠️ v3 폐기(아래 인용은 v2 기록 · 현행 정본 = 일 단위, 머리말 «v3 우선 규칙»)

> 소유일 d 하나하나는 **그 날이 속한 과세연도 Y의 6월 1일 현재 토지 상태**(건축물 유무 + 재산세 구분)로 판정한다. 사건일이 6.1. 당일이면 새 상태가 그날 현재 상태다. 같은 해 안의 다른 변화는 판정에 쓰이지 않는다. 취득 연도·양도 연도도 같은 규칙이며, 소유자가 그 6.1.에 소유자였는지는 묻지 않는다.

## 6. 미검증 레지스터 (착수 전 확인 — 추정 금지)

엔진 V-1~V-12(+신규 V-13~V-17)와 UI UV-1~UV-14를 그대로 둔다(세부 계획서 §8.2 · §15). 2026-11-22 처리 현황:

- ✅ **V-2(처리 — 2026-11-22)** 결론: **«별도합산·분리과세·비과세 대상인 기간동안은 제외» 취지는 현행 문언에서도 그대로.** 법 §104의3①(본문·4호 가·나목)·영 §168의6(가·나·다 모두 해당 · 일수 계산) 구조가 해석례 시점과 같다. 달라진 것은 값뿐 — 영 §168의6 다목 100분의 20 → 40(2015.2.3. — 코드 주석 인용, 이번에 재조회 안 함), 규칙 §83의5①9호 2년 → **5년(2025.3.21.)**. 서면4팀-3431의 «2년»은 개정 전 값이므로 인용 시 일수는 현행 본문을 쓴다. **2025.3.21. 이후 9호 5년을 직접 다룬 회신은 확인하지 못함 → 확인 필요.** (엔진 §4A.7)
