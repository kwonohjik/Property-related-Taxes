### 3.4 #3 — 단기→장기 변경신고 기산일 (PR-C)

**현상**

**단기 임대기간 산입 — 변경 신고일로 구간을 나눈다** (사용자 정리 2026-11-02 + 원문 대조. Q-4는 이 구조로 대체)

| 구간 | 근거 [법령] | 단기로 임대한 기간의 산입 |
|---|---|---|
| **C-old**: 변경 신고 ≤ 2019-02-11 | 2019-01-01 시행본(MST 202147) ④ 후단 「…민간임대주택을 장기일반민간임대주택등으로 등록하는 경우에는 **5년의 범위에서** 민간임대주택으로 임대한 기간의 **100분의 50**에 해당하는 기간을 … 임대기간에 포함하여 산정한다」 + 대통령령 제29527호 부칙 §29① | **50%** 산입, 산입분 최대 5년 |
| **C-old′**: 신고 ≥ 2019-02-12이지만 2019-02-12 현재 단기 임대 > 8년 | 같은 부칙 §29② 「이 영 시행일 현재 단기민간임대주택을 8년 초과하여 임대한 경우에는 … 종전의 규정에 따른다」 | C-old와 같음 |
| **C-new**: 신고 2019-02-12 ~ 2020-07-10 | 2019-02-12 시행본 ④ 후단 → 민특령 §34①(당시 3호) | **전부** 산입. 단기 의무기간 종료 후 변경(나목)이면 수리일부터 의무기간을 역산한 날부터 → 의무기간이 한도 |
| **C-excl**: 신고 ≥ 2020-07-11 | 법 §97의3① 괄호 | 적용 제외 |

- **한도 수치**: 사용자 정리는 「의무임대기간 5년 한도」다. 다만 원문상 C-new 한도는 「해당 단기민간임대주택의 임대의무기간」이고, 단기민간임대주택의 의무기간은 민특법 §2 6호의 **4년**이다(엔진 담당이 2018-10-25 시행본으로 확인). 5년은 C-old의 「5년의 범위」다. Q-3 결정대로 **4년**으로 구현한다(V-4·V-11).
- **용어**: 「단기 개시일」 = max(단기 지자체 임대사업자 등록일, 세무서 사업자등록일, 실제 임대개시일). 「장기 개시일」 = max(장기 변경 수리일, 세무서 사업자등록일)(④ 전단).

**구간별 계산 — 모두 「의제 개시일」 하나로 귀결** (Q-5 결정: 등록기간·임대기간 모두 의제 개시일부터)
- **C-new 가목** (수리일 < 단기 개시일 + 4년): 의제 개시일 = 단기 개시일.
- **C-new 나목** (그 밖): 의제 개시일 = max(수리일 − 4년, 세무서 사업자등록일, 실제 임대개시일). 세 날짜 중 늦은 날 원칙을 나목에도 적용하는 **가정 A-3**이다.
- **C-old·C-old′**: 의제 개시일 = 장기 개시일 − min(⌊(단기 개시일 → 수리일 일수) × 50%⌋일, 5년).
  - 산입분만큼 개시일을 앞당겨 표현한다(사용자 예시 방식). 이후 통산·공실 차감·등록기간 판정은 현행 로직을 그대로 쓴다.
  - 일수 절사 방향(⌊⌋)은 V-6이다.
- **사용자 예시 (2026-11-02)** — 신고일 = 수리일로 본 경우:
  - 신고 2019-05-01, 단기 4년 → C-new → 4년 소급. 2019-05-01 − 4년 = **2015-05-01**(사용자 확인 2026-11-02). 이 사례는 수리일 = 단기 개시일 + 4년(의무기간 종료 당일)이라 가목·나목 어느 쪽이어도 같은 날이 나온다.
  - 신고 2019-02-11, 단기 4년(2015-02-11 개시) → C-old → 산입 2년 → 의제 개시일 **2017-02-11**.
- **기준일**: 사용자 예시는 변경 **신고일**에서 거슬러 올라가지만, 원문은 나목 「변경신고의 **수리일**부터 역산」, 종전 규정은 장기 등록 시점까지의 「민간임대주택으로 임대한 기간」이다. 엔진은 **수리일** 기준으로 계산한다(신고일 = 수리일이면 예시와 같다). 신고일은 구간 판정(2019-02-12·2020-07-11 경계)에만 쓴다.

## 6. 법령 상수·manifest

- `rental-97-3.ts`는 「조특령 §97의3④」·「⑤」·「③1호」를 **문자열 리터럴**로 쓴다(CLAUDE.md 위반, 기존 부채).
  - 이번에 새로 인용하는 곳: ④ 후단, ⑤, 민특령 §34①.
  - 이 조문들은 `lib/tax-engine/legal-codes/transfer-house.ts`에 상수로 추가해 쓴다.
  - 기존 리터럴 정리는 손대는 줄에 한해 같이 한다.
- manifest: `lib/legal-verification/manifest/additions-transfer-decree.ts:700-710` `TRANSFER_DECREE.LONG_GENERAL_RENTAL_97_3`에 키워드를 추가한다(`keywordMode: "ALL"`).
  - ④ 후단: 「같은 법 시행령 제34조제1항제3호에 따른 시점부터 임대를 개시한 것으로 본다」
  - ⑤: 「임대기간 중에 발생한 양도차익에 한정하여 적용하며」
- 민특령: `lib/legal-verification/citation-parser.ts:88` `LAW_ALIAS`에 「민간임대주택에 관한 특별법 시행령」이 **없다**. 그대로 두면 검증 모수에서 조용히 빠진다.
  - alias를 추가하고, manifest를 `additions-common.ts`(`PRIVATE_RENTAL.*` 옆)에 둔다.
  - 인용은 조 단위 「§34①」로 한다. 호 번호(3호)로 인용하면 현행 3호(장기→공공지원)로 검증된다. 구 3호 문언은 주석으로만 남긴다.
- 등록 후 `npm run verify:legal`로 확인한다(이 세션은 `.env.local` 없음 — Do 환경에서 실행).
