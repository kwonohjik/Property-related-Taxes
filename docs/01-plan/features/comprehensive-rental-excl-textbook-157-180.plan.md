## 2. 회차별 절차(모든 회차 공통)

1. **법령 원문** — 교재가 인용한 조문을 KoreanLaw MCP로 확인한다. 연혁 문제는 그 시행본(efYd)과 부칙까지 본다. 인용 해석례는 taxlaw 원문으로 확인한다. MCP 장애 시 `.legal-cache`를 쓰고 그 사실을 적는다.
2. **구현 위치** — 엔진 · ⑤ 위젯 · ⑧ validate · ④ API 변환 · ⑫ Zod · ⑭ route를 file:line으로 적는다.
3. **실측** — 교재 사례를 route 수준 throwaway probe로 돌린다(커밋하지 않음). 결과는 `isExcluded`·failReasons·세액(원)으로 적는다.
4. **판정**(아래 다섯 중 하나)
   - 일치
   - 결함 — 과다배제 또는 과소배제. 세액 차이를 원 단위로 적는다
   - 기능 공백 — 입력 경로가 없음
   - 교재가 법문과 다름 — 법문을 따르고 기록만 한다
   - 이미 결정됨 — MEMORY 재제안 금지 목록과 대조한다
5. **기록** — 이 문서 §3에 회차 결과 표를 붙인다. 결함과 공백은 Q 레지스터에 올리고 권장안을 함께 적는다. 회차마다 커밋 1개.

결함이 확정돼도 이 계획 안에서는 고치지 않는다. 수정은 회차가 끝난 뒤 사용자 결정을 받아 별도 계획서와 PR로 진행한다.

### 3.1 1회차(pp.160~162) — 2026-11-16

**법령 원문**(KoreanLaw MCP · 종부령 MST 290557 · 2026.10.1. 시행 현행본 §3)
- 가액 판정 시점 문언은 2·8·11호에 모두 있다(V-1 해소). 2호 가목1) 「해당 주택의 임대를 개시한 날 또는 최초로 제9항에 따른 합산배제신고를 한 연도의 과세기준일을 기준으로 하여」 · 8호 가목1)가) 같은 문언 · 11호 가목1) 「해당 주택의 임대를 개시한 날 또는 최초로 제9항에 따른 합산배제신고를 한 연도의 과세기준일의 공시가격이」. 1·7·10호는 「2호 이상의 주택의 임대를 개시한 날(…)」.
- 2호 본문은 「민간매입임대주택과 공공매입임대주택」이고, 단서에서 민간매입임대주택은 「2018년 3월 31일 이전에 사업자등록등을 한 주택으로 한정」한다. 단기·장기를 나누지 않는다. 나목은 「5년 이상」이다(V-2 해소 — 교재 「2018.3.31. 이전 등록은 단기·장기 모두 5년」과 같다).
