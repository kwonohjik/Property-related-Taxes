## 4. ★ 핵심 쟁점 — 직전 종부세상당액의 고령자 세액공제 (§5②2호)

**KoreanLaw 축자(시행령 §5②2호, MST 283639)**:
> 종합부동산세액상당액 = 직전 연도의 법을 적용하여 산출한 금액(**1세대 1주택자의 경우에는 직전 연도 과세기준일 현재 연령 및 주택 보유기간을 적용하여 산출한 금액**)

→ **직전 종부세상당액에 고령자·장기보유 세액공제 반영이 법령 명시**. 직전 2021.6.1 기준 69세 → 30% 적용. **단 §8④ 해당 시 고령자 공제는 §9⑦ 공시가격 안분(§4-1)** → 법령 정합 1,182,305(현행 1,119,713은 안분 누락).

**판정**: PDF 1,599,590(고령자 미반영)은 **교재 단순화** — 세부담상한 미적용 케이스라 결과 무관하므로 직전 상당액을 약식 제시한 것. **법령(§5²2호)·현행 엔진(`prior-year.ts:11·116-126`)이 고령자를 반영(1,119,713)하나 §9⑦ §8④ 안분 누락 — 법령 정합은 안분 적용 1,182,305**(§4-1). (memory [[feedback_anchor_correction_legal_priority]] — 법령 정합값 우선, PDF·현행 부정합값 anchor 금지)

- 현행 `prior-year.ts`: `auto.isOneHouseOwner && birthDate && acquisitionDate` → 직전 기준일 연령 재판정 고령자 공제 적용. 사례5 직전 isOneHouseOwner=true → 적용. **법령 정합 동작**.
- api.ts `previousYearAuto.birthDate = formData.birthDate`(현행) → 직전 고령자 반영 자동. **변경 불요**.

### 4-1. ★ 직전 §8④ 안분 — 현행 부정합 (갭 확정, KoreanLaw §9⑦ 실측)

**KoreanLaw §9⑦(MST 280417)**: *"만 60세 이상 1세대 1주택자가 제8조제4항 각 호에 해당하는 경우 ... 산출세액에서 각 호 산출세액(공시가격합계액으로 안분)을 제외한 금액에 연령별 공제율을 곱한다"* (§9⑨ 장기보유 동일). → **§8④ 해당 1세대1주택 고령자 공제는 공시가격 안분 필수**.

§5②2호 "직전 연도의 법(§10 제외)을 적용 ... 1세대1주택자는 직전 연령·보유 적용" → 직전연도도 §9 전체(⑦⑨ 안분 포함) 적용. 사례5 직전(2021)은 부부특례+세종 지방저가 → 1세대1주택 의제 + §8④4호 해당 → **직전 고령자 공제도 §9⑦ 안분(성동 13억/전체 14.95억) 적용이 법령 정합**.

| 직전 종부세상당액 | 값 | 판정 |
|---|---|---|
| PDF | 1,599,590 | 고령자 미반영 — 교재 단순화 |
| 현행 엔진(`prior-year.ts`) | 1,119,713 | 고령자 30% **안분 없이** 전체 적용 — **§9⑦ 부정합(갭)** |
| **법령 정합(§9⑦ 안분)** | **1,182,305** | `1,599,589 − safeMultiplyThenDivide(1,599,589×30, 13억, 14.95억×100)` = `1,599,589 − 417,284` (당해 helpers 단일식 정합) |

→ 현행 `prior-year.ts:116-126` 고령자 공제는 `floor(afterPropertyCredit × rate)` — **§8④ 안분 미적용**. 직전 §8④ 안분은 **신규 로직**(prior-year에 §8④ 안분 비율 전달 필요). 단 **세부담상한 미적용이라 ⑤ 969,711 무관** — numeric 영향 0, 충실 재현·법령 정합 목적.

## 6. anchor 명세 (Phase 0/1)

`__tests__/tax-engine/comprehensive-special-cases.test.ts` (D2-1 인접) 또는 prior-year-multi:

```ts
// PY-S5 (사례5): 부부 §10의2 + 지방저가 §8④4호 + 직전 자동계산
const r = calculateComprehensiveTax({
  assessmentYear: 2022,
  isOneHouseOwner: false,
  isJointOwnershipSpecialCase: true,
  birthDate: new Date("1952-01-01"),       // 당해 70세 / 직전 69세
  acquisitionDate: new Date("2018-01-01"),
  properties: [
    { propertyId: "p1", assessedValue: 1_500_000_000, exclusionType: "none" },
    { propertyId: "p2", assessedValue: 200_000_000, location: "non_metro", exclusionType: "none", section8para4Type: "regional_low_price" },
  ],
  previousYearAuto: {
    assessedValue: 1_495_000_000,
    priorHouseValues: [1_300_000_000, 195_000_000],
    priorSection8Para4Value: 195_000_000,   // 직전 세종(지방저가) — §9⑦ 안분 분자 = priorSum − 이 값
    isOneHouseOwner: true,
  },
});
// 당해 (PDF 정합)
expect(r.calculatedTax).toBe(2_280_000);
expect(r.determinedHousingTax).toBe(969_711);                 // ⑤ PDF 일치
// 직전 자동 (PDF 단순화값 1,599,590 아님 · 현행 부정합 1,119,713 아님)
expect(r.previousYearEquivalent?.propertyTaxEquiv).toBe(2_635_500);    // 직전 재산세 (PDF 일치)
expect(r.previousYearEquivalent?.detail.calculatedTax).toBe(2_402_000);// 직전 ⓐ (PDF 일치)
// ★ G-5 구현 시: §9⑦ §8④ 안분 고령자 → 1,182,305 (법령 정합)
//   G-5 미구현 시: 현행 1,119,713 (안분 누락 부정합) — anchor를 어느 값으로 둘지는 G-5 포함 여부에 종속
expect(r.previousYearEquivalent?.comprehensiveTaxEquiv).toBe(1_182_306); // §9⑦ 안분 (G-5)
expect(r.determinedHousingTax).toBe(969_711);                          // ⑤ 불변 (세부담상한 미적용)
expect(r.taxCap?.isApplied).toBe(false);
```

> ★ anchor 주석: "직전 종부세상당액 1,182,305 = §9⑦ §8④ 안분(13억/14.95억) × 직전 69세 30%. PDF 1,599,590은 고령자 미반영 단순화, 현행 1,119,713은 안분 누락 — 셋 다 세부담상한 미적용이라 ⑤ 969,711 동일."
> ★ **PY-S5는 G-5 미구현 상태에선 1,182,305 expect가 실패(현행 1,119,713)** → Phase 0 갭 실증 anchor로 동작.

## 7. Phase 계획

- **Phase 0/1**: PY-S5 anchor 작성 → 현행+PR#204로 **즉시 통과 예상**(신규 로직 없음). 단 직전 종부세상당액 1,182,305 expect는 G-5(§9⑦ 안분) 미구현이라 실패(현행 1,119,713) — 갭 실증. ※ G-5 미포함 시 anchor를 현행 1,119,713으로 두고 후속 주석. G-5(직전 §8④ 안분) KoreanLaw 확인 후 직전 종부세상당액 anchor 확정.

- **Phase 3**: 메모리 환류(§5² PDF 단순화·사례5 조합 검증 완료).
