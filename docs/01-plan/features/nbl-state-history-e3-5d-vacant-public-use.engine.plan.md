## 1. 법령 확인 (KoreanLaw MCP 본문 · 2026-11-24 조회)

### 1.1 지령 §103의2 — 현행 본문 (MST 290815 · 시행 2026.10.1. · 조문 최종 개정 2025.12.31.)

> 제103조의2(철거ㆍ멸실된 건축물 또는 주택의 범위) 법 제106조제1항제2호다목에서 "대통령령으로 정하는 부속토지"란 **과세기준일 현재** 다음 각 호의 어느 하나에 해당하는 건축물 또는 주택의 부속토지를 말한다. 이 경우 「건축법」 등 관계 법령에 따라 허가 등을 받아야 하는 건축물 또는 주택으로서 허가 등을 받지 않은 건축물 또는 주택이거나 사용승인을 받아야 하는 건축물 또는 주택으로서 사용승인(임시사용승인을 포함한다)을 받지 않은 건축물 또는 주택의 부속토지는 제외한다. <개정 2025.12.31>
> 1. 건축물 또는 주택이 사실상 철거ㆍ멸실된 날(…)부터 1년이 지나지 않은 건축물 또는 주택의 부속토지(건축물 또는 주택의 건축을 위한 용도 외의 다른 용도로 사용하는 부속토지는 제외한다). 이 경우 건축물의 부속토지는 철거ㆍ멸실되기 전 건축물의 바닥면적(…)에 제101조제2항에 따른 용도지역별 적용배율을 곱하여 산정한 면적 범위의 토지를 말한다.
> 2. 「빈집 및 소규모주택 정비에 관한 특례법」에 따른 빈집정비사업 또는 「농어촌정비법」에 따른 생활환경정비사업(빈집의 정비에 관한 사업만 해당한다)의 시행으로 빈집이 사실상 철거된 날(…)부터 3년이 지나지 않은 빈집의 부속토지. 다만, 건축물 또는 주택의 건축을 위한 용도 외의 다른 용도로 사용하는 부속토지는 제외하되, 법 제109조제2항 단서에 따른 재산세의 부과대상이 되는 부속토지로서 국가, 지방자치단체 또는 지방자치단체조합이 1년 이상 공용 또는 공공용으로 사용(1년 이상 사용할 것이 계약서 등에 의하여 입증되는 경우를 포함한다)하는 경우에는 그 공용 또는 공공용으로 사용하는 기간 동안의 그 부속토지는 포함한다.

(확인) **1호에는 «건축 외 용도 제외» 괄호만 있고 공용 사용 포함 문장이 없다.** 단서가 있는 곳은 **2호뿐**이다.

## 3. 설계

### 3.1 입력 — 철거 행 사실 칸에 «답에 따라 열리는» 하위 4칸 (Q-2 (가))

E3f-2의 4칸(허가 · 건축 외 용도 · 빈집정비 · 바닥면적) 다음에 아래 4칸을 둔다. **값 키는 같은 `…Before` 규약.**

| 칸(와이어 · ⑫ 문자열) | 값 | 열리는 조건(= 필수 조건 — 노출 ≡ 필수) | 뜻 |
|---|---|---|---|
| `demolishedPublicUseBefore` | `""`·`yes`·`no`·`unknown` | 구조: `need.otherUse ∧ need.vacantHouse`(철거 행이 **주택** ∧ 후보 과세기준일 ≥ 2024.6.1.) ∧ 답: **건축 외 용도 = `yes` ∧ 빈집정비 = `yes`** | 국가·지자체·지자체조합이 그 부속토지를 공용·공공용으로 **1년 이상 사용**(또는 1년 이상 사용을 **계약서 등으로 입증**)했는가 |
| `demolishedPublicUsePaidBefore` | `""`·`yes`·`no`·`unknown` | 위 + **`demolishedPublicUseBefore = yes`** | 그 사용이 **유료**이거나 **소유권 유상이전 약정 후 취득 전 사용**이라 재산세가 **부과**되는가(법 §109②단서). «무상 사용 = 비과세»는 `no` |
| `demolishedPublicUseFromBefore` | ISO 날짜 문자열 | 위 + **`…PaidBefore = yes`** | 공용·공공용 사용 **개시일**(그날 포함) |
| `demolishedPublicUseToBefore` | ISO 날짜 문자열 | 위 + `…PaidBefore = yes` | 공용·공공용 사용 **종료일**(그날 포함 · **필수 — Q-4 (가)**. 현재도 사용 중이면 구간 끝 이후의 날짜를 직접 입력 — 구간 안으로 잘린다. **빈칸을 «구간 끝까지»로 읽지 않는다**) |

- **왜 «빈집정비 예»에만 여나**: 단서는 2호(빈집)에만 있고(§1.1), 1호(일반 철거)는 건축 외 용도 «예» = 접힘 그대로다. 빈집정비 «아니오·모름»·비주택 건축물 행에서는 4칸을 열지 않는다(stale 값은 ④가 안 보내고 ⑫′·⑭가 무시).
- **왜 3지선다 둘을 나누나**: 법 요건이 둘(영 §103의2 2호 단서의 «공용 1년 이상» + 법 §109②단서의 «부과대상»)이고 **답에 따른 라우팅이 다르다** — 무상(비과세)은 이 단서가 아니라 «비과세·면제» 근거(`PTAX_BASIS_EXEMPT` · Q-5)다. 한 질문으로 합치면 사용자가 «공용 사용했음»만 보고 «예»를 눌러 무상 사용을 혜택으로 오인할 수 있다(Q-2 (나) 기각 이유).
- **1년 이상 요건은 사실 진술로만 받는다**: 법문 «1년 이상 사용(1년 이상 사용할 것이 계약서 등에 의하여 입증되는 경우를 포함한다)» — 입력한 개시·종료일이 1년 미만이어도 계약서로 입증되면 요건이 성립하므로 **날짜로 1년을 검산하지 않고** 3지선다 ①에 «계약서 등 입증 포함» 문구를 넣는다(§3.6 고지가 1년 미만이면 입증 필요를 밝힌다 — 판정 불변).
- **부분 면적**: 공용 사용이 그 구간 토지의 **일부**인 경우의 안분은 하지 않는다(자동 안분 fallback 금지) — ①의 문구를 «그 구간의 토지 전부»로 쓰고 일부면 «아니오»(= 혜택 불성립)로 안내한다(V-9).
- **복수 기간**: 단일 구간만 받는다(둘째 공용 기간이 있으면 한계 고지 — Q-4 (다)는 선택하지 않았다).

```ts
  ev: { demolishedOtherUseBefore?: string; demolishedVacantHouseBefore?: string; demolishedPublicUseBefore?: string; demolishedPublicUsePaidBefore?: string },
): DemolishedPublicUseAsked
// publicUse = need.otherUse ∧ need.vacantHouse ∧ ev.otherUse === "yes" ∧ ev.vacantHouse === "yes"
// paid      = publicUse ∧ ev.publicUse === "yes"
// dates     = paid ∧ ev.paid === "yes"
```

- `DemolishedRequiredFacts`(구조 4필드)는 **바꾸지 않는다** — 구조 술어와 답 의존 술어를 섞지 않는다. `need.otherUse ∧ need.vacantHouse`는 둘 다 «후보 과세기준일 ≥ 2024.6.1. ∧ (vacantHouse는 주택)»이라 별도 구조 필드가 필요 없다(확인: `demolished-temp-status.ts:194-218`).
- `firstBlankDemolishedFact(ev, required)`는 호출 인자 모양을 유지한 채 **내부에서** `demolishedPublicUseAsked`를 불러 첫 빈칸을 돌려준다(허가 → 건축 외 용도 → 빈집정비 → **공용 사용 → 유료 → 개시일 → 종료일** → 바닥면적 순). 따라서 ⑧(`demolishedRowFactError`) · ⑫′ · ⑤ 미리보기(`demolishedRowUnansweredField`)의 **호출처 코드는 바뀌지 않는다** — 필드 유니온·메시지 표(`MESSAGE_OF … satisfies Record<DemolishedRowFactField, …>`)만 컴파일러가 강제로 넓힌다.
- 날짜 결함은 같은 leaf가 점프 필드·문구와 함께 돌려준다 — **개시일 빈칸·해석 불가 → 개시일 칸 · 종료일 빈칸·해석 불가 → 종료일 칸 · 개시일 > 종료일 → 종료일 칸**(⑧ 점프 `nblOtherStateEvents.{i}.demolishedPublicUseFromBefore`·`…ToBefore`, ⑫′ 400 같은 문구). **3지선다는 `""`만 차단**, `no`·`unknown`·`yes`는 차단하지 않는다(Q-11 (나) 일관).
- **«엔진이 이력을 읽을 때만»**: `demolishedRowFactIssue`가 `historyRead`를 먼저 걸므로(`demolished-row-facts.ts:115-116`) 새 4칸도 같은 게이트를 받는다 — 읽지 않으면 요구도 노출도 없다(UQ-8 (가) 일관).

### 3.3 판정 — `demolishedStatusWindow` 확장

입력 `facts`에 `publicUse?` · `publicPaid?`(`DemolishedFact`) · `publicUseFrom?` · `publicUseTo?`(`Date`)를 더한다. 의미:

```
vacantYes      = kind === "house" ∧ facts.vacantHouse === "yes"            // 기존
claimed        = vacantYes ∧ otherUse === "yes" ∧ publicUse === "yes" ∧ publicPaid === "yes"
                 ∧ from·to 유효 ∧ from ≤ to                                  // 단서 주장 — 전부 «예»여야 한다
inPublicUse(s) = from ≤ s ≤ to                                              // 과세기준일 현재 공용 사용 중(양 끝 포함)
otherUseOk(s)  = !clause(s) ∨ otherUse === "no" ∨ (claimed ∧ inPublicUse(s))   // ← 새로 «claimed ∧ inPublicUse»를 더함
```

- `holding` = 기존 `inPeriod`(구간 안 · W 안) ∩ `permitOk` ∩ `otherUseOk` ∩ `areaOk`. 허가·면적 요건은 **그대로** 적용된다(단서는 건축 외 용도 제외에만 걸린다 — 본문 «이 경우 … 허가 등을 받지 않은 … 제외»는 그대로).
- **창**: 기존 `[max(r, 구간 시작), min(만료일 + 1일, 구간 끝))`에 **`claimed`이면** 추가로 `[from, to + 1일)`을 교집합한다(현행 문언 «그 공용 또는 공공용으로 사용하는 기간 동안»). `claimed`가 아니면(건축 외 용도 «아니오») 창은 **바이트 동일**.
- **게이트**: `claimed`이면 과세기준일 `s`가 공용 사용 기간 안(`inPublicUse(s)`)이어야 성립 — 공용 사용 기간에 과세기준일이 없으면 한시 지위가 그날 성립하지 않으므로 **접는다**(Q-4 게이트와 같은 «존재 검사»).
- **접힘 사유**: 기존 우선순위(never → permit → other_use → area)에 **하나만 추가** — `claimed`인데 `holding`이 비면(공용 사용 기간 안에 후보 과세기준일이 없음) `demolished_public_use_no_base_date`, `claimed`가 아니면 종전대로 `demolished_other_use`(= 건축 외 용도 «예» 또는 «모름» 또는 단서 요건 미충족). 사유 문구는 구분해 고지한다(§3.6).
- **창의 의미**: 기존 «철거일부터 만료일까지 전부»는 과세기준일 지위의 일 배정 **상한 근사**(E3f-2 V-14)다. 단서 경로는 **공용 사용 기간으로만 줄여** 인정한다 — 공용 사용 **밖**의 철거 후 기간은 건축 외 용도 사용 여부를 나눠 묻지 않아(사용자 답이 «예» 하나) 인정하지 않는다(보수 쪽 · V-8). 이 한계를 고지한다.
