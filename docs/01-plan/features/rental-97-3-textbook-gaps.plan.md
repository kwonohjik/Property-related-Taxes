- 조특령 §97의3⑤ 산식 A × (B − C) / (D − E). 입주권은 양도일에 주택 기준시가가 없다. 장특 대상 차익(A에 해당)이 「취득일 ~ 인가일」 구간이다(§1.4).
- **(a) 권장** — D = **관리처분계획 인가일 당시(직전 고시) 기준시가**. 분모 구간이 장특 대상 차익 구간과 같아진다. 화면 라벨을 입주권일 때 「관리처분계획 인가일 기준시가」로 바꾸고 「해석 미확인(확인 필요)」 고지.
- (b) 안분하지 않고 인가 전 차익 전부에 특례율 — 임대기간 밖 차익까지 특례를 준다. 비권장.
