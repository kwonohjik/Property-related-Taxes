## 2. 주제 2 — 산림지 "통상적으로 직접 경영할 수 있는 지역" (§16②1호나 단서)

### 2-1. 검색 결과 직접 관련
- **[34068]** 보전임지가 아닌 산림지의 영농상속공제 적용대상여부 (1995-05-23)
- **[220064]** 영농상속공제는 보전임지중 조림기간이 5년 이상인 산림지에 대해 적용함 (1998-07-08)

### 2-2. 후속 본문 분석 필요
- ID 34068·220064 본문에서 "통상 경영 가능 지역" 해석 추출
- 산림조성계획 인가·산림사업지구 사업 범위 (§16⑤1호 다목 인용)

### 2-3. 잠정 정책
PRD v4.1.1 §1-4 **해석 A** 채택 — 본문 괄호 위치상 30km 분기 내부 확장. 헬퍼는 별도 matchKind `forest_manageable_area`로 UI 차별화 (implementation detail).

## 3. 주제 3 — §16②1호나 산림지가 §16⑤1호 다목 "5년 이상 조림" 조건 적용 여부 (E7)

### 3-1. 검색 결과 직접 관련
- **[220064]** 영농상속공제는 보전임지중 조림기간이 5년 이상인 산림지에 대해 적용함 (1998-07-08) — **E7 직접 관련**

### 3-2. 후속 본문 분석 필요
- ID 220064 본문 → §16⑤1호 다목 "5년 조림" 조건이 §16②1호나 거주 요건 대상 산림지에도 적용되는지 명시 여부
- 적용 시 EstateItem에 보조 필드 추가 후속 PR (예: `forestPlantationStartDate?`)

### 3-3. 잠정 결론
**적용됨** 가능성 매우 높음 — §16⑤마목 자산 정의가 §16②1호나 "농지등" 정의에 흡수 적용된다는 해석. 본문 검증 필요.

## 4. 주제 4 — "거주" 정의 (주민등록 필수 여부)

### 4-1. 검색 결과 직접 관련
- **[305392]** 부부가 함께 농사를 짓던 농지를 배우자가 상속받는 경우 (2022-01-27) — 거주 요건 검토
- **[134584]** 병역의무 이행으로 상속개시전 2년동안 계속 영농에 종사하지 못한 경우 (2005-02-02) — 연속 거주 예외
- **[151726]** 영농상속공제 가능여부 (2007-07-13)
- **[231700]** 영농상속공제 가능여부 (2011-03-09)

### 4-2. 후속 본문 분석 필요
- §168-9② (임야 양도세) 주민등록 필수 vs §16②1호나 영농상속 주민등록 명시 없음
- "사실상 거주" 인정 여부

### 4-3. 잠정 결론
주민등록 명시 없음 → 사실상 거주 인정 가능성. 본문 검증 후 PRD v4.1.1 §1-4 보강. 적용 시 farming 입력에 `requireResidentRegistration?` 보조 boolean 추가 후속 PR.
