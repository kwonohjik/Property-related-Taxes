## 1. 감사 목적

현재 코드의 감면 분류·라벨이 실제 조세특례제한법 조문과 일치하는지 검증하고, 정정 대상을 확정한다.

## 2. 감사 결과 — 오류 확정

### 2.1 결정적 오류 ★

**위치**: `app/calc/transfer-tax/steps/Step5.tsx:17`
```ts
unsold_housing: { label: "미분양주택 감면", desc: "미분양주택 취득 특례 100% (§99의3)" },
```

**오류**: 조특법 **§99의3은 신축주택 감면** (2001.5.23~2003.6.30 한시 신축주택 취득자 양도소득세 과세특례)이지, **미분양 조문이 아님**. 화면 라벨이 잘못 표기되어 사용자가 잘못된 조문을 인식하게 됨.

**근거**:
- 실제 조특법 §99의3 = 신축주택 (2001~2003 IMF 2탄)
- 사용자 제공 PDF 사례 = "조특법 99조의3 신축주택 감면"으로 명시 (예제 프로그램 표기와 일치)
- 미분양 조문은 §98 시리즈(§98·§98의2~§98의8) + §99의2 가 정상

### 2.2 잠재 오류 — `legal-codes/transfer.ts`

```ts
REDUCTION_NEW_HOUSING:    "조특법 §99",        // OK
REDUCTION_UNSOLD_HOUSING: "조특법 §98의3",     // OK (실제 미분양 한시)
UNSOLD_HOUSING_EXEMPTION: "조특법 §99의3",     // ★ 오류 — §99의3은 신축
```

`UNSOLD_HOUSING_EXEMPTION` 상수의 라벨이 §99의3 = 미분양 식으로 잘못 표기. **실제 사용처는 종부세 합산배제·다주택 산정 배제 로직**이므로 영향 범위 추가 조사 필요.

### 2.3 시드 데이터 라벨 불일치 가능성

`scripts/seed-transfer-tax-rates.ts` (line 367~):
```ts
{
  code: "99-1",
  article: "§99 ①",
  acquisitionPeriod: { start: "2001-05-23", end: "2003-06-30" },
  region: "outside_overconcentration",
  ...
}
```

**의문점**: 시기(2001.5.23~2003.6.30)는 실제 조특법 §99의3과 일치. 그러나 article 라벨은 "§99 ①". 조특법 §99 본조는 1998.5.22~1999.6.30 IMF 1차 신축주택 감면이고, 2001~2003 시기 신축은 §99의3 IMF 2차임.

→ 시드 데이터의 `article: "§99 ①"`이 실제로는 **§99의3 본조 본문**이거나 **§99의3 ①항**일 가능성. 조특법 원문 대조 검증 필요.

| code | 시드 article | 시드 시기 | **실제 조문 (2026-05-06 원문 대조 확정)** | 시기 정정 필요 |
|---|---|---|---|---|
| `98-2` | §98의2 | 1998.5.22~2001.12.31 | **§99 ①항 1호 + 2호** (자기건설 1998.5.22~1999.6.30, 국민주택 1998.5.22~1999.12.31) | ✓ 시기 1998.5.22~1999.6.30로 단축 |
| `99-1` | §99 ① | 2001.5.23~2003.6.30 | **§99의3 ①항 1호 + 2호** (가격 급등 지역 외 신축) | OK (시기 일치) |
| `99-2-low/mid/high` | §99 ② | 2009.2.12~2010.2.11 | **§98의3** (서울 외 미분양, 수도권과밀 60% / 그 외 100%) | OK |
| `99-3-*` | §99 ③ | 2010.2.12~2011.4.30 | **§98의5** (수도권 외 미분양, 분양가 인하율 60/80/100%) | ✓ 정정 (2010.2.11 현재~2011.4.30 매매계약) |
| `99-4-*` | §99 ④ | 2012.9.24~2013.4.1 | **§98의7** (9억 이하 미분양 100%) | ✓ 시기 2012.9.24~2012.12.31로 정정 |
| `99-5-*` | §99 ⑤ | 2013.4.1~2013.12.31 | **§99의2** (신축·미분양·1세대1주택 100%, 취득가 6억 이하 OR 전용 85㎡ 이하) | OK |
| `99-6-*` | §99 ⑥ | 2014.1.1~2014.12.31 | **§98의8** (준공후미분양 6억·135㎡ 이하 50%) | ✓ 시기 2015.1.1~2015.12.31로 정정 |

> **결론**: 시드 데이터의 `article` 라벨은 **코드 작성자 자체 부여 식별자**(§99 ①~⑥)일 뿐 실제 조특법 조문번호와 **무관**. 게다가 일부 시기도 부정확. Phase 1에서 다음 정정:
> 1. `code` 필드를 실제 조문 표기(`98-3`, `98-5`, `98-7`, `99-2`, `98-8`, `99-3` 등)로 rename
> 2. `article` 필드를 실제 조문 번호(`§98의3`, `§98의5` 등)로 정정
> 3. `acquisitionPeriod.start/end` 일자를 원문에 맞게 정정 (특히 `99-4-*`, `99-6-*`)
> 4. 새로운 조문(§97의2/§97의5/§98/§98의2/§98의4/§98의6/§98의9/§99/§99의4) 추가 행 신설
