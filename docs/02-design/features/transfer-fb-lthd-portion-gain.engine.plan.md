### 1.1 「소득세법」 §95②·④

> **§95②** … 제94조제1항제1호에 따른 자산(…)으로서 보유기간이 3년 이상인 것 및 제94조제1항제2호가목에 따른 자산 중 조합원입주권(…)에 대하여 **그 자산의 양도차익**(…)에 다음 표 1에 따른 보유기간별 공제율을 곱하여 계산한 금액을 말한다. 다만, 대통령령으로 정하는 1세대 1주택(이에 딸린 토지를 포함한다)에 해당하는 자산의 경우에는 그 자산의 양도차익에 다음 표 2에 따른 보유기간별 공제율을 곱하여 계산한 금액과 같은 표에 따른 거주기간별 공제율을 곱하여 계산한 금액을 합산한 것을 말한다.

> **§95④** 제2항에서 규정하는 자산의 보유기간은 그 자산의 취득일부터 양도일까지로 한다. 다만, 제97조의2제1항의 경우에는 증여한 배우자 또는 직계존비속이 해당 자산을 취득한 날부터 기산(起算)하고, **같은 조 제4항제1호에 따른 가업상속공제가 적용된 비율에 해당하는 자산의 경우에는 피상속인이 해당 자산을 취득한 날부터 기산한다.**

- §95②의 LTHD 대상은 **§94①1호 자산(토지·건물)과 §94①2호가목 조합원입주권**이다 — **주식(§94①3호)은 대상이 아니다**. ⇒ F-1(주식 §97의2④)은 이 결함과 무관하다(§7.3).
- §95④ 후단의 한정어 「**비율에 해당하는 자산**」 — 자산을 적용률로 나눈 **부분**이 곧 보유기간 기산 단위다. 두 부분이 별도 양도차익을 갖는지는 법문이 정하지 않는다(§1.5).

## 3. 설계

### 3.1 부분별 양도차익 산식 (의제 §97의2④ 재귀)

기호: `P` 양도가액 · `E` 필요경비 합(양도비·자본적지출 — §97②1호) · `A_d` 피상속인 취득가액 + 피상속인 자본적지출(Q7=B, 기확정) · `V` 상속개시일 평가액 · `n/d` 적용률 정수 분수(`fbFrac`) · `dep` §97③ 감가상각비.

```
취득가액 두 항 (기존·불변):  tD = ⌊A_d × n/d⌋      tH = ⌊V × (d−n)/d⌋      A_imp = tD + tH
X  = P − E = G + A_imp − dep           (G = 안분 전 양도차익 = transferGain)
gD = ⌊X × n/d⌋ − tD (− depD)           ← 적용분 양도차익
gH = G − gD                             ← 비적용분 양도차익 (잔액 흡수 — Σ = G)
```

- `X`(양도가액 − 필요경비)를 **한 번에** r로 안분한다. P와 E를 따로 floor하면 합이 X와 최대 1원 어긋나고(잔액 흡수 위치가 늘어난다), 같은 base의 안분이라 `Σ = 전체` 불변식이 성립하므로 잔액 흡수가 정당하다(lib/tax-engine/CLAUDE.md 「적용 대상 판별」 기준 충족). 취득가액 두 항은 **base가 서로 달라 불변식이 없으므로** 문언대로 각각 floor한 `tD`·`tH`를 **그대로** 쓴다(재절사·흡수 금지).
- 교재 검증(§2.1): `gD = 0.7 × 1,770,000,000 − 350,000,000 = 889,000,000`, `gH = 970,000,000 − 889,000,000 = 81,000,000` ✓.
- `Math.round` · 부동소수 곱 금지 — `applyRateFraction`(BigInt 가드)만 쓴다. 분수는 #3672의 `fbLthdLatter.appliedRateFraction ?? resolveFamilyBusinessRateFraction(appliedRate)`를 그대로 쓴다.
- **잔액 흡수 방향**: 비적용분(상속인분). floor는 적용분에 걸린다 — 취득가액 두 항이 이미 `⌊⌋`(문언)이므로 같은 방향이다.

### 3.2 부분별 공제 (§95②·④·영 §160①)

과세 양도차익 `T` = 12억 초과 안분 후 값(= 현행 LTHD 입력 `taxableGain`). 1세대1주택 고가주택이 아니면 `T = G`.

```
pD = max(gD, 0)   pH = max(gH, 0)                      (Q-2 안 b — 차손 부분은 가중치 0)
tD' = applyRateFraction(T, pD, pD + pH)     tH' = T − tD'
공제액 = applyLthdRate(tD', 보유분율(피상속인 취득일 기산))
       + applyLthdRate(tH', 보유분율(상속개시일 기산))
       + applyLthdRate(T,  거주분율)          ← 표2 거주분: 현행 유지(전체 T · 슬라이스 가중 없음, 기확정 Q3)
```

- 두 부분이 모두 양수이면 `pD + pH = G`이고 `tD' = ⌊T × gD / G⌋`. `T = G`이면 `tD' = gD` 정확(BigInt 몫이 정수) — 교재 사례가 그대로 재현된다.
- 12억 초과 안분(`T < G`)은 **스칼라 비율**이라 슬라이스 몫이 그대로 안분된다. 영 §160①2호(「§95②에 따른 장특공제액」 × 안분비율)와 동치 — 순서(슬라이스 후 안분 / 안분 후 슬라이스)가 달라도 합은 **최대 ±1원**(V-3: 실측 시료 1개 0원 차이).
- `residencePart`(표2 거주분)는 **현행 그대로 전체 `T`**에 곱한다 — 거주기간 승계 명문 없음(`transfer-fb-lthd-95-4-latter.plan.md` §3.4 확정).

- 일반 §97 재귀를 슬라이스로 통일하면 `⌊X·n/d⌋ − ⌊V·n/d⌋` vs `⌊(X−V)·n/d⌋` 절사 차이로 **최대 1원** 달라질 뿐 법리 이득이 없다 ⇒ **Q-4 추천 = 현행 유지**(회귀 0 강제).

### 3.5 Σ 불변식·정수·잔액 흡수

- `gD + gH = G`(항등 — `gH = G − gD`). `tD' + tH' = T`(`tH' = T − tD'`). 두 식 모두 **구성상 항등**이므로 별도 흡수 코드 없음.
- `applyRateFraction` 입력: `X ≥ 0`, `0 ≤ n ≤ d`, `d > 0`, `T ≥ 0`, `pD, pH ≥ 0`, `pD + pH > 0` — 모두 정수. `pD + pH ≥ G > 0`(`G`는 두 부분 합)이라 분모 0이 없다.
- 가드: `G ≤ 0` 또는 `T ≤ 0`이면 `sliceGains`를 주입하지 않는다 → 현행 경로(공제 0 또는 비례). `G ≤ 0`인데 `T > 0`인 조합은 FB 허용 자산(겸용·GB·다건 차단)에서 도달하지 않는 것으로 보나 **미실측 — V-5**.
