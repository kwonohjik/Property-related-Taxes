## 3. 설계

### 3.1 F3 — 엔진: 주택 분모 자동값을 분자 주입과 떼어 낸다

`resolveInheritedAcquisitionInput`(`inheritance-acquisition-helpers.ts`)에서 분모 주입을 `shouldInjectHouseValuation` 블록 밖으로 뺀다:

```
주택 §164⑦ 결과 있음 ∧ 의제 전 ∧ 미공시 구간(isHousePreDisclosure) ∧ 보낸 분모 없음 ∧ 양도 당시 개별주택가격 > 0
  → 분모 = 양도 당시 개별주택가격   (분자를 보냈든 자동 주입했든 같다)
```

- 순서는 지금 자동 분자 경로와 같다: 보낸 분모 > 양도 당시 개별주택가격 > 최상위 `standardPriceAtTransfer`.
- ⑤가 분모 칸에 자동값을 보여 주는 조건(`preDeemedAutoStdPrices` — 3시점 열림 ∧ 양도 당시 개별주택가격 > 0, 분자 토글과 무관)과 같아진다. ④·⑤는 바꾸지 않는다.
- 실측(probe 적용): 증여·상속 20억 → ③ 1,000,000,000 · **84,871,600**(두 칸 직접 입력과 원 단위 같음) · 함께 양도 ③ 460,000,000.
- 자동 분자 경로(H0·H4)·상가·토지는 값이 그대로다(P-0 전체 실패 0).

### 3.2 F4 — ⑧ PD-1: ①·②가 있어도 「분자만 있고 분모 없음」은 막는다

`preDeemedConversionInputError`에서 증여 ③ 범위 반환(`:269`) **앞**에 둔다:

```
④ payload가 pre-deemed
∧ 기준시가 평가 부담부증여 아님 ∧ (주 자산이면) 담보 승 아님        ← 상가 규칙(`:260-268`)과 같은 제외
∧ ③ 칸이 화면에 있음(상속 · 증여 ③ 범위 · 부담부증여 의제 전)       ← ④ conversionInputShown과 같은 술어
∧ 래치 켠 상속 토지 등급 경로 아님(hasPre1990LandEstimation)        ← 기존 :480 문구 보존
∧ ① 있음 ∨ 증여 ③ 범위 ∨ ② 원천 있음(주택·토지 payload)            ← ①② 없음은 기존 :280-283이 같은 칸을 요구한다
∧ 실효 분자 있음 ∧ 실효 분모 없음
  → standardPriceAtTransfer 칸: 「…§164④~⑦ 기준시가·상증법 평가액과 함께 환산취득가액도 비교합니다 — 양도시 기준시가를 입력하세요 (소득세법 시행령 §176의2④)」
```

- **실효 분자** = 보낸 분자(`preDeemedSentStdPrices().atDeemed`) > 0 ∨ 화면 자동값(`preDeemedAutoStdPrices().atDeemed`)이 보이는 중(토글 꺼짐). **실효 분모**도 같은 짝. 두 함수는 ⑤ 칸과 ④ 전송이 이미 쓰는 단일 소스다 — 새 판정을 만들지 않는다.
- 자동 분자를 「있음」으로 센다(Q-3): 토지 등급(L3)·주택 3시점(H2). 화면에 잠긴 분자가 보이는데 분모 칸이 비어 있는 상태다.
- 문구의 칸 이동 대상 `standardPriceAtTransfer`는 ③ 카드(`PreDeemedConversionFields`)의 `FieldCard field="standardPriceAtTransfer"`다 — 자동 분모가 없으면 편집 가능한 칸으로 보인다.
- 컴패니언도 같은 함수를 탄다(`isNonPrimaryAsset` 인자 — 담보 승 제외만 주 자산 한정, 상가 규칙과 같다).

### 3.3 F4 — ⑫ 같은 규칙

`refinePreDeemedAcquisitionSource`의 `if (clauseA) return;`(`:676`)을 `clauseA`일 때 한 번 더 보도록 바꾼다:

```
clauseA ∧ 기준시가 평가 부담부증여 아님 ∧ 담보 승 단건 아님
∧ 분자 원천 있음(ia.standardPriceAtDeemedDate > 0 ∨ inheritedHouseValuation ∨ pre1990Land)
∧ 분모 원천 없음(ia.standardPriceAtTransfer > 0 ∨ 최상위 standardPriceAtTransfer > 0 ∨ inheritedHouseValuation.housePriceAtTransfer > 0 — 모두 아님)
  → ["inheritedAcquisition", "standardPriceAtTransfer"] 400
```

- 분모 원천 3개는 3.1 뒤 엔진이 쓰는 분모 그대로다(`:374` 최상위 fallback 포함).
- 상가(`commercialInheritanceValuation`)는 위 `:662` 규칙이 먼저 막는다 — 여기 넣지 않는다.
- L3i(래치 켠 상속 토지)는 ⑧이 기존 문구로 막고 ⑫는 이 규칙으로 400이 된다 — 「⑧ 막는데 200」 해소.
