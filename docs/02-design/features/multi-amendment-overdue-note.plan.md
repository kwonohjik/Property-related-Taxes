## 1. 측정 (V 레지스터)

**V-1 자산 화면 안내** (이력 → 진입 → 자산 목록 → 자산 편집. 양도일 2024-01-26, 신고일 2024-06-30, 기한 2024-03-31)

| 진입 | 자산 가산세 | 안내 | Step6 토글 |
|---|---|---|---|
| 다건 편집 | 켜짐 | 「가산세 자동 적용」 | 있음 |
| 다건 편집 | 꺼짐 | 「가산세 계산이 꺼져 있어 세액에 포함되지 않습니다」 | 있음 |
| **수정신고** | 켜짐 | **「가산세 자동 적용」** | 있음 |
| 수정신고 | 꺼짐 | 「가산세 계산이 꺼져 있어…」 | 있음 |
| **경정청구** | 켜짐 | **「가산세 자동 적용」** | 있음 |
| 경정청구 | 꺼짐 | 「가산세 계산이 꺼져 있어…」 | 있음 |

원인: 수정신고 상태는 다건 폼(`multiForm.amendmentMode`)에 있고 자산 폼에는 없다(실측 자산 폼 `amendmentMode=false`). `filingOverdueNote`와 Step6 분기(`app/calc/transfer-tax/steps/Step6.tsx:47`)는 자산 폼만 본다. 진입 배너(`CorrectionModeBanner`)도 자산 폼을 봐서 자산 화면에는 뜨지 않는다.

**V-2 다건 계산** (토지 양도 10억, 취득 2억, 공통 설정에서 「세액 계산」)

| 진입 | 자산 가산세 | 요청의 자산 가산세 블록 | 요청의 `amendment` | 총 납부세액 |
|---|---|---|---|---|
| 다건 편집 | 켜짐 | 있음 | 없음 | 249,973,614(가산세 24,550,614) |
| 다건 편집 | 꺼짐 | 없음 | 없음 | 225,423,000 |
| 수정신고 | **켜짐** | **없음** | 있음 | **225,423,000(가산세 0)** |
| 수정신고 | 꺼짐 | 없음 | 있음 | 225,423,000 |

수정신고 쪽 가산세는 공통 설정의 수정신고 항목에서 켠다(시료는 끈 상태). 자산 화면 안내를 믿고 그 항목을 켜지 않으면 가산세 없는 값을 보게 된다.

**V-3 다른 화면 문구**
- Step6: 토글·신고 유형·납부 입력이 그대로 나오고, 「가산세 계산하기」 버튼도 켜짐 상태에서 나온다(`TransferTaxCalculator.tsx:620`). 이 버튼의 단건 계산 결과와 다건 결과의 관계는 미측정이다.
- 공통 설정: 수정신고 중에도 「각 자산 편집 마법사 마지막 단계에서 입력합니다」가 나온다(`components/calc/transfer/AggregateSettingsPanel.tsx:145`).

**V-4 별건 — 진입 마이그레이션 누락**

「편집」은 `migrateMultiForm`을 거치는데(`lib/calc/transfer-resume-entry.ts:115`) 수정신고·경정청구 진입은 `input`을 그대로 넣는다(`lib/calc/transfer-amendment-entry.ts:186·212`).

| 저장 폼 | 편집 | 수정신고 |
|---|---|---|
| `assets` 없음(구 스키마) | 빈 폼으로 열림 | 자산 목록에서 **「페이지를 불러오지 못했습니다」** |
| `isOneHousehold` 없음(후속 추가 필드) | 계산 200 | 계산 **400** (`properties.0.isOneHousehold`) |

그런 이력이 실제로 있는지는 사용자 브라우저 IndexedDB라 확인할 수 없다.

**V-5 미측정**: 시료 세액의 법령 대조, 「가산세 계산하기」 버튼의 수정신고 중 값, 단건 저장 이력에서 넘어온 합산(`enterMultiAggregate`) 뒤 수정신고.

## 2. 결정 (Q 레지스터)

**Q-1 자산 화면 안내**
- a. **권장** — 신고서 단위 수정신고·경정청구면 단건 수정신고와 같이 기한 경과 사실만 표시한다.
- b. 「공통 설정의 수정신고 항목에서 입력합니다」까지 붙인다. 경정청구는 문구가 또 갈린다. Q-2의 Step6 안내가 이 몫을 한다.

**Q-2 Step6 입력**
- a. **권장** — 입력칸 대신 안내만 표시한다. 수정신고: 「가산세는 공통 설정의 수정신고 항목에서 입력합니다」 / 경정청구: 「이 화면의 가산세 입력은 경정청구 계산에 쓰이지 않습니다」. 저장 값은 지우지 않는다(수정신고를 빠져나가도 원래 값이 남도록, 요청은 G-28이 막는다). 「가산세 계산하기」 버튼도 숨긴다. 공통 설정 문구도 수정신고 중에는 바꾼다.
- b. 안내만 고치고 입력칸은 둔다. 쓰이지 않는 입력을 받는 문제가 남는다.

**Q-3 V-4 진입 마이그레이션**
- a. **권장** — 같은 PR에서 두 진입 모두 `migrateMultiForm`을 거치게 한다. 같은 수정신고 진입 경로이고 「편집」과 같은 호출이다.
- b. 별도 PR로 나눈다.
