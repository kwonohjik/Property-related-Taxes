## 0. 결론

| 질문 | 결과 |

| **원인 정정** | O-19 계획서와 메모리는 이 1원을 «O-8 몫 규약(잔액 마지막 양수 조각)의 귀결»이라고 적었다 — **측정하지 않은 추정이었고 틀렸다.** 실제 원인은 **일괄양도 양도가액 안분(영 §166⑥)의 «말단 자산 잔액 흡수»**다: `apportionBundledSale`(`lib/tax-engine/bundled-sale-apportionment.ts`)이 variable 자산의 비율 몫을 `Math.round`로 정하고 **입력 순서상 마지막 자산이 잔여값을 흡수**한다. 단위 몫(`allocateUnitExcessShares`)은 이 시료들에 배율 초과분이 없어 관여하지 않는다(V-2). |

| 영향 | 순열 격자 40셀 중 **양도가액 배정이 순서에 따라 달라진 셀 24 · 총세액이 달라진 셀 5(모두 1원)**. 기준시가가 같은 카드끼리(소수부가 같은 경우)에서만 난다(V-1·V-3). |

## 1. 측정 (V 레지스터)
