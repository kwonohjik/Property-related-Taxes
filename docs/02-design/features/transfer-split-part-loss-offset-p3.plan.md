## 1. 겸용주택 단건 경로의 파트 차손 0 절사 (확인 필요 ①)

> 모의 세율 `makeMockRatesWithHouseEngine` · 양도 2026-06-01 · 실가 취득(`useActualAcquisition`) · 토지·건물 같은 날 취득.

### 1.1 근거 (원문 확인한 것만)
- **국세청 서면인터넷방문상담4팀-2792(2006.8.16.)** — taxlaw 본문 확인.
  - 질의: 상가부분이 더 큰 겸용주택에서 1세대1주택 비과세 요건을 갖춘 고가의 주택부분에 양도차손이 생기면, 상가부분 양도차익과 통산하는가.
  - 요지: 자산별 양도소득금액과 결손금은 서로 통산한다. 붙임 근거는 법 §95③ · 영 §160(고가주택 양도차익 계산) · 법 §102다.
  - 붙임 재일46014-1949(1998.10.10.): 건물부분 양도차손은 법 §102에 따라 토지부분 양도차익과 통산한다.
  - ⚠️ 「초과분만」 통산하는지는 직접 말하지 않는다. 「과세분만 통산」은 조심2016부0323(P2 §9)과 사용자 결정 Q-1(P2 §4.1)에서 가져온다.
- 비과세분 차손은 통산하지 않는다 — 상속증여세과-209(P2 §0).
- 기획재정부 재산세제과-917(2011.10.27., 「비과세대상 양도자산에서 발생한 양도차손의 통산 여부」)은 위 회신의 유사문서 목록에서 제목만 봤다. **본문 확인 필요.**

### 1.3 같은 물건이 함께 양도면 이미 통산된다

### 1.5 판정
1. 🔴 **과대과세(a1 · a3 · a4 · b2 · e · f2)** — 주택 파트(C1 · C2 · C4)와 상가 합계(C5)의 차손을 버린다. §167의2① · 서면4팀-2792 · 재일46014-1949와 어긋나고, 같은 물건의 함께 양도 경로와 갈린다.
2. 🔴 **과소과세(a5)** — 상가 한 파트가 차손이면 C7 불변식이 깨져 §104⑤ 2호 비교를 건너뛰고 1호(합산 누진)만 낸다. 단기 보유(1~2년)에서 2호가 이겨야 할 세액 193,750,868이 빠진다. 절사가 아니라 **차손 때문에 세율 판정이 빠지는** 별개 결함이지만, 같은 수정(절사 해제)으로 불변식이 회복된다.
3. 🟠 **f3** — 프로토타입 후에도 단건과 카드가 다르다. 단건은 915 대칭(이내 토지 = min(0, 안분(전체 토지) − 이전분) = 0)이고, 카드는 이내 토지 카드 차손 −94,207,317을 자기만 안분(−48,987,804)한다. ②와 같은 뿌리다 — 겸용 파트 카드는 `buildHousingPart`의 `rulingApplies`(초과분 > 0)일 때만 몫을 싣는다(`mixed-use-part-cards.ts:279`).

### 1.6 수정 방향
- **A안(권장 · 프로토타입 확인)** — 겸용 단건 엔진 안에서 절사를 풀고 `buildTotalTax`에서 파트 통산.
  1. `buildHousingPart` 차손 과세분: 비과세 아님이면 전액, 전액 비과세면 0, 일부 비과세면 `calculateProration(차손, 주택분 − 12억, 주택분)`(일반 엔진과 같은 0 방향 절사 · −0은 0).
     - 토지 차손 + 배율 초과(이전분 < 0)이면 `highValueExcessLandTaxableGain`(915 대칭)에 위 안분 함수를 넘긴다.
     - G-3(나중 취득 토지)이면 토지 차손 전액.
  2. C4 · C5 · C6 `max(0, …)` 해제. 장특은 이미 양수 파트에만 붙는다(`helpers.ts:424`·`:425`·`:524`·`:525`).
  3. `buildMixedRateParts` 비사업용 파트는 `income !== 0`이면 넣는다(C8). C7 불변식은 절사가 없어져 자연히 성립한다.
  4. `buildTotalTax` 앞에서 음수 파트가 있으면 `offsetLossesCore`(세목 공용 코어)로 §167의2① 1호 → 2호를 통산한다. 세율군 키 = `shortTermRate(보유연수, 주택 여부)` + §104⑦ 가산율. 통산 후 소득으로 세 부분 합과 2호 버킷을 계산하고(C9), `aggregateIncome`은 `max(0, Σ)`.
  - 프로토타입 결과: a0~e2b · f · f2 전부 단건 = 파트 카드 합산, 차손 없는 기존 값 불변.
- B안: 단건 겸용도 파트 카드 + aggregate로 계산(함께 양도 경로 재사용). 단일 소스가 되지만 결과 화면 · 상세명세서 · 신고서 · PDF가 쓰는 `MixedUseGainBreakdown`(파트 산식 · §104⑤ 표시 · 감면 F17-B · 가산세 G-43 · 경정)을 카드 결과에서 다시 만들어야 한다. 권장하지 않는다.
