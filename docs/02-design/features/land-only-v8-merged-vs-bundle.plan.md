## 1. 측정 (V 레지스터)

시료: O-19 계획서와 같은 격자 — 주택 16억(취득 7억) + 부수토지 카드 4억 100㎡(취득 2억/6억/4억) · 2026-06-15 양도 · 조정지역 · hc 1·2 × 같은/다른 세대(토지만 본인) × 취득일 2014/2025/2026-03 = 36셀. «합쳐 입력»은 카드를 없애고 양도가 20억·토지 12억·토지 취득가 4억+카드 취득가로 한 장에 넣은 것.

| ID | 측정 | 결과 |
|---|---|---|
| V-1 | 36셀 재측정 | **33셀 같음 · 3셀 다름**(O-19 계획서와 동일). 다른 셀: ① hc1 같은 세대 2014 카드 취득 6억 — 번들 57,945,800 ↔ 합쳐 65,971,400 ② hc1 다른 세대 2014 6억 — 22,093,500 ↔ 40,573,500 ③ hc2 다른 세대 2014 6억 — ②와 같은 값 |
| V-2 | 분해 | 36셀 전부 **과세 양도차익이 같다**(번들 `Σ(income+장특)` = 합쳐 `taxableGain`). 36셀 전부 `양도소득금액(합쳐) − 양도소득금액(번들) = 장특(번들) − 장특(합쳐)` 항등. 세액이 다른 셀의 집합 = 장특이 다른 셀의 집합(3셀). |
| V-3 | 3셀의 장특 차 | ① 번들 86,400,000(주택 과세분 3.6억 × 24%) ↔ 합쳐 67,200,000(순 2.8억 × 24%) = 19,200,000 = 24% × 카드 차손 안분 8,000만 · ② 96,000,000 ↔ 48,000,000 = 24% × 카드 차손 2억. 세 셀 모두 «차손 × 장특율» 정확히. 독립 산식: ② 번들 과세표준 101,500,000 × 35% − 15,440,000 = 20,085,000 × 1.1 = 22,093,500 ✅ · 합쳐 149,500,000 → 36,885,000 × 1.1 = 40,573,500 ✅ |
| V-4 | **등가 시료** — 한 주택 안 파트 차손 | 단일 주택(분리취득, 양도가 20억): 토지 12억(취득 3억 → +9억) · 건물 8억(취득 10억 → −2억). 1주택·2014 취득. 결과: 토지 장특 86,400,000(과세분 3.6억 × 24%) · 건물 차손 파트 장특 0·과세분 −8,000만 · 양도소득금액 193,600,000 · 과세표준 191,100,000 · **총세액 57,945,800 — V-1 ①의 번들 값과 원 단위까지 같다.** 즉 번들은 엔진이 한 주택 안의 파트 차손에 이미 쓰는 규약(양수 파트에만 장특, 차손은 장특 뒤에 통산)을 필지 사이로 그대로 옮긴 것이다. |
| V-5 | 차손이 없으면 | 같은 격자에서 카드 이익·0인 셀은 장특이 선형이라 번들 = 합쳐 입력 — 장특율이 0인 셀(2025·2026 취득 · 2014 2주택 중과)도 같다. 차이는 «카드 차손 + 장특율 > 0»에서만 난다. |

## 2. X-1 (법 근거) — ✅ 2026-10-30 사용자 확정으로 종결

| ID | 내용 | 상태 |
