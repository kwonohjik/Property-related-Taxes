## 1. 근거

### 1.1 조문·해석례

| 근거 | 내용 | 이 계획에서 |

- 0893 회신의 사실관계(자경 100% + 수용 20%)는 한도에 걸리는지 언급이 없다. 한도가 걸린 상황에 대한 해석례·심판례는 찾지 못했다(PR #2220 계획서 §7 「확인 필요」). 사용자 결정은 1685의 「유리한 순서」로 그 공백을 메운다.

### 1.2 결정의 범위

- **같은 날 양도한 감면소득 사이**(§103② 2단계 동순위)만. 양도일이 다른 감면소득은 현행대로 양도일 순이다(조문 침묵 — PR #2220 D-2 유지).
- 감면 외 소득 먼저(1단계)는 그대로다 — 유리 판정보다 앞선다(§103② 명문).
- `FIRST` 전략(사용자가 고른 입력 순서)·파트 축(`PARTS_HIGHEST_RATE`)의 표시 배분은 범위 밖이다.

## 3. 설계

### D-1. 같은 날 감면소득 조각을 감면율과 무관하게 한 묶음으로

- `sameDayTieGroups`의 2단계 묶음 키를 `(양도일, 감면율)` → `(양도일)`로 넓힌다. 묶음에 공제가 닿고 **조각을 가진 자산이 둘 이상**일 때만 묶음이 된다(조각이 한 자산 것뿐이면 그 자산 안 순서는 `absorbBasicDeduction`이 감면율 낮은 것부터 정한다 — 한 자산은 감면 유형이 하나라(조특법 §127⑦) 한도 그룹도 하나다).
- 1단계 묶음(감면 외 · 같은 날)은 그대로다.

### D-2. 후보 = 「0893 순서」 + 「자산 블록 순서」

- 후보의 단위는 **자산**이다(자산 안의 조각은 항상 감면율 오름차순으로 붙어 다닌다). 한도는 유형(= 자산) 단위로 걸리므로, 어느 **자산**이 공제를 먼저 받느냐가 갈림이다.
- **첫 후보 = 현행 0893 순서**(조각을 감면율 오름차순으로 끼워 넣은 순서, 같은 율은 propertyId 순). 세액이 같으면 첫 후보가 남으므로 한도가 안 걸리는 사안은 현행과 같다.
- 나머지 후보 = 묶음 안 자산 순열마다 「그 순서대로 자산의 조각을 통째로」. 상한은 PR #2220의 24(`TIE_CANDIDATE_LIMIT`)를 **0893 후보 묶음과 블록 후보 묶음에 각각** 적용하고(최대 48회 평가), 넘으면 묶음마다 「누가 첫째인가」만 평가한다(PR #2220 Q-2와 같은 방식).
- 비교 기준은 그대로다: `totalTax` 최소 → 결정세액 최소 → 먼저 나온 후보.

### D-3. 순서 전달 — `tieRank`를 조각 순서까지 확장

- 지금 `allocateBasicDeduction`의 2단계 정렬은 `양도일 → 감면율 → tie`라 `tieRank`가 감면율을 넘지 못한다. 2단계에 한해 **「같은 날 조각 순서」(자산 블록 순서 또는 0893 순서)** 를 받는 인자를 둔다. 인자가 없으면 현행 정렬 그대로다.
- `finishWith`는 1단계 `tieRank`와 2단계 조각 순서를 한 후보로 받는다. 감면 계산용 배분(`allocatedBasicForReduction`, :253-260)도 같은 후보를 쓴다.
- 감면 단계(`aggregateReductions`)는 손대지 않는다 — 자산별 배분에서 C를 읽는 단일 소스(PR #2220 D-3)라 배분만 바뀌면 따라온다.

### D-4. 표시

- 계산 과정 「기본공제」 단계 문구(:263-266): 채택 후보가 0893 순서와 **다르면** 「같은 날 감면소득 — 조특법 §133 감면 한도를 반영해 납세자에게 유리한 순서(재일46014-1685)」. 같으면 종전 0893 문구. (현행 판정 `sameDayReducibleRatesDiffer`는 배분만 보므로 그대로 두면 한도 때문에 순서를 바꾼 경우에도 「감면율 낮은 소득부터」라고 틀리게 말한다.)
- 자산별 배분 기본공제·감면 내역(`basicDeductionApplied`)·신고서·PDF는 배분을 읽으므로 따로 손대지 않는다(Do-5에서 역방향 grep으로 확인).
- 14 동기화 지점: 입력·결과 필드 신설 없음 — 해당 없음.

### D-5. 손대지 않는 것

- 양도일이 다른 감면소득의 순서 · 감면 외 우선 · `FIRST` · 파트 축 표시 배분.
- 한도 초과분을 어느 자산에서 깎는가(조특법 §133 「자산양도의 순서」) — 기존 `applyAnnualLimits`·`applyFiveYearLimits`.
- P2 부수 발견(입력 순서 1원 갈림).
