# 국외자산 부동산 양도소득세 (소득세법 §118의2~§118의8) — 계획 색인

> 상태: **계획(PR-0) · C-1~C-3 사용자 결정 완료** · 2026-11-27
> 엔진·API: [transfer-foreign-realestate.engine.plan.md](transfer-foreign-realestate.engine.plan.md) (Q-1~Q-13 · V-1~V-16 · K-1~K-27)
> 화면: [transfer-foreign-realestate.ui.plan.md](transfer-foreign-realestate.ui.plan.md) (UQ-1~UQ-12 · V-1~V-14)

## 1. 출발점

교재 사례(국외 토지 A 미등기 · 취득 2022.1.15. $400,000 · 양도 2026.7.10. $900,000 · 양도비 $30,000):

| 항목 | 값 | 근거 |
|---|---|---|
| 양도가액 | 900,000 × 1,100 = 990,000,000 | 영 §178의5① 기준환율 (매입률 1,050·매도율 1,150 아님) |
| 취득가액 | 400,000 × 1,300 = 520,000,000 | 〃 (매입률 1,250·매도율 1,350 아님) |
| 양도비 | 30,000 × 1,100 = 33,000,000 | 〃 · 지출일=양도일로 봄 |
| 장기보유특별공제 | 0 | §118의8 단서 (교재 8%는 함정) |
| 양도소득금액 | **437,000,000** | 교재 정답 |
| 기본공제 | 2,500,000 | §118의7① — 미등기 배제 단서 없음 |
| 과세표준 | **434,500,000** | 교재 정답 |
| 산출세액 | 147,860,000 | §118의5① → §55① (교재 미제시 · 엔진 계획 계산값) |

현재 부동산 양도세 엔진에는 국외자산 경로가 없다(주식 엔진에만 있음).

## 2. 두 계획서 충돌 — 사용자 결정 필요

| # | 쟁점 | 엔진 계획 | 화면 계획 | 통합 추천 |
|---|---|---|---|---|
| C-1 | 여러 건(연간 합산) | Q-2: 다건 허용, 차손 있으면 차단 (PR-3) | UQ-3: 첫 PR은 단건만, 다건 차단 | **단건 먼저** — 엔진 PR-3(다건)은 화면 U 이후 후속으로 미룸. 국외 차손 통산 근거(엔진 V-1)가 없어 다건 가치가 제한적 |
| C-2 | 5년 거주 요건 입력 | Q-3 (b) 계속 거주 시작일(날짜) | UQ-8 (a) 거주 연수 숫자(주식 재사용) | C-1이 단건이면 **(a) 연수** — 다건 도입 시 (b)로 전환. 다건까지 볼 거면 처음부터 (b) |
| C-3 | 미등기 입력 칸 | `registered` 칸 검토 | UQ-9: 칸 없이 안내 카드 | **칸 없음** — §118의5① 세율·§118의7 공제 어디에도 미등기 분기가 없어 세액 무관 (엔진 V-3 확정 전까지 «확인 필요» 안내) |

**사용자 결정 (2026-11-27 · 재제안 금지)**
- **C-1 = 처음부터 여러 건** — 엔진 Q-2 채택. 엔진 PR-3(다건·기본공제 §118의7② 순서·외국납부세액)을 화면 U 이전 순서에 둔다. 화면 UQ-3(다건 차단)은 폐기 — 다건 마법사도 국외 자산을 받는다. 국외 차손이 섞이면 막고 «확인 필요» 고지(엔진 V-1 해소 전).
- **C-2 = 거주 연수 숫자** (UQ-8 (a)) — 엔진 Q-3 (b) 폐기. 폼 전역 1칸을 모든 국외 자산에 적용한다. 한계: 양도일이 서로 다른 다건에서 5년 경계가 자산마다 갈리는 경우는 표현할 수 없다 → 연수가 5에 걸치면(예: 5년 입력 + 양도일 사이 간격) «확인 필요» 고지. 엔진 입력은 정수 연수.
- **D-M = 다건(/multi 연간 합산) 마법사는 국외 건을 막고 «국외 자산은 한 건 계산 안에서 여러 개를 추가하세요» 안내** (2026-11-27 · U2 — [UI 계획 §14.5](transfer-foreign-realestate.ui.plan.md)). C-1(여러 건 = 한 계산 안 `foreignAssets[]` ≤ 20)과 한 쌍이다.
- **C-3 = 칸 없이 안내만** (UQ-9) — 엔진 `registered` 칸 만들지 않는다. 안내 카드 1장, 엔진 V-3 해소 전 «확인 필요» 문구 포함.

일치(결정 불필요): 별도 엔진·route·Zod(엔진 Q-1)를 양도세 마법사의 «자산 소재 = 국외» 라디오(UQ-1)가 호출 · 환율은 항목별 기준환율 수동 입력·fallback 금지(Q-4 = UQ-4·5·7) · 외국납부세액공제 v1 포함(Q-7 = UQ-10) · 가산세·장기할부·시가 모드 후속(Q-5·Q-11·Q-13 = UQ-2·UQ-11).

## 3. 세액이 갈리는 미검증 (착수 전 해소 또는 차단+고지)

- 엔진 V-1 국외 자산 사이 양도차손 통산 근거 (§102 미준용)
- 엔진 V-3 미등기 70% 비적용의 확정 근거 (영 §178의2④)
- 엔진 V-5 국내·국외 과세표준 합산 누진 여부 (예시 차이 30,630,000원)
- 엔진 V-7 지방소득세 base(외국납부세액공제 전/후)·절사 단위
- 엔진 V-12 = UI V-12 외국납부세액 환산 기준일

## 5. 별건 발견 (이 계획 범위 밖 · 수정 안 함)
