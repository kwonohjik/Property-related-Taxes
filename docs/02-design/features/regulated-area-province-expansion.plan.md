> 선행: `regulated-area-bjd-history.plan.md`(수도권 P1~P6, ✅ PR#257). 본 계획은 데이터 범위만 전국으로 확장한다.
> worktree: `feat/reg-province` (slot 1, dev 3001 / E2E 3101). base origin/master cf7f1e5b.

## 1. 배경·문제

`REGULATED_REGIONS`(`lib/tax-engine/data/regulated-areas.ts`)가 **수도권(서울11·경기41·인천28) 49개 시군구만** 수록.
지방(세종·부산·대구·대전·광주·울산 + 2020.11.19 지정 비수도권)도 역사적 조정대상이었으나 미수록.

**현 동작의 위험(미수록 지방)**:
- `isRegulatedByBjdCode`(코드 경로): region 미발견 → **"미지정"(high)으로 단정** → 다주택 중과·거주요건 판정 오류 (예: 세종 2주택 양도, 부산 해운대).
- `isRegulatedByAddress`(주소 경로): 미수록 시도 → `low`("직접 확인"). ← 코드 경로와 **비대칭**(코드 경로가 더 위험).
