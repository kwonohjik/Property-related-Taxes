## 0. 왜 네 항을 묶는가

넷 다 **§155의 1세대1주택 의제**이고, 넷 다 **비과세(§154①)와 중과 배제(영 §167의10①15호·
§167의3①13호)에 동시에** 걸린다. 앞 계획서 Phase B가 `deemedOneHouseBy155`라는 **단일 슬롯**을
만들어 뒀으므로, 각 항은 「비과세 판정 + 그 슬롯 채우기」 한 번으로 양쪽에 반영된다.

따로 구현하면 같은 배선을 네 번 반복하게 된다.

## 1. 검증된 법령

「소득세법 시행령」 MST 286211 · 시행 2026-07-01 · 2026-07-31 법제처 Open API 전문 조회.

### 1.1 §155⑯ — 공공기관 지방이전 시 §155① 「3년」→「5년」

> 제1항을 적용(**수도권에 1주택을 소유한 경우에 한정**한다)할 때 수도권에 소재한 법인 또는
> 「지방자치분권 및 지역균형발전에 관한 특별법」 제2조제14호에 따른 공공기관이 **수도권 밖의
> 지역으로 이전**하는 경우로서 법인의 임원과 사용인 및 공공기관의 종사자가 구성하는 1세대가
> 취득하는 다른 주택이 해당 공공기관 또는 법인이 **이전한 시·군 또는 이와 연접한 시·군**의
> 지역에 소재하는 경우에는 제1항 중 **"3년"을 "5년"으로 본다**. 이 경우 해당 1세대에 대해서는
> **종전의 주택을 취득한 날부터 1년 이상이 지난 후 다른 주택을 취득하는 요건을 적용하지 아니한다.**

⇒ 효과 **둘**이다: ① 처분기한 5년 ② **1년 요건 면제**. ②를 빠뜨리기 쉽다.

> ⚠️ 항번호는 법제처 API가 ⑯ 이후를 렌더하지 않아 **순서로 역산**했다(앞 계획서 §1.4 각주와 동일 근거):
> ⑮(다가구) → **⑯**(공공기관 이전) → ⑰(삭제) → ⑱(§89①4호나목 사유) → ⑲(협의분할) → ⑳(장기임대 거주주택).

### 1.2 §155⑱ — §155① 3년 기한의 예외 사유 5종

§155① 본문 괄호가 이를 준용한다: 「… 3년 이내에 종전의 주택을 양도하는 경우
**(제18항에 따른 사유에 해당하는 경우를 포함한다)**」.

> 법 제89조제1항제4호나목에서 "대통령령으로 정하는 사유"란 **다른 주택을 취득한 날부터 3년이
> 되는 날 현재** 다음 각 호의 어느 하나에 해당하는 경우를 말한다.
> 1. 한국자산관리공사에 **매각을 의뢰**한 경우
> 2. 법원에 **경매를 신청**한 경우
> 3. 「국세징수법」에 따른 **공매가 진행 중**인 경우
> 4. 재개발·재건축·소규모재건축사업등의 시행으로 **현금청산금 지급 소송 진행 중** 또는 종료됐으나 **미지급**
> 5. 재개발·재건축·소규모재건축사업등의 시행으로 **수용재결·매도청구소송 진행 중** 또는 종료됐으나 **미지급**

⇒ 판정 기준시점이 **「3년이 되는 날 현재」**로 고정돼 있다. 양도일이 아니다.

### 1.3 §155⑧ — 부득이한 사유로 취득한 수도권 밖 주택

> 재정경제부령으로 정하는 **취학, 근무상의 형편, 질병의 요양, 그 밖에 부득이한 사유**로 취득한
> **수도권 밖에 소재하는 주택**과 그 밖의 주택(일반주택)을 국내에 각각 1개씩 소유하고 있는 1세대가
> **부득이한 사유가 해소된 날부터 3년 이내**에 일반주택을 양도하는 경우에는 국내에 1개의 주택을
> 소유하고 있는 것으로 보아 제154조제1항을 적용한다.

중과 쪽 대응 호는 §167의10①**4호**「제155조제8항에 따른 수도권 밖에 소재하는 주택」이다 —
15호를 거치지 않고 **직접** 배제된다(앞 계획서 F-4 ⑧행에서 「별개 호」로 짚은 것).

### 1.4 §155⑦ — 농어촌주택 + 일반주택

> 다음 각 호의 어느 하나에 해당하는 주택으로서 **수도권 밖의 지역 중 읍지역(도시지역안의 지역을
> 제외한다) 또는 면지역**에 소재하는 주택(**농어촌주택**)과 그 밖의 주택(일반주택)을 국내에 각각
> 1개씩 소유하고 있는 1세대가 **일반주택을 양도**하는 경우에는 국내에 1개의 주택을 소유하고 있는
> 것으로 보아 제154조제1항을 적용한다. 다만, **제3호의 주택에 대해서는 그 주택을 취득한 날부터
> 5년 이내에 일반주택을 양도하는 경우에 한정**하여 적용한다.
> 1. **상속**받은 주택(피상속인이 **취득 후 5년 이상 거주**한 사실이 있는 경우에 한한다)
> 2. **이농주택** — 이농인이 **취득일 후 5년 이상 거주**한 사실이 있는 주택
> 3. 영농·영어 목적으로 취득한 **귀농주택**

부속 조항:

| 항 | 내용 |
|---|---|
| ⑨ | **이농주택** 정의 — 영농·영어 종사자가 전업으로 다른 시·구·읍·면 전출로 거주하지 못하게 된 주택 |
| ⑩ | **귀농주택** 요건 — 2호 취득 당시 **고가주택 아닐 것**(§89①3호) · 3호 **대지 660㎡ 이내** · 4호 영농·영어 목적 · 5호 **세대전원 이사·거주** |
| ⑪ | 귀농은 **귀농 후 최초로 양도하는 1개** 일반주택에 한정 |
| ⑫ | 사후관리 — 귀농일부터 **3년 이상** 영농·영어 미종사 또는 미거주 시 **추징**(2개월 내 신고·납부) |
| ⑬ | 특례적용신고서 제출 의무 |

## 3. 설계

### 3.1 `deemedOneHouseBy155` union 확장

```ts
// 현재: "temporary_two_house"
// 확장: | "unavoidable_outside_capital"   // ⑧ — 단, 중과는 §167의10①4호로 직접 배제
//       | "rural_house"                    // ⑦
```

⑯·⑱은 **①의 변형**이므로 새 값을 만들지 않는다 — `temporary_two_house` 판정 안에서 처리한다.

### 3.2 ⑯·⑱ — §155① 판정 내부 확장 (가장 작다)

```
resolveTemporaryTwoHouseDeadlineYears(input, rule):
  + if (input.temporaryTwoHouse?.publicInstitutionRelocation) return 5   // ⑯ 3년→5년

judgeTemporaryTwoHouseTiming(p):
  + oneYearWaived ||= publicInstitutionRelocation                        // ⑯ 후단
  + threeYearMet ||= disposalDelayReason !== undefined                   // ⑱ 기한 예외
```

두 함수는 앞 계획서 Phase A에서 **비과세·중과 단일 소스**가 됐으므로, 여기만 고치면 양쪽에 반영된다.

### 3.3 ⑧ — 별도 의제 경로

비과세: `checkExemption`에 E-3.7 신설. 요건 = 2주택 + 수도권 밖 부득이 주택 보유 + **해소일부터 3년 이내**
+ §154① 충족(「§154①을 적용한다」이므로 앞 계획서 N7과 같은 구조).

중과: `deemedOneHouseBy155`가 아니라 **§167의10①4호**로 직접 배제한다(법문이 15호를 거치지 않는다).
2주택 전용 배제 블록에 추가.

🔶 **미확인 — 사유 미해소 상태의 양도**: 법문은 「해소된 날부터 3년 이내」로 기산점만 정한다.
해소 전 양도가 적용 대상인지 명문이 없다. **명문 부재를 불리하게 해석하지 않는다**
(memory `feedback_no_unfavorable_application_without_legal_basis`) → 해소일 **미입력 = 미해소**로
보아 기한 제한 없이 적용하고, 결과에 근거를 명시한다.

### 3.4 ⑦ — 농어촌주택 (가장 크다)

3유형 × 소재요건 × 유형별 추가요건. 귀농(3호)만 요건이 무겁다.

```
농어촌주택 성립 =
  소재: 수도권 밖 AND (읍(도시지역 제외) OR 면)
  AND 유형별:
    1호 상속   : 피상속인 취득 후 거주 ≥ 5년
    2호 이농   : 이농인 취득 후 거주 ≥ 5년
    3호 귀농   : 고가주택 아님(취득 당시) AND 대지 ≤ 660㎡ AND 세대전원 이사·거주
                 AND 일반주택 양도가 취득일부터 5년 이내 (⑦ 단서)
```

⑪(최초 1개 한정)·⑫(3년 사후관리)는 **엔진이 판정할 수 없다**(과거·미래 양도 이력).
→ 경고(`warnings`)로 노출하고 자기선언 입력에 맡긴다. 앞선 §156의2⑬ 추징 경고와 같은 패턴.
