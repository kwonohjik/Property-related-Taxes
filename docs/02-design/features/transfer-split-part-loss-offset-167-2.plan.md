# 토지·건물 분리 자산의 파트 양도차손 통산 — 「소득세법 시행령」 §167의2① (계획서 v0.2 — P1 구현)

> 작성 2026-10-19 · 워크트리 `Property-related-Taxes-splitloss` · 브랜치 `fix/split-part-loss-offset` (origin/master 4f9172372 위)
> 계기: PR #2272(구주택 멸실·신축 통산) 후퇴 사례 — 건물 파트 양도차손이면 토지 통산 기간이 세율에 닿지 않았다.

## 1. 결함

토지·건물 분리 계산(split) 자산은 파트마다 §104② 기산일로 세율을 정한다. 그런데 **한 파트라도 양도소득금액이 음수이면**
파트 판정을 포기하고 자산 전체를 **건물 기산일(자산 `acquisitionDate`) 세율 하나**로 계산한다.

- 위치: `lib/tax-engine/transfer-tax-split-part-seeds.ts:161-164` (게이트 6)
  ```ts
  // 6. 어느 파트든 결손이면 자산 내부에서 이미 통산된 뒤다 …
  if (seeds.some((s) => s.raw < 0)) return notJudged;
  ```
- 결과: 토지의 세율 기산일(상속·증여 통산, 구주택 멸실·신축 통산, 비주택 토지 장기 보유 등)이 버려지고, 토지 소득에 **건물의 단기세율**이 붙는다.

## 2. 법령 근거 (원문 확인 2026-10-19, KoreanLaw MCP)

- **「소득세법」 §102②** — 양도차손은 「해당 자산 외의 다른 자산에서 발생한 양도소득금액에서」 공제하고, 공제방법은 대통령령으로 정한다.
- **「소득세법 시행령」 §167의2①** (시행 2026.10.1. 본)
  > 양도차손은 다음 각호의 자산의 양도소득금액에서 순차로 공제한다.
  > 1. 양도차손이 발생한 자산과 같은 세율을 적용받는 자산의 양도소득금액
  > 2. 양도차손이 발생한 자산과 다른 세율을 적용받는 자산의 양도소득금액. 이 경우 다른 세율을 적용받는 자산의 양도소득금액이 2 이상인 경우에는 각 세율별 양도소득금액의 합계액에서 당해 양도소득금액이 차지하는 비율로 안분하여 공제한다.
- **「소득세법 시행령」 §167의2②** — 감면소득금액이 포함되어 있으면 순양도소득금액과 감면소득금액 비율로 안분해 공제한 것으로 본다.
- **조세심판원 국심2007중3718 (2008.3.13.)** 재결요지 — 「토지 및 건물등을 동일한 과세기간에 양도하여 각각 양도차익과 양도차손이 발생하는 경우 이를 통산하여 양도소득금액을 산정함이 타당」.
  저장소는 이미 이 재결로 비주택 split 다건 통산을 파트 단위로 한다(`transfer-tax-split-part-seeds.ts:117` `splitPartsForLossOffset`).
- 참고: 「소득세법」 §104⑤ 후단의 「각각을 별개의 자산으로 보아」는 **한 필지의 비사업용 토지와 그 외 토지**에 관한 것이다 — 토지·건물 별개 자산의 근거로 인용하지 않는다.

## 3. 수정 방향

게이트 6을 「후퇴」에서 「§167의2① 통산」으로 바꾼다.

1. 파트마다 「같은 세율」 키를 만든다 — 다건과 **같은 함수** `lossOffsetRateKey`, 세율 사실은 다건 차손 자산 규약(`transfer-tax-aggregate-asset-records.ts:99` `resolveRateFacts` — 차손이면 `calcTax(0)`)과 같게 한다.
2. 통산은 기존 코어 `offsetLossesCore`(`loss-offset-core.ts`)를 그대로 쓴다 — 1호(같은 세율) → 2호(다른 세율, 소득 비율 안분), 최대잉여법 배분.
3. 통산 후 파트 소득으로 기존 흐름(1차 세율 → 게이트 7 세율 동일 접기 → §103② 기본공제 배분 → §104⑤ 비교과세)을 그대로 탄다.
   - 차손 파트는 소득 0으로 남는다(파트 수 불변 — `partIncomeWeights`·표시층이 파트 수를 전제한다).
   - 자산 전체가 차손이면(Σ ≤ 0) 종전대로 후퇴(세액 0 — 바뀔 것 없음).
   - 불변식: Σ파트 소득 > 0이면 차손은 전액 흡수되어 `Σ통산 후 = Σ통산 전 = 자산 양도소득금액` — 기존 안분·잔액 흡수 로직이 그대로 성립한다.
4. 표시 — 산출세액 단계의 파트별 내역(`shortTermNote`)에 한 줄을 더한다: 「건물 양도차손 N을 토지 양도소득금액에서 공제(「소득세법 시행령」 §167의2①2호)」. 결과 4뷰는 이 문구를 이미 읽는다(확인 필요 — Do에서 4뷰 실측).
5. PR #2272 대체 고지 `LAND_REBUILD_NOT_APPLIED_NOTICE`의 「건물 파트 양도차손 등으로」 문구 — 차손은 더 이상 후퇴 사유가 아니므로 사유 문구를 남은 후퇴 사유(§155⑳ 특례 등)로 고친다.

## 5. 결정 필요

### Q-1 다건 신고에서 건물 차손을 어디서 먼저 공제하는가
- **A (자산 내부 먼저)** — 프로토타입 그대로. 단건 엔진이 자산 안에서 먼저 통산하고, 다건은 그 자산의 순소득만 다른 자산과 통산한다.
- **B (신고 전체 §167의2)** — 토지·건물을 다건 통산의 별개 자산 행으로 두어, 건물 차손이 **신고 전체의 같은 세율 자산**부터 공제된다.
  - 비주택 split은 이미 파트 행 구조가 있다(`splitPartsForLossOffset`) — 다만 차손 파트가 있으면 자산 한 행으로 빠진다(`:135`).
  - 주택 split은 파트를 다건 합산 단위로 남기지 않는다 — 구조 변경이 크다.
  - A와 B가 갈리는 입력: 같은 해에 건물 파트와 같은 세율(예: 주택 1년 미만 70%)의 다른 자산이 이익일 때. A는 차손이 자기 토지(기본세율)에서, B는 그 70% 자산에서 공제된다. 세액 차이는 B 미구현이라 **실측 전**이다.
- 권장: **P1 = A**(단건 정확 + 다건 자산 내부), **P2 = B**를 별건 계획. 단건은 A·B가 같다.
- ✅ **확정(2026-10-19 사용자)**: 이번 PR은 **A**, 머지 후 **B를 바로 이어서** 계획·구현한다.
