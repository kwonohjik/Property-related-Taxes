## 9. SCOPE_OUT 명시

UI에서도 SCOPE_OUT:
- 중견·일반 기업규모 계산 (Select 선택은 가능하나 거래비율차감 본문 미확보 → 경고 표시)
- 나목(일반) 1천억 초과 특수관계매출 추가 요건 입력
- 다단계 간접출자 (3단계 이상 — 현재 1단계만)
- 간접 2경로 정렬 입력

중소 이외 기업규모 선택 시 결과 뷰 경고 배너:
```
⚠️ 중견·일반 기업규모의 거래비율차감 법령 박스 미렌더로 인해 결과가 부정확할 수 있습니다.
   중소기업(50%)만 교재 사례로 확인됐습니다.
```

## 11. 3대 핵심 정책 자가 점검

1. **useEffect → store 미러링 금지**: `totalDirectPct`·`salesSum` 파생은 `useMemo` + validate. `useEffect` 내 `set()` 없음 확인.
2. **자동 안분 fallback 금지**: 매출처·주주 미입력 = R-4·R-6·R-7 오류 차단. 자동채움 없음.
3. **Validation 8번째 동기화**: UI display fallback(지분합 배지·매출합 배지) = API 변환(있는 그대로 전달) = validate(R-4·R-7) 3중 일치.
4. **타입 내로잉 존재 가드**: `DeemedGiftAnyResult` union에서 신규 optional 필드 접근 시 `result.type === "related_corp" && result.recipientBreakdown` 조합 필수. 단독 type 내로잉으로 TS2339 발생.
