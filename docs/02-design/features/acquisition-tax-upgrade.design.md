## 2. 갭 분석 — 문서 vs 현재 구현

### 2.1 ✅ 핵심 미구현 / 오류 (Critical)

#### G1. 사치성 재산 중과세율 공식 오류 (단독·중복 분기 분리)
**문서 근거**: 페이지 12, 19~20, 28
> "골프장·고급주택·고급오락장·고급선박의 취득세는 일반세율에 **중과기준세율의 100분의 400(=8%p)**을 합한 세율 (지법 §13⑤)"
> "고급주택은 ... 가격에 따라 9%, 10%, 11% 적용 (= 1%+8%, 2%+8%, 3%+8%)"
> "고급주택과 주택 중과세 중복: 주택중과 8%+8%=**16%** / 주택중과 12%+8%=**20%** (지법 §13⑥)"

**현재 구현 (`acquisition-tax-surcharge.ts:164`)**:
```ts
function getSurchargeRateForLuxury(basicRate: number): number {
  return basicRate * 5;  // ❌ 잘못됨 — 기본세율 × 5
}
```

**올바른 산식 — 케이스 분기 (지법 §13⑤·§13⑥·§13의2③)**:

| 케이스 | 산식 | 예시 |
|---|---|---|
| **단독 사치성** (§13⑤) | `기본세율 + 8%p` | 9억 초과 주택 매매 3% → **11%** |
| **사치성 + 다주택 중복** (§13의2③) | `다주택중과율(8% or 12%) + 8%p` | 조정 3주택 + 고급주택 → 12% + 8% = **20%** |
| **사치성 + 대도시 법인 중복** (§13⑥) | `표준세율 × 3 + 8%p` | 대도시 5년 이내 법인 + 사치성 토지 매매 → 12% + 8% = **20%** |

**예시 검산**:
- 토지 매매 일반: 4% → 사치성 단독: 4% + 8% = **12%**
- 9억 초과 주택 매매: 3% → 사치성 단독: 3% + 8% = **11%**
- 6억 이하 주택 매매: 1% → 사치성 단독: 1% + 8% = **9%**
- 6~9억 선형보간 8억 매매 2.333% → 사치성 단독: 2.333% + 8% = **10.333%**
- 조정 2주택 + 고급주택: 8% + 8% = **16%**
- 조정 3주택 + 고급주택: 12% + 8% = **20%**

(현재 코드: 4×5=20%, 3×5=15%, 1×5=5%, 2.333×5=11.665% — 모두 **틀림**)

**조문 근거**: 지방세법 §13⑤·§13⑥, §13의2③.
- §13⑤: "표준세율 + 중과기준세율(2%)의 100분의 400(=8%p)"
- §13⑥: 사치성 + §13① 본점/공장 중과 중복 시 가산
- §13의2③: 사치성 + §13의2① 다주택·법인 주택 중과 중복 시 §13의2① 세율에 8%p 가산

**별장 폐지**: 2023.3.14 이후 잔금일 케이스는 별장 중과 자체 미적용 (지법 부칙).

**영향**: 고급주택·골프장·고급오락장·고급선박 모두 세율이 5~9%p 잘못됨. 다주택 중복 시는 12%p 차이까지 발생. 실거래 1건당 세금 수억 원 차이 가능.

#### G2. 다주택 중과세 — 비조정대상지역 3주택+/4주택+ 누락 + 표준세율 베이스 명확화 (v3)
**조문 근거 (v3 정밀)**: 지방세법 §13의2① 본문 — "**제11조제1항제7호나목의 세율(=4%)을 표준세율로 하여**"
> "1호 (법인): 4% + 중과기준세율 × 400%(=8%p) = **12%**
> 2호 (조정 2주택 OR 비조정 3주택): 4% + 중과기준세율 × 200%(=4%p) = **8%**
> 3호 (조정 3주택+ OR 비조정 4주택+): 4% + 중과기준세율 × 400%(=8%p) = **12%**"

**핵심**: 다주택 중과 적용 대상이면 **가격 무관 표준세율 베이스가 항상 4%** (§11①8 1~3% 주택세율 베이스 아님).

**현재 구현 (`acquisition-tax-surcharge.ts:97~131`)**:
```ts
if (isHousing && input.isRegulatedArea && isOnerousForMultiHouse) {
  // 2주택→8%, 3주택+→12%만 처리. 비조정지역 3주택/4주택+ 분기 없음.
}
```

**누락**:
- 비조정지역 3주택 → 8% 중과 **미적용**
- 비조정지역 4주택+ → 12% 중과 **미적용**
- 무상취득(증여) 조정지역 시가표준액 3억 이상 → 12% 중과 **미적용** (현재 증여는 무조건 3.5%)
- (v3) 산식 표기 — 결과는 4%/8% 산식이지만 코드상 "기본세율 1%에서 가산" 표현 → 혼동 야기

#### G2-2. §13⑦ 사치성 + 대도시 법인 중복 분기 (v3 신규 발견)

#### G14. 중과 적용 단계 흐름도(Flow) 부재
**현재 결과 뷰**: 적용된 세율과 사유만 텍스트로 노출. "왜 이 세율인지" — 5단계 판단 흐름(§13①사치성 → §13의2법인 → 다주택 → 일시적 2주택 → 1억 이하 → 기본세율) **시각화 없음**.

#### G15. 조정대상지역 자동 조회 미연동
**문서 근거**: 양도세에서는 `regulated_areas` DB 테이블 + 시점 판정 사용.
**현재 구현**: 사용자가 직접 토글. 잔금일·등기일 입력해도 조정지역 자동 매칭 안 됨.

#### G16. 고급주택 + 다주택 중과 중복 적용 표시
**문서 근거**: 페이지 12 표
> "고급주택 + 주택중과(2020.8.12~) 중복: 8% + 8% = 16% 또는 12% + 8% = 20%"

**현재 구현**: 사치성 우선 분기로 다주택 중과 무시 → 결과적으로 잘못된 세율 산출.

#### G17. 신탁재산 중과세 (§13의2)
**문서 근거**: 페이지 12
> "신탁법에 따라 신탁된 주택은 위탁자의 주택 수에 가산. 수탁자가 취득한 신탁재산도 중과세 대상에 포함 (2020년~)."

**현재 구현**: 없음.

#### G18. 가격구간별 지방교육세 차등 (선형보간 시)
**문서 근거**: 페이지 11
> "지방교육세 = 취득세 × 50% × 20% = 6억 이하 0.1% / 6~9억 0.2~0.3% / 9억 초과 0.3%"

**현재 구현**: `calcLocalEducationTax`는 일률 `과세표준 × 0.4%` 적용. 주택 유상거래 시 **0.1%~0.3% 차등 미적용** → 6억 이하 주택 시 약 4배 과대계산.

```ts
// 현재: floor(taxBase * 0.02 * 0.20)  → 0.4% 일률
// 옳음 (주택 유상거래): floor(취득세본세 × 50% × 20%)
```

지법 §151의 "취득세액의 50%에 20% 적용" 공식이 주택 유상거래에는 직접 작동해야 함.

#### G20. 1세대 주택 수 — "취득일 현재" 기준 명시 (UX)
**문서 근거**: 지령 §28의4①
> "1세대의 주택 수 산정 시 ... 1세대가 국내에 소유하는 ... **주택 취득일 현재**의 세대별 주택 수를 산정한다."

**현재 구현**: Step 2에 "취득 후 보유 주택 수" 텍스트만 있고, 취득일 기준임이 명시 안 됨. 사용자가 "오늘 시점"으로 오해할 가능성.

**개선**: Step "주택 현황"에
- 취득일(잔금일/등기일) 자동 anchor 표시
- "이 날짜 기준으로 보유한 주택만 카운트하세요" 안내 banner
- 종전 처분 예정일 입력 시 일시적 2주택 자동 판정

#### G21. 농특세 비과세 — 국민주택규모 도시·지방 분기
**문서 근거**: 농특세법 §4(11), 주택법 §2⑥
> "농어촌특별세는 ... 국민주택규모 이하의 주거용 건물에 대한 취득세를 비과세한다."
> "국민주택규모: 주거전용면적 1호당 **85㎡** 이하 (수도권 외 도시지역 외 읍·면 지역은 **100㎡** 이하)"

**현재 구현 (`acquisition-tax-rate.ts:231`)**:
```ts
if (input.areaSqm <= ACQUISITION_CONST.RURAL_EXEMPT_AREA_SQM) // 85 하드코딩
```

**누락**: 수도권정비계획법 §2① 외 도시지역 외 읍·면 지역 100㎡ 분기 없음.

**개선**:
```ts
function isExemptByArea(areaSqm: number, isRuralRegion: boolean): boolean {
  return areaSqm <= (isRuralRegion ? 100 : 85);
}
```
→ 새 입력 `isRuralRegion?: boolean` (수도권정비계획법 §2①의 수도권 외 도시지역 외 읍·면 지역 여부) 추가.

#### G22. 비도시형 공장 중과 — 토지·건물 분리 적용
**문서 근거**: 페이지 29, 지법 §13①
> "공장 신·증설 → 표준세율 + 중과기준세율 × 200% = 표준세율 + 4%p"

**핵심**: 공장 부지 매매(토지)와 공장 건물 신축(원시취득)은 **세율이 다르므로 분리 계산**.
- 공장 토지 매매: 4% + 4%p = **8%**
- 공장 건물 신축: 2.8% + 4%p = **6.8%**

**현재 구현**: 없음 (G9에 통합).

**개선**: P2-2 `acquisition-corp-surcharge.ts`에서 토지·건물 분리 입력 + 분리 세율 산출.

#### G19. 농특세 사치성·다주택 중과 시 세율
**문서 근거**: 페이지 11
> "고급주택 농특세 = (표준세율 + 8%) × 10% = 1.0%"
> "다주택 8% 중과 농특세 = (표준세율 + 6%) × 10% = 0.6%"
> "다주택 12% 중과 농특세 = (표준세율 + 10%) × 10% = 1.0%"

**현재 구현**: `calcRuralSpecialTax`에서 `(appliedRate - 0.02) × taxBase × 10%` 적용 → **이론적으론 맞음**. 다만 사치성 세율 자체가 G1으로 잘못되어 결과 농특세도 잘못됨.
