# P4 — §98의2 + §98의4 엔진 설계

> 작성: 2026-06-12 · 법령: KoreanLaw 원문 — 법 §98의2·§98의4 (MST 286597) / 령 §98의2 (MST 286143)
> D-10 해소: 령 §98의2① "법 제98조의2제1항" 확정. §98의4는 위임령 없음 (법 단일 문장 — 매핑 표 정합).
> D-5 해소: 법 §98의2①1호 "표2에 따른 **보유기간별** 공제율" — 표2의 보유기간 열(연 4%, 3년 12%~10년+ 40%)만 적용, 거주기간 열 불포함. §95② "각 표 외의 부분 본문" 배제 — 단서(1세대1주택 표2 보유+거주)는 배제 대상 아님 → 1세대1주택 특례(보유+거주)가 적용되는 경우 그대로 유지 (항상 ≥ 표2 보유 단독), 그 외에는 표2 보유열 강제 (표1 2%/년 대비 항상 유리 — 무조건 override).

## 2. 구현 — 하이브리드 dispatcher 합류

- `UnsoldHybridResult.effectCategory` += `"lthd_rate_special"` (§98의2 — 감면액·차감액 0, 특칙 플래그 역할).
- **evaluateUnsold982**: 거주자(기본 true)·시한(취득일 or 계약일 — 둘 중 하나 기간 내)·`isNonCapitalUnsold982` 토글·`isFirstOrFcfsContract982` 토글(령①1·2호). eligible → effectCategory `lthd_rate_special`, rate echo 0 (감면 없음), ruralSurtaxExempt true(농특세 자체 미발생 의미).
- **evaluateUnsold984**: `isNonResidentNoPe984` 토글(미확인 시 NOT_NONRESIDENT — 거주자 차단)·시한·`isNotUnsold983House984` 토글. eligible → effectCategory **tax_amount 고정** (5년 무관), rate 0.1. 기준시가 불요.
- 라우터: `lthd_rate_special`은 appliedId 미설정 + eligibleId 설정 + 안내 step ("장특 표2·기본세율 특칙 적용 — 감면세액 없음").
- calcReductions: §98의4 tax_amount → 후보 `applyRate(calculatedTax, 0.1)`. §98의2는 후보 없음.
- finalize STEP 8.7: HYBRID_ARTICLE += unsold_98_4 (농특세 ×20%). §98의2 도달 불가.
- **중과 배제**: SURCHARGE_EXCLUDED += `unsold_98_2`만. **unsold_98_4 비추가** (5호 비열거 — anchor로 중과 적용 유지 검증).
- **단기세율 배제**: RATE_SPECIAL += `unsold_98_2` (법 ①2호). §98의4는 특칙 없음.
- **장특 표2 override (transfer-tax.ts STEP 4 직후)**: STEP 0.45 선판정(`surchargeExclusionByReduction.appliedId === "unsold_98_2"`) 신호로, `!isOneHouseSpecial`일 때 `deduction = applyRate(taxableGain, min(보유년 × 4%, 40%))` (3년 미만 0) 강제 + step 교체 주석. 표2 보유열은 항상 표1(2%/년·30%) 이상이므로 단순 override.
