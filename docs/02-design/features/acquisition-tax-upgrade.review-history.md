## 2. v4 외부 재검토 (M1~M5 + D1~D8 + V1~V3)

### 🔴 반박 — M1·M2 (법령 해석 오류 주장)

외부 검토자가 v4에서 "다주택 중과는 §13의2① '1천분의 120/80 직접 규정'이지 '베이스 4% + 가산'이 아니다"라고 주장했으나, **국가법령정보 시스템 직접 조회 원문**은 다음과 같음:

> "1. 법인이 주택을 취득하는 경우: **제11조제1항제7호나목의 세율을 표준세율로 하여** 해당 세율에 **중과기준세율의 100분의 400을 합한 세율**"

→ 법령 원문이 명백히 "**§11①7나(4%) 표준세율 + 중과기준세율 × N% 가산**" 구조 명시. 외부 검토자가 v2에서 안내한 "베이스 4%" 의견이 **정확했고**, v4에서 자기 의견을 부정한 것이 오히려 잘못. **우리 v3 산식 구조 유지 (정정 불필요)**.

다만 외부 검토자 우려(가독성·디버깅 측면)는 합리적 → **결과 매핑(12%/8%/12%) + 산식 분해 주석 병기**로 보강:
```ts
// 지방세법 §13의2① — 산식: §11①7나(4%) 표준세율 + 중과기준세율 × N%
// 결과 직접 매핑 (가독성 + 디버깅)
const SURCHARGE_RATES = {
  CORP: 0.12,           // 1호: 4% + 8%p (×400%) = 12%
  MULTI_HOUSE_8: 0.08,  // 2호: 4% + 4%p (×200%) = 8%
  MULTI_HOUSE_12: 0.12, // 3호: 4% + 8%p (×400%) = 12%
} as const;
```

§13의2②(무상취득 12%)도 동일 구조 — 외부 검토자 M2 주장도 같은 이유로 반박.

|---|---|---|---|

**현재 4단계** (Step 0/1/2/3 — 18 필드)

```

Step 1 — 물건 상세        │ 소재지·면적·시가표준액·전체주택시가·정비구역·수도권여부
```
