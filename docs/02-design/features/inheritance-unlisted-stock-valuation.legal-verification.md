|---|---|

> "1주당 ... '순손익가치'와 1주당 순자산가치를 **각각 3과 2의 비율**[부동산과다보유법인(「소득세법」 제94조제1항제4호다목에 해당하는 법인을 말한다)의 경우에는 1주당 순손익가치와 순자산가치의 비율을 **각각 2와 3**으로 한다]로 가중평균한 가액"

### 2-3. §55③ 영업권 가산 제외 사유 (계획서 보완)

영업권(§59②)을 순자산가액에 **가산하지 않는** 경우:
1. §54④ 1호(청산) 또는 3호(부동산 80%)
2. §54④ 2호(사업개시 3년 미만) — 단, 무체재산권 현물출자 + 사업 영위 + 합산 3년 이상이면 가산
3. **평가기준일 속하는 사업연도 전 3년 내 사업연도부터 계속 결손금이 있는 법인**

→ `goodwillIncluded` 자동 판정 로직 보강 필요. 사용자 토글이 아닌 §55③ 자동 분기:
```ts
function shouldIncludeGoodwill(input): boolean {
  if (netAssetOnlyReason === "liquidation") return false;       // §55③ 1호 (§54④1호)
  if (netAssetOnlyReason === "real_estate_80") return false;    // §55③ 1호 (§54④3호)
  if (netAssetOnlyReason === "lt3y") {                          // §55③ 2호 (§54④2호)
    if (isInfusionWithThreeYearTotal) return true;              // §55③ 2호 가·나목 단서
    return false;
  }
  if (isContinuousLossLastThreeYears) return false;             // §55③ 3호
  return true;
}
```

### 2-4. 사례 6 영업권 0원 검증 (계획서 U-13 anchor)

§55③ 3호 "평가기준일 속하는 사업연도 전 3년 이내 사업연도부터 **계속하여 결손금**이 있는 법인"에 해당 시 영업권 0원.

PDF 사례 6 (별지 양식 5쪽):
- 1년 전 (2023) 순손익액 76,842,660원 (양수)
- 2년 전 (2022) 순손익액 62,416,500원 (양수)
- 3년 전 (2021) 순손익액 △5,311,910원 (음수)

→ **계속 결손 아님** (1·2년 양수). 영업권 미배제 사유는 §55③ 3호가 아님.

영업권 = {3년 가중평균 × 50% − 자기자본 × 10%} × 5년 연금현가
- 가중평균 = (76,842,660×3 + 62,416,500×2 + (−5,311,910)×1) / 6 = 58,341,511
- 50% = 29,170,755
- 자기자본 × 10% = 489,351,700 × 10% = 48,935,170
- **초과이익금액 = 29,170,755 − 48,935,170 = △19,764,415 (음수)**
- 음수 → 영업권 = **0원** ✅

→ 사례 6 영업권 0원은 **초과이익금액이 음수**라서 0이며, §55③ 결손법인 배제가 아님. **U-13 anchor 사유 정정**.

### 2-5. PDF 사례 6 영업권 산식 변형 분석

PDF 별지 양식 5쪽 영업권:
- 가. 3년간 순손익액 가중평균 = 58,341,511
- 나. 가 × 50% = 29,170,755
- 다. 자기자본 = 489,351,700
- 라. 기재부령이 정하는 이자율 = 10% (= 상증규 §19①)
- 마. 다 × 라 = 48,935,170
- 바. 영업권 지속연수 = 5년
- 사. ∑[(나 − 마)/(1+0.1)^n] for n=1..5 = **0** (음수 → 0)
- 자. 영업권 평가액 (사 − 아) = **0**

→ 산식이 "[(가×50% − 다×10%) × 5년 연금현가(3.7908)]"이 아닌 **연도별 할인 합 ∑(나−마)/(1.1)^n**.

다만 (나−마)가 매년 같다면 ∑(상수)/(1.1)^n = 상수 × 3.7908 (연금현가). PDF 본 양식 명시 산식과 사례 1 〈해설〉의 약식(3.7908)은 등가.

★ **상증규 본칙은 §19①만 = 10%**, 5년 연금현가 3.7908은 본칙에 직접 명시되지 않고 §59② "기재부령이 정하는 방법"에 의한 평가심의위원회 운영규정 별지 부표3 **양식 본문 산식**으로 보임. → KoreanLaw MCP로 후속 검증 필요 (F-8).

### Critical 정정 4 — 환원율 본칙 위치 **분리**

| 산식 | 본칙 조문 | 값 | 1차 정정 메모 |
|---|---|---|---|
| 비상장주식 §54① 환원율 (가중평균 ÷ 환원율 → 1주당 순손익가치) | **상증규 §17** | 10% | 1차에서 "§19①"으로 통합 표기 → **분리**: §17이 §54① 전용 |
| 영업권 §59② 이자율 ("재정경제부령이 정하는 율") | **상증규 §19①** | 10% | 1차 정정 그대로 |
| 유상증자 순손익액 조정 (§56⑤·§17의3⑥ "재정경제부령이 정하는 율") | **상증규 §17** (= §17의3⑥에서 §17 준용) | 10% | §17 단일 본칙으로 통합 |

**상증규 §17 원문**:
> 영 제54조제1항의 계산식에서 "재정경제부령으로 정하는 이자율"이란 **연간 100분의 10**을 말한다.

**상증규 §17의3⑥ 원문**:
> 영 제56조제5항제1호 및 제2호에서 "재정경제부령으로 정하는 율"이란 **제17조에 따른 이자율**을 말한다.

→ 영업권(§19①)과 비상장주식(§17)은 **두 다른 조문**이나 둘 다 **10%**로 일치. 코드에서 `CAPITALIZATION_RATE` 단일 상수 사용 가능하되, 법령 인용 라벨은 분리:
```ts
export const VALUATION = {
  UNLISTED_RATE: "상증규 §17 (10%)",           // §54① 환원율
  GOODWILL_RATE: "상증규 §19① (10%)",          // §59② 이자율
  CAPITAL_INCREASE_RATE: "상증규 §17 (10%)",   // §56⑤ via §17의3⑥
};
```

### 보완 발견 — §55② 무형자산·준비금·충당금 평가 = **상증규 §17의2** (1차에서 누락)

상증령 §55② "재정경제부령이 정하는 무형고정자산·준비금·충당금등 기타 자산 및 부채의 평가" 위임 → **상증규 §17의2** 1~4호:

| 호 | 처리 | 항목 |
|---|---|---|
| 1호 | **자산 가산** | 평가기준일 현재 지급받을 권리가 확정된 가액 |
| 2호 | **자산 차감** | 선급비용(평가기준일 현재 비용 확정분) + 법인세령 §24①2호바목 무형자산 |
| 3호 | **부채 가산** | 가. 법인세·법인세 감면액·농특세·지방소득세 / 나. 평가기준일 현재 확정 배당금·상여금·지급의무 확정 금액 / 다. 재직 임원·사용인 전원 퇴직 시 퇴직급여 추계액 |
| 4호 | **부채 차감** | 평가기준일 현재 제충당금 + 조특법 등 제준비금. 단서: 4호 가(비용 확정 충당금)·나(보험사업 책임준비금·비상위험준비금)·다(보험회사 책임준비금·해약환급금준비금) 제외 |

→ 계획서 §4-1 `NetAssetCalculation` 모델 항목 추가 정정:
- 자산 ⑤·⑥ 매핑 명확화 (§17의2 1호·2호)
- 부채 ⑩~⑭ 매핑 (§17의2 3호 가·나·다)
- 부채 ⑯·⑰ 매핑 (§17의2 4호) — "(제외)" 표현 → "(부채에서 차감, 단 단서 가·나·다 제외)"
- 부채 신규: 보험사업 단서 가·나·다 (디자인 §2 `net-asset-calc.ts`에서 옵셔널 처리)

### 보완 발견 — 부동산과다보유법인 정의 (§54① 괄호 → 소법 §94①4호다목)

상증령 §54① 본문 괄호: "부동산과다보유법인(「소득세법」 제94조제1항제4호다목에 해당하는 법인을 말한다)"

**소법 §94①4호다목 원문**:
> 법인의 자산총액 중 다음의 합계액이 차지하는 비율이 **100분의 50 이상**인 법인의 과점주주가 그 법인의 주식등의 100분의 50 이상을 해당 과점주주 외의 자에게 양도하는 경우 ... 해당 주식등
> 1) 토지·건물 (§94①1호 자산)
> 2) 부동산권리 (§94①2호 자산)

→ §54① "부동산과다보유법인"은 **법인 정의만 인용** (양도 조건은 평가 시 적용 안 함). 즉:
- **부동산과다보유법인 = 자산총액 중 토지·건물·부동산권리(§94①1·2호) 합계 ≥ 50%인 법인**
- "과점주주가 50% 이상 양도" 조건은 양도소득세 기타자산 분류에만 사용 — 비상장주식 평가에는 불적용

→ 계획서 §4-1 `isRealEstateHeavy: boolean` 입력 토글 유지 가능. UI에서 자동 판정(자산총액 중 토지·건물·권리 비율 50% 이상 계산) 기능은 **후속 PR F-3**로 분리. 사용자 명시 토글이 우선.
