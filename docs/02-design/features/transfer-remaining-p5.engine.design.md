## 1. §98 (unsold_98) — 모드 1

| 요건 | 내용 |
|---|---|
| 주체 | 거주자 |
| 대상 | 미분양 국민주택 — 국민주택규모 이하 + **서울 밖** + 시장·군수·구청장이 1995.10.31(③: 1998.2.28) 현재 미분양 확인 + 주택건설사업자로부터 최초 분양 + 완공 후 타인 입주사실 없음 (민간·공공임대주택 제외 — 령①·⑤) |
| 시한 | ① 취득 1995.11.1~1997.12.31 / ③ 1998.3.1~1998.12.31 (각 시한 내 계약+계약금 포함) — 취득일 OR 계약일 어느 한 기간 내 (2-트랙 자동) |
| 보유·임대 | **5년 이상 보유·임대** 후 양도 — 보유 ≥ 5년은 일자로 검증 (§95④ 준용 — 상속 통산), 임대 사실은 확인 토글 |
| 효과 | **선택**: ①1호 양도세 — 세율 **20% 단일** (§104① 불구 — 누진·단기·중과 모두 대체) / ①2호 종합소득 합산 (범위 외 — UI 안내만) |
| 농특세 | 대상 아님 (감면 정의 밖 — 농특세법 §2①2호 특례세율 열거에 §98 없음, plan §2-1 D-2) |
| 중과 배제 | 소령 §167의3①**3호** (§97·§97의2·§98 감면 임대주택 — 5년 이상 임대 국민주택) — 5호 아닌 3호 경로. eligible 시 동일 isTaxSpecialExemption 주입 (legalBasis 3호 표기) |
| 모드 2 | 령②·⑥ — 미분양주택 외 다른 주택만 기준으로 §89①3호 |

구현: `effectCategory: "flat_rate_20"` 신설 → STEP 7에서 `forceFlatRate20` 주입 → calcTax 조기 분기 `applyRate(taxBase, 0.2)` (누진공제 0·중과/단기/NBL 비교 없음 — "§104①에도 불구하고"). LTHD는 일반 규칙 유지 (특칙 없음).

## 2. 모드 2 N-way — `specialHouseExclusions` (신규 폼-전역 입력)

7개 조문 ②항 + §98 령②·⑥ + §99② — 감면주택 보유 중 **다른 주택** 양도 시 §89①3호 적용에서 감면주택을 소유주택으로 보지 않음 (비과세 판정 주택수 제외 — 중과 주택수와 별개 R-D).

```ts
specialHouseExclusions?: {
  article: "unsold_98" | "unsold_98_2" | "unsold_98_3" | "unsold_98_5" | "unsold_98_6"
         | "unsold_98_7" | "unsold_98_8" | "unsold_99_2" | "new_99";
  houseAcquisitionDate?: Date;   // 감면주택 취득일 (시한 판정 — D-1' 패턴)
  houseContractDate?: Date;      // 감면주택 매매계약일 (계약 기준 조문)
  requirementsConfirmed: boolean; // 해당 조문 본 요건 충족 확인 (모드 1 evaluator 상세 판정은 자체 양도 시)
}[]
```

- 시한 표 (취득 OR 계약 어느 하나): §98 1995.11.1~1997.12.31/1998.3.1~12.31 · §98의2 2008.11.3~2010.12.31 · §98의3 2009.2.12~2010.2.11 · §98의5 2010.2.12~2011.4.30 · §98의6 ~2011.12.31 · §98의7 2012.9.24~12.31 · §98의8 2015.1.1~12.31 · §99의2 2013.4.1~12.31 · §99 1998.5.22~1999.12.31.
- **§99②만 양도시한**: 다른 주택을 **2007.12.31까지 양도**하는 경우만 — 현재 양도분은 사실상 부적격 (시한 검증으로 차단 + 사유).
- 적용: STEP 0.9에서 기존 §99의4/§98의9 제외(−1)와 합산 — `effectiveCount = max(count − hce − specialCount, 0)`. 복수 적격 전부 차감 (각 ②항 독립 — N개 감면주택 모두 제외).
- echo: `specialHouseExclusionDetail` (entries + excludedCount) + step.
