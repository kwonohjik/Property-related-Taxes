## 1. 측정 (V 레지스터)

**V-1 같은 취득일** — 현행과, 컴패니언 `residencePeriodMonths`를 직접 넣은 반사실. 거주 60개월 · 양도 2026-02-16(재개발·겸용은 2024-06-01).

|---|---|---|---|
| 조정 취득 10억 50/50 | 0(비과세) | 102,839,000 | 0 |
| 비조정 15억 50/50 | 19,013,500 | 37,493,500 | 19,013,500 |
| 재개발 완공 APT 20억 50/50 | 87,774,280 | 118,769,200 | 89,914,440 |
| 겸용 20억 50/50 | 대조 못 함(응답 형태가 달라 합계를 읽지 못함) | 117,647,036 | 96,640,214 |
| 다주택(세대 3주택) 15억 50/50 | 측정 안 함 | 402,831,000 | 402,831,000(영향 없음) |

- 재개발 APT의 반사실은 단건과 2,140,160 차이가 남는다. 차이의 원인은 재지 않았다(**확인 필요**).
- 겸용은 `mixedUse.residencePeriodYears`만 넣어서는 세액이 그대로이고(117,647,036), `residencePeriodMonths`를 넣으면 달라진다. 연수까지 함께 넣어도 96,640,214로 같다. 즉 **표2 판정은 이 한 줄이 정한다.**
- 겸용 컴패니언의 `mixedUse.residencePeriodYears`는 0으로 실린다. 이번 시료에서는 세액에 영향이 없었다. 값이 남아 있어도 되는지는 구현 때 확인한다.

## 2. 법 근거

| 근거 | 내용 | 이번 건에서의 의미 |
|---|---|---|
| 「소득세법 시행령」 §154① | 「1세대가 … 1주택을 보유 … 해당 주택의 보유기간 … 그 보유기간 중 거주기간이 2년 이상」 | 판정 단위는 1세대·해당 주택이다 |
| 같은 영 §154⑥ | 거주기간은 「주민등록표 등본에 따른 전입일부터 전출일까지」 | 사람의 거주 사실이라 지분별로 나뉘지 않는다 |
| 같은 영 §159의4 | 표2 대상도 「1세대 … 1주택 … 보유기간 중 거주기간이 2년 이상」 | 같은 구조다 |
| 법령해석과-2938(2021.8.26.) | 지분을 배우자에게 증여한 신축주택(70/30) — 「갑과 을이 … 1세대로서 거주한 기간을 통산」 | 지분별로 따로 세지 않는다 |
| 법규과-1660(2022.5.30.) | 이월과세 지분의 표2 보유·거주기간은 증여한 배우자 취득일 이후 기간으로 산정 | 기산일은 지분별로 다를 수 있다 |

- 조문은 KoreanLaw MCP로 현행(2026-10-01 시행) 본문을 확인했다. 해석례 2건은 국세법령정보 공개 페이지 본문을 읽었다.
- **동일인이 지분을 매매로 추가 취득한 경우의 거주 기산을 정면으로 다룬 해석례는 찾지 못했다.** 국세청 「지분 거주기간」 4건, 「지분 장기보유특별공제 거주기간」 1건, 「공동명의 거주기간」 1건, 조세심판 「지분 거주기간」 1건을 봤고 전수 조사는 아니다. 조세심판 1건(조심 2021전4671)은 제목상 상속주택 소수지분 건이고 본문은 읽지 않았다.
- 그래서 **같은 취득일은 법문으로 확정**, **다른 취득일의 상한은 「그 보유기간 중」을 지분 보유기간으로 읽은 판단**이다(Q-2).

## 3. 결정 요청 (Q 레지스터)

**Q-1 수정 범위 — 승인됨: a) 완전 지분 번들의 컴패니언에 한해 주 자산 거주기간을 상속한다.** b) 컴패니언 카드에 입력칸을 만든다(같은 사실을 다시 묻는다).
- 적용 대상: 일반 주택·재개발 APT·겸용 컴패니언(같은 줄을 지난다, V-1). 함께 양도는 제외.

**Q-2 취득일이 다른 지분의 상한** — **a) 그 지분의 보유기간으로 자른다(권장).** b) 상속하지 않고 0개월을 유지한다. c) 상한 없이 그대로 상속한다.
- a 근거: §154① 「그 보유기간 중」. #2771의 상한 규칙을 그대로 쓴다.
- b는 같은 주택에 산 사실을 지우고, c는 보유기간을 넘는 거주가 되어 #2771과 어긋난다.

**Q-3 취득일이 달라 거주기간이 잘렸거나 승계됐다는 안내** — **a) 주 자산 거주기간 입력칸에 「같은 주택의 다른 지분에도 적용합니다(그 지분의 보유기간까지)」 힌트를 한 줄 넣는다(권장).** b) 안내 없이 계산만 고친다.
- a 근거: 칸이 하나뿐이어서 사용자가 지분별 적용을 알 방법이 없다.

**Q-4 첫 지분이 더 늦게 취득된 경우의 입력 막힘(V-3)** — **a) 이번 범위에서 제외하고 기록한다(권장).** b) ⑧·⑫ 상한을 번들의 가장 이른 취득일 기준으로 넓힌다.
- a 근거: b는 입력 검증 규칙을 바꾸는 별도 판단이고 #2771 anchor와 맞닿는다. 지금도 먼저 취득한 지분을 자산 1로 입력하면 계산할 수 있다.
