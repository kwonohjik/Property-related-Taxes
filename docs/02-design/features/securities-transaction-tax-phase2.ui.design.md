## 2. 컴포넌트 변경 명세

### 2-1. `SecuritiesTransactionTaxCard.tsx` — 영세율 표시 1분기 추가

조건: `stx.appliedRateNum === 0 && stx.agriculturalTax > 0` (코스피 2025 구간 전용 — 기타자산 0은 `warning`만 있고 농특세 0이므로 미충돌). **result·inline 양 variant 공통** — 단일 카드 컴포넌트 내부 분기이므로 Step3 미리보기에도 자동 적용.

```
┌─ (sky 카드 — 기존 톤·배지 유지) ─────────────────────┐
│ 증권거래세 (정보용)   [양도소득세와 별도 납부]        │
│ 시행령 §5 (2025 — 코스피 영세율) + 농특세법 §5①5호   │
├──────────────────────────────────────────────────────┤
│ 증권거래세 — 영세율 적용 (시행령 §5 1호, 2025년)      │   ← 산식 행 대체 (×0.00% 표기 금지)
│ 농어촌특별세 (0.15%)                     150,000     │
│ ───────────────────────────────────────────────      │
│ 합계                                     150,000     │
└──────────────────────────────────────────────────────┘
```

- 일반 구간(num>0)은 Phase 1 레이아웃 그대로 — 산식 행 "양도가액 N × X.XX%" 유지(% 는 num/den 파생이라 연도 세율 자동 반영).
- 경고 슬롯(amber)·disclaimer — **변경 없음** (문구는 엔진 `warning`·`rateReference` 소관).
- 표현 중립: "영세율"은 법령 용어 그대로. "면제·절감" 표현 금지(memory `feedback_tax_calculation_principle`).
