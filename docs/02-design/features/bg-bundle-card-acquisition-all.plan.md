## 2. Pre-Do 실측 (2026-10-27 · 임시 변경 → 측정 → 복원, python 백업)

임시 변경 4가지(§4 D-1~D-4와 같다)를 넣고 측정했다.

### 2.1 표시값

- 일반건물 지분 7시료(§9.1 표): 7건 모두 명세 취득가액·개산공제 = 카드 합. 예: 감정가액 다름 290,000,000 · 환산 300,000,000 / 3,600,000 · 기준시가 120,000,000 / 3,600,000. 세액 불변(57,552,880 · 45,985,984 · 42,264,112 · 9,024,576 · 12,978,240 · 94,646,200).
- 같은 경로 상세명세서 산식이 맞는 등식이 된다(지분 명세를 읽는다):
  - 감정가액 같음 · 지분1 토지 「120,000,000 × 300,000,000 / 600,000,000 = 60,000,000」 · 지분2 토지 「80,000,000 × 200,000,000 / 400,000,000 = 40,000,000」.
  - 감정가액 다름 · 지분2 토지 「120,000,000 × 200,000,000 / 400,000,000 = 60,000,000」(지분2 자기 감정가액 3억 × 40%).
  - 개산공제 「60,000,000 × 300,000,000 / 600,000,000 × 0.03 = 900,000」.
- 함께 양도 6시료(§9.2 표): 6건 모두 명세 = 카드 합. 예: 실지 200,000,000 · 환산 153,750,000 · 혼합 200,000,000 / 개산공제 1,500,000. 카드별 행이 물건마다 자기 방식(실지·감정가액)으로 그려진다.

### 2.2 불변식 전수 (route 최종 응답 계측)

route의 두 묶음 반환(`calculateBundledTransfer` · 일반건물 지분)에 임시 계측을 넣고 부담부증여·묶음·결과 카드 관련 테스트 578파일(8,202건)을 돌렸다.

- 부담부증여 묶음 최종 응답 217건 중 카드별 명세 216건. **216건 모두 「카드별 신고서 취득가액 합(§166 카드는 `redevFilingAcquisition`, 그 밖은 §159 칸) = `aggregated.properties[].acquisitionPrice` 합」**.
- 카드가 안 생긴 1건: `axis-b-burdened-gift-high-value-g1-14.anchor.test.ts` — 명세 272,727,272인데 자산별 취득가액 합 0(§97②2호 단서 실비 택일로 취득가액 슬롯 0). 지분 결과 중 하나에 명세가 없어 가드가 물건 전체를 둔다. **변경 전에도 같다**(이 계획과 무관 — V-1).
- 개산공제 불일치 6건은 모두 §166 카드(재개발) — §159 개산공제 슬롯 0, 신고서 필요경비 1,020,419(§166 경로가 따로 계산). 카드별 행은 개산공제가 0이면 줄을 그리지 않고, 합계 문구가 「원조합원 지분은 인가 전 분」이라 거짓 줄은 없다(V-2).
- 계측 초기에 엔진 집계 안에서 비교했을 때 불일치가 보였던 것(토지 300,000,000 vs 50,000,000 · `a2` 1,000,000,000 vs 423,076,924)은 이월과세 A/B 반사실 실행의 **중간 집계**였다. 최종 응답은 카드 합과 같다(실측: 토지 50,000,000 · `a2` A 채택 63,461,538).

## 3. 사용자 결정 (2026-10-28: Q-1 a · Q-2 a)

### Q-1 발동 범위

- **(a) 부담부증여 묶음이면 언제나 카드별 (권장)**: 축 B(#2648)·일반건물 지분·함께 양도 모두 같은 규칙. 발동 조건(의제 카드·이월과세 A·축 B)을 없애 규칙이 하나가 된다. 기준시가 평가처럼 이미 맞던 묶음도 카드별 행으로 바뀌지만 합은 같다(§2.2 216/216).
- (b) 어긋나는 경우만(일반건물 지분 · 함께 양도 시가 평가): 화면 변화는 작지만 판정 술어가 늘고, 기준시가 평가 함께 양도는 물건 전체 한 줄로 남는다.

### Q-2 리뷰 게이트 G-1·G-2 해제

- **(a) 해제 (권장)**: §2.3의 이유로 두 전제가 사라진다. 측정상 카드 합 = 세액에 쓰인 값(216/216).
- (b) 유지: 함께 양도에 일반건물이나 재개발 자산이 섞이면 종전 물건 전체 값(첫 물건 기준)이 남는다.
