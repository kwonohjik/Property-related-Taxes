## 0. 근거 (원문 확인 2026-10-19)
- 「소득세법 시행령」 §167의2① — 양도차손은 1호 같은 세율 자산 → 2호 다른 세율 자산(세율별 소득 비율 안분) 순으로 공제.
- 조세심판원 국심2007중3718 — 같은 과세기간에 양도한 토지·건물의 양도차익과 양도차손은 통산한다(토지·건물을 각각의 자산으로 본다).
- 국세청 상속증여세과-209(2013.6.10.) — 비과세 자산의 양도차익·차손은 과세 자산과 통산하지 않는다(엔진 `loss-offset-core.ts` 헤더 인용).

## 2. 수정 방향 (프로토타입으로 확인한 것)

### 2.1 A1
- 비과세가 걸리지 않으면(`!(isExempt || isPartialExempt)`) 파트 차손을 그대로 둔다 → P1 파트 통산이 받는다. 장특공제는 세 파트 모두 음수를 0으로 본다(`transfer-tax-lthd.ts:446-447·490`) — 바꿀 것 없음.
- 전액 비과세면 종전대로 0(상속증여세과-209). 고가주택 일부 비과세는 **Q-1**.

### 2.2 B
1. `splitPartsForLossOffset` — 주택 split·차손 파트·배율 초과 파트도 파트 행으로 낸다. 차손 파트 세율 사실은 `calcTax(0)`(다건 차손 자산 규약).
2. `prepareSplitParts` — 다건이 넘긴 파트 통산 결과(`partIncomeWeights`)가 있으면 그 값이 정본: 자산 안에서 다시 통산하지 않고, 「자산 전체 차손」 판정도 그 값으로 한다.
3. `offsetLosses` — 같은 자산 안 파트끼리의 통산 행은 통산 표와 「받은 차손」(1호·2호 합계)에서 뺀다. 넣으면 §167의2② 감면소득 안분에서 이중 차감된다(실측: 단건 감면 8,665,000 vs 다건 7,352,352).
4. 감면 자산 + 차손 파트는 자산 한 행(A 유지) — **Q-2**.

### 2.3 프로토타입 회귀 (A1 + B, tax-engine·api·calc·components·lib 36,647건)
- 실패 4건 = 전부 SPCO-T9(파트별 이월과세 순서 의존 사례) — A1 절사 결함이 만들던 값이다(§3).

## 4. 결정 필요

### Q-1 고가주택(12억 초과 일부 비과세) + 배율 초과·나중 취득 부수토지 + 파트 차손
- 현행: 0으로 자른다. 정상 경로(배율 초과 없음)는 차손 파트를 안분하지 않고 그대로 둔다(`transfer-tax-taxable-gain.ts:115` `prorateNonNegative`) — 두 경로가 이미 다르다.
- 권장: **이번 범위 밖(현행 유지) + 확인 필요 기록**. 비과세분 차손의 통산 제한(상속증여세과-209)과 12억 안분의 관계를 다룬 해석례를 먼저 찾아야 한다.

### Q-2 감면 자산(세액감면형 §90①)에 차손 파트가 있을 때 B를 적용하는가
- 단건 감면소득(B)은 자산 안 통산 후 값이다. B로 파트 행을 펼치면 감면소득을 통산 전 파트 소득에서 다시 계산해야 한다(§167의2② — 2026-10 #90① 작업 영역).
- 권장: **이번엔 A 유지(자산 한 행) + 확인 필요 기록**.

### Q-3 표시 — 자기 차손을 다른 자산에 준 이익 자산
- B에서 자산 a(토지 +470,000,000 · 건물 −9,000,000)가 건물 차손을 b에 주면 a의 통산 후 소득(470,000,000)이 통산 전 자산 소득(461,000,000)보다 커진다. 결과 화면·신고서·상세명세서는 「통산 후 = 통산 전 − 받은 차손」을 전제로 그려져 있다.
- 권장: 통산 표 행에 파트를 싣는다(`fromPart: "building"` → 「[a 건물] → [b]」). 자산 산식은 「토지 470,000,000 + 건물 −9,000,000 = 461,000,000 · 건물 차손 중 9,000,000은 [b]에서 공제 → 통산 후 470,000,000」. 신고서 합산표 통산 행은 Do에서 실측 후 정한다.

## 4.1 ✅ 결정 (2026-10-19 사용자)
- **Q-1**: 「12억 초과분에 대한 양도차손은 12억 초과분에 대한 양도차익과 통산」 — **과세분만** 통산한다. 파트 차손도 양도차익과 같은 비율로 안분해
  과세분만 남기고, 비과세분 차손은 버린다. 배율 초과 경로와 **정상 경로(`prorateNonNegative`) 모두** 같은 규칙.
  - 정상 경로는 자산 합계를 이미 `prorate(토지 − 건물 차손)`으로 안분하고 있어, 파트 값만 맞춘다(Σ파트 = 자산 불변식 회복).
  - 전액 비과세 주택은 과세분이 0 — 종전과 같다.
  - 배율 초과 경로의 **토지** 차손 + 비과세(전액·일부)는 재산세제과-915 회신 산식(`highValueExcessLandTaxableGain`)과 얽혀 종전 0 유지 — 확인 필요로 남긴다.
- **Q-2**: 감면 자산 + 차손 파트는 다건에서 **A 유지**(자산 한 행).
- **Q-3**: **파트를 밝혀 표시** — 통산 표 「[a 건물] → [b]」, 자산 산식에 파트 소득과 넘겨준 차손.

- 재산세제과-915 원문(taxlaw 확인)은 이익만 전제한다(차손 언급 없음).
- 사전-2015-법령해석재산-0377은 서브에이전트 보고이고, 본문을 직접 확인하지 못했다.

**① 토지 차손 + 배율 초과**
- 배율 초과분 = floor(토지 차손 × 초과 비율)이다. 비사업용 토지라 비과세 대상이 아니므로 과세분 차손으로 그대로 둔다.
- 기준면적 이내분 = min(0, 안분(전체 토지) − 초과분)이다. 이익 경로의 915 틀을 부호만 대칭으로 쓰는 A안이다(`highValueExcessLandTaxableGain`).
- 실측(20억 · 토지 차손 2억): 초과 0㎡일 때 과세 양도차익 40,000,000이다. 초과 60㎡도 종전 120,000,000(세액 6,943,200)에서 40,000,000으로 바뀌어 같아졌다.
- 12억 이하(전액 비과세)이면 이내 토지·건물은 0이고, 초과분 차손만 남는다.

**§155⑳ 특례 경로**
- `splitAppurtenantExcess`가 토지 차손을 0으로 자르지 않는다.
- 초과분이 자산 양도차익 이상이어도 분리한다. 종전에는 분리를 포기해 비사업용 초과분까지 특례로 비과세했다(10억 · 건물 차손: on 0 / off 6,946,500 — 이번에 함께 발견).
- `resolveClause5TaxDetailed`는 한 파트가 차손이면 다른 파트에서 먼저 공제한다(§167의2①2호). 종전에는 이익 파트에 기본공제만 빼, 과세표준이 자산보다 컸다.

**④ 다건**

- 실측: 단건 on = off = 다건 1건 72셀 · 다른 자산과 함께 신고 on = off 132셀 · 입력 순서 무관.

## 10. 확인 필요 ② 해소 — 감면 자산도 파트 행으로 신고 전체 통산(B) (2026-10-20 사용자 「순서대로 진행」)

**근거**
- 국심2007전0147(본문 확인): 청구인은 함께 사서 함께 판 임야①에서 임야② 차손을 먼저 빼야 한다고 주장했으나 기각됐다.
- 심판원은 차손을 임야①과 감면 농지의 양도차익에 안분하고, 영 §167의2②로 감면소득을 줄인 처분을 정당하다고 봤다.
- 따라서 감면 자산에만 「자산 안 먼저(A)」를 둘 근거가 없다.

**종전 결함 2건** (그래서 Q-2 게이트로 막아 두었다)
1. 다건은 받은 차손을 「파트 통산 전 − 후」로 셌다. 그런데 단건 감면소득 B는 이미 자기 건물 차손을 자기 토지가 다 받은 뒤의 값이라, 자기 몫이 한 번 더 빠졌다(단건 8,665,000 / 다건 7,352,352).
2. 다른 자산에 넘긴 파트 차손을 B에 되돌리지 않았다.

**수정**
- `netLossOnReducibleUnit` = 단건이 B를 만든 소득 − 다건 통산 후 소득이다.
  - 단건이 B를 만든 소득은 자산 양도소득금액이다. 파트별 감면(5B `partWise`)이면 감면 파트 적격소득이다.
  - 양수면 B를 줄이고(종전 `lossShareOnReducible`), 음수면(넘긴 차손이 더 크다) 같은 비율로 늘린다(`reducibleShiftOf`). 조각 배분은 최대잉여법이다.
- 세액감면형 B′와 소득공제형(§99의3·§99·§98의8 등)이 같은 함수를 쓴다.
- Q-2 게이트를 삭제했다. 자산 1건이면 순차손이 0이라 단건과 같다.

**실측**
- §77, 토지만 2년 요건 충족: 건물 차손 1억이 같은 40% b로 간다(1호). 감면소득은 233,000,000 → 333,000,000, 결정세액은 95,634,000이다.
- §77, 두 파트 모두 충족: 건물 차손이 같은 누진 세율의 자기 토지와 b에 1호로 안분된다. 기본공제는 감면 없는 b가 먼저 흡수한다.
- §98의8: 단건 116,666,666이다. 건물 차손 28,571,429를 o에 넘기면 126,190,475가 된다.

**검증**
