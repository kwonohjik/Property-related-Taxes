# 비상장주식 평가 — 다른 비상장법인 주식 소유 시 평가방법 (상호출자 연립방정식 포함)

> 작업 계획서 (PLAN)
> 브랜치: `feat/unlisted-cross-holding` · 워크트리: `.claude/worktrees/unlisted-cross-holding`

> 작성일: 2026-06-26

## 1. 배경 · 목적

평가대상 비상장법인 A가 **다른 비상장법인 B(·C)의 주식을 자산으로 보유**한 경우, A의 1주당 가액을
산정하려면 그 보유 주식 B를 먼저 평가해 A의 순자산가액(자산총액)에 반영해야 한다.
보유비율·상호출자 여부에 따라 평가방법이 3갈래로 갈린다.

이번 작업은 교재 6절의 **(1) 10% 이하 / (2) 10% 초과(비상호) / (2)② 상호출자 연립방정식** 3분기를
엔진·UI로 구현하고, 교재 워크드 예제 3건(사례 Ⅰ·Ⅱ·Ⅲ)을 1원 단위로 재현하는 것을 목표로 한다.

**경계·예외 (설계 시 별도 처리)**
- 🔴 **10% 경계 (E2)**: 사례 Ⅱ에서 B는 A를 **정확히 10%**(5,000/50,000) 보유하나 상호출자 연립방정식이
  적용된다. 즉 **상호출자 + 일방이 10% 초과**이면 양방향 모두 연립방정식 보충평가로 간주되는 것으로 보인다
  (방향별 10% 판정이 아니라 **관계 단위** 판정). 준칙 §60②의 정확한 발동 요건은 **확인 필요** —
  Pre-Do에서 규명 후 분기 조건 동결.
- **다단계 중첩 깊이 = 1 (M3)**: 피출자법인(B)이 또 다른 비상장주식을 보유하는 다단계는 본 작업 scope-out.
  B 평가 시 그 하위 보유분은 장부가액/기존 입력으로 처리(추가 연립 미전개). 상호출자(A↔B)는 깊이 1의 순환.
- C5/C6의 최종 자산반영도 **Max(장부가액, 보충적평가가액)** 적용 (사례 Ⅱ·Ⅲ의 ⑭ 단계 참조).
- 할증평가: 사례 Ⅰ은 최대주주 할증 30%를 연립방정식 **계수(1.3)에 내장**. 단, §53⑧4호로
  **1차 출자·보유분은 할증 제외** → 어느 단계에 1.3을 곱하고 어느 단계는 제외하는지 정밀 분기 필요.
- 부동산과다보유법인 여부 → 가중치 (2α+3ρ)/5 ↔ (3α+2ρ)/5 전환 (기존 `isRealEstateHeavy` 재사용).
- 순자산가액 0 이하 §55① 0 처리, 1주당 순손익 음수 가드 — 기존 로직 적용.

## 4. 핵심 수식 (교재 일반식)

### 4.1 기본형
1주당가액 = (2α + 3ρ) / 5  (일반법인) — α: 1주당 순자산가치, ρ: 1주당 순손익가치
부동산과다: (3α + 2ρ) / 5

### 4.2 N법인 상호출자 연립방정식 (교재 A·B·C 3원 일반식)
```
A: (2α+3ρ₁)/5 = [ 2 × { P₁ + (b·(2β+3ρ₂)/5 + c·(2γ+3ρ₃)/5) − d₁ } / η₁ + 3ρ₁ ] ÷ 5
B: (2β+3ρ₂)/5 = [ 2 × { P₂ + (a·(2α+3ρ₁)/5 + c·(2γ+3ρ₃)/5) − d₂ } / η₂ + 3ρ₂ ] ÷ 5
C: (2γ+3ρ₃)/5 = [ 2 × { P₃ + (a·(2α+3ρ₁)/5 + b·(2β+3ρ₂)/5) − d₃ } / η₃ + 3ρ₃ ] ÷ 5
```
- **Pᵢ**: i법인이 소유한 다른 법인 주식가액을 **제외한** 자산총액
- **a,b,c**: 각 법인이 보유한 다른 법인 주식수 (a=A주식수, b=B주식수, c=C주식수)
- **dᵢ**: 부채총계 · **ηᵢ**: 발행주식 총수 · **αβγ**: 1주당 순자산가치 · **ρᵢ**: 1주당 순손익가치

> 미지수는 αᵢ뿐(ρᵢ는 상수). 위 식은 αᵢ에 대한 **선형 연립방정식** → 행렬 `M·α = k` 닫힌해.
> 사례 Ⅰ은 ρ=0(순자산가치만 사례)이고 할증 1.3이 b·a 항에 곱해진 변형.

   - N법인 선형 연립방정식 빌더 + 닫힌해(가우스 소거 or 2x2 직접해). 순수 함수.
   - 할증 계수(1.3) 적용 위치는 §53⑧4호 분기에 따라 파라미터화. ρ=0 degenerate(사례 Ⅰ)도 일반해로 자연처리.
   - 🔴 **정수 연산 (L2 — Critical)**: 연립 닫힌해는 분수·역행렬 → 분자 곱셈이 2^53 초과 가능
     (`feedback_safemul_decimal_apportion_precision`·`bigint-round-half-up`). **BigInt 유리수 연산으로
     αᵢ 산출 후 최종 1주당가액에서 `Math.floor` 1회 절사**. 교재 절사 시점(각 1주당가액 반올림 여부)은
     사례 Ⅱ·Ⅲ anchor로 동결 — 교재가 중간 반올림하면 1원 tolerance 정책 적용.
2. **C2 자산반영 완성**: `evaluateOtherUnlistedHoldings` 결과를 순자산 자산총액에 가산하는 경로 추가
   (현행 "참고용 메타" → 실제 반영). 3중 패턴(display/API/validate) 준수.
3. **C4 Max 분기**: 보충적평가가액 vs 장부가액 max 헬퍼.
4. **입력 타입 확장**: `OtherUnlistedHolding`에 `evaluationMethod`(시가/취득가액/보충적/상호출자) +
   상호출자 상대법인 재무 입력 그룹 추가. 보유비율 자동판정(10% 경계)으로 분기 표시.
5. **순환참조 방지**: 비상호(C4)는 피출자법인을 1회 평가(2α+3ρ)/5로 종결 — 자기 주식가 미참조.
   상호(C5/C6)만 연립방정식.
