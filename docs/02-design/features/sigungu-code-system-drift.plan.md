## 1. 발단

`W-2` 시·군·구 인접 매트릭스를 생성하다 Vworld가 반환하는 시도코드에 **`12`(전남광주통합특별시)**가
있고 구 광주 `29`·전남 `46`은 **하나도 없다**는 것을 발견했다. 프로덕션 주소검색이 주는 PNU도 같다.

## 2. 검증된 사실

### 2.1 통합 시행일 — **2026-07-01**

「전남광주통합특별시 설치를 위한 특별법」 (법령ID 015064 · MST 286591)
— 공포 **2026-06-02** · 시행 **2026-07-01**. 법제처 실측 2026-08-01.

⇒ 시행된 지 한 달이며, 외부 API는 이미 전환을 마쳤다.

### 2.2 프로젝트에 코드 체계가 **셋** 섞여 있다

| 소스 | 광주 | 전남 | 전북 | 강원 | 광역시 | 건수 |
|---|---|---|---|---|---|---|
| **Vworld `LT_C_ADSIGG_INFO` · 프로덕션 PNU** (현행) | `12` 통합 | `12` | `52` | `51` | 26~31 | 256 |
| `data/regulated-areas.ts` · `data/population-decline-areas.ts` | **`29`** | **`46`** | `52` | `51` | 현행 | 부분 |
| `lib/korean-law/sigungu-codes.ts` | **`24`** | **`46`** | **`45`** | **`42`** | **21~26** | **154** |

`sigungu-codes.ts`는 **10개 시도가 불일치**한다(부산·대구·인천·광주·대전·울산·세종·강원·전북·전남).
서울·경기·충북·충남·경북·경남·제주만 일치. 게다가 전국 250여 개 중 **154개만** 담고 있다
(`lib/calc/address-sigungu-name.ts:4` 주석이 이미 「일부만 담고 있어」라고 인정).

> ⚠️ 시도코드 `26`이 **양쪽에 있으나 의미가 다르다**(구=울산 / 현행=부산). 실측 결과 실제 겹치는
> 하위 코드는 없어 **오매칭은 발생하지 않았고 전부 조회 실패**로 떨어졌다 —
> 우연이며, 코드가 늘면 오매칭으로 바뀔 수 있다.

**실측** — 현행 PNU로 `lookupSigungu()` 조회:

```
26410(부산 금정) ❌   26260(부산 동래) ❌   12210(통합 동구) ❌
46890(구 전남 완도) ❌  12850(현행 완도) ❌   51760(강원 평창) ❌   52110(전북 전주완산) ❌
```

### D-3 🔶 NBL 재촌 「연접 시·군·구」 판정 실패 — 영향 미측정

`form-mapper.ts:85`가 `lookupSigungu(landSigunguCode)?.adjacentCodes`로 연접 목록을 만든다.
10개 시도에서 조회가 실패해 `undefined` → 연접 판정(§153③**2호**)이 비활성된다.

다만 재촌은 3단계다(`non-business-land/residence.ts:51-70`):

| 호 | 판정 | 드리프트 영향 |
|---|---|---|
| 1호 동일 시·군·구 | 코드 일치 비교 | ⚪ **영향 없음** — 거주지·토지 코드가 같은 소스(주소검색)라 함께 이동 |
| 2호 **연접** | `adjacentCodes` 조회 | 🔴 **실패** |
| 3호 직선거리 30km | 좌표 haversine | ⚪ 좌표가 있으면 정상 |

⇒ **좌표가 있으면 연접 시·군·구는 대개 30km 안이라 3호로 흡수**될 가능성이 높다.
좌표가 없고 코드만 있는 입력에서만 재촌이 부정되어 비사업용 판정 → 과다과세.
🔶 **발현 조합·세액 미측정** — 수정 착수 전 probe 필요.

## 5. 설계 쟁점 — 단순 치환은 **틀린다**

### 5.1 구 코드를 신 코드로 바꾸기만 하면 안 되는 이유

양도세는 **과거 양도**를 다룬다(경정청구 5년 · 수정신고). 2021년 광주 양도를 지금 계산하면:

- 주소검색은 **항상 현행 `12xxx`**를 준다 (과거 시점 주소검색이라는 것은 없다)
- 조정지역 이력은 **그 시점 광주광역시**에 대한 것

⇒ 판정 집합이 `12xxx`만 알면 **저장된 이력·수동 입력의 구 코드**가 깨지고,
`29xxx`만 알면 지금 조회한 주소가 깨진다. **양쪽을 다 인식해야 한다.**

### 5.2 방향 — 코드 정규화 레이어 (권장)

```
lib/geo/sigungu-code-alias.ts  (신규)
  normalizeSigunguCode(code) → 현행 대표 코드
  expandSigunguAliases(code)  → [현행, 구] 전부
```

각 판정 집합은 조회 시 `expandSigunguAliases`를 거치게 한다 — 데이터 파일을 **건드리지 않고**
양쪽 코드를 모두 인식시킬 수 있다(회귀 표면 최소).

### 5.3 `sigungu-codes.ts`는 별칭으로 못 고친다 — **재생성**

10개 시도가 구 체계이고 154개뿐이라 별칭 몇 개로 메울 수 없다.
다행히 **W-2에서 만든 자산으로 재생성이 가능하다**:

- 좌표·이름: `.legal-cache/adsigg-raw.json` (Vworld 256건)
- 인접: `lib/geo/administrative-district-adjacency.json` (654 관계)
- 스크립트: `scripts/build-sigungu-adjacency.ts` 확장

단 NBL은 **5자리계**이고 매트릭스는 10자리계다 — 변환 지점을 명시해야 한다.
