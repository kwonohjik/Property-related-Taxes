### ★★ 정밀도 상한 — 실측 확정

표본 전부 **`mainPurpsCd` 뒷 3자리 = "000"**(세부용도 미특정). 즉 **표제부 주용도는 별표1 대분류까지만** 준다(예: 은마아파트도 "아파트"가 아닌 `02000 공동주택`).

→ 별표1·국세청 분류 축 차이(§X)가 **실데이터로 확증**됨. 표제부 단독으로는:
- **구조**: high — `strctCd` 코드 직매핑.
- **용도 대분류 직결 항목**(공동주택·업무·운수·종교·의료 등): high.
- **근생 내부 세분(목욕장 #37~39 / 의원·학원 모두 #41), 판매 세분(#9/#10/#11), 숙박 등급(#3/#4)**: 표제부 한계 → 대분류 fallback.

### 표제부 한계 회피책 (실데이터 기반)

1. **공동주택 #1 vs #2 → `grndFlrCnt`로 derive**: 별표1 정의(아파트=5개층 이상 / 연립·다세대=4개층 이하) 그대로. 은마(14층)→아파트→#1. ✅ 표제부만으로 해결.
2. **`etcPurps`(복수 용도 텍스트)**: 복합건물 부수용도 파악 보조(예 코엑스 "판매시설, 위락시설, 업무시설, 운동시설"). 주용도 판정은 `mainPurpsCd` 우선.
3. **세부 정밀 필요 시 → 전유부(`getBrExposInfo`)·층별개요(`getBrFlrOulnInfo`) 후속 검토**: 호별 세부용도 코드 제공 여부 확인 대상(특히 목욕장·근생 상가).
4. **잔여 fallback**: 위로도 안 되는 세분(호텔 등급 등) → 잠정값 + "확인 필요" 배지 → 사용자 확정.

1. **세부용도(§B) 우선 → 대분류(§A) fallback**: 대장 `mainPurpsCdNm`을 §B 룩업 → 미스 시 대분류 §A.
2. **면적 의존(★) 셀**: 대장 `totArea`로 자동 구간 판정(목욕장·상점·체육관). 자동 적용 가능.
3. **등급/정보 부족 셀(관광호텔 등급 등)**: 자동값 잠정 세팅 + UI에 "확인 필요" 배지 → 사용자 확정.
4. **확인 필요/미대응(교정·군사·도시형생활주택 등)**: 자동채움 안 함 → 기존 수동 드롭다운 유지.
5. **신뢰도 라벨**: 자동값에 `confidence: high|medium`(세부 직접매핑=high, 대분류 fallback·★=medium) 부여, medium은 사용자 확인 유도.

## D. 확정 전 잔여 작업 (검증 비중順)

1. **KoreanLaw — 건축법 시행령 별표1 본문 검증** (★ 최우선): 세부용도 정식 명칭·소속 대분류 확정. 특히 의원(#27 vs #41), 단란주점/고시원 소속, 도시형생활주택 분류.
2. **국세청 고시 본문 대조**: 교정·군사·공공업무 등 미대응 셀 처리 확인. (`usage-index.ts` 주석의 별표1 인용과 교차)
3. **활용신청 후 실 API 표본 수집**: 대장 `mainPurpsCdNm` 실제 문자열 표기(띄어쓰기·괄호) → §B 키 정규화 룩업 확정. 표본 ≥20건(주택·근생·업무·공장 혼합).
4. **과거 스킴 매핑**: 2017 이하 평가 자동화 시 scheme-59/2014/… 별도 매핑표(본 초안은 scheme-60 전용).
