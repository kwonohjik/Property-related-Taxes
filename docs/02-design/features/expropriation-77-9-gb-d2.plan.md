## 1. 실측 (route probe · 화면 입력 형식 → `callTransferTaxAPI` 본문 → `POST /api/calc/transfer` · 세율 mock)

공통: 수용(`transferCause: public_expropriation`) · 사업인정고시일 2025-06-01(소급 2년 = 2023-06-01) · 양도 2026-06-30 · 양도가액 12억 · 전액 현금 보상. 상속개시일 2024-01-10(고시일 소급 2년 안 — 상속개시일로 판정하면 불성립).

### 1.1 일반건물 (V-1)

| 입력 | 피상속인 취득일 | 감면액(합계) | 결정세액(합계) |
|---|---|---|---|
| G1 토지·건물 상속(분리 OFF) | 2000-01-01 / 2010-01-01 | 25,958,999 | 147,101,001 |
| G1 | 2023-12-01 (소급 2년 안) | **0** | 173,060,000 |
| G2 분리 ON · 토지 매매 2008 · 건물 상속 — 건물 피상속인 취득일 | 2000-01-01 / 2010-01-01 | 26,775,345 | 151,726,963 |
| G2 | 2023-12-01 | **22,872,499** (건물분 빠짐) | 155,629,809 |

- G1은 토지 카드의 피상속인 취득일, G2는 「건물 피상속인 취득일」 칸이 §77① 「2년 이전 취득」 판정을 바꾼다.
- 이로써 #2906이 공용 안내(일반건물 토지 카드에도 뜬다)에 쓴 「수용 감면의 취득일(조특법 §77⑨)」이 일반건물에서도 맞음을 확인했다.

### 1.2 D2 — 주택 · 건물 상속 · 토지 매매 2010 (V-2)

| 건물 피상속인 취득일 | 감면액 | 결정세액 | 비고 |
|---|---|---|---|
| 2000-01-01 | 18,759,000 | 106,301,000 | 토지·건물 모두 성립 |
| 2023-12-01 | 13,913,960 | 111,146,040 | 건물분 제외(`partWise.eligiblePart: "land"`) |

화면 입력 → ④가 `decedentAcquisitionDate`로 싣고 → ⑫ 통과 → 엔진 건물 파트가 이 날로 판정한다. #2911 안내(§77⑨)와 맞다.

### 1.3 D-1 — 일반건물 · 분리 ON · 토지 상속 2024-01-10 · 건물 매매 2008-01-01

| 피상속인 취득일(토지) | ⑧ | 서버 | 법상 |
|---|---|---|---|
| 2000-01-01 | 통과 | 200 · 감면 26,702,653 | 정상 |
| 2010-01-01 | **「피상속인 취득일은 상속개시일보다 이전이어야 합니다.」** | **400** 같은 칸 | 정상 입력(2010 < 상속개시일 2024-01-10) |
| 2023-12-01 | **막힘** | **400** | 정상 입력 |

원인(코드):
- ⑧ `getAssetDateOrderIssue`(`lib/calc/transfer-tax-validate-asset.ts`)와 ⑫(`lib/api/transfer-tax-schema-refines.ts` 상속 분기)가 `decedentAcquisitionDate`를 **`acquisitionDate`와 비교**한다.
- 일반건물 분리 ON에서 `acquisitionDate`는 **건물** 취득일이다(요청 본문 실측: `acquisitionDate: 2008-01-01` · `landAcquisitionDate: 2024-01-10`). 토지 카드의 상속개시일 칸은 `landAcquisitionDate`에 쓴다(`GeneralBuildingAcquisitionCards.tsx` — `fieldAcquisitionDate={isSeparate ? "landAcquisitionDate" : "acquisitionDate"}`).
- 그래서 건물 취득일 ≤ 피상속인 취득일 < 토지 상속개시일인 정상 입력이 막힌다. 반대로 토지 상속개시일 ≤ 피상속인 취득일 < 건물 취득일(건물을 나중에 취득)인 **틀린** 입력은 통과한다(재지 않음 — 같은 비교식에서 나오는 추론 · 확인 필요).
- 고칠 길이 없다: 피상속인 취득일을 2008 이전으로 거짓 입력해야 통과하는데, 그러면 §104②1호 세율 기간과 §77⑨ 판정이 바뀐다.
- 빈도: 토지 소유자(피상속인)가 상속인이 건물을 취득한 뒤에 토지를 취득한 경우뿐이다. 드물다.
