## 3. 감면 적용 판정

### 3.1 §99의3 감면 요건 — 모두 충족

1. **거주자일 것** ✓ (갑氏 거주자)
2. **신축주택 취득기간 내 취득** ✓ (분양계약 2001.5.24, 시기 2001.5.23~2002.12.31 서울·과천·5대 신도시 지역, 고가주택 제외 요건)
3. **주택건설업자로부터 신축주택 최초 매매계약 + 계약금 납부** ✓
4. **감면배제 주택 아닐 것** ✓ (고가주택 판정 필요 — 분양계약일 2001.5.24 기준 고급주택 = 전용 165㎡ 이상 AND 양도가 6억 초과. 본 사례는 전용 138㎡로 면적 미달 → 고급주택 배제)

### 3.2 다주택 중과세 배제

갑氏 2주택자 + 조정대상지역 X. **조특법 §99의3 적용 시 중과세 배제** (양도세 신고서 "주택수 및 과세특례" = "해당없음").

### 3.3 5년 경과 후 양도 — 안분 산식 적용

취득일 2003-09-23, 양도일 2023-02-16 → 5년 경과 후 양도. 5년간 발생 양도소득금액만 감면.

```
감면소득금액 = 양도소득금액 × (5년 시점 기준시가 - 취득시 기준시가) / (양도시 기준시가 - 취득시 기준시가)
```

**부호별 처리** (PDF 표):

| 분자 | 분모 | 감면소득금액 |
|---|---|---|
| 양수(+) | 양수(+) | 5년간 발생 양도소득금액에 대해서만 감면 |
| 음수(-) | 양수(+) | 0 (부동산-136, 2012.3.6.) |

## 5. 핵심 산식 검증 메모

### 5.1 5년 안분 산식

```
감면소득금액 = 415,118,683 × (5년시점 기준시가 - 취득시 기준시가) / (양도시 기준시가 - 취득시 기준시가)
            = 179,917,278

→ 비율 = 179,917,278 / 415,118,683 = 0.4334...
```

### 5.2 PHD 환산 필요 — 취득시 기준시가

취득(2003-09-23)이 최초고시(2004-04-30) 이전이므로, §164⑤ 공동주택 PHD 환산으로 취득시 기준시가 산출 필요. 본 anchor 사례는 PHD 환산을 통과한 후 §99의3 감면 산식 적용 — **두 모듈 통합 테스트** 시나리오.

### 5.3 고가주택 (분양계약일 기준)

분양계약일 2001-05-24 → 적용 기준일 2002.12.31 이전 → **고급주택 정의** (전용면적 165㎡ 이상 AND 양도가 6억 초과). 본 사례 전용면적 138.2㎡ → 면적 미달 → 고급주택 아님 → 감면 적용 가능.

> 적용기준일별 고급/고가주택 정의 표 (PDF):
> - ~2002.9.30: 면적 165㎡ 이상 AND 양도가 6억 초과 (고급주택)
> - 2002.10.1~2002.12.31: 면적 149㎡ 이상 AND 양도가 6억 초과 (고급주택)
> - 2003.1.1~ : 양도가 9억 초과 (2008.10.6 이전 6억 초과) (고가주택)
> - 2021.12.8~ : 양도가 12억 초과 (고가주택)
