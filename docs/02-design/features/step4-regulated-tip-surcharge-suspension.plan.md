# Step4 조정대상지역 팁 — 다주택 중과 한시배제 미반영 수정 계획서

작성: 2026-07-23 · 상태: **Do 완료** (rev.3) · rev.2 (자가검토 반영 — E1 ToneCard·E2 변수명·V1 §167의10 원문·V2 E2E 실측)

> **rev.3 Do 환류 (중요)**: **B1은 이미 현행 코드가 처리 중이었음** — `surchargeSuspended === true`이면

## 1. 증상 (사용자 보고)

Step4 "양도일 기준 조정대상지역" 토글 ON 시 표시되는 팁:

> ⚠️ 양도일 현재 조정대상지역 — 조정대상지역 주택 양도는 중과세 적용 여부를 검토하세요.

**중과 한시배제 기간 내 양도인 경우에도 무조건 "중과세 검토" 경고**가 떠서 혼선 유발. 배제 기간이면 중과 자체가 적용되지 않으므로(일반세율) 경고가 오히려 오해를 낳는다.

## 2. 법령 근거 (KoreanLaw 원문 실측 — 2026-07-23)

현행 소득세법 시행령 §167의3①**12의2** (공포 2026-05-22 · 시행 2026-07-01, MST 286211 조회):

> 법 제95조제4항에 따른 보유기간이 2년 … 이상인 주택으로서 다음 각 목의 어느 하나에 해당하는 주택
> **가. 2026년 5월 9일까지 양도하는 주택**
> **나.** 토지거래허가 대상 주택부수토지 정착 주택 — 2026.5.9까지 허가 신청 + 허가 + 매매계약·계약금 확인 + 계약체결일부터 4개월(표 지역 6개월) 이내 양도(5.10 이후 계약은 2026.9.9/11.9까지)
> **다.** 토지거래허가 비대상 — 2026.5.9까지 매매계약·계약금 확인 + 계약체결일부터 4개월(표 지역 6개월) 이내 양도

- **⚠️ 사용자 보고의 "2026.5.29"는 원문과 불일치** — 가목 기한은 **2026.5.9**. 계획·문구 모두 원문 기준(5.9) 채택.
- 2주택 중과 §167의10①12의2도 **원문 조회로 나·다목 포함 동일 구조 확인**(rev.2 V1 — 추정 아님).
- **나·다목은 2026-05-22 공포 신설 경과조치** — 현행 엔진(`multi-house-surcharge-exclusion.ts`)은 가목(양도일 윈도우 + 보유 2년, :326~330)과 2025-10-16 신규지정 계약 경과조치(:86~99)만 구현. **나·다목(계약·허가 기반 4·6개월 연장) 미구현** → §7 별건 기록.
