## 0. 요약 — 무엇이 없는가

「소득세법」 §104의3①4호**나목**은 「지방세법」 §106①**2호**(별도합산) 또는 **3호**(분리과세) 대상 토지를 비사업용에서 제외한다. 공장용 건축물의 부속토지는 이 두 경로 중 하나로 들어가는데, **양쪽 모두 면적 한도가 있다**. 한도 초과분은 잔여 규정인 §106①1호(**종합합산**)로 떨어져 **비사업용**이 된다.

현행 엔진은 이 한도를 **전혀 적용하지 않는다**. 사용자가 재산세 유형을 "분리과세" 또는 "별도합산"으로 고르면 면적과 무관하게 **전량 사업용**으로 통과한다(`lib/tax-engine/non-business-land/other-land.ts:302`).

이 계획은 그 한도를 넣는다.

## 1. 법령 근거 (KoreanLaw 실측 — 2026-08-05 조회)

### 1.1 위임 체인

```
「소득세법」 §104의3①4호나목  (비사업용 제외 = 사업용)
   └→ 「지방세법」 §106①2호 (별도합산)  →  「지방세법 시행령」 §101①1호
   │        한도 = 공장용 건축물 바닥면적 × §101② 용도지역별 적용배율
   │        적용 지역: 특별시·광역시(군 제외)·특별자치시·특별자치도·시지역
   │                  ─ 단, 읍·면지역 / 산업단지 / 공업지역은 제외
   │
   └→ 「지방세법」 §106①3호가목 (분리과세) → 「지방세법 시행령」 §102①1호
            한도 = 「지방세법 시행규칙」 §50 → **별표 6** 공장입지기준면적
            적용 지역: §101①1호 각 목의 지역 = 읍·면지역 / 산업단지 / 공업지역
```

**두 경로는 지역으로 배타 분기한다.** 같은 공장이라도 소재 지역에 따라 한도 산식이 완전히 달라진다.

- 「소득세법」 MST 280405 (시행 2026-07-01) §104의3①4호나목 원문:
  > 나. 「지방세법」 제106조제1항제2호 및 제3호에 따른 재산세 별도합산과세대상 또는 분리과세대상이 되는 토지

- 「지방세법 시행령」 MST 287223 (시행 2026-07-01) §101①1호 원문:
  > 1. 특별시ㆍ광역시(군 지역은 제외한다)ㆍ특별자치시ㆍ특별자치도 및 시지역(다음 각 목의 어느 하나에 해당하는 지역은 제외한다)의 공장용 건축물의 부속토지로서 공장용 건축물의 바닥면적(건축물 외의 시설의 경우에는 그 수평투영면적을 말한다)에 제2항에 따른 용도지역별 적용배율을 곱하여 산정한 범위의 토지
  > 　가. 읍ㆍ면지역
  > 　나. 「산업입지 및 개발에 관한 법률」에 따라 지정된 산업단지
  > 　다. 「국토의 계획 및 이용에 관한 법률」에 따라 지정된 공업지역

- 같은 영 §102①1호 원문:
  > 1. 공장용지: 제101조제1항제1호 각 목에서 정하는 지역에 있는 공장용 건축물(제103조제1항제2호 및 제3호의 건축물을 포함한다)의 부속토지로서 행정안전부령으로 정하는 공장입지기준면적 범위의 토지. 다만, 「건축법」 등 관계 법령에 따라 허가 등을 받아야 하는 건축물로서 허가 등을 받지 않은 공장용 건축물이나 사용승인을 받아야 하는 건축물로서 사용승인(임시사용승인을 포함한다)을 받지 않고 사용 중인 공장용 건축물의 부속토지는 제외한다.

> ⚠️ **군 지역 처리** — §101①1호 본문은 "광역시(군 지역은 제외)"라 하고 각 목 가에서 "읍·면지역"을 뺀다. 「지방자치법」상 군은 읍·면으로 구성되므로 군 지역 공장은 가목에 해당해 §102①1호(분리과세) 경로로 간다고 **해석**된다. **이 해석은 조문 대조에 의한 것이고 예규·판례로 확인하지 않았다 — Phase 0에서 확인 필요.**

### 1.2 공장입지기준면적 산식 — 「지방세법 시행규칙」 별표 6 (개정 2025.10.31, 실측)

```
                       100
공장입지기준면적 = 공장건축물 연면적 × ─────────────
                    업종별 기준공장면적률
```

**2. 산출기준**

| 항 | 내용 |
|---|---|
| 가 | **공장건축물 연면적** = 공장 경계구역 안 모든 공장용 건축물 연면적(부대시설 포함, **무허가·위법시공 건축물 제외**) + 옥외 기계장치·저장시설의 **수평투영면적** |
| 나 | **업종별 기준공장면적률** = 「산업집적활성화 및 공장설립에 관한 법률」 §8에 따라 산업통상부장관이 고시하는 값 |
| 다 | 2개 이상 업종이면 **업종별로 산출해 합산**. 업종 구분 불가 시 **매출액 최대 업종**의 면적률 적용 |

**3. 추가 인정기준 (초과분이라도 기준면적에 포함)**

| 목 | 내용 |
|---|---|
| 가1 | 「산집법」 §20① 본문 공장 신설 **제한지역** 소재 공장: 산출면적의 **10% 이내**(단, **3,000㎡ 초과분 제외**) |
| 가2 | 그 밖의 지역: 산출면적의 **20% 이내** |
| 나 | 도시관리계획상 녹지지역, 활주로, 철로, **6m 이상 도로**, 접도구역 |
| 다 | 생산공정 특성상 대규모 저수지·침전지 |
| 라 | 경사도 **30도 이상** 사면용지 |
| 마 | 공장 가동 오염피해 인접토지를 소유자 요구로 취득한 경우 → 합산해 기준면적 산정 |
| 바 | 종업원용 체육시설용지(기준면적표 별도 · **공장입지기준면적의 10% 이내**) |

> 바목 체육시설 기준면적표는 종업원 수 구간(100/500/2,000/10,000명)별 운동장·코트·실내시설 수치를 별도로 갖는다. 비고 라: **실내체육시설은 기준면적 × §101② 용도지역별 적용배율**을 합산.

### 1.3 기준공장면적률 데이터 — 「공장입지 기준고시」 별표1 (산업통상부, 공포 20260225)

- 행정규칙일련번호 `2100000274928`. §3① → 별표1이 KSIC 세세분류(5자리)별 면적률(%).
- **실측(절단본)**: 50,000자 응답 안에서 **303행** 추출됨(KSIC `10111`~`26211`). 값 분포는 `{3, 5, 7, 10, 12, 15, 20}` %.
- §4: **지식산업센터는 40%** 고정.
- ⚠️ **전체 행 수 미확인** — API 응답이 50,000자에서 절단되었다. 제조업 세세분류 전체를 받으려면 분할 조회가 필요하다(Phase 0-2).

> ⚠️ **고시의 산식은 별표6과 방향이 반대다.** 고시 §3②는 `기준공장건축면적 = 공장부지면적 × 기준공장면적률`(면적률을 **곱한다**)이고, 별표6은 `공장입지기준면적 = 연면적 × 100 ÷ 면적률`(**나눈다**)이다. 서로 역함수 관계이며 **모수도 다르다** — 고시는 "공장건축**면적**"(각 층 바닥면적 합계 + 옥외 수평투영), 별표6은 "공장건축물 **연면적**". 두 값은 대체로 같지만 별표6은 무허가·위법시공분을 명시 배제한다. **세법 계산에는 별표6 산식만 쓴다.**

### 1.4 단서 — 허가·사용승인 미이행

§102①1호 단서와 §101① 단서는 같은 취지다. **선행 작업에서 이미 확인**했다 — 법제처 법령해석례 **25-0823**(2026.02.03)은 "허가 등"이 「건축법」 §11 신축 허가에 한정되지 않고 **§19② 용도변경 허가 미이행**도 포함한다고 회답했다. 기존 `isUnregistered` 필드 의미가 이미 그렇게 확장되어 있다(`lib/tax-engine/types/commercial-appurtenant.types.ts:46-52`).

## 4. 설계안

### 4.1 방향 — `other_land` 안의 신규 스텝 (권장)

`LandType`에 `factory_site`를 신설하지 **않는다**. 이유:

1. 「소득세법」상 공장용지는 §104의3①**4호**(농지·임야·목장용지 **외의** 토지)로, 현행 `other_land`가 담당하는 바로 그 호다. 별도 `LandType`을 만들면 §168의11①(다목) 호별 면적기준·수입금액비율 등 **4호 공통 로직을 통째로 복제**해야 한다.
2. 이미 §101①2호나목 carve-out이 `other_land` 안에서 부분 안분을 하고 있다(`other-land.ts:499`). 같은 층위다.
3. `LandType` 신설은 `getLandCategoryGroup`·`land-category.ts`·PDF 지목 분류까지 파급된다 — 기존 별건 **A-BS-1**(`building_site`가 주택 배율을 쓰는 문제)과 얽힌다.

⇒ `OtherLandUsage`에 **`factory?: FactoryLandUsage`** 를 추가하고, `judgeOtherLand` 안에 **Step 0.5 "공장 기준면적 한도"** 를 넣는다.

### 4.2 진입 위치

```
Step 0     나대지 간주 (2% / 무건축물)
Step 0.5   ★ 신규 — 공장 기준면적 한도            ← 여기
Step 3-1   비종합합산 + 기간기준 → 전량 사업용
Step 3-1-1 §168의11① 호별 기준면적
Step 3-2   §101①2호나목 바닥면적 carve-out
```

**Step 3-1보다 앞**이어야 한다. Step 3-1이 `propertyTaxType !== "comprehensive"`만 보고 `buildPass`로 조기 반환하기 때문이다(`other-land.ts:302-315`).

Step 0.5의 출력:
- 한도 이내 → 아무것도 하지 않고 통과(Step 3-1이 기존대로 처리)
- 초과 → `computeAreaProportioning(landArea, allowedArea)`로 부분 비사업용 반환
- 단서 해당 → `effectiveTaxType`을 `"comprehensive"`로 강등(전량 비사업용 경로로 합류)

### 4.3 지역 분기 입력

`FactoryLandUsage.locationCategory: "eup_myeon_or_complex" | "urban_other"`

- `"eup_myeon_or_complex"` → §102①1호, 별표6 산식
- `"urban_other"` → §101①1호, `judgeAppurtenantLandExcess()` 재사용

> 지역 자동판정은 하지 않는다. 산업단지·공업지역 지정 여부는 현행 입력(`zoneType`)만으로 결정되지 않고(공업지역은 `zoneType`으로 알 수 있으나 산업단지·읍면은 알 수 없다), 자동 안분 fallback 금지 원칙에 따라 **미입력은 검증 오류로 차단**한다.

### 4.4 기준공장면적률 입력 — Phase 0에서 결정할 것

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| ㉮ | 사용자가 **면적률(%)** 직접 입력 | 데이터 유지보수 0. 고시 개정 무관 | 사용자가 별표1을 찾아야 함 |
| ㉯ | KSIC 세세분류 **데이터셋 내장** + 선택 UI | 입력 부담 최소 | ~500행 데이터 + 고시 개정 추적 필요 |
| ㉰ | 사용자가 **공장입지기준면적(㎡)** 자체 입력 (재산세 현행 방식) | 최소 구현 | 별표6 산식이 구현되지 않음 = 이 기능의 핵심이 빠짐 |

**잠정 권고: ㉮ + 지식산업센터 40% 프리셋.** ㉯는 별표1 전체 확보(Phase 0-2)와 개정 추적 체계가 선행되어야 하고, 이 계획의 핵심(초과분 중과)과는 독립적으로 나중에 얹을 수 있다. ㉰는 산식 미구현이라 기능 목적에 미달한다.

> ⚠️ **미확정 — 사용자 결정 필요.** ㉯를 택하면 Phase가 1개 늘고 데이터 검증 작업이 추가된다.

### 4.5 별표6 3호 추가 인정기준 — Phase 0에서 범위 결정

가1·가2(10%/20% 가산)는 **산식이 명확하고 파급이 작다** → 포함 권고.
나~바(녹지·활주로·철로·도로·접도구역 / 저수지 / 사면용지 / 오염피해 인접 / 종업원 체육시설)는 **각각 별도 면적 입력**이 필요하다 → 단순 가산 면적 1칸(`additionalRecognizedArea`)으로 받고 근거를 사용자가 판단하게 할지, 항목별로 나눌지 결정 필요.

> 마목(오염피해 인접토지)은 NBL에 **이미 유사 입력이 있다** — `unconditional-exemption.ts:126` `isFactoryAdjacent`(§168의14③5호). **다른 조문이므로 혼동 금지**: §168의14는 그 인접토지 자체를 무조건 사업용으로 보는 규정이고, 별표6 마목은 공장입지기준면적 **산정 시 합산**하는 규정이다. Phase 0에서 상호작용 확인 필요.

## 8. 범위 밖 (기록만)

- **재산세 §102①1호 산식 미구현** — `factoryStandardArea` 직접입력 유지(§2.2). Phase A 헬퍼 완성 후 별건으로 전환 검토.

- **「지방세법 시행규칙」 별표6 3호 바목 체육시설 기준면적표** — 종업원 수 구간별 표. 0-4 결과에 따라 포함/제외.
