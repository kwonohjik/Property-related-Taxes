# 승계조합원 완공 아파트 — 취득가액 추계(감정가액·매매사례가액·환산취득가액) 지원

> **출처**: `redev-successor-bg-acq-method.plan.md` Q-2 — 그때 (a) 「실거래가 전용」으로 닫았고, (b) 「추계(나목) 지원」을 후속으로 남겼다. 남은 V-2(개산공제 「취득 당시 기준시가」 시점)도 이 문서에서 다룬다.
> **깊이**: L3 — 엔진 승계 분기 · ④⑤⑧⑫ · 결과 산식. 지금 화면에서는 추계를 고를 수 없어 조용히 틀리는 세액은 없다. API 직접 호출 한 경로(1.1 S1)만 개산공제가 빠진다.

## 0. 결론

1. **화면**: 승계조합원 완공 APT는 「취득가액 산정 방식」 라디오가 없다. 실거래가 칸 하나뿐이다(#2582 · anchor `__tests__/calc/redev-successor-apt-actual-only-render.anchor.test.tsx`). 계약서를 잃은 사람은 계산할 수 없다.
2. **API**: 감정가액 방식을 직접 보내면 200이 나온다. 하지만 엔진 승계 분기가 산정 방식을 읽지 않아 **개산공제(§163⑥)가 빠진다**(S1 — 양도차익 470,000,000 · 일반 주택이라면 461,000,000). 매매사례·환산은 ⑫가 400으로 막는다(S2·S3).
3. **법령**: 승계조합원 신축주택의 취득일은 사용승인일이다(소령 §162①4호 · 사전-2021-법령해석재산-1236 · 서면4팀-2072 · 조심2020서7932). 추계 기준일(§176의2③ 「취득일 전후 각 3개월」)과 환산·개산공제의 「취득 당시 기준시가」도 **사용승인일**이 된다. 승계조합원 추계를 직접 다룬 해석은 찾지 못했다(2.2). 인접 해석 2건(재산세제과-702 · 서면법규과-448)은 조특법 감면 계산의 「취득 당시 기준시가」를 같은 방향(신축주택 취득 당시)으로 봤다.
4. **권장**: Q-1 (a) 3종 모두 지원. 계산은 「취득일 = 사용승인일인 일반 주택」과 같다(대조 H1~H3 값이 목표치). Q-2 (a) §114의2 가산세는 적용하지 않고 결과에 「확인 필요」를 고지한다. Q-3 (a) 사용승인일 당시 공동주택가격이 없으면 직접 입력과 §164⑦ 환산 도우미 중 고른다. (→ 구현 중 (b)로 재결정 — §4 결정)
5. **작업량**: 결정 후 구현 약 1일. 엔진 승계 분기 1곳 + ④⑤⑧⑫ + 결과 산식 + anchor·E2E.

## 2. 법령

### 2.1 확인한 본문 (KoreanLaw MCP · 2026-11-06)

- 소득세법 §97①1호 나목 — 실지거래가액을 확인할 수 없으면 매매사례가액·감정가액·환산취득가액.
- 소득세법 시행령 §176의2③ — 1호 매매사례가액 · 2호 감정가액(「양도일 또는 취득일 전후 각 3개월 이내」) · 3호 환산취득가액을 순서대로 적용한다. ②2호의 환산식은 「양도당시의 실지거래가액 × 취득당시의 기준시가 / 양도당시의 기준시가」이다. ②2호 후단은 「개별주택가격 및 공동주택가격이 최초로 공시되기 이전에 취득한 주택」의 취득당시 기준시가를 **§164⑦로 계산**한다고 정한다.
- 소득세법 시행령 §162①4호 — 자기가 건설한 건축물의 취득시기는 사용승인서 교부일이다(사실상 사용·임시사용승인이 먼저면 그날).
- 소득세법 시행령 §164⑦ — 공시 전 취득 주택의 취득당시 기준시가 = 최초 공시 주택가격 × (취득당시 토지·건물 기준시가 합계 / 최초 공시당시 토지·건물 기준시가 합계).
- 소득세법 §114의2① — 「거주자가 건물을 **신축** 또는 증축하고 그 건물의 취득일 … 부터 5년 이내에 해당 건물을 양도하는 경우로서 … 감정가액 또는 환산취득가액을 그 취득가액으로 하는 경우」 감정가액·환산취득가액의 5%를 결정세액에 더한다.

## 3. 설계 (Q-1 a 기준)

1. **엔진** — 승계 분기의 취득가액·필요경비를 산정 방식별로 구한다. 실거래가는 지금과 같다(취득가액 − 인가 후 필요경비). 감정·매매사례·환산은 그 값을 취득가액으로 쓰고, 필요경비는 개산공제 = 취득시 기준시가 × §163⑥ 비율(지분 축소는 `computeEstimatedDeduction`)이다. 인가 후 필요경비는 빼지 않는다(§163⑥ — 추계면 개산공제만). 환산은 §97②2호 단서(가목 < 나목이면 나목)도 일반 경로와 같은 함수를 쓴다. 중복 구현을 피하려고 `calcTransferGain`의 추계 부분을 leaf로 꺼내 두 경로가 함께 쓴다.
2. **④** — `isRedevSuccessorAptActualOnly`가 막던 추계 플래그를 싣는다(주 자산 `primaryAcquisitionModeFlags` · 컴패니언 payload 같은 leaf). 술어 이름·뜻이 바뀐다(「실거래가 전용」 → 「승계 APT」). 부담부증여는 제외한다 — 그쪽은 `bgAcquisitionMethod`가 따로 있다(V-4).
3. **⑤** — 승계 APT에 산정 방식 라디오를 다시 보인다. 칸 안내: 「승계조합원 신축주택의 취득일은 사용승인일입니다(소득세법 시행령 §162①4호). 감정가액·매매사례가액은 사용승인일 전후 3개월, 취득 당시 기준시가는 사용승인일 당시 값입니다.」 「지원하지 않는 분기」 목록에서 「추계 3종」 줄을 지운다.
4. **⑧ · ⑫** — 일반 주택의 추계 검증을 그대로 탄다(승계 예외 삭제). ⑫는 승계 APT의 `acquisitionPrice > 0` 요구를 실거래가 방식으로 좁힌다.
5. **결과·사이드바** — 승계 분기 결과 카드에 개산공제 행과 산정 방식 이름을 보인다. 사이드바 `isLumpSumMode`(`transfer-per-asset-summary-helpers.ts:54-56`)의 승계 예외를 지운다.

## 4. 결정 게이트

### Q-1 지원 범위

- (a) **감정가액·매매사례가액·환산취득가액 3종 모두**(권장) — 법문이 사용승인일로 연결된다(2.2). 목표치는 대조 H1~H3이다. S1(API 개산공제 누락)도 함께 고쳐진다.
- (b) 감정가액·매매사례가액만 — 환산은 계속 막는다. 환산에 필요한 「사용승인일 당시 공동주택가격」은 대개 아직 공시되지 않아 §164⑦ 계산이 필요하다(Q-3). 그 부담을 피한다. 대신 계약서가 없고 감정도 없는 사람은 여전히 계산할 수 없다.
- (c) 현행 유지(실거래가 전용) — ⑫가 승계 APT의 `appraisal`·`salesCase` 방식을 거부하도록 고쳐 S1만 막는다. 문서만 남긴다.

### Q-2 §114의2 가산세 (사용승인일부터 5년 안에 감정가액·환산취득가액으로 양도)

- (a) **적용하지 않는다 + 결과 화면에 「확인 필요」 고지**(권장) — 법문은 「거주자가 건물을 신축」이다. 승계조합원은 조합이 지은 건물을 받는다. §162①4호는 취득시기 규정일 뿐이고, 가산세 요건까지 넓힌다는 해석은 찾지 못했다. 법 근거 없이 불리하게 적용하지 않는다(MEMORY `feedback_no_unfavorable_application_without_legal_basis`). 원조합원 §166 경로도 지금 §114의2를 적용하지 않는다 — 같은 축이다.
- (b) 적용한다 — 사용승인일부터 5년 안의 감정·환산 양도에 5%를 더한다. 해석이 없는 상태에서 세액을 늘린다.
- (c) 5년 안의 감정·환산은 사유 문구로 막는다 — 계산할 수 없는 사람이 다시 생긴다.

### Q-3 「취득 당시 기준시가」 칸 (사용승인일 당시 공동주택가격이 아직 없는 경우)

- (a) **직접 입력 + §164⑦ 환산 도우미를 보인다**(권장) — 일반 주택 카드에 이미 있는 도우미(`PhdConvertedPriceFill` · 「환산 공동주택가격」)를 승계 APT에도 연다. 자동 안분 fallback은 쓰지 않는다 — 미입력은 ⑧이 막는다.
- (b) 직접 입력만 — 안내 문구로 §164⑦을 알려 준다. 작업이 작지만 사용자가 계산을 직접 해야 한다.

### 결정 (2026-11-06)

- **Q-1 = (a)** — 매매 승계 완공 APT(부담부증여 아님)는 추계 3종을 계산한다.
- **Q-2 = (a)** — §114의2는 더하지 않고 결과에 「확인 필요」를 고지한다.
- **Q-3 = (b)** — 구현 중 재결정(처음 (a) → (b)). §164⑦ 도우미는 ① 기본정보의 「토지 면적」 칸과 취득일(입주권 취득일)을 읽는데, 재개발 APT 카드에는 그 칸이 없고 기준일도 사용승인일로 바꿔 읽어야 했다. 계획서 (a)의 「이미 있는 도우미를 연다」는 실측 전 추정이었다(정정). 안내 문구로 §164⑦ 산식을 알린다. 도우미는 별건으로 남긴다(§8 V-7).
